##10.章节前一致性检查清单

在开始写每章之前，执行以下检查：

### 时间连续性
- [ ] 上一章结束的时间点是？
- [ ] 本章开始的时间点是？
- [ ] 如果有时间跳跃，装备/状态是否同步更新？

### 空间合理性
- [ ] 上一章结束时各角色的位置？
- [ ] 本章开始时各角色的位置？
- [ ]位置转移是否合理（有足够时间/交通方式）？

###状态延续性
- [ ] 上一章有角色受伤吗？伤势应该如何？
- [ ] 上一章有物件被使用/损坏吗？状态应该如何？
- [ ] 上一章有情绪爆发吗？余波应该如何？

### 信息一致性
- [ ] 本章需要提及哪些已有设定？
- [ ] 已查询登记簿确认这些设定的正确值？

##11.章节后自检步骤

在完成每章创作后，执行以下自检：

### 新设定登记
- [ ] 本章是否引入了新的时间点？→登记
- [ ] 本章是否引入了新的数值/规则？→登记
- [ ] 本章是否引入了新的角色属性？→登记
- [ ] 本章是否有物件状态变化？→更新登记

###一致性扫描
- [ ]全文搜索本章中的所有数字/日期
- [ ]逐一与登记簿比对：
- [ ] 日期格式一致？（2024 vs24年）
- [ ]数值准确？（天数、距离等）
- [ ]名称一致？（角色名、地名）

###能力/规则使用检查
- [ ] 本章中超自然能力的使用是否符合已定义的规则？
- [ ] 是否无意中扩展或修改了能力的边界？

###跨章节一致性
- [ ] 如果本章提及了之前章节的事件，描述是否一致？
- [ ]角色对过去事件的回忆是否与原文吻合？
