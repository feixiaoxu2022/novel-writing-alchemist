# 《古城秘事》写作日志

##2025-01-16

###今日进度
- **完成章节**：第一章《遗物》（约4100字）
- **场景数量**：3个（店铺、公寓、老郑处）
- **核心事件**：林烈收到父亲遗物水壶，得知父亲可能还活着，决定寻找真相。

###写作细节
1. **场景一（店铺）**：
 -重点描写了店铺的环境（气味、光线、声音），营造压抑氛围。
 - 通过林烈打结的动作展现其军人背景和内心的压抑。
 -包裹的到来打破平静，制造悬念。

2. **场景二（公寓）**：
 -重点描写林烈的心理活动，通过抚摸水壶、看照片等动作展现其对父亲的思念和痛苦。
 -电话通话揭示关键信息（老郑、沈书白、南诏古城）。
 - 林烈的决心转变：从绝望到寻找真相。

3. **场景三（老郑处）**：
 - 通过老郑的视角补充背景信息（当年的探险、照片的诡异）。
 - 老郑决定加入寻找，为后续剧情埋下伏笔。

###遇到的问题与解决方案
- **问题**：如何自然地引出沈书白？
- **解决方案**：通过老郑的电话，以“必须找到这个年轻人”为由引出沈书白，避免生硬。
- **问题**：如何平衡林烈的军人硬汉形象和内心的脆弱？
- **解决方案**：在店铺场景中展现其硬汉的一面（利落的动作、冷硬的语气），在公寓场景中展现其脆弱的一面（颤抖的手、压抑的哭声）。
