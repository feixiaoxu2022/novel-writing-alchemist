# 《溺亡守则》长篇小说大纲

## 一、总体规划

###1. 字数目标
- **总字数**：约15万字
- **章节数**：48章（8卷 ×6章）
- **每卷字数**：约1.8万字
- **每章字数**：约3000字

###2. 结构设计
采用"卷-章"两级结构：
- **8卷**：对应原短篇的8章，每卷为一个大的叙事单元
- **48章**：每卷6章，每章为一个具体的场景单元

###3.叙事节奏
- **每卷结构**：铺垫（2章）→ 发展（2章）→ 高潮（1章）→ 余韵（1章）
- **小高潮**：每卷第5章为小高潮
- **大高潮**：第6卷第5章为全书大高潮
- **情感曲线**：悬疑→紧张→恐惧→释然→开放

###4.核心主题扩展
- **法医的心理异化**：从困惑→恐惧→接受→超越
- **民国上海的时代氛围**：租界、码头、洋行、旗袍、黄包车
- **声学实验细节**：次声波原理、共振效应、材料科学
- **规则的哲学意涵**：束缚与自由、见证与永恒
