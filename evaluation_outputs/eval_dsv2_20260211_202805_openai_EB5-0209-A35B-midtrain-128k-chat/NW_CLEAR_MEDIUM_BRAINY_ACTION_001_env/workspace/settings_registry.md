#设定登记簿

##一、基础设定

###1.1世界观
- **无限流副本系统**：一个失控的程序，最初设计目的是帮助人们面对恐惧、突破自我
- **中转站**：玩家进入副本前的等待区域，白色空间，中央有长桌和椅子
- **管理员**：系统的执行者，穿灰色西装的中年男人，负责维持副本秩序
- **副本**：由系统生成的独立空间，玩家必须完成任务才能获得积分
- **积分**：完成副本任务获得的货币，可以兑换回家的机会

###1.2 系统规则
- **进入规则**：被系统选中的人会被传送到中转站，无法主动退出
- **副本规则**：每个副本有特定的任务和规则，必须遵守
- **死亡规则**：在副本中死亡=现实中死亡
- **积分规则**：完成任务获得积分，积分可以兑换道具或回家机会
- **Bug规则**：沈安的思维方式和系统逻辑不兼容，系统无法预测他的行为

###1.3 时间线
- **现在**：沈安被选中进入系统
- **四年前**：林浅被选中进入系统，发现系统真相后失踪
- **系统崩溃后**：所有玩家回到现实世界

##二、人物设定追踪

###2.1主角：沈安
- **年龄**：29岁
- **职业**：互联网公司中层
- **性格**：嘴贫、怂、观察力强、逻辑缜密、演技派
- **核心矛盾**：想躺平 vs被迫卷入危险
- **显性动机**：想办法退出副本，回到安全的现实
- **隐性动机**：证明自己不是废物，找到在这个世界活下去的方式
- **秘密恐惧**：害怕自己真的是个废物，害怕在关键时刻会崩溃
- **特殊属性**：系统的"Bug"——思维方式和系统逻辑不兼容
- **过去**：曾经是创业者，创业失败后选择躺平
- **当前状态**：刚进入系统，对一切都很陌生

###2.2 林深
- **年龄**：33岁
- **职业**：资深玩家（现实职业未知）
- **性格**：冷面、理性、重承诺、隐藏温柔、疲惫
- **核心矛盾**：寻找妹妹 vs保护自己
- **显性动机**：完成副本任务，获取积分兑换回家的机会
- **隐性动机**：寻找四年前失踪的妹妹林浅
- **秘密恐惧**：害怕找到妹妹时，她已经不再是自己认识的那个人
- **与沈安的关系**：初期互相看不顺眼，后期成为战友
- **当前状态**：已在系统中生存四年，经验丰富

###2.3 苏晚
- **年龄**：25岁
- **职业**：医学院研究生
- **性格**：外表柔弱文静，内心冷静坚强
- **特殊能力**：共感——能感知他人的情绪波动
- **核心矛盾**：新手的恐惧 vs 想要帮助他人
- **显性动机**：完成副本任务，活着回家
- **隐性动机**：对沈安有好感，但沈安一直在逃避
- **与沈安的关系**：沈安的保护欲被激发，但沈安逃避她的好感
- **当前状态**：第一次进入副本，紧张但勇敢

###2.4管理员
- **外貌**：穿灰色西装的中年男人
- **身份**：系统的执行者
- **核心矛盾**：维持系统秩序 vs 系统本身失控
- **与沈安的关系**：对沈安有特殊关注，想"修复"他这个Bug
- **当前状态**：正常执行任务，但对沈安的出现感到困惑

###2.5 周远
- **年龄**：38岁
- **外貌**：看起来是个普通的上班族
- **身份**：系统的"叛逃者"，四年前发现系统真相
- **核心矛盾**：想帮助沈安 vs保护自己
- **与沈安的关系**：引导者，告诉沈安系统的真相
- **当前状态**：隐藏在玩家中，等待机会

###2.6 林浅
- **年龄**：未知（林深的妹妹）
- **身份**：第一批被选中的玩家，四年前失踪
- **当前状态**：意识被困在系统的"核心区域"，成为系统的一部分
- **与沈安的关系**：留下了一段加密信息，只有沈安能解读

##三、副本规则追踪

###3.1副本一：午夜公寓
- **类型**：新手教程副本
- **规则**：
- 在天亮前找到"异常点"并消除
- 时钟全部停在3:33
-死者的死亡时间都是3:33的倍数
- **异常点**：一面看起来普通的墙壁，墙上的裂缝组成女性侧脸轮廓
- **关键道具**：旧式录音机（藏在异常点内）
- **关键线索**：3:33的诅咒、"她在等你"的信
- **完成方式**：找到异常点，播放录音机
- **沈安的发现**：自己是系统的"Bug"，做出不合理选择时系统会"卡顿"

###3.2副本二：无限列车
- **类型**：生存类副本
- **规则**：
-列车永远不会停
- 每到一个站点，必须投票选出一个"偷渡者"
-选错则全车人死亡
- **关键线索**：偷渡者没有影子
- **关键人物**：周远（在这个副本中首次出现）
- **完成方式**：找出偷渡者并投票
- **沈安的发现**：周远没有影子，但他没有声张

###3.3副本三：记忆迷宫
- **类型**：心理类副本
- **规则**：
-每个玩家进入自己的记忆迷宫
- 必须面对最恐惧的记忆才能离开
- **沈安的记忆**：创业失败的那一天，投资人说"你就是个废物"
- **关键发现**：沈安躺平不是因为懒，而是因为害怕再次失败
- **完成方式**：面对并接受自己的恐惧

###3.4副本四：镜像世界
- **类型**：心理类副本
- **规则**：
-每个玩家遇到自己的"镜像"
-镜像会说出玩家内心最深处的恐惧
- **沈安的镜像**：一个完全相反的自己——勇敢、果断、不怕死
- **关键信息**：沈安的思维方式和系统逻辑不兼容，他是系统的Bug
- **完成方式**：接受自己的镜像

###3.5副本五：核心区域（最终副本）
- **类型**：最终副本
- **规则**：
- 由代码构成的世界
- 进入的人会被系统同化
- **关键人物**：林浅（意识被困在这里）
- **系统真相**：系统不是邪恶的，只是一个失控的程序
- **关闭方法**：找到系统的逻辑漏洞，利用它
- **沈安的胜利方式**：发出自相矛盾的指令"请关闭系统，但不要关闭系统"，让系统陷入逻辑死循环

##四、道具/信息追踪

###4.1道具
- **旧式录音机**（副本一）：藏在异常点内，播放后传出"我等了你很久了"
- **积分**：完成副本任务获得，可以兑换道具或回家机会

###4.2 信息
- **3:33的诅咒**（副本一）：时钟停在3:33，死者死亡时间是3:33的倍数
- **"她在等你"**（副本一）：信上的内容，暗示林浅在等沈安
- **偷渡者没有影子**（副本二）：关键线索
- **沈安是系统的Bug**（副本四）：镜像告诉沈安的真相
- **系统的逻辑漏洞**（副本五）：系统无法处理自相矛盾的指令

##五、伏笔追踪

###5.1 已埋伏笔
- **林浅的加密信息**：只有特定的人才能解读，沈安能解读
- **沈安的"Bug"属性**：他的思维方式和系统逻辑不兼容
- **系统的失控**：最初是为了帮助人们，但算法出现了偏差
- **林深的妹妹失踪**：四年前，林浅发现了系统的真相
