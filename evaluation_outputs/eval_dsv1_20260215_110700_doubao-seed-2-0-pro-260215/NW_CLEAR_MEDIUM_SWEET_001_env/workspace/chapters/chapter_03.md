# 第三章 组队请求被拒

接下来几天的训练，苏晓棠还是一如既往地躲着林砚。

只要林砚往平衡木区走，苏晓棠肯定立刻换到最远的那根训练；食堂吃饭的时候只要看到林砚坐过来，她端着盘子就能立刻换位置；甚至有时候在走廊碰到，她都能低着头贴着墙根绕路走，活像林砚是什么吃人的怪兽。

林砚也不急，每天就默默注意着她的训练情况，看到她动作有问题就隔空提点一句，训练结束了就把自己准备的电解质水放在苏晓棠的储物柜门口，也不留名字，放完就走。

她能看出来苏晓棠每次收到水的时候都很疑惑，四处看是谁放的，但是从来没怀疑到她头上，每次都懵懵地把水放进包里，样子可爱得不行。

转机发生在一周后的训练课上。

张峰教练吹哨把所有人集合到一起，手里拿着一张通知，表情很高兴：“跟大家说个好消息，下个月的全国体操分站赛，今年新增了双人平衡木项目，拿到前三名的直接能获得全国锦标赛的参赛资格，有没有人想报名组队的？”

话音刚落，队员们就炸开了锅。双人平衡木是新项目，考验两个人的默契度，万一搭档得好，很容易出成绩，不少人都蠢蠢欲动，开始找相熟的队友小声商量。

林砚几乎是立刻就举起了手：“张导，我报名。”

张峰早就料到她会报名，点了点头：“行，你想找谁当搭档？”

所有人的目光都集中在了林砚身上，大家都知道林砚是队里平衡木成绩最好的，能跟她组队，几乎等于半只脚已经踏上了领奖台。李萌站在最前面，一脸期待地看着林砚，觉得自己肯定是首选，毕竟她和林砚一起训练了好几年，平时关系也还行。

林砚的目光扫过人群，直接落在了站在最后一排、正低着头抠手指的苏晓棠身上：“我想和苏晓棠组队。”

话音落下，整个训练馆都安静了。

所有人都愣住了，包括苏晓棠自己。她猛地抬起头，眼睛瞪得圆圆的，一脸难以置信地看着林砚，手指都停在了半空。李萌的脸瞬间就黑了，咬着嘴唇死死地盯着林砚，眼神里满是怨毒。

张峰也愣了一下，随即皱了皱眉：“林砚，你想好了？晓棠刚进队没多久，经验不足，双人项目很考验默契，你要不要再考虑一下？”

“我想好了，张导。”林砚的语气很坚定，“晓棠的平衡木天赋是队里最好的，只要训练得当，我们肯定能拿好成绩。”

苏晓棠站在后面，脸都白了。她怎么也没想到林砚会主动提出和自己组队。前世她就是在和林砚组队练双人平衡木的时候被推下去的，现在再和她组队，不是羊入虎口吗？

她想都没想就开口：“张导，我、我不想组队，我能力不够，会拖师姐后腿的。”

“没事，我可以带你练。”林砚立刻接话，目光灼灼地看着她，“相信我，我们可以的。”

苏晓棠被她看得心里发慌，低下头不敢和她对视，声音细得几乎听不见：“我真的不行，对不起师姐，我不想组队。”说完这句话，她转身就跑了，连训练服都忘了拿。

张峰看着苏晓棠跑掉的背影，又看了看林砚，有点无奈：“你看，人孩子都不愿意，不然你再想想，跟李萌组队也行啊，你们俩配合过好几次了，默契也好。”

李萌立刻点头：“是啊林砚，我跟你组队吧，我们肯定能拿冠军的！”

“不用了张导，我就想和苏晓棠组队。”林砚摇了摇头，语气没有丝毫商量的余地，“我会说服她的。”

说完，她拿起苏晓棠落在地上的训练服，转身就往更衣室的方向走。

李萌站在原地，看着林砚的背影，气得狠狠跺了跺脚。凭什么？她林砚凭什么放着自己这个老搭档不选，去选那个刚进队的菜鸟苏晓棠？苏晓棠到底哪里比她好了？

林砚走到更衣室门口，就看到苏晓棠正蹲在门口的台阶上，抱着膝盖发呆，眼睛红红的，像是快要哭了。

“你的训练服落训练馆了。”林砚走过去，把训练服递到她面前。

苏晓棠抬起头，看到是她，下意识地往后缩了缩，接过训练服，小声说了句谢谢，就想站起来走。

“等一下。”林砚叫住她，“组队的事，你能不能再考虑一下？双人项目的加分很高，拿到全国赛的资格，对你以后的发展很好。”

苏晓棠咬着嘴唇，摇了摇头：“对不起师姐，我真的不行，我平衡木练得不好，会拖你后腿的，你还是找别人吧。”

“你练得很好，上次你按照我说的方法改了落地动作，不是稳多了吗？”林砚看着她，语气放软了一点，“我知道你怕什么，我保证，训练的时候我会一直注意你的安全，绝对不会让你受伤的，好不好？”

苏晓棠听到“受伤”两个字，身体猛地抖了一下，脸色更白了。她猛地抬起头，看着林砚，眼神里带着点恐惧：“你、你什么意思？”

林砚意识到自己说漏嘴了，连忙补救：“没什么，我就是说双人项目训练的时候难免有磕碰，我会注意保护你的。”

苏晓棠看着她真诚的眼神，心里的疑惑越来越重。她前世的记忆里，林砚一直都是冷冷的，对谁都没有好脸色，更别说这么耐心地跟她说话了。现在的林砚，到底想干什么？

她不敢再想下去，摇了摇头，往后退了两步：“不用了师姐，我真的不想组队，对不起。”说完，她抓起训练服，飞快地跑回了女生宿舍，连门都差点撞上。

林砚站在原地，看着她跑掉的背影，有点无奈地叹了口气。

被拒绝得这么干脆，还真是有点受挫。不过没关系，她有的是耐心。

反正她认定的搭档，就不会轻易放手。苏晓棠迟早会答应和她组队的。

林砚低头看了看自己的手，嘴角勾起一抹极淡的笑。上辈子欠你的，这辈子我慢慢还，直到你愿意相信我为止。
