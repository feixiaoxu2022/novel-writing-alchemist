# 第九章 真假黄四郎
黄四郎的替身最近过得挺滋润。
正主躲在碉楼里不敢出来，他就穿着黄四郎的衣服，戴着一样的帽子，坐着一样的轿子，到处去收租，逛窑子，到处耀武扬威，别提多威风了。
这天他带着两个家丁去乡下收租，刚走到半路，就被六子带着人截住了。
“哟，这不是黄老爷吗？这么巧啊。”六子靠在树上，手里转着左轮枪，笑得一脸不怀好意。
替身吓得脸都白了，转身就要跑，身后的麻匪直接围了上来，把他按在地上，嘴一堵，绑回了县衙。
约翰看着跪在地上的替身，上下扫了两眼，笑得不行，译制片腔带着点调侃：“噢，我的老伙计，你这身衣服穿着跟黄四郎一模一样，不知道的还以为你就是真的呢。”
替身吓得浑身发抖，连连磕头：“张县长饶命啊！我就是个替身！黄四郎逼我当的！我什么坏事都没干啊！”
“没干？”约翰挑了挑眉，姜文式的短句砸得他一哆嗦：
“穿着他的衣服收租。”
“欺负百姓。”
“还说没干坏事？”
替身吓得哭了出来：“我也是被逼的啊！黄四郎说我要是不干，就杀我全家！我没办法啊！”
“行了，别哭了。”约翰摆了摆手，“我给你个机会，将功补过。你要是干得好，我就放你走，还给你钱，让你带着老婆孩子离开鹅城。”
替身立刻不哭了，抬头看向约翰：“您说！您让我干什么我都干！”
“简单。”约翰站起身，指了指他身上的黄四郎衣服，“你就穿着这身衣服，戴着他的帽子，坐着他的轿子，去鹅城大街上游街，告诉所有人，你是黄四郎，你被我抓了，投降了。”
替身愣了一下，随即连忙点头：“我干！我干！”
第二天一大早，鹅城的百姓就看见“黄四郎”被绑在轿子里，游街示众，脸上还画了个大王八，旁边的六子拿着个锣，一边敲一边喊：“黄四郎被抓了！他投降了！以后再也不用交地租了！”
百姓们一开始还不信，仔细一看，衣服帽子都是黄四郎的，连走路的姿势都像，瞬间就炸了锅，欢呼声响彻整个鹅城，有人往“黄四郎”身上扔烂菜叶，有人扔臭鸡蛋，替身不敢反抗，只能缩着脖子喊：“我是黄四郎！我投降了！你们别扔了！”
消息很快传到了黄四郎的手下耳朵里，那些本来就跟着黄四郎混口饭吃的家丁、团练，一看黄四郎都被抓了，纷纷跑到县衙投降，还把黄四郎藏在外面的粮食、银子的位置全都告诉了约翰。
没几天功夫，黄四郎的势力就散了一大半，碉楼里只剩下几百个亲信，还在苦苦支撑。
黄四郎在碉楼上看着下面游街的替身，气得肺都要炸了，拿起枪就要打，旁边的管家连忙拦住他：“老爷！不能打啊！您一开枪，不就告诉所有人真的您还在碉楼里吗？那张麻子的狙击手正等着您露头呢！”
“我操他妈的张牧之！”黄四郎气得把枪摔在地上，翡翠烟壶都砸了个粉碎，“他敢用个假的来糊弄我！我要杀了他！我一定要杀了他！”
“老爷，您消消气！”管家连忙劝他，“刘督军的援军明天就到了，等援军来了，我们直接踏平县衙，把张牧之碎尸万段，还有那个假的，一起杀了！”
黄四郎喘着粗气，咬着牙点了点头：“好！我就等一天！等援军到了，我要把张牧之的脑袋砍下来，挂在碉楼门口示众！”
而此时的县衙里，约翰正看着手下统计的投降名单，还有黄四郎藏粮食的位置，笑得很开心。汤师爷站在旁边，算盘打得噼里啪啦响，笑得眼睛都眯成了一条缝：“我的县长大人啊！您这招太高了！现在黄四郎的手下差不多都投降了，粮食也找到了，够我们吃半年的！等援军来了我们也不怕！”
约翰点了点头，看向窗外碉楼的方向，手指轻轻敲着桌面：
“援军来了正好。”
“省得我一个个去找。”
“来多少。”
“我打多少。”
六子凑过来，兴奋得摩拳擦掌：“爸！明天我打头阵！我倒要看看，刘督军的兵，比西部的牛仔快枪手还厉害吗？”
约翰笑了，拍了拍他的肩膀，译制片腔带着点战意：“噢，小子，明天让你看看，什么叫做真正的西部战术，再多的兵，在我们牛仔眼里，都是活靶子。”
第二天一早，远处就传来了军号声，刘督军的援军到了，足足有五百个人，拿着步枪，抬着机枪，浩浩荡荡地往鹅城开了过来。
约翰站在城墙上，看着下面的军队，嘴角勾起一抹笑，把牛仔帽往下压了压。
“兄弟们。”
“准备干活了。”
风吹过城墙，带着点硝烟的味道，一场大战，一触即发。
