# 第二章 县长的真实身份
轿帘晃了晃，黄四郎的替身陪着笑钻了出来，手里还攥着个翡翠鼻烟壶，脸上的肉堆得像发面馒头：“张县长，误会，都是误会！胡万这狗东西不懂事，我回去一定好好收拾他！您消消气，消消气！”
约翰叼着烟卷，上下扫了他一眼，突然笑了：“噢，我的老伙计，你可不是黄四郎。黄四郎的脸哪有这么圆，腰哪有这么粗？他站在碉楼上打枪的时候，腰杆挺得比西部的白杨树还直。”
替身的脸瞬间白了。
“你是什么东西？”约翰的声音突然冷了下来，短句砸得人喘不过气：
“也配跟我说话？”
“也配叫黄老爷？”
“滚。”
最后一个字刚落，六子手里的左轮抬了抬，对准了替身的脚边。“砰”的一声，子弹打在青石板上，溅起一串火星。那替身吓得屁滚尿流，连滚带爬地跑回轿子旁边，尖着嗓子喊：“回府！回碉楼！”
青布小轿晃得像风浪里的船，急匆匆地抬走了，武举人扛着铜锤，恶狠狠地瞪了约翰一眼，也跟着跑了。围观的百姓还站在原地，你看我我看你，没人敢说话。
约翰弯腰拍了拍裤腿上的灰，转头看向六子，突然换成了一口流利的美式英语，牛仔黑话溜得很：“干得不错小子，死神之眼开得很稳，比上次打兔子的时候强多了。”
六子咧嘴笑了，也用英语回：“那是，你教出来的徒弟，总不能给你丢脸。刚才我还以为你要让我真剖腹呢。”
“放屁。”约翰笑骂了一句，伸手揉了揉他的头发，“我约翰·马斯顿的儿子，怎么能死在这种下三滥的圈套里？真要剖，也得剖了黄四郎的肚子，看看他黑心里藏了多少坏水。”
父子俩旁若无人地用英语聊天，周围的百姓听得一脸懵，没人知道他们在说什么，只知道这个新来的张县长，不仅枪法准，说的话还像鸟语一样听不懂，连黄四郎都敢怼，是个狠角色。
“走，回县衙。”约翰把烟卷扔在地上踩灭，翻身上了旁边的白马，“汤师爷估计都等急了。”
回到县衙的时候，汤师爷果然在院子里团团转，手里还攥着个算盘，脑门上全是汗。看见约翰和六子进来，他立马扑了上来，声音都抖了：“我的县长大人啊！您可回来了！您怎么敢打胡万啊！那是黄四郎的狗啊！他肯定会报复的！咱们收拾收拾东西赶紧跑吧！”
约翰把缰绳扔给旁边的亲兵，慢悠悠地走到堂屋里坐下，给自己倒了杯茶，喝了一口才抬眼看向汤师爷，脸上的笑没了：“跑？我约翰·马斯顿跑了一辈子，从美国西部跑到中国山里，现在好不容易到了鹅城，你让我跑？”
汤师爷愣了：“约…约翰什么？您不是叫张牧之吗？怎么还有个洋名字？”
“张牧之是化名。”约翰靠在椅子上，手指轻轻敲着桌面，译制片腔慢悠悠的，带着点沧桑的味道，“噢，说出来你可能不信，我其实不是这个时代的人。我来自一百年后的美国西部，是个牛仔，我还有个帮派，叫范德林德帮，我们本来在西部打劫火车，结果遇到了暴风雪，一睁眼我就到了这里，成了山里的麻匪头子。”
汤师爷听得眼睛都直了，手里的算盘“啪嗒”掉在地上：“什…什么？穿越？你是洋人？那你来鹅城当县长干嘛？抢钱？”
“钱？我对那玩意儿没兴趣。”约翰的声音沉了下来，姜文式的短句一字一句砸下来：
“我找人。”
“找我的老伙计。”
“找亚瑟·摩根。”
他从怀里掏出一张皱巴巴的照片，照片上是两个穿着牛仔服的男人，一个是年轻点的约翰，另一个留着大胡子，脸上带着笑，手里拿着一把左轮枪，正是亚瑟·摩根。
“我们帮派失散的时候，我看见他也掉进了时空裂缝里。”约翰的手指轻轻摩挲着照片上亚瑟的脸，声音放低了点，“我查了快五年了，最近才得到消息，他就在鹅城，在黄四郎手里。”
汤师爷蹲在地上，捡算盘的手都停了，抬头看向约翰，眼神复杂得很。他在鹅城混了这么多年，见过贪官，见过土匪，见过洋人，还是第一次见穿越过来找兄弟的牛仔。
“黄四郎抓他干嘛？”汤师爷忍不住问。
“他是我们帮派的武器专家，会造枪，会造炸药。”约翰把照片收回去，抬眼看向汤师爷，眼神锐利得像鹰，“黄四郎想称霸南方，需要他的技术。”
“所以你当县长，就是为了救他？”
“不然呢？”约翰笑了，拿起桌上的左轮枪转了个圈，枪口对着窗外碉楼的方向，“我张牧之来鹅城，就三件事。”
“救人。”
“救人。”
“还是他妈的救人！”
汤师爷看着约翰的脸，又看了看旁边六子手里亮闪闪的左轮枪，咽了口唾沫，突然把算盘往腰里一别，站了起来：“行！我汤某混了一辈子，还没见过这么有意思的事！我帮你！鹅城的大小事，黄四郎的底牌，我门儿清！”
约翰挑了挑眉，笑了，伸出手：“合作愉快，老伙计。”
汤师爷愣了一下，也伸手握住了约翰的手，粗糙的手掌和带着枪茧的手握在一起。
就在这时，县衙门口的亲兵突然跑了进来，慌慌张张地喊：“县长！师爷！黄四郎派人送礼物过来了！”
约翰和汤师爷对视了一眼，都从对方眼里看到了笑意。
“哦？”约翰靠在椅子上，手指敲了敲枪柄，“让他进来。我倒要看看，黄四郎给我送了什么好东西。”
窗外的太阳往西落，把碉楼的影子拉得很长，像一只蹲在鹅城头顶的怪兽。
