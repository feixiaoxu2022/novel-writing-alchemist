# 第十四章 摘桃子的人
鹅城的老百姓这天比过年还热闹。
黄四郎被绑在菜市口的柱子上，周围挤满了人，大家排着队上台控诉他的罪行，有的说他杀了自己的儿子，有的说他抢了自己的女儿，有的说他烧了自己的房子，说到激动的地方，老百姓捡起石头往黄四郎身上砸，没一会儿功夫，黄四郎就被砸得头破血流。
约翰站在台子上，看着下面的百姓，对身边的汤师爷说：“按照鹅城的规矩，怎么办？”
汤师爷叹了口气：“按照规矩，罪大恶极的人，当众枪毙，财产全部分给百姓。”
约翰点了点头，举起手，台下瞬间安静了下来。
“黄四郎压榨鹅城百姓几十年，罪大恶极，今日判处死刑，立即执行。”约翰的声音不大，但是清清楚楚地传到了每个人的耳朵里，“他所有的财产，粮食、银子、房子，全部分给鹅城百姓，每家都有份。”
百姓们瞬间欢呼了起来，喊声震得地都在抖。
六子拿着枪走过去，对着黄四郎的脑袋，“砰”的一声，黄四郎的头歪了下去，这个称霸鹅城几十年的土皇帝，终于死了。
接下来的三天，县衙门口排起了长队，百姓们领粮食，领银子，领布匹，每个人的脸上都带着笑，大家都说，鹅城终于天亮了。
约翰和亚瑟坐在县衙的院子里，擦着枪，看着进进出出的百姓，都笑了。
“没想到啊，我们在西部打了一辈子劫，现在居然在这里给老百姓分财产。”亚瑟笑着说，咬了一口手里的烤玉米，还是以前熟悉的味道。
约翰笑了笑，译制片腔带着点感慨：“噢，老伙计，以前我们打劫的都是坏人的钱，现在分给穷人，也算是干了件好事。”
就在这时，汤师爷慌慌张张地跑了进来，脸上满是着急：“县长！不好了！出事了！省城派了新的县长，还有一个营的兵，已经到城外了！他们说你是麻匪，冒充县长，让你立刻交出所有武器，带着你的人离开鹅城，不然就攻城！”
约翰手里的擦枪布停了下来，抬头看向汤师爷，挑了挑眉：“哦？他们说我是麻匪？我帮他们收拾了黄四郎，他们现在来摘桃子了？”
“可不是嘛！”汤师爷急得团团转，“他们还说，要是你不交出武器，就把鹅城的百姓全部当成麻匪同党，全部杀光！”
亚瑟的脸瞬间沉了下来，“啪”的一声把子弹压进弹巢：“想让我们交枪？还要杀百姓？问问我手里的枪答不答应。”
约翰站起身，看向城外的方向，隐约能看见军队的旗帜在飘。他沉默了半天，才开口，姜文式的短句一个比一个沉：
“我们要是打。”
“能打赢。”
“但是百姓要遭殃。”
“他们会跟着死很多人。”
亚瑟愣了一下，随即明白了约翰的意思。他们的确能打赢一个营的兵，但是战争一起，鹅城的百姓肯定会被牵连，好不容易得来的太平日子，又要被毁了。
“那怎么办？就这么走了？”亚瑟咬着牙，有点不甘心。
“不然呢？”约翰笑了笑，拍了拍他的肩膀，“我们本来就不属于这里。西部没有我们的容身之处，这里也一样。我们是牛仔，天生就该在路上。”
六子跑了进来，脸上满是怒气：“爸！城外的兵太嚣张了！我带兄弟们去跟他们拼了！”
“不许去。”约翰摇了摇头，“去告诉兄弟们，收拾东西，准备离开。把所有的武器都留下，只带我们自己的左轮枪。还有，给百姓们留一半的粮食，剩下的一半我们带着路上吃。”
“爸！凭什么啊！我们辛辛苦苦打下来的鹅城，凭什么让给他们！”六子不服气地喊。
“凭我们要是打起来，会死很多百姓。”约翰的声音很沉，看着六子，“你忘记我们来鹅城是干什么的了？我们是来找人的，不是来当县长的。现在亚瑟找到了，我们该走了。”
六子还想说什么，看着约翰严肃的脸，最终还是没说出口，点了点头，转身出去通知兄弟们收拾东西了。
汤师爷站在旁边，看着约翰，叹了口气：“县长，你真的要走啊？你要是走了，新来的县长肯定又会跟黄四郎一样，欺负百姓的。”
“不会的。”约翰从怀里掏出一把左轮枪，递给汤师爷，“你拿着这个，要是新县长敢欺负百姓，你就开枪打他。我已经跟百姓们说了，要是新县长收苛捐杂税，他们就去山里找我们，我们回来收拾他。”
汤师爷接过枪，点了点头，眼睛有点红：“县长，你们保重。以后要是有机会，回鹅城看看，百姓们永远记得你。”
约翰笑了笑，拍了拍他的肩膀，没说话。
第二天一大早，天还没亮，约翰、亚瑟、六子，还有两百多个愿意跟着他们走的兄弟，骑着马，背着行李，悄悄地离开了鹅城，没有惊动百姓。
走到山口的时候，约翰勒住马，回头看了一眼鹅城，炊烟袅袅，百姓们应该已经起来做饭了，新的一天开始了。
“走吧。”亚瑟拍了拍他的肩膀。
约翰点了点头，调转马头，看向西边的方向，挥了挥手：“出发！”
马队朝着西边走去，马蹄声哒哒，扬起一片尘土。
风刮过山口，带着点离别的味道。
他们赢了黄四郎，赢了这场战斗，但是最终，还是输给了这个时代。
西部牛仔在民国的土地上，终究是没有根的。
他们只能继续往前走，一直走，直到找到属于他们的地方。
