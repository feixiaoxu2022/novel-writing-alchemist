# 第五章 碉楼夜探
汤师爷果然没吹牛，天还没黑，就把碉楼的地图搞到了，还贴心地用红笔标出了密室的位置，还有守卫换岗的时间。
“我的县长大人，您看看！这地图可是我花了三块大洋从碉楼以前的老管家手里买的，绝对靠谱！”汤师爷把地图铺在桌子上，手指点着东南角的位置，“您看，密室就在这，旁边就是黄四郎的住处，守卫最严，一个时辰换一次岗。”
约翰趴在桌子上，看着地图上的标记，手指轻轻敲着桌面，译制片腔带着点笑意：“噢，干得漂亮老伙计，你这本事要是去我们西部当探子，肯定能混个二当家当当，比你当师爷有前途多了。”
他直起腰，声音瞬间变得干脆，姜文式短句砸得响亮：
“今晚就去。”
“看看亚瑟到底关在哪。”
“六子跟我去，你留县衙看家。”
半夜三更，月亮被乌云遮住，鹅城一片漆黑。约翰和六子换上黑色的夜行衣，腰间挎着左轮枪，顺着城墙根摸到了碉楼底下。碉楼建在半山腰，墙高十米，上面挂满了灯笼，守卫拿着枪来回晃，脚步声听得清清楚楚。
约翰从背包里掏出飞爪，“唰”的一声甩上去，铁爪牢牢勾住了墙垛。他比了个手势，六子点了点头，两个人顺着绳子往上爬，像两只夜猫子，一点声音都没出。
翻进碉楼院子，两个人蹲在阴影里，看着守卫换岗。等换岗的间隙，约翰猫着腰往东南角的密室摸过去，六子跟在后面，手里紧紧攥着短刀，大气都不敢喘。
密室门口站着两个守卫，手里拿着步枪，靠在墙上打盹。约翰从兜里掏出两个麻醉针，“咻咻”两声打在守卫的脖子上，两个守卫哼都没哼一声就瘫软在地。
约翰走到密室门口，掏出汤师爷给的钥匙，打开了锁。推开门的瞬间，里面传来“叮当”的敲击声，还有个沙哑的男声，在用英语骂人，骂的是西部牛仔最脏的黑话，一听就是亚瑟的声音。
约翰的心脏猛地一缩，差点冲进去。他压着情绪，从门缝往里面看，就见亚瑟穿着破破烂烂的牛仔服，手上戴着镣铐，正在敲一个枪械零件，脸上的疤还是那么显眼，比五年前苍老了不少，胡子更长了，头发也白了不少。
旁边站着两个黄四郎的手下，拿着鞭子，见亚瑟停下就抽一下：“快点干！黄老爷说了，这个月造不出一百把枪，就扒了你的皮！”
亚瑟吐了口唾沫，骂了句脏话，继续敲零件，手上的动作没停。
约翰的手指攥得咯咯响，恨不得立刻冲进去把亚瑟救出来，但是他知道不行，现在冲进去，不仅救不出亚瑟，他们两个也得栽在这里。他咬了咬牙，对着六子比了个撤退的手势。
两个人转身往回走，六子走得急，没注意到门槛，脚一绊，腰间挂着的铜哨“当啷”一声掉在了地上，滚出去老远。
“谁！”旁边巡逻的守卫听见声音，立刻喊了起来，手电筒的光往这边照了过来，枪声瞬间响了起来，子弹打在墙上，溅起一串火星。
“跑！”约翰喊了一声，拉着六子往墙根跑，后面的守卫追了上来，喊叫声响彻整个碉楼。
两个人翻出碉楼，顺着山坡往下跑，后面的枪声越来越远，直到跑回县衙，两个人才靠在墙上喘气，一身的冷汗。
“怎么样？没受伤吧？”约翰看向六子，喘着气问。
“没有。”六子摇了摇头，伸手摸腰间，突然脸色一变，“坏了！爸，我那铜哨丢了！就是你给我的那个，上面有V字标记的！”
约翰的脸色瞬间沉了下来。
那个铜哨是范德林德帮的信物，每个兄弟都有一个，黄四郎既然认识子弹上的V字标记，肯定也认识铜哨上的。
“黄四郎拿到铜哨，就知道是我们干的。”约翰的声音冷得像冰，姜文式的短句一个比一个重：
“他肯定会报复。”
“大概率会冲着你来。”
“接下来几天，你别一个人出门。”
六子点了点头，脸上满是愧疚：“都怪我，太不小心了。”
“不怪你。”约翰拍了拍他的肩膀，笑了笑，译制片腔带着点安抚的味道，“噢，没关系小子，本来就瞒不住，摊牌了也好，省得我们躲躲藏藏的。”
他走到窗边，看向碉楼的方向，那里现在灯火通明，肯定在到处搜人。
约翰从怀里掏出那张皱巴巴的照片，手指摩挲着亚瑟的脸，眼神坚定得很。
“放心吧老伙计。”
“我很快就会救你出来。”
“一定。”
风刮过院子，吹得窗户哐哐响，山雨欲来风满楼。
而此时的碉楼里，黄四郎正盯着桌上的铜哨，铜哨上面的V字标记和子弹上的一模一样，在灯光下闪着冷光。
武举人站在旁边，颤颤巍巍地说：“老爷，守卫说夜闯碉楼的是两个人，身手特别好，一眨眼就没影了，肯定是张麻子和他儿子干的！”
黄四郎捏着铜哨，脸上的笑阴冷得很：“看来约翰先生比我想象的还要急啊。”
他站起身，对着管家吩咐：“去，给我布个局。”
“我要抓了六子。”
“我倒要看看，约翰·马斯顿是要他的儿子，还是要他的老伙计亚瑟。”
窗外的月亮从乌云里钻了出来，冷清清的光落在铜哨上，映出黄四郎残忍的笑脸。
