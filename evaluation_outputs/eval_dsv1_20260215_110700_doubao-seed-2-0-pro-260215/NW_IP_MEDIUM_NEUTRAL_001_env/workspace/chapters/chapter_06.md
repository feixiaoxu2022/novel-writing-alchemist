# 第六章 六子被俘
约翰的警告还是晚了一步。
第二天下午，六子在县衙门口碰到个卖烟的老头，老头偷偷塞给他一张纸条，说有人在城西破庙里等他，有亚瑟的消息要告诉他。六子本来想告诉约翰，但是转念一想，上次夜探碉楼是自己不小心弄丢了铜哨，才惹出这么多麻烦，要是这次能自己打探到亚瑟的消息，也算将功补过。
他没跟任何人说，揣着枪就偷偷溜出了县衙，往城西破庙去了。
破庙里空荡荡的，到处都是蜘蛛网，连个人影都没有。六子刚觉得不对劲，身后突然传来笑声，黄四郎的替身带着十几个拿枪的家丁从门后走了出来，把门口堵得严严实实。
“六爷，您还真敢来啊。”替身笑得一脸得意，“我们老爷等你半天了。”
六子立刻拔枪，但是已经晚了，身后两个家丁一棍子打在他的后脑勺上，六子眼前一黑，栽倒在地，枪也掉在了地上。
等他醒过来的时候，已经被绑在碉楼的刑房里了，手上脚上都是镣铐，黄四郎坐在对面的椅子上，手里把玩着他的左轮枪，脸上带着笑。
“你就是约翰的儿子？”黄四郎转着左轮枪，抬眼看向六子，“胆子不小啊，敢一个人去破庙。”
六子吐了口唾沫，瞪着他：“有本事你就杀了我！我爸不会放过你的！”
“杀你？我哪舍得啊。”黄四郎笑了，站起身走到六子面前，用枪托拍了拍他的脸，“你可是我手里最好的筹码。我要拿着你，跟你爸换点好东西。”
他拍了拍手，管家拿着一张布告走了进来，上面写着：“县长之子六子，夜闯民宅杀人放火，三日后于菜市口公开处决。若有家属愿意拿左轮枪制作图纸来换，可免一死。”
“去，把这张布告贴到县衙门口去。”黄四郎挥了挥手，笑得一脸残忍，“我倒要看看，约翰·马斯顿是要他的宝贝儿子，还是要他的规矩。”
天快黑的时候，六子被抓的消息传到了县衙。
汤师爷气喘吁吁地跑进来，手里攥着那张布告，脸都白了：“县长！不好了！六子被黄四郎抓了！三天后要在菜市口处决！他要你拿左轮枪的制作图纸去换！”
约翰正擦着枪，听到这话手里的布瞬间掉在了地上。他猛地站起来，一把抢过布告，看完之后气得浑身发抖，译制片腔里带着压抑的怒火：“噢，看在上帝的份上！这个傻小子！我跟他说过多少遍不要单独出门！他就是不听！”
他把布告揉成一团扔在地上，牙齿咬得咯咯响，姜文式的短句一个比一个重，每一个字都带着火气：
“黄四郎。”
“你敢动他一根手指头。”
“我踏平你整个碉楼。”
“把你挫骨扬灰。”
汤师爷站在旁边，急得团团转：“我的县长大人啊，现在生气也没用啊！黄四郎说了，不给图纸就当众杀了六子！咱们怎么办啊？真给他图纸？那他造出来枪，鹅城百姓就更没活路了！”
约翰走到窗边，看向碉楼的方向，拳头攥得紧紧的，指节泛白。他当然知道不能给图纸，黄四郎拿到图纸，造出成千上万把左轮枪，不仅鹅城要遭殃，整个南方都得陷入战乱。但是六子是他的儿子，是他一手带大的，他不能眼睁睁看着六子死。
一边是百姓的命，一边是儿子的命。
约翰陷入了两难。
就在这时，之前给他们报信的那个汉子又偷偷跑来了，脸上满是着急：“张县长！我刚从碉楼那边过来，黄四郎不仅抓了六爷，还把亚瑟先生从密室里提出来了，说到时候处决六爷的时候，要把亚瑟先生也押过去，当着您的面杀了他，给您下马威！”
约翰的眼睛瞬间亮了。
他突然笑了，伸手拍了拍那汉子的肩膀：“太好了。多谢你兄弟。”
汤师爷一脸懵：“好什么啊县长！现在两个人都在黄四郎手里了，咱们更难办了啊！”
“难办？”约翰挑了挑眉，擦了擦手里的左轮枪，把子弹一颗一颗压进去，译制片腔带着点笑意，“噢，老伙计，这有什么难办的？黄四郎要在菜市口处决人，那我们就去劫法场。”
他压完最后一颗子弹，“咔哒”一声合上弹巢，声音冷得像冰，姜文式的短句铿锵有力：
“他要处决两个人。”
“我们就救两个人。”
“顺便。”
“把他的刑场，变成他的坟场。”
汤师爷看着约翰眼里的光，咽了口唾沫，突然就不怕了。他把算盘往腰里一别：“行！我这就去准备！我认识不少江湖上的兄弟，到时候都喊过来帮忙！”
约翰点了点头，看向窗外的月亮，手指轻轻摩挲着腰间亚瑟送给他的那颗子弹。
“亚瑟。”
“六子。”
“等我。”
“我一定会救你们出来。”
风刮过院子，带着点血腥味，三天后的菜市口，注定要血流成河。
