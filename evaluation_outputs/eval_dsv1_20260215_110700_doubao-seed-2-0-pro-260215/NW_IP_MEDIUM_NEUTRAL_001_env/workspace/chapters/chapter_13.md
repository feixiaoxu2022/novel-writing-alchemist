# 第十三章 兄弟重逢
密道里又黑又潮，六子带着兄弟们猫着腰往前走，亚瑟在前面带路，手里拿着从守卫身上摸来的枪，脚步轻得像猫。
“亚瑟叔叔，我爸就在外面等着呢。”六子压低声音说。
亚瑟点了点头，脸上的疤在黑暗里显得格外明显，他笑了笑，用英语说：“我知道，我就知道约翰那个老家伙不会丢下我的。”
两个人带着兄弟们很快摸到了碉楼的大门口，门口的两个守卫正靠在墙上打盹，亚瑟抬手两枪，打在守卫的肩膀上，守卫哼都没哼一声就倒了下去。
“开门！”亚瑟喊了一声，六子和兄弟们冲上去，把大门的插销拔开，用力一推，沉重的木门“吱呀”一声开了。
外面的约翰看见大门开了，举起手里的左轮枪，大喊：“冲！”
兄弟们像潮水一样冲了进去，碉楼里的守卫本来就喝得醉醺醺的，看见这么多人冲进来，吓得魂都飞了，要么投降，要么往楼上跑，根本没有反抗的力气。
约翰冲在最前面，刚进大门，就看见了站在门口的亚瑟。
时间仿佛在这一刻静止了。
五年了。
他找了亚瑟整整五年，从美国西部找到中国民国，从山里的麻匪窝找到鹅城，他以为亚瑟早就死在了西部的雪地里，没想到两个人会在鹅城的碉楼里重逢。
亚瑟也看着约翰，笑了，胡子拉碴的脸上露出一口白牙，用一口带着口音的中文说：“约翰，你这个老家伙，怎么穿得像个中国官员一样？”
约翰的眼睛有点湿，走过去，两个人用力抱了抱，拍着对方的后背，像以前每次完成打劫任务之后那样。
“噢，看在上帝的份上，亚瑟，我还以为你死在那个鬼地方了。”约翰的译制片腔带着点颤抖，然后换成了熟悉的姜文式短句，声音很稳：
“没死就好。”
“我答应过达奇，要带你回家。”
亚瑟笑了，拍了拍他的肩膀：“我就知道你不会丢下我。黄四郎在楼上的天台，他刚才带着几个亲信跑上去了，手里还有马克沁。”
约翰点了点头，把腰间的另一把左轮枪递给亚瑟：“你的枪，我一直给你留着。”
亚瑟接过枪，熟悉的手感传来，他转了个枪花，笑了：“好久没摸过它了，正好，用黄四郎的血，给它开个光。”
六子站在旁边，看着两个老兄弟重逢，笑得一脸开心，他举起手里的枪，大喊：“杀黄四郎！为鹅城的百姓报仇！”
“杀黄四郎！”兄弟们的喊声震天，朝着楼上冲了上去。
楼上的守军负隅顽抗，子弹打在墙上，溅起一串火星。约翰和亚瑟并肩站在一起，同时开启死神之眼，时间瞬间慢了下来，两个人的双枪同时开火，子弹像长了眼睛一样，枪枪打中守军的手腕，枪全部掉在地上，没有一个人死亡，但是全部失去了战斗力。
这是他们合作了十几年的默契，从西部的火车劫案，到鹅城的碉楼攻坚战，两个人的配合永远天衣无缝。
没一会儿功夫，楼上的守军就全部投降了，约翰和亚瑟踩着楼梯，一步步往天台走，六子跟在后面，手里的枪上好了膛。
天台的门是锁着的，黄四郎的声音从里面传出来：“张牧之！你别过来！你要是敢过来，我就和你同归于尽！我这里有炸药，大不了大家一起死！”
约翰笑了，抬手就是一枪，打在门锁上，锁“咔哒”一声断了。
他推开门，风从天台吹过来，吹得他的牛仔帽檐晃了晃。黄四郎站在天台的边缘，手里拿着打火机，脚边放着一堆炸药，脸色惨白，看着约翰和亚瑟，眼神怨毒得像毒蛇。
“约翰·马斯顿，亚瑟·摩根。”黄四郎咬着牙，念着他们的名字，“我谋划了这么多年，居然毁在你们两个洋鬼子手里！我不甘心！”
亚瑟冷笑了一声，用英语骂了句脏话，然后换成生硬的中文：“你害得我被关了五年，这笔账，我们今天慢慢算。”
约翰往前走了一步，姜文式的短句砸得硬邦邦：
“投降。”
“或者死。”
“你选一个。”
黄四郎笑得疯狂，举起手里的打火机，就要往炸药上凑：“我就算死，也要拉你们垫背！”
约翰和亚瑟同时举起了枪，死神之眼再次开启，时间慢得像凝固了一样。他们看见黄四郎的手指在往下按，看见打火机的火苗在晃，看见风把黄四郎的衣服吹得鼓起来。
“砰——”
两声枪响同时响起，子弹同时打在黄四郎的两只手上，打火机掉在地上，黄四郎惨叫一声，捂着双手蹲了下去，血顺着指缝往下流。
六子冲上去，一脚把他踹倒在地，把炸药踢到了一边，用枪指着他的头。
黄四郎输了。
彻彻底底地输了。
约翰走到天台边缘，看着下面欢呼的百姓和兄弟们，风刮过他的脸，带着硝烟的味道。
五年的寻找。
无数次的生死危机。
终于结束了。
亚瑟走过来，站在他身边，也看着下面的人群，笑了笑：“接下来怎么办？我们回西部？还是留在中国？”
约翰摇了摇头，看着西边的方向，眼神复杂得很。
“不知道。”
“先把鹅城的事处理完。”
“再说吧。”
太阳从东边升了起来，金色的阳光洒在两个人身上，像很多年前，他们站在西部的草原上，看着日出的时候一样。
