# 第十一章 烧粮与开荒
后半夜的火光把鹅城的天都映红了。
黄四郎派了十几个死士，偷偷溜出碉楼，把百姓存在粮仓里的粮食全烧了，等约翰带着人赶过来的时候，粮仓只剩下一片灰烬，烧焦的麦粒散落一地，百姓们蹲在地上哭，老人孩子的哭声连成一片。
“我的粮食啊！这是我全家一年的口粮啊！”
“黄四郎这个天杀的！他不让我们活啊！”
六子气得攥紧了拳头，就要带着人去攻碉楼，约翰伸手拦住了他，站在粮仓的灰烬前面，看着哭成一片的百姓，脸色沉得像水。
“噢，看在上帝的份上，黄四郎这个杂种，连百姓的口粮都烧，简直连西部的响马都不如。”约翰的译制片腔压着怒火，随即声音抬高，姜文式的短句传遍了整个粮仓：
“哭什么？”
“粮烧了，我们再种。”
“天塌不下来。”
百姓们抬起头，看着约翰，眼泪还挂在脸上。
约翰指着城外的那片荒地：“看见城外那片荒地没有？以前没人种，是因为没人会种。我在西部种过十年地，那地方比这荒十倍，我都能种出土豆玉米，养活一整个帮派。这片地，我带着你们种，三个月就能收粮食，够你们吃两年的。”
百姓们你看我我看你，都有点不信。那片荒地荒了几十年了，从来没人能种出东西来，张县长真能行？
约翰没多说，第二天一早就带着兄弟们和愿意跟着干的百姓，拿着锄头去了城外的荒地。他从仓库里翻出以前从西部带过来的土豆种子和玉米种子，教百姓们怎么深耕，怎么施肥，怎么修水渠引山上的水下来灌溉，都是西部农场最实用的技术。
六子和汤师爷也跟着干，汤师爷虽然身子弱，但是算账厉害，把种子、农具都算得清清楚楚，一点都不浪费。
没几天功夫，水渠就修好了，清水流进了荒地，地也翻好了，种子都种了下去。约翰还给百姓们发了之前缴获的粮食，每家每户都能领三个月的口粮，足够等到新粮收上来。
百姓们终于放下心来，干活更卖力了，每天天不亮就去地里干活，天黑了才回来，脸上都有了盼头。
半个月后，种子发芽了，绿油油的一片，看着就喜人。百姓们高兴得不行，凑钱给约翰送了一块匾，上面写着“鹅城青天”四个大字。
黄四郎在碉楼上看着城外绿油油的庄稼，气得牙都要咬碎了。他本来以为烧了粮食，百姓们肯定会内乱，会造反找张牧之的麻烦，没想到张牧之还有这本事，居然把荒地给种活了，还让百姓更拥护他了。
“老爷，现在怎么办啊？再这样下去，百姓都要被他拉拢完了，我们的粮食也快不够了。”管家站在旁边，小声问。
黄四郎咬着牙，眼神阴冷得很：“他不是有种吗？我让他种！去，把上游的水给我截了！我看他的庄稼喝什么！”
“是，老爷！”
第二天，百姓们发现水渠里的水突然干了，跑到上游一看，黄四郎的人建了个水坝，把水全截了，流不下来。
百姓们又急了，跑到县衙找约翰。约翰听完之后，笑了笑，一点都不着急：
“他截了上游的水。”
“我们就打井。”
“我在西部打了几十年的井，地下有没有水，我一脚就能踩出来。”
当天下午，约翰就带着人在地里找水，踩了几个地方，让兄弟们往下挖，挖了不到三丈，果然出水了，清冽冽的地下水往上冒，百姓们欢呼雀跃。
黄四郎接到消息的时候，正在吃饭，气得直接把碗摔了，一口饭都吃不下去。他现在是真的没办法了，断粮不行，断水也不行，援军也被打跑了，手下的人越来越少，碉楼里的粮食也快吃完了。
“张牧之！我跟你势不两立！”黄四郎咬着牙，一拳砸在桌子上。
而此时的田埂上，约翰正坐在土堆上，看着地里绿油油的庄稼，身边坐着六子和汤师爷，风一吹，麦苗晃得像波浪一样。
“爸，你真厉害，你居然还会种地。”六子咬着烤土豆，含糊不清地说。
约翰笑了，译制片腔带着点怀念：“噢，小子，我以前在西部的时候，帮派没钱了，我们就去农场帮人干活，种土豆、养牛、修房子，什么活没干过？这点事算什么。”
他抬头看向碉楼的方向，眼神冷了下来：
“等庄稼收了。”
“我们就去收了黄四郎的碉楼。”
“该算总账了。”
风刮过田野，带着麦苗的清香，胜利的曙光，已经看得见了。
