# 第一章：这该死的屎山代码

许安死的时候，正在修一个祖传的Bug。

那是凌晨三点十七分，心脏像被一只无形的大手狠狠攥住，剧痛顺着脊椎炸开。视网膜上最后残留的画面，是显示器上那行报错红字：`FATAL ERROR: Null Pointer Exception`。

“草，空指针异常……”

这是许安留在人世间的最后一句话。

……

再睁开眼时，许安以为自己还在公司那张散发着霉味的折叠床上。

但很快，职业本能让他察觉到了不对劲。

头顶的天花板不是公司那种廉价的矿棉板，而是一片发黄起皮的石灰墙，上面布满了像血管一样蔓延的黑色裂纹。空气中弥漫着一股陈旧的腐烂味道，像是放了半个月的外卖混合着下水道的馊味。

许安猛地坐起身，心脏狂跳。

“我没死？”他下意识地摸了摸胸口。心跳很快，快得不正常，每一下都撞击着肋骨，发出沉闷的咚咚声。

但他顾不上这些。他的目光死死盯着正对床铺的那面墙。

墙上贴着一张A4纸。纸张边缘已经泛黄卷曲，用某种暗红色的胶带——或者干涸的血迹——歪歪斜斜地粘在墙皮上。

借着窗外透进来的惨白月光，许安看清了上面的字。

**《幸福公寓住户守则》**

1.  **本公寓实行严格的宵禁制度。午夜12:00至次日凌晨6:00，所有住户禁止离开房间。违者后果自负。**
2.  **请保持邻里和睦。严禁在走廊大声喧哗、奔跑或使用重型机械。**
3.  **本公寓注重礼貌。当听到敲门声时，住户必须在一分钟内开门回应。拒绝开门将被视为不礼貌行为，房东有权进行惩罚。**
4.  **猫眼是用来确认访客身份的，请勿长时间注视猫眼，否则猫眼也会注视你。**
5.  **如果你在房间内看到红色的气球，请立即闭上眼睛数到十，那是前任房客留下的恶作剧。**

许安盯着这张纸看了足足三分钟。

作为一名资深的高级测试工程师，他的大脑在极度恐惧中反而进入了一种诡异的冷静状态——或者说，是一种名为“找茬”的职业病状态。

“这需求文档是谁写的？”许安嘴角抽搐了一下，声音沙哑，“逻辑全是坑。”

他伸出颤抖的手指，在第一条和第三条规则之间虚划了一条线。

“第一条说午夜12点后**禁止离开房间**。”
“第三条说听到敲门声**必须开门**。”

许安的瞳孔微微收缩。

如果午夜12点后有人敲门呢？

开门，意味着打破了房间的封闭性，在某种严格的逻辑判定中，这可能被视为“离开”的前置动作，或者至少是与外界建立了物理连接。而不开门，则直接违反了第三条。

“死锁（Deadlock）。”许安从牙缝里挤出这个词。

这是一个经典的逻辑陷阱。无论怎么选，都是死路一条。

就在这时，一阵剧烈的眩晕感袭来。

许安痛苦地捂住额头。眼前的世界突然开始扭曲。墙壁上的裂纹不再是裂纹，而是变成了无数细密、杂乱的字符流。那张泛黄的守则纸像信号不良的电视画面一样闪烁了一下，边缘出现了锯齿状的马赛克。

*`WARNING: Rendering_Lag_Detected`*

一行鲜红的半透明小字突兀地悬浮在空气中，紧接着又是一行：

*`Texture_Pack_Error: Wall_04.png not found`*

“什么鬼……”许安用力眨了眨眼。

幻觉？还是说……

他伸出手，试着去触碰那行悬浮的红字。手指穿透了字符，但指尖却传来一种微妙的静电刺痛感。

这不是幻觉。这是……底层代码？

许安环顾四周。在他眼中，这个阴森恐怖的房间正在发生质的变化。那把摇摇欲坠的木椅子，椅腿部分正在不断地在“木头材质”和“线框模型”之间切换；窗外的月光不是光，而是一束束不断刷新的白色数据流。

这个世界，是一个巨大的、破破烂烂的程序。

而且优化做得极差，到处都是补丁和溢出的内存。

“咚——”

一声沉闷的巨响打断了许安的观察。

声音来自门口。

许安浑身一僵，脖子像生锈的齿轮一样一点点转过去。

那扇斑驳的防盗门正在微微震动。

“咚——咚——”

敲门声再次响起。沉重，缓慢，每一次敲击都像是砸在许安的心口上。

许安下意识地看向墙上的挂钟。

时针和分针，精准地重合在“12”的位置。

午夜12点。

敲门声。

死锁触发了。

许安感到一股寒意从脚底直冲天灵盖。他的身体在生理性地颤抖，腿软得几乎站不住，但他的大脑却像一台高速运转的CPU，疯狂地处理着眼前的信息。

“咚！咚！咚！”

敲门声变得急促起来，仿佛门外的东西失去了耐心。防盗门发出不堪重负的吱呀声，门框周围的墙皮簌簌落下。

许安能感觉到，门外有一种恐怖的压迫感，那是某种无法用常理度量的存在。如果是在普通的恐怖片里，主角这时候应该已经尖叫着钻进床底下了。

但许安没有。

他扶着墙，强撑着发软的双腿，一步步挪向门口。

“别慌，别慌……”他在心里疯狂弹幕，“这就是个逻辑题。只要是程序，就一定有Bug。只要有Bug，就能卡过去。”

他走到门前，距离那扇颤抖的门板只有不到半米。

透过猫眼？不，规则第四条说了不能长时间注视猫眼。虽然不知道“长时间”的具体定义是几秒，但许安不想冒这个险。

“有人吗？”门外突然传来一个声音。

那声音听起来像是一个老太太，嘶哑，干瘪，但仔细听去，语调平得没有任何起伏，就像是……电子合成音。

“小伙子，开开门，我孙子的皮球踢到你家了。”

许安深吸一口气。

皮球？在这阴间公寓里踢球？这借口找得也太敷衍了，简直就像是随便从“借口库”里随机调取的一条文本。

“咚咚咚！开门！我知道你在里面！”

声音陡然变得尖利，门板被砸得向内凸起。

规则第三条：必须在一分钟内开门。

许安瞥了一眼挂钟。秒针已经走了半圈。

如果不做点什么，三十秒后，他就会因为违反规则被抹杀。如果开了门，门外这个东西——不管它是什么——绝对不会只是进来找皮球那么简单。

进退必死。

许安的手心全是冷汗。他在赌。赌这个世界的底层逻辑，依然遵循着代码的严谨性——哪怕是屎山代码，也是代码。

他清了清嗓子，对着门外大喊一声：

“我在！”

门外的敲击声戛然而止。

死一般的寂静。

过了几秒，那个嘶哑的声音再次响起，带着一丝疑惑和机械的卡顿：“在……就……开门……”

“我不能开门。”许安语速极快地说道，声音因为紧张而微微发颤，但逻辑清晰得可怕，“根据《幸福公寓住户守则》第一条，午夜12点后，住户**禁止离开房间**。”

门外的声音停顿了一下：“我……没让你……离开……我让你……开门……”

“开门这个动作，涉及到门扇的位移。”许安的大脑飞速运转，他盯着门缝，眼中闪烁着疯狂的光芒，“如果我把门打开，门扇就会向外或向内移动。如果向外开，门扇就离开了房间的物理范围；如果向内开，外界的空间就与内部空间连通，破坏了‘房间’作为独立封闭单元的定义。在严格的拓扑学定义下，开门等于打破了房间的边界。”

许安咽了口唾沫，继续胡扯——不，是进行逻辑攻击。

“而且，如果我开门，我就必须站在门口。门口是房间和走廊的临界点。根据量子力学的测不准原理，在这一瞬间，我既在房间里，也在房间外。这就构成了对‘禁止离开’这一状态的叠加态违背！”

门外陷入了长久的沉默。

许安能听到一阵细微的滋滋声，就像是电流短路的声音。

他眼前的视野中，门板的位置开始出现大量的红色乱码。

*`ERROR: Logic_Conflict_Detected`*
*`Processing... Processing...`*

那个东西正在试图解析许安的逻辑。

“但是……规则……第三条……”门外的声音变得断断续续，像是卡带了一样，“听到……敲门……必须……开门……”

“对！”许安大声打断它，“规则第三条要求我开门，规则第一条要求我保持房间封闭（禁止离开）。这两条规则在当前时间点（午夜12点）是互斥的！你作为执行者，要求我同时执行两个互相矛盾的指令！”

“这……是……违规……”

“不！违规的是你！”许安厉声喝道，尽管他的腿还在发抖，“你发出的指令导致了逻辑死锁！如果我开门，我违反第一条；如果我不开门，我违反第三条。无论我怎么做，都是错的。这意味着——”

许安深吸一口气，喊出了最后的杀手锏：

“这意味着**系统逻辑错误**！你的存在本身就是个Bug！你在诱导系统崩溃！”

轰！

门外突然传来一声爆响。

不是爆炸，而是某种东西瞬间崩塌的声音。

许安眼前的红色乱码瞬间爆发，铺天盖地。他看到门外的那个“存在”——一团扭曲的黑色阴影——剧烈地颤抖起来。

*`CRITICAL ERROR: Infinite_Loop`*
*`System_Protection: Terminating_Process_ID_7749`*

“不……不……逻辑……正……确……”

门外的声音变成了刺耳的电子杂音。紧接着，那团阴影像是被一只无形的手狠狠揉碎，化作无数破碎的像素点，消散在空气中。

走廊里恢复了死寂。

只有那扇变形的防盗门，静静地立在那里。

许安靠着墙，身体顺着墙壁滑落，瘫坐在地上。他大口大口地喘着粗气，冷汗浸透了背后的衣衫。

赌赢了。

他看着自己的双手，指尖还在微微颤抖。

刚才那一瞬间，他不仅看到了怪物的崩溃，还看到了更深层的东西——在怪物消散的地方，有一串淡蓝色的代码一闪而过。

*`Access_Granted: Logic_Override_Level_1`*

许安眨了眨眼。那行代码消失了，取而代之的是一种奇怪的感觉。他觉得自己的大脑里似乎多了一些东西，就像是……安装了一个新的插件。

他抬起头，看向墙上的守则。

原本平平无奇的A4纸，此刻在他眼中竟然浮现出了一个个半透明的文本框，上面标注着各种参数：

*`Object: Rule_Sheet`*
*`Authority: Level_3`*
*`Status: Active`*

许安扯了扯嘴角，露出了一个比哭还难看的笑容。

“这破游戏，”他低声骂道，“连个新手引导都没有，差评。”

他扶着墙站起来，目光投向那扇紧闭的房门。

第一关过了。但如果不搞清楚这个世界的底层逻辑，如果不把这个满是Bug的系统彻底重构一遍，他迟早会被玩死。

“行吧。”许安整理了一下凌乱的衣领，眼神逐渐变得锐利，“既然你们代码写得这么烂，那就别怪我卡Bug了。”

他伸手握住了门把手。

这一次，不是为了应付怪物，而是为了主动出击。

（本章完）
