# 第三章：影子里的贴图错误

公寓大厅就像是一个被遗弃的剧场。

昏黄的吊灯在头顶摇摇欲坠，投下斑驳的光影。几十个“住户”聚集在这里，有的穿着睡衣，有的穿着西装，还有的……穿着寿衣。

他们大多面无表情，像是一群等待指令的NPC。只有少数几个人眼神惊恐，显然是和许安一样的新人玩家。

大门紧闭，上面缠绕着生锈的铁链。

“滋滋——”

大厅角落里的老式广播突然响了起来。

“各位亲爱的住户，晚上好。”

那个声音嘶哑、干瘪，带着一种令人不适的电流杂音。

“我是你们的房东。今晚，我们来玩个小游戏。”

“在你们中间，混进了一只不干净的东西。它披着人皮，学着人话，想要混出公寓。”

“请在一小时内把它找出来。如果找不出来……嘿嘿，为了公寓的安全，我只能把你们全部清理掉了。”

“计时开始。”

广播戛然而止。大厅里的气氛瞬间凝固到了冰点。

“这特么是什么鬼游戏！”一个穿着西装的中年男人崩溃地大喊，“放我出去！我有钱！我可以给你们钱！”

他冲向大门，用力摇晃着铁链。

下一秒，一只苍白的手从黑暗中伸出，直接穿透了他的胸膛。

中年男人瞪大了眼睛，身体软软地倒了下去。那只手缩回黑暗中，仿佛从未出现过。

人群爆发出一阵尖叫。

许安站在角落里，冷冷地看着这一幕。

“这就是违规操作的下场。”苏糖舔了一口棒棒糖，语气轻松得像是在看电影，“未经允许试图离开副本，触发即死判定。”

雷猛咽了口唾沫，握紧了手中的消防斧：“那我们怎么办？真要找鬼？”

“当然。”许安推了推并不存在的眼镜，“这是唯一的通关条件。”

他的目光在人群中快速扫视。

几十个住户，每个人看起来都很正常——或者说，都很不正常。在这个充满了Bug的世界里，想要分辨谁是鬼，简直就像是在一堆乱码里找一个特定的字符。

“通常来说，鬼没有影子。”雷猛小声说道，“我们要不要看看谁没影子？”

“太低级了。”苏糖嗤笑一声，“这种新手村的设定，早在十年前的恐怖片里就被用烂了。在这个副本里，鬼肯定有影子，甚至可能比你的影子还黑。”

许安点了点头：“苏糖说得对。在这个世界，视觉是可以被欺骗的。但是……”

他的眼中闪过一丝精光。

“物理引擎是不会骗人的。”

“什么意思？”雷猛一脸懵逼。

“在这个虚拟世界里，光影效果是需要实时渲染的。”许安指了指头顶那盏摇摇欲坠的吊灯，“当光源移动时，物体的影子会根据透视原理发生形变。如果是实体，影子的拉伸和缩短会符合几何光学定律。但如果是‘鬼’……”

许安顿了顿，嘴角勾起一抹冷笑：“它的影子很可能只是一个贴图（Texture），是直接贴在地面上的。无论光源怎么动，那个贴图的形状都不会发生透视变化。”

雷猛听得云里雾里，但苏糖的眼睛却亮了。

“有点意思。”苏糖把玩着手中的兔子玩偶，“你是说，我们要让光源动起来？”

“对。”许安看向雷猛，“大个子，你的力气派上用场了。看到那盏吊灯了吗？我想让你把它晃起来。幅度越大越好。”

雷猛抬头看了看那盏离地三米高的吊灯，又看了看许安：“你确定？万一掉下来砸死人怎么办？”

“砸死人算我的。”许安淡淡地说道。

雷猛咬了咬牙，把斧头往地上一扔，助跑几步，猛地跳起来，抓住了吊灯的边缘。

“起——！”

随着雷猛的一声怒吼，沉重的吊灯开始剧烈晃动。

昏黄的光线在大厅里疯狂摇摆，所有人的影子都在地面上拉长、缩短、扭曲，像是一群群魔乱舞的幽灵。

住户们惊慌失措，尖叫声此起彼伏。

许安站在原地，双眼死死盯着地面。

在他的视野里，世界变成了一张巨大的网格。每一个影子都被标记上了坐标和矢量。

*`Shadow_01: Rendering... OK`*
*`Shadow_02: Rendering... OK`*
*`Shadow_03: Rendering... OK`*

大部分影子的变形都符合物理规律。

直到他的目光锁定在人群中央的一个老太太身上。

那个老太太穿着一件红色的碎花棉袄，手里拿着一个红苹果，正慈祥地看着周围惊慌的人群。

当光线扫过她时，她脚下的影子……纹丝不动。

就像是一块黑色的污渍，死死地粘在地上，无论光线角度如何变化，它始终保持着原本的形状。

*`Target: Unknown_Entity`*
*`Shadow_Render: Static_Texture (静态贴图)`*
*`Error: Perspective_Mismatch`*

“找到了。”许安低声说道。

就在这时，苏糖突然动了。

她像一只灵巧的猫，瞬间穿过人群，指着那个老太太大喊一声：“是她！她是鬼！”

许安眉头一皱。这丫头，抢功？

老太太缓缓转过头，浑浊的眼珠盯着苏糖，嘴角裂开一个诡异的弧度：“小姑娘，饭可以乱吃，话可不能乱说哦。”

“少废话！”苏糖冷笑一声，“你的影子根本没动！你是贴图怪！”

老太太脸上的笑容消失了。她手中的红苹果突然腐烂，化作一滩黑水。

“既然被发现了……”

老太太的声音变得尖利刺耳，身体猛地膨胀，原本慈祥的面孔瞬间扭曲成一张青面獠牙的鬼脸。她张开血盆大口，向苏糖扑了过去。

“小心！”雷猛大喊一声，想要冲过去救援，但距离太远了。

苏糖却站在原地没动，甚至还眨了眨眼。

就在鬼爪即将触碰到苏糖鼻尖的一瞬间——

“根据《幸福公寓住户守则》补充条款第7条！”

许安的声音突然在大厅里炸响。

“当住户指认鬼时，如果被指认者进行攻击行为，视为**默认身份**！系统将立即执行清除程序！”

老太太的动作僵在半空。

它的爪子距离苏糖只有一厘米，但再也无法前进分毫。

它的身体开始剧烈颤抖，无数红色的报错代码从它体内喷涌而出。

*`System_Alert: Identity_Confirmed`*
*`Action: Delete`*

“不……这不公平……你们卡Bug……”

老太太发出最后一声凄厉的惨叫，身体像破碎的玻璃一样炸裂开来，化作无数黑色的数据碎片，消散在空气中。

大厅里一片死寂。

苏糖拍了拍胸口，转过头对着许安甜甜一笑：“哎呀，好险。多亏了哥哥反应快。”

许安冷冷地看着她。

这丫头根本不是在抢功。她是在拿自己当诱饵，逼那个鬼现原形。因为如果没有攻击行为，单纯的指认可能无法触发系统的清除判定。

她在赌。赌许安能看穿她的意图，并且及时补上那条规则判定。

“下次再玩这种心跳游戏，我就不救你了。”许安面无表情地说道。

“知道啦。”苏糖吐了吐舌头，“不过，哥哥刚才那句‘补充条款第7条’是编的吧？守则上根本没有这一条。”

“系统逻辑是死的。”许安指了指自己的脑袋，“只要逻辑链闭环，系统就会默认执行。这就是所谓的‘言出法随’——当然，前提是你要懂代码。”

就在这时，大门上的铁链哗啦一声滑落。

沉重的大门缓缓打开，露出了外面漆黑的夜色。

“恭喜各位住户，游戏通关。”

广播里的声音再次响起，带着一丝遗憾，“看来这次的鬼不太聪明啊。那么，祝各位晚安。”

幸存的住户们争先恐后地涌出大门。

许安、雷猛和苏糖走在最后。

“外面是什么？”雷猛问道。

“不知道。”许安看着门外的黑暗，深吸了一口气，“但肯定比这里更糟糕。”

他迈出了大门。

在他身后，那座名为“幸福公寓”的建筑，正在像沙堡一样缓缓崩塌，化作无数绿色的代码流，消失在虚空中。

第一关，通关。

（本章完）
