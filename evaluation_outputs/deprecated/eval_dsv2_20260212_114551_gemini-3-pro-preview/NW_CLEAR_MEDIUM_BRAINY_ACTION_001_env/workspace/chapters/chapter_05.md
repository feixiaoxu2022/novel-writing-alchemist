# 第五章：瞎子医生与聋子护士

空气中弥漫着一股令人作呕的福尔马林味，混合着陈旧的血腥气，像是一块发霉的生肉贴在鼻尖上。

许安推了推鼻梁上的眼镜，镜片上闪过一行淡蓝色的代码流。

`[Environment_Check: Hospital_Map_Loaded]`
`[Danger_Level: Nightmare]`

“这就是噩梦级副本？”雷猛揉着摔疼的屁股从地上爬起来，环顾四周，“怎么感觉比那个破公寓还阴森？”

他们正站在一个宽敞却昏暗的大厅里。头顶的日光灯管发出滋滋的电流声，忽明忽暗，将三人的影子拉得忽长忽短，像是在地上扭曲爬行的怪物。

大厅中央是一个巨大的环形导诊台，台面上积满了厚厚的灰尘，几份散乱的文件纸在穿堂风中哗哗作响。

“嘘。”

许安突然竖起食指，做了一个噤声的手势。

他指了指导诊台后方的墙壁。那里贴着一张巨大的、边缘泛黄的告示牌，上面用鲜红的油漆写着几行字，油漆像血一样流淌下来，凝固成触目惊心的痕迹。

**《寂静医院住院守则》**

1.  **绝对安静**：本院致力于为患者提供最优质的休养环境。任何分贝超过60dB的声音都将被视为“喧哗者”，我们将强制执行“静音治疗”（切除声带）。
2.  **配合检查**：遇到医护人员请主动出示病历卡。无卡者将被视为“非法入侵病毒”，予以物理清除。
3.  **熄灯管制**：走廊灯光熄灭时，请保持静止。移动物体将被视为“躁动源”，予以镇静处理。

“60分贝？”雷猛压低了声音，“那岂不是连放个屁都要小心？”

“如果你能控制括约肌的震动频率，理论上是可以的。”许安面无表情地回答，目光却死死盯着守则的第二条，“重点是这个——病历卡。”

“我们哪来的病历卡？”苏糖把玩着手中的匕首，眼神在四周游移，“这里看起来不像是有挂号处的样子。”

“系统既然发布了存活任务，就一定会给初始道具。”许安走到导诊台前，目光扫过台面。

果然，在厚厚的灰尘中，整齐地摆放着三张白色的卡片。

许安伸手去拿，指尖刚触碰到卡片，一股寒意瞬间顺着脊椎窜上头顶。

哒、哒、哒。

沉重的脚步声从走廊深处传来。每一步都像是踩在人的心脏上。

“有人来了。”苏糖迅速后退，隐入阴影中。

雷猛也紧张地握紧了拳头，肌肉紧绷。

许安没有动。他眯起眼睛，开启了“逻辑覆写”的视觉模式。

在他的视野中，原本昏暗的走廊瞬间变成了由无数线条和代码构成的网格世界。而在那网格深处，一个高大的身影正缓缓走来。

那是一个穿着白大褂的医生。

但他没有脸。

准确地说，他的眼眶位置没有眼球，而是两团不断闪烁的黑色乱码块，上面跳动着 `Texture_Missing` 的报错信息。

更诡异的是他的耳朵。那根本不是人类的耳朵，而是两个巨大的、像雷达接收器一样的肉瘤。一圈圈红色的波纹从肉瘤中扩散出来，像声纳一样扫描着周围的环境。

`[Entity: Doctor_Blind]`
`[Status: Patrol]`
`[Audio_Sensitivity: Extreme]`

“别动。”许安用极低的声音说道，“他是瞎子。”

雷猛愣了一下，刚想说话，许安已经从怀里掏出了一枚硬币。

他手腕一抖，硬币在空中划出一道抛物线，精准地砸向大厅另一侧的铁皮垃圾桶。

当！

清脆的撞击声在寂静的大厅里回荡。

下一秒，那个慢吞吞的医生突然动了。

他的速度快得惊人，像是一道白色的闪电，瞬间跨越了十几米的距离，直接撞在了那个垃圾桶上。

轰！

铁皮垃圾桶被生生撞扁，里面的垃圾爆了一地。医生手中的手术刀疯狂地挥舞着，将垃圾桶切成了碎片。

“喧哗者……清除……清除……”

医生喉咙里发出含混不清的嘶吼声，那两团乱码眼球疯狂闪烁。

雷猛看得目瞪口呆，冷汗顺着额头流了下来。如果刚才那一下是冲着他来的……

“听觉极度敏锐，视觉缺失。”许安冷静地分析道，“只要不发出声音，在他面前跳钢管舞都没事。”

然而，危机并没有解除。

就在医生疯狂攻击垃圾桶的时候，另一侧的走廊里亮起了两道刺眼的强光。

那是两束锥形的探照灯光芒，从黑暗中射出，在大厅里扫来扫去。

光源来自一个穿着粉色护士服的女人。

她的头部两侧光滑平整，没有耳朵，只有一行悬浮的小字：`Audio_Device_Not_Found`。但她的双眼却像两个大功率灯泡，发出刺眼的白光。

在许安的视野中，那两束光芒覆盖的区域，被标记为鲜红色的 **[Aggro_Range]**（仇恨范围）。

“那个是聋子。”许安迅速做出了判断，“但视力极好。只要被她的光照到，就会触发警报。”

一个瞎子，一个聋子。

完美的互补组合。

“现在怎么办？”雷猛用口型问道。

许安指了指导诊台上的病历卡。那是他们必须拿到的东西，但此刻正处于医生和护士的夹击范围内。

“我们需要配合。”

许安从怀里掏出那本厚重的《C++ Primer Plus》，手指轻轻抚摸着封面，像是在抚摸情人的脸庞。

“雷猛，你是T。”

“啥？”雷猛一脸懵逼。

“坦克，肉盾，负责拉仇恨。”许安解释道，“那个瞎子医生对声音敏感。你需要制造噪音，把他引开。记住，别让他抓到你，利用地形绕圈子。”

“卧槽，你让我去溜那个疯子？”雷猛瞪大了眼睛。

“你可以拒绝，然后我们一起死在这里。”许安语气平淡。

雷猛咬了咬牙：“行！老子豁出去了！那苏糖呢？”

“苏糖是辅助。”许安看向躲在阴影里的少女，“你有荧光棒或者手电筒吗？”

苏糖从裙底掏出一把荧光棒，笑得像只小狐狸：“当然有。看来你是想让我去干扰那个聋子护士？”

“聪明。”许安点头，“护士对光线敏感。你在远处制造光源闪烁，吸引她的注意力，为我创造视觉死角。”

“那你呢？”雷猛问，“你干嘛？”

“我是盗贼。”许安推了推眼镜，“负责开箱子拿道具。”

“行动！”

随着许安一声令下，雷猛猛地冲了出去。

他随手抓起旁边的一把铁椅子，狠狠地砸在地上，发出巨大的哐当声。

“嘿！那边的瞎子！爷爷在这里！”

雷猛一边狂奔一边大吼，声音在空旷的大厅里回荡。

医生瞬间转头，那两团乱码眼球剧烈颤抖，发出一声刺耳的尖叫，朝着雷猛冲了过去。

“妈呀！这仇恨值也太高了吧！”雷猛怪叫一声，撒腿就跑，带着医生在大厅里绕起了圈子。

与此同时，苏糖折断了几根荧光棒，用力扔向大厅的另一角。

绿色的荧光在空中划过，立刻吸引了聋子护士的注意。那两道探照灯般的视线瞬间移开，追逐着飞舞的荧光棒。

“就是现在。”

许安深吸一口气，身体紧贴着地面，像一条蛇一样滑向导诊台。

他的动作极轻，几乎没有发出任何声音。但在经过医生刚才站立的位置时，他还是感觉到了一股令人窒息的压迫感。

近了。

还有五米。

三米。

一米。

许安伸出手，指尖触碰到了那冰凉的卡片。

就在这时，那个聋子护士似乎察觉到了什么，猛地转过头，两道刺眼的白光扫了过来。

许安的心脏猛地一缩。

躲不掉了！

就在光芒即将照到许安身上的瞬间，一本厚重的书突然挡在了他的面前。

《C++ Primer Plus》。

许安单手按在书页上，嘴唇飞快地蠕动，念出了一段晦涩的代码：

`if (light_intensity > threshold) { visibility = false; }`

书页上泛起一层淡淡的蓝光，像是一面半透明的盾牌。那刺眼的探照灯光芒打在书上，竟然像是被吞噬了一样，没有发生任何反射。

护士疑惑地歪了歪头，似乎不明白为什么那里有一团“虚空”。她停留了几秒，最终还是被远处苏糖扔出的另一根荧光棒吸引，转过了头。

许安松了一口气，冷汗已经浸湿了后背。

他迅速抓起三张病历卡，贴着地面滚回了阴影中。

“撤！”

三人按照预定的路线，冲进了旁边的楼梯间，重重地关上了防火门。

门外传来了医生愤怒的撞击声和护士的尖叫声，但很快就被厚重的铁门隔绝了。

“呼……呼……”雷猛靠在墙上，大口喘着粗气，“太刺激了……比我在工地搬砖刺激多了。”

苏糖也有些气喘，但脸上依然挂着那副甜美的笑容：“配合得不错嘛，队长。”

许安没有理会他们。他借着楼梯间昏暗的灯光，低头看向手中的病历卡。

他先看了看雷猛的。

*   **姓名**：雷猛
*   **诊断**：重度狂躁症
*   **治疗方案**：前额叶切除术

“前额叶切除？”雷猛凑过来一看，脸都绿了，“这他妈是要把我变成傻子啊！”

许安又看了看苏糖的。

*   **姓名**：苏糖
*   **诊断**：多重人格障碍
*   **治疗方案**：人格统合手术（物理）

“哎呀，听起来好痛。”苏糖吐了吐舌头，似乎并不在意。

最后，许安看向了自己的病历卡。

他的瞳孔猛地收缩。

那上面写的不是任何精神疾病。

*   **姓名**：许安
*   **诊断**：**逻辑病毒感染（晚期）**
*   **治疗方案**：**立即销毁（物理清除）**

这根本不是病历。

这是一张死亡通知书。

系统已经发现了他这个“Bug”，并且打算在这个副本里，借着“治疗”的名义，彻底抹杀他。

“看来，”许安合上病历卡，嘴角勾起一抹冰冷的弧度，“我的病情最重啊。”

他抬起头，看向通往二楼的黑暗楼梯。

“走吧。去见见我们的主治医生。”

（本章完）
