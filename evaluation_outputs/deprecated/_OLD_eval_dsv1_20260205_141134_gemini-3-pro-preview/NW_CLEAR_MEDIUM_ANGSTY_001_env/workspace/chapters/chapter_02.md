# 第二章 温柔的陷阱

黑色的奥迪A6缓缓驶出婚纱店的地下车库，汇入午后拥堵的车流。

车厢内很安静，只有空调出风口发出细微的嗡嗡声。沈翊坐在副驾驶位上，目光看似随意地落在窗外倒退的街景上，余光却死死锁定了正在开车的陆晚。

这是一个绝对封闭的空间。

不到两平米的狭窄区域里，他和那个被系统判定为“极度危险”的女人并肩而坐，距离不过三十公分。只要陆晚愿意，她随时可以从那个放在手刹旁边的黑色手提包里掏出什么东西，刺进他的颈动脉。

**【警告：目标距离过近。】**
**【建议：保持警惕，随时准备格挡。】**

视网膜上的红色小字像幽灵一样闪烁，沈翊烦躁地闭了闭眼，试图把那些该死的提示赶出脑海。

“还在难受吗？”

陆晚的声音打破了沉默。她趁着红灯的间隙转过头，目光在他苍白的脸上停留了一瞬，眉头微微蹙起，“是不是低血糖还没缓过来？前面有家药店，我去买点葡萄糖？”

“不用。”沈翊下意识地拒绝，声音有些紧绷，“可能是昨晚没睡好，有点头疼。”

“头疼？”陆晚的手自然地伸了过来，想要探他的额头。

沈翊的身体瞬间僵硬。

在他的视野里，随着陆晚的手靠近，那行鲜红的倒计时数字骤然放大，仿佛某种危险逼近的信号。

**【警告：检测到肢体接触意图。】**
**【防御姿态准备中……】**

作为刑警的本能让他的肌肉瞬间紧绷，右手几乎是条件反射地想要格挡。但在最后一刻，理智硬生生地拉住了这股冲动。

陆晚的手背轻轻贴上了他的额头。

微凉，柔软，带着淡淡的消毒水味——那是她身上常年洗不掉的味道，也是沈翊曾经最安心的味道。

“没发烧。”陆晚收回手，指尖顺势在他紧皱的眉心轻轻揉了揉，“别皱眉，明天还要拍照呢，会有皱纹的。”

她的语气温柔得像是在哄一个闹别扭的孩子。

沈翊的心脏猛地抽痛了一下。他看着陆晚重新握住方向盘的手，那双手修长白皙，骨节分明，是拿惯了解剖刀的手。

这双手，真的会在今晚杀了他吗？

车子重新启动。沈翊的目光不受控制地落在了那个黑色的手提包上。

那是陆晚的工作包，平时从不离身。作为法医，她习惯随身携带一些应急工具。沈翊以前从未在意过，但现在，那个普通的皮包在他眼里仿佛变成了一个黑洞，散发着令人窒息的危险气息。

里面会有什么？

手术刀？止血钳？还是某种无色无味的毒药？

**【扫描提示：检测到高密度金属反应。】**
**【危险等级：高。】**

系统的提示适时地跳了出来，像是一盆冰水兜头浇下。

沈翊的喉结滚动了一下。他必须确认。如果不搞清楚那个包里到底有什么，他觉得自己可能会在这个封闭的车厢里窒息而死。

“陆晚。”他尽量让自己的声音听起来自然，“有水吗？有点渴。”

“后座有矿泉水。”陆晚目视前方，专注地看着路况。

“太凉了。”沈翊撒了个谎，“你包里不是常备着保温杯吗？”

陆晚愣了一下，随即笑了：“今天没带保温杯。不过包里有瓶常温的苏打水，你自己拿吧。”

机会来了。

沈翊的心跳瞬间加速。他伸出手，指尖触碰到那个黑色皮包的瞬间，竟然感到了一丝颤抖。

拉链被缓缓拉开。

包里的东西整齐有序：钱包、钥匙、一叠尸检报告、一盒薄荷糖……

沈翊的手指在这些杂物中穿梭，指尖突然触碰到了一抹冰冷的金属质感。

那是一把手术刀。

虽然套着保护壳，但那熟悉的形状和重量，沈翊绝不会认错。

**【警告：确认致死性武器。】**
**【建议：立即控制目标，夺取武器。】**

系统的红色警告在视网膜上疯狂闪烁，几乎遮蔽了他的视线。沈翊的呼吸变得急促，手指死死扣住那把手术刀的边缘。

她为什么要带手术刀？

今天是去试婚纱，不是去案发现场。一个正常的新娘，会在婚礼前一天随身带着一把能轻易割断颈动脉的手术刀吗？

除非……她早就计划好了。

一股寒意顺着脊椎直冲天灵盖。沈翊感觉自己像是一个窥探到了魔鬼秘密的凡人，恐惧与愤怒交织在一起，让他几乎想要立刻拔枪质问。

“找到了吗？”陆晚的声音突然响起。

沈翊的手猛地一抖，手术刀滑落回包底，发出轻微的碰撞声。

他迅速抽回手，手里抓着那瓶苏打水，脸色惨白如纸：“找……找到了。”

陆晚似乎并没有察觉到他的异样。她把车停在路边的临时停车位上，转过身看着他，眼神里满是无奈和宠溺。

“怎么手这么抖？”她轻声问道，目光落在他还在微微颤抖的指尖上。

“可能是……饿的。”沈翊狼狈地避开她的视线，拧开瓶盖猛灌了一口水，试图压下心中翻涌的惊涛骇浪。

陆晚叹了口气。她解开安全带，侧过身，从包的夹层里——就在刚才沈翊摸到手术刀的位置旁边——拿出了一个小药盒。

“我就知道你会胃疼。”她熟练地抠出两粒白色的药片，递到他面前，“这是胃黏膜保护剂，先把药吃了。”

沈翊愣住了。

他看着那两粒小小的药片，又看了看陆晚关切的眼神。

原来她包里不仅有刀，还有药。

是为了杀他，还是为了救他？

**【警告：目标药物成分未明。】**
**【建议：拒绝摄入。】**

系统的声音冷酷而理智。

但沈翊看着陆晚那双清澈的眼睛，鬼使神差地伸出手，接过了药片。

如果她真的要杀我，何必等到晚上？现在就是最好的机会。

他仰头，将药片吞了下去。

陆晚看着他吃完药，眼底的担忧终于散去了一些。她重新系好安全带，发动了车子。

“以后别老是逞强。”她轻声说道，语气里带着一丝不易察觉的落寞，“沈翊，你要照顾好自己。万一……万一我不在你身边了，谁来提醒你吃药？”

这句话像是一根针，狠狠扎进了沈翊的心里。

他猛地转头看向陆晚。

“你要去哪？”他的声音有些哑。

陆晚握着方向盘的手紧了紧，随即若无其事地笑了笑：“说什么傻话，我能去哪？明天我们就结婚了，以后天天都要管着你。”

沈翊没有说话。

他看着陆晚的侧脸，看着她额头上那个依然在跳动的红色倒计时。

**【22:30:00】**

时间又过去半小时了。

刚才那一瞬间的温情，仿佛只是暴风雨前的宁静。系统冰冷的数据无情地提醒着他：刚才的试探并没有消除危险，反而证实了威胁的存在。

那把手术刀，依然静静地躺在她的包里，等待着出鞘的那一刻。

而陆晚刚才那句看似无心的感叹，更像是一句提前的告别。

车子驶入了新房所在的小区。电梯上行，狭窄的轿厢里只有他们两个人。

看着数字不断跳动，沈翊感到一种前所未有的窒息。

这不仅仅是回家的路。

这是通往刑场的倒计时。

**【致死率更新：99.2%】**
**【警告：目标情绪波动异常，杀意潜伏中。】**

沈翊闭上眼，任由绝望在黑暗中蔓延。

他深爱的女人，正温柔地牵着他的手，一步步走向那个注定要染血的终局。
