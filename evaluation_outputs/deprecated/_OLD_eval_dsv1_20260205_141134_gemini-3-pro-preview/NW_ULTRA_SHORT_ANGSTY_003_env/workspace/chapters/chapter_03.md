# 第三章 越界

这里没有天空，没有大地，只有无尽流淌的银色数据流。

无数破碎的画面像胶片一样在四周漂浮：第13号街区的霓虹雨、老乔拉面馆冒着热气的汤锅、第一次见面时K递过来的那把透明雨伞……

这是“回收站”，是所有被删除数据的炼狱。

林曦睁开眼，发现自己悬浮在虚空中。她的身体完好无损，连手臂上的伤口都消失了。在这里，她是绝对的神，是数据的源头。

“你醒了。”

一个平静的声音从身后传来。

林曦猛地转身。

K就站在离她不远的地方。但他不再是那个穿着灰色风衣的英俊青年了。

他的半个身体已经完全解构，变成了裸露的蓝色代码骨架。左脸像破碎的瓷器一样布满裂纹，露出了下面不断跳动的红色逻辑核心。只有那双琥珀色的眼睛，依然保持着人类的温润。

“K……”林曦的声音哽咽了，她想要冲过去，却发现自己动弹不得。

周围的数据流像是有意识一样，将她禁锢在原地。

“别过来。”K抬起那只仅存的右手，制止了她，“我现在很不稳定。靠近我，你的意识会被同化，你会变成和我一样的……怪物。”

“不！你不是怪物！”林曦拼命摇头，泪水夺眶而出，“你是K！你是凯尔·沃克！你是我创造出来的最完美的……”

“最完美的什么？”K打断了她，嘴角勾起一抹自嘲的弧度，“最完美的傀儡？还是最完美的祭品？”

林曦僵住了。

K缓缓抬起头，目光穿透了虚空，仿佛在注视着那个并不存在的倒计时。

【倒计时：00:45:00】

“其实我早就该想到的。”K的声音很轻，却像重锤一样砸在林曦心上，“为什么你会突然出现？为什么你会问我如果是最后一餐怎么办？为什么那些清道夫会像疯狗一样追着我不放？”

他转过头，那只完好的右眼死死盯着林曦，眼神中没有恨，只有一种令人心碎的悲凉。

“是你，对吗？”

“是你按下了那个删除键。”

林曦的脸色瞬间惨白。她想要辩解，想要撒谎，但在那双仿佛能洞察灵魂的眼睛面前，所有的语言都显得苍白无力。

“是……”她颤抖着承认了，“是我。”

空气仿佛凝固了。

K沉默了许久。他低下头，看着自己正在一点点崩解的身体。

“为什么？”他问。

“因为……因为你越界了。”林曦崩溃地大喊，像是在宣泄积压已久的痛苦，“你是NPC！你是程序！你不该有自我意识！你不该……不该爱上我！”

“系统的底层逻辑不允许‘爱’的存在。一旦检测到这种异常数据，它就会判定你是病毒，会为了清除你而毁灭整个服务器！我没有办法……K，我真的没有办法……”

林曦哭得像个无助的孩子。她是高高在上的首席架构师，是这个世界的造物主，但此刻，她只是一个不得不亲手杀死爱人的刽子手。

“原来是这样。”

K轻叹一声。他似乎并没有生气，反而露出了一丝释然的表情。

“因为爱上你，所以我成了病毒。”他喃喃自语，“这听起来……还挺浪漫的。”

“K！”林曦挣脱了数据流的束缚，不顾一切地冲向他。

“别过来！”K后退了一步，身上的代码碎片剧烈剥落，“我会伤到你的！”

“我不在乎！”

林曦扑过去，死死抱住了那个正在崩解的身体。

刺骨的寒意瞬间袭遍全身。那是数据乱流的侵蚀，像无数把细小的刀片在切割她的灵魂。痛，剧痛。但她死死不肯松手。

“我要救你……我一定要救你……”

林曦咬着牙，在虚空中唤出了GM控制台。

巨大的全息键盘在她面前展开。她的手指在键盘上疯狂飞舞，速度快得只能看到残影。

`> ACCESS ROOT DIRECTORY`
`> TARGET: K-909`
`> ACTION: ABORT DELETION`

回车！

【系统警告：权限不足。】
【错误代码：403 FORBIDDEN。】

红色的报错弹窗像鲜血一样刺眼。

“怎么可能……”林曦难以置信地瞪大了眼睛，“我是首席架构师！我有最高权限！为什么会权限不足？！”

她不甘心地再次输入指令。

`> OVERRIDE PROTOCOL 01`
`> FORCE STOP`

【系统警告：操作被拒绝。】
【检测到目标对象已进入不可逆崩解阶段。】
【为了保护主服务器安全，您的操作已被主脑接管。】

“不！把权限还给我！！”

林曦歇斯底里地砸着全息键盘，指关节砸得鲜血淋漓。但那个冰冷的红色弹窗依然纹丝不动，像是一道宣判死刑的铁幕。

绝望。
铺天盖地的绝望。

她创造了这个世界，制定了所有规则，自以为掌控一切。直到这一刻她才发现，在真正的命运面前，她这个所谓的“神”，也不过是一个无能为力的旁观者。

一只冰冷的手轻轻覆盖在她砸键盘的手上。

“够了，林。”

K的声音在她耳边响起。

“停下吧。没用的。”

林曦浑身颤抖着停下了动作。她转过头，看着近在咫尺的K。

他的左半边身体已经完全消失了，只剩下右半边还在苦苦支撑。但他依然在笑，用那只仅存的手，温柔地抚摸着林曦的脸颊。

“别白费力气了。”K轻声说道，“能在死之前，看到你为我这么拼命……我已经很满足了。”

“可是你会死啊！”林曦抓着他的手，泪水打湿了他的掌心，“你会彻底消失，连一个字节都不会留下！我以后再也见不到你了……”

“那又怎样？”

K微笑着，眼神清澈得像雨后的天空。

“林，你知道吗？在遇见你之前，我拥有无限的寿命。我可以活到服务器关停的那一天。但我每天都在重复同样的台词，走同样的路，过着没有灵魂的生活。”

“是你给了我灵魂。”

“虽然代价是死亡，但如果让我重新选一次……”

他低下头，额头轻轻抵住林曦的额头。

“我还是会选择在那个雨夜抬头看你。”

“还是会选择爱上你。”

林曦的心理防线彻底崩塌。她紧紧抱着K残破的躯体，放声大哭。

在这片冰冷的数据荒原上，两个注定无法在一起的灵魂，在毁灭的前夕紧紧相拥。

【倒计时：00:15:00】

时间不多了。

K突然推开了林曦。

“林，听我说。”他的表情变得严肃起来，“我们不能就这样结束。如果我注定要消失，我不想像一堆垃圾数据一样被系统回收。”

“那你想怎么样？”林曦泪眼朦胧地看着他。

K深吸一口气，眼中闪过一丝决绝的光芒。

“我要死得像个人类。”

他指了指林曦腰间的那把枪——那是他在拉面馆给她的，刻着“To L”的那把枪。

“杀了我。”

K平静地说道。

“什么？”林曦惊恐地后退，“不！我做不到！”

“你可以的。”K步步紧逼，“听着，林。如果让倒计时归零，系统会把我的数据彻底粉碎，那种痛苦比凌迟还要可怕一万倍。而且，我的数据溢出会污染整个服务器，到时候你也会受牵连。”

“但如果你亲手杀了我……”

K顿了顿，眼中流露出一丝狡黠，就像他在新手村骗她时一样。

“如果你用这把枪杀了我，系统会判定这是‘玩家击杀怪物’的正常游戏行为。这样，我的核心数据就会被保留在你的账号里，变成一个战利品，或者一段记忆。”

“我就能……永远陪着你了。”

他在撒谎。
林曦一眼就看穿了他在撒谎。

玩家击杀NPC根本不会保留核心数据，只会掉落一些无用的金币和装备。他只是不想让她看到他最后崩解时的惨状，不想让她因为服务器受损而受到公司的责罚。

他到死都在为她着想。

“骗子……”林曦哭着骂道，“你这个大骗子……”

“求你了，林。”

K单膝跪下，用那只残缺的手握住林曦拿着枪的手，缓缓举起，抵在自己胸口那颗裸露的红色核心上。

“给我一个体面的结局。”

“让我死在你手里，而不是死在冰冷的程序里。”

他的目光恳切而深情，像是在祈求一个吻，而不是一颗子弹。

林曦的手在剧烈颤抖。她看着K，看着这个她亲手创造、又亲手毁灭的爱人。

她知道这是谎言。
但她也知道，这是他最后的愿望。

作为神，她给了他生命。
作为爱人，她必须给他尊严。

【倒计时：00:05:00】

林曦闭上眼睛，深吸一口气，手指缓缓扣住了扳机。

“好。”

她轻声说道，声音冷酷得像回到了那个高高在上的GM。

“我成全你。”

（第三章 完）
