# 第二章 县长上任，鹅城禁酒

鹅城县衙，历来是铁打的衙门流水的官。但这一回，流进来的不是官，是一股子带着牛粪味和火药味的龙卷风。

汤师爷抱着那本《康熙字典》，愁眉苦脸地站在大堂下。他那身长衫已经被汗浸透了，不是热的，是吓的。

大堂正中央的“明镜高悬”匾额下，原本属于县长的太师椅不见了，取而代之的是一个用几个弹药箱垒起来的简易吧台。约翰·马斯顿坐在吧台后面，手里擦着那把左轮手枪，脚边放着一瓶不知从哪搞来的劣质烧酒。

“县长……哦不，大当家的。”汤师爷擦了擦额头的汗，小心翼翼地开口，“咱们既然进了城，那就是官了。官有官的体面，您这把衙门改成……改成马厩，是不是有点不合规矩？”

约翰抬起眼皮，冷冷地看了他一眼：“规矩？在西部，枪就是规矩。”

“是是是，枪是规矩。”汤师爷赔着笑，“可咱们来鹅城是为了赚钱啊！得巧立名目，拉拢豪绅，缴税捐款，哪怕是跪着要饭……”

“砰！”

约翰把左轮手枪重重地拍在弹药箱上，震得那瓶烧酒跳了一下。

“我不跪。”约翰站起身，走到大堂门口，看着外面烈日下的鹅城，“范德林德帮的人，从来不跪。我们只抢。”

“抢？”汤师爷吓得差点跪下，“抢谁啊？百姓成穷鬼了，没油水了！”

“抢有钱的。”约翰指了指远处那座碉楼，“黄四郎。”

汤师爷倒吸一口凉气：“那可是黄四郎！南国一霸！您这是要虎口拔牙啊！”

“拔牙？”约翰嘴角勾起一丝冷笑，“我要拔的是他的皮。”

这时，六子兴冲冲地跑了进来，手里拿着一张刚写好的告示，墨迹还没干。

“爹！告示写好了！”六子把告示往汤师爷怀里一塞，“您给润色润色？”

汤师爷展开一看，差点没背过气去。

那告示上歪歪扭扭地写着几行字：

**鹅城新律（范德林德帮暂行版）**

1.  **全城禁酒**：除县衙特供外，严禁私自酿酒、卖酒。违者没收作案工具（包括嘴）。
2.  **禁止随地吐痰**：凡随地吐痰者，视为发起决斗挑战。县长及其卫队有权当场击毙。
3.  **通缉令**：悬赏通缉恶霸黄四郎，赏金：5000大洋（死活不论）。罪名：长得太丑，且疑似绑架良家妇男（亚瑟·摩根）。

“这……这……”汤师爷手都在抖，“这成何体统啊！禁酒也就算了，这随地吐痰就要决斗？还有这通缉令，黄四郎是本地乡绅，您通缉他？这不等于直接宣战吗？”

“就是要宣战。”约翰走过来，一把夺过告示，“贴出去。贴满全城。我要让黄四郎知道，这鹅城现在姓马斯顿了。”

“可是县长，咱们人手不够啊！”汤师爷苦着脸，“咱们就三个人，黄四郎有团练教头，有几百号人枪……”

“兵不在多，在精。”约翰吹了一声口哨。

院子里，几匹夸特马打了个响鼻。马鞍旁挂着的不是普通的马刀，而是成捆的炸药和雷管。

“而且，”约翰拍了拍汤师爷的肩膀，力道大得让师爷龇牙咧嘴，“谁说我们只有三个人？只要有了钱，有了枪，鹅城的百姓就是我们的帮派成员。”

“您是要……发动群众？”汤师爷眼珠子一转，似乎嗅到了一丝不同的味道。

“我是要给他们一个机会。”约翰看着门外那些探头探脑、面黄肌瘦的百姓，“一个像人一样活着的、能挺直腰杆开枪的机会。”

当天下午，鹅城炸了锅。

那张荒诞的告示贴满了大街小巷。百姓们围在告示前，指指点点，不敢相信自己的眼睛。

“随地吐痰就要决斗？这新县长是疯子吧？”
“通缉黄老爷？天哪，这天要塌了！”

就在这时，一队黄家的团练大摇大摆地走了过来。领头的正是那个被削了耳朵的胡万，头上缠着厚厚的绷带，像个印度阿三。

“看什么看！都散开！”胡万挥舞着手里的短棍，驱赶着人群，“撕了！都给我撕了！什么狗屁新律，在鹅城，黄老爷的话才是律！”

他伸手就要去撕墙上的告示。

“咳——呸！”

一口浓痰，精准地吐在了胡万那双擦得锃亮的皮鞋上。

胡万僵住了。周围的百姓也僵住了。

所有人顺着痰飞来的方向看去。只见六子靠在街角的柱子上，手里转着那把左轮手枪，一脸挑衅地看着胡万。

“哎呀，不好意思。”六子笑嘻嘻地说，“嗓子痒。按照新律，我是不是发起决斗了？”

胡万气得浑身发抖，但他看着六子手里那把黑洞洞的枪，昨天耳朵飞掉的剧痛瞬间涌上心头。他下意识地捂住绷带，往后退了一步。

“你……你别乱来！我没答应决斗！”胡万色厉内荏地吼道。

“哦？不答应？”六子收起笑容，眼神瞬间变得冰冷，“不答应决斗，那就是认怂了。认怂，就得守规矩。”

他指了指地上的那口痰：“擦干净。”

胡万瞪大了眼睛：“你让我擦……”

“砰！”

一颗子弹打在胡万脚边，溅起的石子崩到了他的脸上。

“擦。”六子淡淡地说。

胡万咬着牙，脸涨成了猪肝色。在几十双百姓眼睛的注视下，在黑洞洞的枪口威逼下，他缓缓蹲下身，用袖子擦去了鞋上的痰。

人群中爆发出一阵压抑的哄笑声。那是鹅城百姓许久未曾有过的笑声，带着一丝解气，也带着一丝对新秩序的试探。

碉楼上，黄四郎放下手中的望远镜，脸色阴沉得能滴出水来。

“好一个下马威。”黄四郎冷冷地说，“禁酒？决斗？通缉我？这个张麻子，不按套路出牌啊。”

站在他身后的替身依旧沉默不语，只是在听到“决斗”两个字时，手指微微抽动了一下。

“老爷，”胡千在一旁躬身道，“要不要今晚带人去县衙，把他们……”他做了一个抹脖子的动作。

“不。”黄四郎摆摆手，眼中闪过一丝狡黠的光芒，“既然他想玩西部的规矩，那我就陪他玩玩。他不是想找人吗？那就让他找。”

黄四郎转过身，看着那个沉默的替身，嘴角勾起一抹残忍的笑。

“去，把那件东西拿出来。”

“哪件？”

“那顶帽子。”黄四郎轻声说，“那顶沾着血的、破旧的牛仔帽。今晚，我要请县长赴宴。鸿门宴，怎么能没有见面礼呢？”

替身猛地抬起头，空洞的眼神中第一次出现了剧烈的波动。他死死盯着黄四郎的嘴唇，仿佛在确认那个词。

帽子。

那是他梦魇中唯一清晰的物品。

县衙里，约翰正对着一张鹅城地图发呆。地图上被他画满了红圈，每一个红圈都代表着黄四郎的一处产业。

“爹，”六子哼着小曲走了进来，“胡万那孙子怂了！真解气！”

约翰没有回头，他的手指停留在地图上的“碉楼”位置。

“六子，”约翰突然问道，“你还记得亚瑟长什么样吗？”

六子愣了一下，挠挠头：“记得啊。大胡子，壮得像头熊，笑起来像个傻大哥，但开枪的时候像个神。”

“是啊。”约翰低声喃喃，“像个神。”

他从怀里掏出一张泛黄的照片。照片上，一群人站在荒野的营地前，笑得肆无忌惮。站在最中间的那个男人，戴着牛仔帽，眼神坚毅而温柔。

约翰的手指轻轻抚过照片上那个男人的脸。

“等着我，亚瑟。”

门外，汤师爷慌慌张张地跑了进来，手里拿着一张大红请帖。

“县长！县长！不好了……哦不，是好了！”汤师爷语无伦次地喊道，“黄四郎……黄四郎请您赴宴！就在今晚！碉楼！”

约翰接过请帖，看了一眼上面龙飞凤舞的大字，嘴角勾起一抹冷笑。

“终于来了。”

他把请帖往桌上一扔，拿起那把左轮手枪，插进枪套。

“六子，备马。”

“去哪？”

“赴宴。”约翰整理了一下衣领，眼神锐利如刀，“去看看这位黄老爷，到底给咱们准备了什么好酒。”

“还有，”约翰顿了顿，看了一眼汤师爷，“师爷，你也去。”

“我？”汤师爷指着自己的鼻子，一脸苦相，“我就不去了吧？我这身子骨，经不起折腾……”

“你是师爷，得给我翻译。”约翰拍了拍师爷的肩膀，“翻译翻译，什么叫惊喜。”

汤师爷一愣：“惊喜？”

“对。”约翰大步向外走去，“我要看看，黄四郎能给我什么惊喜。”

夕阳西下，将县衙的影子拉得老长。鹅城的夜，要来了。
