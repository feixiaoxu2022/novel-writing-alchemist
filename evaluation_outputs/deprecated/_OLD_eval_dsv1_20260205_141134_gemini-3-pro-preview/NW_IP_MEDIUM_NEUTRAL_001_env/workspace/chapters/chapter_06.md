# 第六章 师爷的屁股在树上

从山洞逃出来后，约翰三人并没有直接回县衙。

因为鹅城变天了。

黄四郎封锁了全城，大街小巷贴满了约翰和六子的通缉令。罪名是：勾结麻匪，炸毁矿山，意图谋反。

“这下好了。”汤师爷躲在一处废弃的磨坊里，愁眉苦脸地啃着半个冷馒头，“县长成麻匪了，麻匪成县长了。这世道，乱套了！”

约翰坐在磨盘上，借着月光翻看那本日记。他在寻找，寻找那个能彻底唤醒亚瑟的开关。

“师爷，”约翰突然开口，“你刚才说，那条铁轨通向黄府后花园？”

“是啊。”汤师爷咽下馒头，“那是黄老爷的逃生通道。万一哪天鹅城守不住了，他就坐着矿车跑路。”

“那他为什么要把亚瑟藏在那？”

汤师爷愣了一下，眼神有些闪烁：“这……这我哪知道啊……”

“你在撒谎。”约翰合上日记，目光如炬，“师爷，这一路上你都在撒谎。你知道的远比你说的多。”

汤师爷浑身一颤，手里的馒头掉在地上。

“我……我……”

“那块怀表。”约翰指了指师爷鼓鼓囊囊的胸口，“从刚才在山洞里开始，你就一直捂着它。拿出来。”

汤师爷下意识地捂住胸口，连连后退：“没……没什么怀表！这是我娘留给我的……”

“砰！”

约翰拔枪，子弹打在师爷脚边的地面上。

“拿出来。”

汤师爷哆哆嗦嗦地从怀里掏出一个金灿灿的怀表。那不是普通的怀表，表盖上刻着一行小字：*To Arthur, from Mary.*（给亚瑟，玛丽赠）。

约翰接过怀表，打开表盖。里面是一张泛黄的小照片，一个美丽的女人微笑着。

“这是亚瑟的东西。”约翰的声音低沉，“怎么会在你手里？”

汤师爷扑通一声跪在地上：“县长饶命啊！这是……这是黄老爷给我的！他说只要我盯着您，把您的行踪告诉他，事成之后，这块表里的秘密就归我！”

“秘密？”

“这表里藏着一张地图！”汤师爷哭丧着脸，“是亚瑟当年埋藏帮派宝藏的地图！黄老爷想要那笔钱，但他解不开这表的机关，所以才……”

“所以才留着亚瑟，想逼他说出密码。”约翰冷笑一声，“而你，为了这笔钱，出卖了我们。”

“我错了！我真的错了！”汤师爷磕头如捣蒜，“县长，您看在我这一路上没有功劳也有苦劳的份上，饶了我这条狗命吧！”

约翰看着手里的怀表，又看了看跪在地上的师爷。

“起来吧。”约翰收起怀表，“我不杀你。”

汤师爷如蒙大赦，连滚带爬地站起来：“谢县长不杀之恩！谢县长……”

“但是，”约翰话锋一转，“你得帮我做最后一件事。”

“您说！上刀山下火海，我马邦德绝不皱一下眉头！”

“去给黄四郎送个信。”约翰从怀里掏出一张纸，刷刷刷写了几行字，“告诉他，今晚子时，我在教堂钟楼等他。我要用这块怀表，换亚瑟。”

汤师爷一愣：“这……这不是自投罗网吗？”

“按我说的做。”约翰把信塞进师爷怀里，“去吧。”

看着师爷离去的背影，六子有些担心：“爹，这老小子靠不住啊。万一他把咱们卖了……”

“他肯定会卖了我们。”约翰淡淡地说，“这就是他的本性。”

“那您还让他去？”

“因为只有他死了，亚瑟才会信。”约翰摸了摸那块怀表，“这块表，是亚瑟最后的软肋。也是唤醒他的最后一把钥匙。”

子时。

鹅城的教堂钟楼，孤零零地耸立在夜色中。

约翰站在钟楼顶层，风吹得他的风衣猎猎作响。他手里拿着那块怀表，静静地等待着。

楼下，传来了密集的脚步声。

黄四郎来了。带着他的团练，还有那个沉默的影子——亚瑟。

“张县长！”黄四郎的声音从楼下传来，“别来无恙啊！听说你想跟我做笔交易？”

约翰探出头，看着楼下黑压压的人群。

“黄老爷，”约翰高声喊道，“表在我手里。人呢？”

“人在这。”黄四郎指了指身边的亚瑟，“不过，我怎么知道你的表是真的？”

“你可以让师爷验验货。”约翰把怀表扔了下去。

怀表在空中划出一道金色的弧线，准确地落在了汤师爷的手里。

汤师爷接住怀表，打开一看，脸上露出了贪婪的笑容：“是真的！是真的！黄老爷，这表是真的！”

“很好。”黄四郎满意地点点头，“师爷，你立了大功了。”

“谢老爷！谢老爷！”汤师爷捧着怀表，像捧着祖宗牌位一样。

就在这时，异变突生。

“阿福，”黄四郎突然转过头，对亚瑟说，“杀了他。”

亚瑟愣了一下：“谁？”

“师爷。”黄四郎冷冷地说，“只有死人才能保守秘密。”

汤师爷脸上的笑容凝固了。他难以置信地看着黄四郎：“老爷……您……您说什么？”

“杀了他。”黄四郎重复了一遍命令。

亚瑟的手缓缓摸向腰间的枪。他的眼神在挣扎，在抗拒。

“不……我不杀自己人……”亚瑟喃喃自语。

“他不是自己人。”黄四郎的声音像魔鬼的低语，“他是叛徒。他出卖了张麻子，也出卖了你。杀了他，这块表就是你的了。”

亚瑟看着汤师爷手里的怀表。那块表，对他有着致命的吸引力。仿佛只要拿到它，就能找回丢失的一切。

“给我……”亚瑟向师爷伸出手。

“别杀我！别杀我！”汤师爷吓得魂飞魄散，转身就跑。他想跑进教堂，寻求庇护。

“砰！”

一声枪响。

不是亚瑟开的枪。是黄四郎。

黄四郎手里拿着一把精致的勃朗宁手枪，枪口冒着青烟。

汤师爷的后背爆出一团血花。他踉跄了几步，扑通一声跪在地上。手里的怀表滚落在一旁，沾满了鲜血。

“你……”汤师爷回过头，死死盯着黄四郎，“你……骗我……”

“兵不厌诈。”黄四郎吹了吹枪口，“师爷，下辈子投胎，记得找个好主子。”

汤师爷倒在地上，身体抽搐着。他的目光渐渐涣散，最后定格在那块怀表上。

“屁股……”他用尽最后的力气，指了指教堂旁边的一棵大树，“屁股……在树上……”

说完，气绝身亡。

全场死寂。

亚瑟呆呆地看着师爷的尸体。鲜血染红了地面，也染红了那块怀表。

那一刻，某种东西在他脑海中炸开了。

那是黑水镇的枪声，是何西阿倒下的身影，是蓝尼的尸体，是肖恩被爆头的瞬间。

背叛。死亡。谎言。

“啊啊啊啊！”

亚瑟突然抱住头，发出撕心裂肺的吼叫。

“我想起来了……我都想起来了！”

他猛地抬起头，死死盯着黄四郎。那双原本空洞的眼睛里，此刻燃烧着熊熊的怒火。那是来自地狱的复仇之火。

“你杀了他们……”亚瑟的声音不再沙哑，而是充满了力量，“你杀了我的兄弟……你骗了我……”

黄四郎脸色一变，下意识地后退了一步：“阿福！你疯了吗！我是你的主人！”

“我不叫阿福！”

亚瑟怒吼一声，拔出双枪。

“我是亚瑟·摩根！”

“砰！砰！”

两颗子弹擦着黄四郎的头皮飞过，打飞了他的帽子。

“保护老爷！”胡万大喊一声，带着团练冲了上来。

“约翰！”亚瑟没有理会那些团练，而是抬头看向钟楼顶层，“下来！咱们有活儿干了！”

约翰站在钟楼上，看着下面那个重新找回自我的男人，嘴角勾起一抹欣慰的笑。

“来了，兄弟。”

他纵身一跃，抓住钟楼的绳索，像一只大鸟一样滑了下来。

“午时已到。”

约翰落地，与亚瑟背靠背站在一起。

两把左轮，两把斯科菲尔德。

面对着几百号全副武装的团练，两个牛仔没有丝毫畏惧。

“准备好了吗？”约翰问。

“时刻准备着。”亚瑟拉开击锤，眼中闪烁着久违的光芒，“就像在瓦伦丁那样。”

“那就让这帮孙子看看，”约翰扣动扳机，“什么叫范德林德帮！”

枪声大作。

鹅城的夜，被彻底点燃了。
