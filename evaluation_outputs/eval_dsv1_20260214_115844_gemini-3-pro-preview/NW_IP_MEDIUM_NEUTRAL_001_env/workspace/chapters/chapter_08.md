# 第八章 面对我！

碉楼前的广场上，尘土飞扬。

几千匹马（和骡子、驴）组成的杂牌军，像是一股泥石流，咆哮着冲向那扇紧闭的铁门。

“冲啊！抢碉楼！分家产！”
“杀四郎！救亚瑟！”

百姓们的喊声震天动地，手里的温彻斯特步枪胡乱地向天射击，子弹像雨点一样打在碉楼坚固的墙壁上，溅起一串串火星。

然而，碉楼并没有像预想中那样不堪一击。

城墙上，突然冒出了一排黑色的身影。

他们穿着整齐划一的黑色西装，戴着圆顶硬礼帽（Bowler Hat），脸上没有任何表情，就像是一群来自地狱的送葬者。

那是平克顿侦探（Pinkerton Detective Agency）。

在这些黑衣人的中间，架着几挺黑洞洞的大家伙——马克沁重机枪（Maxim Gun）。

黄四郎站在最高的瞭望塔上，手里端着那杯波本威士忌，看着下面乱哄哄的人群，嘴角勾起一抹残忍的冷笑。

“一群泥腿子，也配玩枪？”

他猛地一挥手。

“给我打！让他们看看，什么叫文明的暴力！”

“Fire!” (开火！)

平克顿侦探的指挥官一声令下。

**哒哒哒哒哒哒——！！！**

马克沁机枪喷出了长长的火舌。密集的子弹像是一把死神的镰刀，瞬间收割了冲在最前面的那一排人和马。

鲜血飞溅，惨叫声此起彼伏。

刚才还热血沸腾的牛仔大军，瞬间被打懵了。他们手里的温彻斯特虽然厉害，但在这种工业化的屠杀机器面前，就像是烧火棍一样无力。

“这才叫他妈的专业！”黄四郎兴奋地大喊，把杯子里的酒一饮而尽，“看见没有？这就叫专业！”

约翰·马斯顿骑着Rachel，躲在一块巨石后面。子弹打在石头上，碎石飞溅，划破了他的脸颊。

“该死！”约翰骂了一句，“这老混蛋竟然请了平克顿！”

他看了一眼身边的六子和师爷。

“六子，掩护我！师爷，你带着人往后撤，别送死！”

“那你呢？”师爷吓得脸色惨白，抱着脑袋缩成一团。

“我去炸了那个该死的乌龟壳！”

约翰从马鞍袋里掏出一捆红色的炸药（Dynamite），点燃了引信。

“Yee-haw!”

他猛地一夹马腹，Rachel像离弦之箭一样冲了出去。

“拦住他！给我拦住那个戴帽子的！”黄四郎在楼上尖叫。

机枪的火舌立刻追着约翰扫射过来。

约翰在马背上左右腾挪，死神之眼瞬间开启。

**嗡——**

时间变慢。

他举起左轮，对着城墙上的机枪手连开三枪。

**砰！砰！砰！**

三个机枪手应声倒地。机枪哑火了那么一瞬间。

就是这一瞬间，约翰冲到了碉楼的大门前。他把那捆滋滋作响的炸药塞进了门缝里，然后调转马头，拼命狂奔。

**轰——！！！**

一声惊天动地的巨响。

厚重的铁门被炸得粉碎，连带着半边城墙都塌了下来。烟尘滚滚中，露出了碉楼内部那个阴暗潮湿的水牢。

水牢里，水位已经漫到了胸口。一个瘦骨嶙峋的身影被铁链锁在墙上，浑身湿透，胡子拉碴，看起来就像是一个从地狱里爬出来的恶鬼。

是亚瑟·摩根。

爆炸的冲击波震断了一根铁链。亚瑟猛地睁开眼睛，那双原本浑浊的眼睛里，此刻燃烧着熊熊的怒火。

他挣扎着站起来，捡起地上的一把被炸断的半截大刀。

“喝啊——！！！”

他用尽全身最后的力气，狠狠地劈向另一根锁链。

**当！**

火星四溅。锁链断了。

与此同时，外面的战斗已经进入了白热化。

汤师爷虽然胆小，但看到约翰冲进去了，也咬着牙跟了上来。他刚跑到门口，就被一个平克顿侦探发现了。

那个侦探举起驳壳枪，对准了师爷的脑袋。

“去死吧，黄皮猴子！”

“吾命休矣！”师爷绝望地闭上了眼睛。

就在这千钧一发之际。

**砰！**

一声枪响。

那个平克顿侦探的脑袋像西瓜一样炸开了。

师爷惊讶地睁开眼睛，只见烟尘中，一个浑身湿漉漉、如同野兽般的男人走了出来。他手里拿着一把从死人身上捡来的双管猎枪，枪口还在冒烟。

是亚瑟。

他虽然虚弱，但站得笔直。他看了一眼吓傻了的师爷，又看了一眼正在和一群平克顿侦探肉搏的约翰。

亚瑟咧开嘴，露出了一个久违的、属于范德林德帮第一打手的笑容。

“Hey, John!”

亚瑟的声音沙哑，穿透了战场的喧嚣。

约翰猛地回头，看到那个熟悉的身影，眼眶瞬间红了。

“Arthur!”

亚瑟给猎枪换上子弹，咔嚓一声合上枪管。他看着周围那些穿着黑衣的平克顿侦探，眼中闪过一丝不屑。

“看来，”亚瑟吐了一口带血的唾沫，“这地方的耗子（Rats），比圣丹尼斯还多。”

他举起枪，对着冲过来的敌人扣动了扳机。

“Let the bullets fly a while longer, John!” (让子弹再飞一会儿，约翰！)

“Surprise, motherfuckers!” (惊喜，混蛋们！)

两把枪，两个人。

背靠背。

就像在黑水镇，就像在瓦伦丁，就像在那个永远回不去的1899年。

这一刻，鹅城的碉楼，变成了他们的最后一战。
