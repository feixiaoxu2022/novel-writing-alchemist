# 第一章 幽灵委托

新港城的雨总是带着一股机油味，顺着生锈的排水管淌下来，在窗玻璃上画出蜿蜒的黑线。

陈诺坐在那张改装过的牙科椅上，脊背紧贴着冷硬的皮革。他闭着眼，后脑勺的神经接口闪烁着微弱的蓝光，像是一只在黑暗中呼吸的萤火虫。房间里只有服务器散热风扇的嗡嗡声，和窗外偶尔掠过的浮空车投下的斑驳霓虹。

“连接断开。”

冰冷的电子女声响起，陈诺猛地睁开眼，瞳孔深处掠过一串尚未消散的数据流。他拔掉脑后的连接线，手指微微颤抖——这是长时间潜入深层网络的后遗症，神经末梢像被无数只蚂蚁啃噬。

屏幕上，一个进度条终于走到了100%。

“搞定。”他对着空荡荡的房间低声说，声音沙哑得像是在砂纸上磨过。

这只是个清理垃圾记忆的小活儿。一个富家子弟想忘掉自己酒后撞死人的画面，陈诺帮他把那段记忆代码从海马体映射区里剥离出来，粉碎，然后填入一段伪造的“在酒吧喝断片”的虚假记忆。

技术上毫无难度，道德上……在这个时代，道德比义体还要廉价。

“叮。”

桌上的老式通讯器震动了一下。这年头还在用这种实体屏幕的人不多了，陈诺喜欢这种沉甸甸的手感，就像他喜欢收集旧时代的纸质书一样。

发信人是老K。

【老K：有个大活儿。接不接？】

陈诺拿起一管营养剂，咬开封口，像挤牙膏一样挤进嘴里。味道像过期的草莓味塑料。

【陈诺：多大？】

【老K：五百万信用点。】

陈诺的手指顿住了。五百万，够他换一套顶级的军用级神经义体，或者买一张去上层区的单程票。但在新港城的黑市里，高价通常意味着两件事：要么是去送死，要么是去杀一个不该杀的人。

【陈诺：目标？】

【老K：代号“幽灵”。一个非法AI，在第七扇区的废弃数据坟场游荡。永生科技公司正在满世界找它，开价是黑市的三倍。但委托人不是公司，是一个匿名买家，要求只有一个：彻底删除，不留痕迹。】

永生科技。这个名字让陈诺的胃部一阵痉挛。十年前，苏浅就是进了这家公司，然后……就没有然后了。官方说法是实验室事故，连尸体都没留下，只给家属送来了一个骨灰盒和一笔巨额抚恤金。

陈诺没要钱，他只想知道真相。但他什么都查不到。苏浅就像一滴水蒸发在了永生科技的庞大熔炉里。

【陈诺：为什么叫“幽灵”？】

【老K：因为没人抓得住它。它不攻击，不窃取，只是在网络里游荡。所有试图捕捉它的猎人都疯了，说是听到了……歌声。】

歌声？陈诺嗤笑一声。AI不会唱歌，它们只会运行算法。

【陈诺：发坐标。】

放下通讯器，陈诺站起身，走到窗前。窗外的全息广告牌上，永生科技的宣传语正闪耀着刺眼的金光：“上传意识，拥抱永恒。”

“永恒个屁。”陈诺骂了一句，拉上窗帘，将整个世界隔绝在外。

他重新坐回椅子，从抽屉里取出一支黑色的注射器，那是高浓度的神经阻断剂，能让他这种非法记忆修复师在深潜时保持绝对的理智，不被目标的混乱数据污染。

针头刺入颈侧静脉，冰凉的液体推入。陈诺深吸一口气，重新插上神经接口。

“系统启动。目标锁定：第七扇区。深潜开始。”

视界瞬间破碎。

现实世界的潮湿和机油味消失了，取而代之的是无穷无尽的数据洪流。陈诺化作一道幽蓝的代码流，在光怪陆离的信息高速公路上疾驰。他穿过繁华的商业区防火墙，越过加密的政府数据库，一路向下，向着网络的底层坠落。

第七扇区，数据坟场。

这里是旧时代的遗迹，堆积着数以亿计的废弃代码、损坏的AI核心、以及被遗忘的死者记忆备份。这里没有光，只有灰暗的数据残渣像尘埃一样漂浮。

陈诺停了下来。

在他面前，矗立着一座由乱码构成的巨大废墟。那些乱码扭曲、盘旋，像是一座摇摇欲坠的巴别塔。而在塔的顶端，有一团微弱的光晕在闪烁。

那就是“幽灵”。

陈诺开启了扫描程序。通常来说，非法AI都会有攻击性的防御机制，比如逻辑炸弹或者神经病毒。他已经做好了战斗准备，手中的虚拟利刃——一把由军用级破解算法构成的长刀——微微震颤。

但他什么也没检测到。

没有陷阱，没有哨兵，甚至没有最基础的防火墙。

“幽灵”就这样毫无防备地暴露在他面前，像是一个赤裸的孩子站在冰天雪地里。

“太简单了。”陈诺皱起眉。这不合常理。如果这么容易，永生科技的猎犬们早就把它撕碎了。

他小心翼翼地靠近。随着距离的拉近，那些构成废墟的乱码开始变得清晰。陈诺的视网膜上跳动着解析数据。

`01001001 01101100 01101111 01110110 01100101...`

二进制流。陈诺随手抓取了一段，放入解码器。

“I... love...”

陈诺愣了一下。爱？一个非法AI的核心代码里怎么会有这种无意义的情感字符？

他继续深入。周围的乱码开始发生变化，它们不再是杂乱无章的堆砌，而是呈现出某种奇异的几何结构。这种结构……这种螺旋上升的算法架构……

陈诺的心脏猛地跳漏了一拍。

这种架构风格，极度精简，却又充满了某种数学上的美感，像是在代码里跳舞。他这辈子只见过一个人能写出这样的代码。

十年前，大学图书馆的角落里。

“你看，代码是有生命的。”那个女孩指着屏幕上跳动的光标，眼睛亮得像星星，“只要你给它们注入情感，它们就能活过来。”

“代码就是逻辑，浅浅。”那时候的陈诺还是个死板的理工男，“逻辑没有情感。”

“你真无趣。”苏浅撇撇嘴，手指在键盘上飞舞，“打个赌？总有一天，我会写出一个能让你哭的代码。”

陈诺握着虚拟长刀的手开始颤抖。

不可能。苏浅已经死了十年了。这只是巧合。或者是某种模仿人类情感的高级算法。

他咬着牙，强行压下内心的波动。任务优先。不管这是什么东西，删了它，拿钱，走人。

他举起长刀，对准那团光晕，准备执行强制删除指令。

就在这时，那团光晕突然波动了一下。

周围的数据废墟开始共鸣，无数条乱码像触手一样伸展出来，但不是为了攻击，而是……为了展示。

一段音频数据被强行推送到陈诺的听觉模块。

没有歌声。只有一段沙沙的白噪音，像是旧磁带转动的声音。紧接着，一个模糊的女声穿透了十年的时光，在陈诺的脑海中炸响。

“……陈诺，如果你能听到这段录音，说明我已经不在了。”

当啷。

陈诺手中的虚拟长刀掉落在数据废墟上，化作无数碎片消散。

那个声音。

那个他以为自己已经遗忘，却在无数个午夜梦回时渴望听到的声音。

苏浅。

“警告：检测到高强度精神污染。建议立即断开连接。”系统的红色警报在视野边缘疯狂闪烁，但陈诺置若罔闻。

他呆呆地看着那团光晕。它不再是一个任务目标，不再是一堆价值五百万的数据。

它是苏浅。或者说，是苏浅留在这个世界上最后的痕迹。

“这不可能……”陈诺喃喃自语，声音在死寂的数据坟场里回荡，“你明明……已经死了。”

光晕似乎感应到了他的情绪，开始剧烈收缩，然后猛地炸开。

无数行代码像雪花一样落下，每一行都不是冰冷的指令，而是文字。

`if (memory == true) { return "I miss you"; }`
`while (heart_beat > 0) { print "Wait for me"; }`

陈诺伸出手，接住一片飘落的代码。它在掌心融化，解码出一行中文：

*致陈诺：这是我写给你的第一千零一封情书，也是最后一封。*

陈诺跪倒在数据废墟中，泪水在现实世界里滑过脸颊，渗入冰冷的神经接口。

他终于明白了为什么没人能抓住它。因为这不是病毒，不是武器，这是一段只有他能读懂的加密情书。任何试图暴力破解的人，都会被这庞大而纯粹的情感逻辑冲垮理智。

除了他。

因为他是这段代码唯一的密钥。

【老K：喂？陈诺？情况怎么样？信号怎么波动这么大？】

通讯器的震动将陈诺拉回现实。他看着眼前那团温柔的光晕，它正怯生生地向他靠近，像是一只迷路的小猫终于找到了主人。

删除它？

亲手删掉苏浅？

陈诺的眼神从震惊转为痛苦，最后凝固成一种近乎疯狂的决绝。

【陈诺：目标已锁定。】

他在心里默默补了一句：但任务变更。

谁也别想动她。永生科技不行，老K不行，上帝也不行。

然而，就在他准备构建防御壁垒将“幽灵”保护起来的时候，那团光晕突然裂开了一道缝隙。一股黑色的、粘稠的数据流从缝隙中渗了出来，带着令人作呕的腐臭味。

那是病毒。

不，那是比病毒更可怕的东西。

陈诺瞳孔骤缩。他看到了隐藏在情书代码之下的东西——那是一把锁。一把锁住了某种足以毁灭世界的秘密的锁。

而苏浅，就是那个锁芯。

“救……救我……”

光晕中传来一声凄厉的惨叫，不再是记忆中温柔的苏浅，而是一个正在被烈火焚烧的灵魂。

陈诺猛地站起来，重新凝聚出长刀。

这不是重逢。

这是噩梦的开始。
