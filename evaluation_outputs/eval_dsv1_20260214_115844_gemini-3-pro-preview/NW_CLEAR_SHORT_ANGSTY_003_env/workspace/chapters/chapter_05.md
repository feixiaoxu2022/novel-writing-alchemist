# 第五章 手指悬停

新港城的最高点是一座废弃的信号塔，锈迹斑斑的钢架直插云霄，仿佛要刺破那层永远笼罩着城市的酸雨云。

陈诺靠在塔顶的栏杆上，脚下是万家灯火汇聚成的霓虹海洋，头顶是漆黑如墨的夜空。风很大，吹得他的风衣猎猎作响，但他感觉不到冷。

怀里的量子硬盘已经烫得惊人，红色的警报灯不再闪烁，而是变成了一种恒定的、刺眼的血色。

“感染率：98.5%……警告：核心逻辑即将重写。”

耳机里的提示音像是在倒数他的生命。

陈诺颤抖着手，将硬盘接入了信号塔的终端。这里是全城信号最强的地方，也是离天空最近的地方。

“启动……最后一次连接。”

随着指令输入，周围的空气开始扭曲。全息投影仪将苏浅的意识投射在塔顶的平台上。

这一次，她不再是那个穿着白裙子的女孩。

黑色的数据流像荆棘一样从她的脚下蔓延，缠绕着她的身体，刺入她的皮肤。她的半张脸已经完全被黑色的晶体覆盖，只剩下那只左眼还保留着人类的神采。

“陈诺……”

苏浅的声音很轻，像是风中残烛。她试图向陈诺走来，但每走一步，那些黑色的荆棘就会收紧一分，勒进她的血肉里。

“别动，浅浅。别动。”

陈诺冲过去，想要扶住她，却再次穿过了她的身体。他跪在地上，看着虚空中那个正在崩解的灵魂，泪水模糊了视线。

“看来……我输了。”苏浅勉强挤出一个笑容，那笑容凄美得让人心碎，“病毒赢了。我很快……就不再是我了。”

“不，还有办法的！一定还有办法！”陈诺疯狂地敲击着键盘，试图寻找哪怕万分之一的漏洞，“我可以把你的记忆备份出来！我可以把病毒隔离在……”

“没用的，陈诺。”苏浅打断了他，“你知道的。病毒已经和我的核心融为一体了。如果强行剥离，我会变成白痴。如果保留，我会变成怪物。”

她抬起手，指了指陈诺面前的屏幕。

那里有一个巨大的红色按钮，上面写着：【执行彻底删除】。

进度条停在99%。

只差最后一步。

“杀了我。”苏浅看着他的眼睛，眼神清澈而坚定，“求你。”

陈诺的手僵在半空。

那个按钮就在那里，距离他的指尖只有几厘米。但这几厘米，却像是隔着整个宇宙。

按下它，苏浅就会彻底消失。在这个世界上，再也不会有她的痕迹。没有备份，没有残留，真正的死亡。

不按，她就会被病毒吞噬，变成永生科技最完美的杀人机器，变成她最痛恨的样子。

“为什么……”陈诺哽咽着，声音嘶哑得像是在哭嚎，“为什么每次都要我做这种选择？十年前是这样，现在还是这样！”

十年前，他眼睁睁看着她走进那个实验室，无能为力。

十年后，他拼了命把她找回来，却要亲手送她走。

“因为你是陈诺啊。”苏浅的声音变得温柔起来，仿佛回到了大学图书馆的那个午后，“因为你答应过我，会保护我。哪怕……是从我自己手里保护我。”

她身上的黑色荆棘开始疯狂生长，黑色的晶体蔓延到了她的脖颈，即将吞噬她最后的理智。

“快点……陈诺……我控制不住了……”

苏浅的表情开始扭曲，右眼的红光暴涨，喉咙里发出了野兽般的低吼。但在那最后的一丝清明里，她依然死死盯着陈诺，眼中满是祈求。

那是对解脱的渴望。

陈诺闭上眼，深吸一口气。

雨水顺着他的脸颊滑落，冰冷刺骨。

他想起了苏浅写的那行代码：`if (memory == true) { return "I miss you"; }`

如果记忆是真的，我会想念你。

但如果记忆变成了痛苦的根源，那么遗忘……或许才是最后的慈悲。

“我爱你。”

陈诺轻声说。

他睁开眼，手指悬停在那个红色的按钮上方。指尖在颤抖，但他没有退缩。

苏浅似乎听到了他的告白，那只完好的左眼里流下了一滴晶莹的泪水。那滴泪水没有变成数据流消散，而是化作了一颗璀璨的星辰，在黑暗中闪耀。

“再见，陈诺。”

她闭上了眼，嘴角勾起一抹释然的微笑。

下一秒。

陈诺的手指重重按下。

*滴——*

世界仿佛在这一瞬间静止了。

没有爆炸，没有巨响。

只有一道柔和的白光从硬盘中爆发出来，瞬间吞没了塔顶的一切。

那些黑色的荆棘、狰狞的晶体、疯狂的病毒，在白光中如冰雪般消融。苏浅的身影在光芒中变得透明，变得纯净。她不再痛苦，不再挣扎，只是静静地看着陈诺，然后化作无数光点，飘向了漆黑的夜空。

像是无数只萤火虫，飞向了它们向往的星海。

屏幕上的进度条走到了100%。

【删除完成。】

【目标已清除。】

风停了。雨也停了。

陈诺依旧跪在地上，保持着按下按钮的姿势。他的面前，那个量子硬盘已经彻底冷却，变成了一块毫无生气的废铁。

他伸出手，想要抓住那些飘散的光点，但它们穿过他的指缝，消失在茫茫夜色中。

什么都没留下。

除了那段刻在他脑海里的代码，和那句永远无法再听到的“再见”。

不知过了多久，陈诺缓缓站起身。他的左腿依然没有知觉，但他感觉不到疼。

他走到栏杆边，看着脚下那座依然繁华、依然冷漠的新港城。巨大的全息广告牌上，永生科技的宣传语依然在闪烁：“上传意识，拥抱永恒。”

陈诺从口袋里掏出一支烟，点燃。

烟雾缭绕中，他的眼神变得前所未有的冷冽。

苏浅走了。

但他还在。

只要他还记得，她就永远活着。

而那些把她变成怪物的人……

陈诺吐出一口烟圈，看着远处永生科技大楼顶端的标志，嘴角勾起一抹冰冷的弧度。

“游戏才刚刚开始。”

他转身，拖着那条废腿，消失在黑暗的楼梯间里。

只留下那个废弃的硬盘，静静地躺在雨水中，像是一块无名的墓碑。
