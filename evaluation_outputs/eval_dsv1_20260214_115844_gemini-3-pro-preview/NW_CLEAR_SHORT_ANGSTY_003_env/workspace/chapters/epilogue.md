# 尾声：永恒的漏洞

三个月后。

新港城的雨季终于结束了，难得的晴天让这座钢铁丛林显露出几分生机。但在第七扇区的地下黑市里，阳光永远是奢侈品。

陈诺坐在那张熟悉的牙科椅上，左腿已经换上了一条二手的军用义肢。虽然不如原装的好用，但至少能让他跑得比以前快。

“叮。”

通讯器震动了一下。还是老K。

【老K：听说你最近在找永生科技的麻烦？疯了吗？】

陈诺没有回复。他拿起桌上的一块芯片——那是从那个废弃的量子硬盘里提取出来的唯一残留物。

虽然苏浅的核心代码已经被删除了，但在删除的一瞬间，她似乎利用某种逻辑漏洞，在这个芯片里留下了一段极其微小的代码。

那不是记忆，也不是情感。

那是一把钥匙。

一把通往永生科技底层数据库的后门密钥。

陈诺将芯片插入神经接口。

视界瞬间展开。这一次，他没有看到那些繁杂的数据流，而是直接进入了一个纯白的空间。

在这个空间的中央，漂浮着一棵树。

一棵由无数行代码构成的、发光的树。

那是苏浅生前最喜欢的梧桐树。十年前，他们在树下埋过一个时间胶囊。

陈诺走到树下，伸手触碰树干。

一段文字浮现在空中：

`if (world == cruel) { be the bug. }`

如果世界是残酷的，那就做那个漏洞。

陈诺笑了。这是苏浅留给他的最后一份礼物。她不仅救了他，还给了他一把剑。一把足以刺穿永生科技心脏的剑。

“系统启动。”

陈诺低声说。

随着他的指令，那棵发光的树开始生长，枝叶蔓延，化作无数条数据触手，刺入了永生科技的防火墙。

屏幕上，永生科技的股价开始疯狂跳水。无数份关于“非法意识上传”和“情感剥离实验”的绝密文件被打包发送到了各大新闻媒体的邮箱里。

警报声在整个新港城的上空拉响。

但陈诺不在乎。

他闭上眼，仿佛又看到了那个穿着白裙子的女孩，站在树下对他微笑。

“我会一直陪着你。”

风中似乎传来了她的低语。

陈诺睁开眼，拔掉连接线，站起身。他推开门，走进了阳光里。

这一次，他不再是一个人在战斗。

因为在这个庞大而冰冷的网络世界里，到处都是她的影子。每一个漏洞，每一次溢出，每一行报错，都是她在对他眨眼。

她是幽灵。

她是病毒。

她是永恒。

（全书完）
