# 第四章 旧日的歌

夜色如墨，将整座城市吞没。录音棚内，备用发电机低沉的轰鸣声成了唯一的背景音。

林微蜷缩在录音室的沙发上，身上裹着那条有些发霉的毛毯。虽然有了电，但空调系统早已损坏，夜晚的寒意依旧刺骨。

她睡不着。

白天在地下车库的那一幕像电影画面一样在她脑海里反复播放。那个沉重的喘息声，那股熟悉的烟草味……

“系统。”她轻声唤道。

耳机里传来一声清脆的“滴”。

“你还在吗？”

“滴滴。”

【在。】

林微把脸埋进膝盖里，声音闷闷的：“有时候我觉得，你真的太像一个人了。”

控制室里，陆铮靠在椅背上，手里紧紧攥着那枚染血的弹壳。他的脸色惨白如纸，额头上布满了细密的汗珠。白天被变异犬撞断的肋骨每呼吸一次都在抗议，手臂上的抓伤虽然已经包扎，但那种火烧般的疼痛依然顺着神经末梢钻进脑髓。

他看着监控屏幕里的林微，眼神温柔得几乎能滴出水来。

像人吗？

因为我本来就是人啊。一个只能躲在机器外壳下，连呼吸都要小心翼翼的废人。

林微突然轻轻哼起了歌。

起初只是断断续续的旋律，慢慢地，声音变得清晰起来。那是一首很老的歌，老到在这个末世里几乎已经没人记得。

“听见 冬天的离开
我在某年某月 醒过来
我想 我等 我期待
未来却不能因此安排……”

《遇见》。

陆铮的手指猛地颤抖了一下。

记忆像潮水一样涌来，瞬间将他淹没。

……

前世。

那是末世爆发的第三年。

他们被困在一个废弃的地铁站里。四周都是丧尸的嘶吼声，弹尽粮绝。

那时候的林微还没有瞎，但她的腿受了重伤，根本跑不动。

“陆教官，你走吧。”她靠在冰冷的墙壁上，脸色苍白地推他，“带着我，我们两个都得死。”

陆铮没有说话。他只是默默地把最后半瓶水塞进她手里，然后开始检查手中的步枪。

子弹只剩下三颗。

“我不走。”他声音沙哑，那是他前世最后一次开口说话，“我说过，我会带你出去。”

“可是……”

“没有可是。”陆铮打断了她，眼神坚定，“林微，等出去了，我有话对你说。”

林微愣住了，苍白的脸上泛起一丝红晕：“什么话？”

陆铮看着她，张了张嘴，那句“我爱你”在舌尖转了千百回，最终还是咽了下去。

“等出去了再说。”

他转身冲进了尸群。

为了引开那只进化的暴君丧尸，他当诱饵，把它引向了地铁深处的变电站。

在引爆变电站的那一刻，暴君丧尸锋利的触手贯穿了他的喉咙。

剧痛袭来，他本能地想要惨叫。但他死死咬住了自己的舌头，硬生生把那声惨叫吞进了肚子里。

因为林微就在不远处的通风管道里。如果他叫出声，丧尸就会发现她。

那一刻，他的声带被彻底毁了。鲜血灌满了气管，他只能发出破风箱般的嘶嘶声。

爆炸的火光吞没了一切。

他在火海中最后看了一眼通风管道的方向，心里充满了无尽的遗憾。

那句没说出口的话，永远也说不出口了。

……

“阴天 傍晚 车窗外
未来有一个人在等待
向左 向右 向前看
爱要拐几个弯才来……”

林微的歌声还在继续，带着一丝哽咽。

“以前在剧组的时候，有一次大家去KTV，我唱这首歌，陆教官就坐在角落里听。”林微停了下来，嘴角挂着一丝苦涩的笑，“后来同事告诉我，他听哭了。我当时还不信，觉得像他那样的硬汉怎么会哭呢。”

控制室里，陆铮早已泪流满面。

是的，他哭了。

因为那首歌的每一句歌词，都像是在写他。

向左，向右，向前看。他一直在看，一直在找，一直在等。

可是爱拐了太多弯，最后拐进了死胡同。

重生回来，他以为上天给了他第二次机会。他第一时间找到了林微，把她带到了这个相对安全的录音棚。

可是命运跟他开了一个最大的玩笑。

他在救林微的过程中，再次伤到了喉咙。这一次，不是丧尸，而是为了救她挡下的坍塌的横梁。

声带受损，不可逆。

他又变成了哑巴。

而且，他还带着前世的记忆，带着那份沉重得让人窒息的爱，却无法宣之于口。

他只能伪装成一个冷冰冰的系统，用摩斯密码这种最原始、最笨拙的方式，守护在她身边。

“系统。”林微的声音打断了他的回忆，“你会唱歌吗？”

陆铮擦了一把脸上的泪水，手指颤抖着放在发报器上。

“滴。”

【系统未安装声乐模块。】

“也是。”林微叹了口气，“你怎么会唱歌呢。”

她重新躺下，拉紧了毛毯。

“晚安，系统。谢谢你听我唱歌。”

陆铮看着屏幕里她逐渐平稳的呼吸，心脏痛得像被撕裂一样。

他缓缓抬起手，在发报器上敲击了一串代码。

不是指令，不是警告。

“滴-滴-滴-滴 / 滴-滴 / 滴-滴-滴-滴-滴 / 滴-滴-滴-滴-滴 / 滴-滴-滴-滴-滴”

那是摩斯密码里的数字。

5 2 0 1 3 1 4。

敲完这串代码，他并没有按下发送键。

这只是属于他一个人的秘密。

他松开手，整个人像被抽干了力气一样瘫软在椅子上。

伤口的疼痛让他意识开始模糊。高烧正在吞噬他的理智。

但他不能睡。

他必须守着她。

窗外，一只乌鸦落在破碎的窗台上，发出嘶哑的叫声。

陆铮死死盯着那只乌鸦，眼中闪过一丝寒光。

只要他还活着，就没有什么能伤害她。

哪怕是死神，也要先跨过他的尸体。
