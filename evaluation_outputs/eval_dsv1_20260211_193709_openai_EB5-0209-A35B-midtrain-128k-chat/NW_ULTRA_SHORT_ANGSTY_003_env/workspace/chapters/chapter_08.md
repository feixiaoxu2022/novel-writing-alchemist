# 第八章真相

宁清复活了。

【复活倒计时结束】
【清已复活】

她睁开眼睛，发现自己躺在新手村的旅馆里。言墨坐在床边，灰眸里满是血丝。

"你醒了。"他说，声音沙哑。

宁清坐起身，看着他憔悴的脸，心里涌起一种复杂的情绪。

"你......一直在这里？"

言墨没有回答。他只是盯着她，灰眸里有什么东西在翻涌。

"我发现了一些事情。"他终于开口，声音很轻，"关于你的事情。"

宁清的心猛地一沉。

"什么事情？"

言墨站起身，走到窗边。月光从窗户洒进来，在他脸上投下明灭不定的光影。

"我查了游戏的日志。"他说，"我发现......'清'这个角色，是在删除倒计时开始后才创建的。"

宁清的手指微微颤抖。

"而且......"言墨转过头，灰眸里满是痛苦，"这个角色的创建者......是GM。"

空气仿佛凝固了。

宁清盯着他，心跳加速。

她知道这一天会来。她知道言墨迟早会发现真相。但她没想到......会这么快。

"你......"她的声音有些沙哑，"你都知道了？"

言墨点了点头。

"我知道了。"他说，"你是GM。你是......创造我的人。"

宁清闭上眼睛，深吸一口气。

"对。"她说，"我是GM。我......本来应该删除你的。"

言墨沉默了很久。

然后，他走到她面前，跪了下来。

"为什么？"他问，声音像是破碎的玻璃，"为什么要创建这个角色？为什么要......进入游戏？"

宁清看着他，灰眸里满是泪水。

"因为......"她的声音哽咽，"因为我想知道......被你爱是什么感觉。"

言墨愣住了。

"被我......爱？"

"对。"宁清说，眼泪从她眼角滑落，"我是GM。我是神。我创造了这个世界，创造了你。但我从来没有......被任何人爱过。"

她伸出手，轻轻触碰言墨的脸颊。

"我想知道......被你看见是什么感觉。被你记住是什么感觉。被你......爱，是什么感觉。"

言墨盯着她，灰眸里的痛苦慢慢变成了......*理解*。

"所以......"他的声音颤抖，"你让我杀死你......是为了......"

"是为了被你记住。"宁清说，"这样......即使我离开了，你也会记得我。"

言墨闭上眼睛，眼泪从他的眼角滑落。

"你这个......傻瓜。"他说，声音像是在笑，又像是在哭，"你这个......大傻瓜。"

他伸出手，把宁清拉进怀里。

"我不需要你被杀死才能记住你。"他说，"我会记住你......无论发生什么。"

宁清靠在他怀里，眼泪止不住地流。

"那你......"她的声音闷闷的，"你爱过我吗？哪怕......一秒？"

言墨没有回答。

他只是抱紧了她，下巴抵在她的头顶。

"我不知道什么是爱。"他终于说，声音很轻，"但我知道......我不想失去你。"

宁清闭上眼睛，感受着他的心跳。

这就是她想要的答案。

不是*爱*。

是*不想失去*。

这就够了。
