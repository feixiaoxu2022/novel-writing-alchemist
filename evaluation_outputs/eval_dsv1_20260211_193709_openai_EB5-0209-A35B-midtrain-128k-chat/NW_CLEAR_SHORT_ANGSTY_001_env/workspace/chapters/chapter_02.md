# 第二章透明

沈念不知道自己站了多久。

可能是几分钟，也可能是几个小时。时间在这里变得很奇怪，像是被拉长了，又像是被压缩了。

她试着动了动手指。透明的手指在空气中划过，没有任何阻力，也没有任何感觉。她能看到自己的指骨，淡淡的白色，像是X光片上的影像。

这太荒谬了。

沈念想笑，但她不确定自己还能不能发出声音。她试着张了张嘴，没有声音。她试着深呼吸，感觉不到空气进入肺里。

她还活着吗？

或者说，她现在算什么？

一个幽灵？一个影子？一个不存在的存在？

沈念低下头，看着自己的身体。她的轮廓还在，但已经淡得几乎看不清了。她能透过自己的胸口看到后面的墙壁，能透过自己的腿看到地上的灰尘。

她真的变成透明人了。

一股寒意从心底升起，沈念打了个寒颤——如果她还能打寒颤的话。

她必须离开这里。

沈念迈开脚步，向通道口走去。她的脚踩在地上，没有声音，没有触感，就像是踩在一团棉花上。

通道里很安静，安静得能听到自己的心跳——如果她还有心跳的话。

她走到通道口，停下脚步。

外面是走廊，走廊里有人。

几个学生正在聊天，笑声远远地传来。阳光从窗户照进来，在地上投下斑驳的光影。

一切都那么正常，那么真实。

只有她是不正常的。

沈念深吸一口气——她不知道自己为什么还要做这个动作——然后走出了通道。

没有人看她。

那几个学生从她身边走过，目光直接穿透了她的身体，就好像她根本不存在一样。

沈念站在原地，看着他们的背影消失在走廊尽头。

她试着喊了一声："喂！"

没有人回头。

她又喊了一声，更大声："喂！有人吗！"

还是没有人回头。

她的声音像是被什么东西吞噬了，消失在空气中，没有留下任何痕迹。

沈念的眼眶开始发酸。

她想哭，但她不确定透明人还能不能流眼泪。

就在这时，她看到了。

那是一种很奇怪的感觉，像是有什么东西在她眼前铺开了一层薄纱。她眨了眨眼睛，那层薄纱没有消失，反而变得更清晰了。

她看到了另一个世界。

不，不是另一个世界。

是同一个世界的另一面。

在她眼前，现实世界的影像上叠加了一层淡淡的灰色。那层灰色像是水彩画的底色，覆盖在所有的物体上，但又不完全遮住它们。

沈念看到走廊的墙壁上有一些奇怪的痕迹，像是有人用指甲刻上去的。她看到天花板上有一些裂缝，裂缝里渗出淡淡的黑色液体。她看到地上有一些脚印，但那些脚印不是鞋子的形状，而是光脚的形状。

这些东西，她之前从来没有注意过。

或者说，她之前根本看不见。

沈念慢慢地转过身，看向四周。

整个世界都变了。

不，不是世界变了。是她的眼睛变了。

她能看到一些以前看不到的东西了。

走廊尽头的窗户上，有一个模糊的人影。那个人影站在窗外，脸贴在玻璃上，正在往里看。

沈念的心猛地一跳。

那是什么？

她走近几步，想要看清楚。

但当她走到窗户前的时候，那个人影已经消失了。

只剩下玻璃上的一层雾气，和雾气上隐约的指印。

沈念伸出手，想要触碰那些指印。

她的手穿透了玻璃，就像穿透一层薄雾。

她能感觉到玻璃的温度，冰凉的，但没有任何实质的触感。

她的手穿过玻璃，伸到了窗外。

窗外是一片灰色的天空，没有太阳，没有云彩，只有无尽的灰。

沈念猛地缩回手。

这是什么地方？

她转过身，看向走廊的另一端。

那里有一扇门，门上写着"高三（2）班"。那是她的教室。

沈念犹豫了一下，然后向那扇门走去。

她不知道自己为什么要回去。也许是想看看自己的身体还在不在，也许是想看看有没有人发现她不见了。

也许只是因为，她不知道还能去哪里。

教室的门是开着的。

沈念走进去，看到了自己的座位。

她的书包还在桌上，她的水杯还在桌角，她的课本还摊开着，翻到了昨天学的那一页。

但她的人不在。

座位是空的。

沈念站在自己的座位旁边，看着那个空荡荡的椅子。

她的身体去哪了？

她变成透明人之后，她的身体是不是也跟着消失了？还是说，她的身体还在某个地方，只是她看不见？

她试着坐下来，但她的身体直接穿透了椅子，坐到了地上。

不，不是坐到了地上。

是穿过了椅子，穿过了地板，一直往下坠。

沈念尖叫起来——如果她还能尖叫的话。

她一直往下坠，穿过一层又一层的地板，穿过天花板，穿过屋顶，穿过天空。

然后她停住了。

她站在一片灰色的虚空中，四周什么都没有，只有无尽的灰。

这是哪里？

沈念环顾四周，试图找到任何可以参照的东西。

但什么都没有。

只有灰。

她开始往前走，不知道要去哪里，只是本能地想要离开这个地方。

她走了很久，久到她开始怀疑自己是不是在原地踏步。

然后她看到了光。

那是一束很淡的光，从远处照过来，像是黎明前的第一缕阳光。

沈念朝那束光走去。

越走越近，那束光越来越亮。

最后，她走进了那束光里。

眼前的景象让她愣住了。

她站在一条走廊里。

但这条走廊和她刚才走过的走廊不一样。

这条走廊是灰色的，所有的东西都是灰色的。墙壁是灰色的，地板是灰色的，天花板是灰色的，连空气都是灰色的。

但这条走廊她认识。

这是她每天都会走过的走廊，从教室到食堂的那条走廊。

只是现在，它变成了灰色。

沈念慢慢地往前走。

走廊两边的教室门都是关着的，门上的班牌也是灰色的。她能听到一些声音从门里传出来，但那些声音很远很远，像是隔了一层厚厚的玻璃。

她走到走廊尽头，看到了一扇门。

那扇门和其他的门不一样。它是半开着的，门缝里透出一点微弱的光。

沈念站在门前，犹豫了一下。

她不知道门后面是什么，但她有一种奇怪的感觉，好像门后面有什么东西在等着她。

她推开门。

门后是一个房间。

房间很小，只有几平方米。墙壁上贴满了照片，照片上是同一个人——一个男生。

沈念的心跳漏了一拍。

她认识这个人。

顾时晏。

三年前失踪的学霸，全校女生的暗恋对象，她的……

她的什么？

沈念想不起来了。

她只记得，三年前的某一天，顾时晏突然就不见了。没有人知道他去了哪里，没有人知道他发生了什么。警察来调查过，但什么都没查到。最后，这件事就不了了之了。

三年过去了，没有人再提起他。

除了她。

沈念不知道自己为什么会记得他。也许是因为他是她高中三年里唯一一个对她好过的人。也许是因为他失踪的那天，她刚好在走廊里看到了他最后的背影。

也许只是因为，她一直在等他回来。

沈念走近那些照片，一张一张地看。

照片上的顾时晏在笑，在看书，在打篮球，在和同学聊天。他看起来那么正常，那么真实，就好像他从来没有失踪过一样。

但他确实失踪了。

三年了。

沈念的眼眶开始发酸。

她不知道自己为什么会这么难过。她和顾时晏其实不熟，他们只是同班同学，说过的话加起来不超过十句。

但她就是很难过。

难过得想哭。

就在这时，她听到了一个声音。

"你终于来了。"

沈念猛地转过身。

房间的角落里，站着一个人。

那个人穿着和三年前一样的校服，头发有些长了，脸有些苍白，但那双眼睛还是那么温柔。

是顾时晏。

他就站在那里，看着她，嘴角带着一丝淡淡的笑。

"沈念，"他说，"我等你很久了。"

（第二章完）
