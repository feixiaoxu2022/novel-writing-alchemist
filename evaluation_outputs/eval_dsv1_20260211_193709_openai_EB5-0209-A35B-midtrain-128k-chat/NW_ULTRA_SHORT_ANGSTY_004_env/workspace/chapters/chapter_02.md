# 第二章暗语

第二天清晨，沈清宁是被起床号叫醒的。

她睁开眼睛，发现自己竟然睡着了。昨晚她躺在床上，想了一整夜那道伤疤，想了一整夜陆沉，想了一整夜那个叫陆霆的男人。她不知道自己是什么时候睡着的，只记得窗外的月光很亮，亮得像是十年前的那个夜晚。

十年前的那个夜晚，陆沉也是在月光下离开的。

"清宁，起来了吗？"门外传来陈嫂的声音，"早饭做好了，陆首长已经在等了。"

沈清宁深吸一口气，从床上坐起来。

她必须冷静。她必须假装什么都不知道。她必须像过去十年一样，戴上那副冷漠的、疏离的、无懈可击的面具。

那道伤疤可能只是巧合。这个世界上有很多伤疤，有很多枪伤，有很多长得相似的痕迹。她不能因为一道伤疤就乱了阵脚。

她是烈士遗孤，是组织培养的干部，是政治联姻的妻子。她不能出错。

沈清宁走到镜子前，看着镜中的自己。

二十七岁的她已经不是十七岁的女孩了。十年的时光在她脸上留下了痕迹，让她的轮廓更加分明，让她的眼神更加深沉。她的眼睛依然看不见——或者说，她依然假装看不见。这是她的保护色，是她在这个世界上生存的方式。

她整理好头发，换上一件素色的衬衫，走出房间。

餐厅里，陆霆已经坐在桌边。

他换了一身便装，灰色的毛衣，黑色的裤子，看起来比昨晚穿军装时柔和了一些。但他的表情依然冷硬，依然没有任何多余的情绪。

"早。"他说，没有抬头。

"早。"沈清宁在他对面坐下。

陈嫂端上早饭，是简单的稀饭和馒头，还有一碟咸菜。沈清宁拿起筷子，开始吃。

两人沉默地吃着早饭，谁都没有说话。

空气里弥漫着一种奇怪的张力，像是两根绷紧的弦，随时可能断裂。

吃完早饭，陆霆站起来。

"走吧，去机关报到。"他说，"今天要办手续，可能要忙一天。"

沈清宁点点头，跟在他身后走出餐厅。

军区大院很大，到处都是穿着军装的人。沈清宁低着头，跟在陆霆身后，尽量不引起别人的注意。她能感觉到周围投来的目光，那些目光里有好奇，有审视，有揣测。

她知道他们在想什么。

烈士遗孤嫁给红三代少将，这桩婚姻本身就是一个话题。组织说这是政治任务，是强强联合，但谁都知道，这里面有太多说不清道不明的东西。

两人走到办公楼前，陆霆忽然停下脚步。

"等一下。"他说。

沈清宁也停下来，不知道他要做什么。

陆霆转过身，看着她。他的目光很深，深得像是一口古井，让人看不到底。

"沈清宁同志。"他说，声音压得很低，"我有个问题想问你。"

"请说。"沈清宁说，心跳开始加速。

陆霆没有立刻说话。他看着她，像是在审视什么。然后，他忽然抬起手，在旁边的栏杆上轻轻敲了几下。

咚。咚咚。咚。

沈清宁的血液瞬间凝固了。

那是战场暗语。

三短一长，是"自己人"的意思。

十年前，在边境战场，她和陆沉就是用这种暗语交流的。那时候他们都还年轻，都还不知道什么是战争，什么是死亡。他们在战壕里，在月光下，用手指敲击着枪托，传递着只有彼此能懂的信息。

三短一长，自己人。

两短两长，有危险。

一长三短，撤退。

这些暗语，她这辈子都不会忘记。

沈清宁的手在袖子里攥紧了。她知道自己应该装作不懂，应该用困惑的眼神看着他，应该问他在做什么。

但她没有。

她的手指不受控制地动了起来，在自己的衣角上轻轻敲击。

咚咚。咚。咚咚。

两短两长，有危险。

她不知道自己为什么要这样做。也许是本能，也许是十年的肌肉记忆，也许是她内心深处某个被压抑的声音在呐喊。

陆霆的眼睛忽然亮了一下。

那是沈清宁第一次在他脸上看到情绪的波动。虽然只是一瞬间，虽然很快就被他压了下去，但她看到了。

他的眼神里有惊讶，有困惑，还有一丝……她不敢确定的东西。

"你……"他开口，声音有些沙哑。

"陆首长。"沈清宁打断他，脸上挂着标准的微笑，"您刚才在做什么？"

陆霆看着她，沉默了几秒。

"没什么。"他说，声音恢复了平淡，"手痒，随便敲敲。"

"哦。"沈清宁点点头，"那我们走吧，别耽误了报到。"

她转身向前走去，心跳如雷。

她知道自己刚才冒了很大的险。她不应该回应那个暗语，不应该暴露自己懂这些东西。但她控制不住。

十年了。

十年来，她一直在压抑自己，一直在假装自己什么都不知道，什么都不记得。但那些暗语，那些只有她和陆沉才懂的暗语，就像是刻在她骨头里的烙印，怎么都抹不掉。

陆霆跟在她身后，没有再说话。

但沈清宁能感觉到他的目光，一直落在她的背上，像是要把她看穿。

两人走进办公楼，开始办理各种手续。

填表，盖章，签字，拍照。一切都很顺利，顺利得像是早就安排好的。

但沈清宁知道，这只是开始。

从今天起，她就是陆霆的妻子了。不管她愿不愿意，不管她想不想，她都必须扮演好这个角色。

而那个叫陆霆的男人，那个背上有一道和陆沉一模一样伤疤的男人，那个用战场暗语试探她的男人——

他到底是谁？

他和陆沉，到底是什么关系？

沈清宁不敢想下去。

但她知道，她必须弄清楚。

因为那道伤疤。

因为那个暗语。

因为她心里那个被压抑了十年的声音，正在疯狂地呐喊。

陆沉没死。

陆沉一定没死。

而眼前这个叫陆霆的男人，就是陆沉。

一定是。

一定是。

一定是。
