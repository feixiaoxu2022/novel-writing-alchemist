# 第三章共犯

那之后的日子，变得奇怪起来。

沈清宁说不清是从什么时候开始的。也许是第三天，也许是第五天，也许是某个她已经记不清的深夜。她只知道，她和陆霆之间，多了一些不该有的东西。

那些东西藏在眼神里，藏在手势里，藏在每一个不经意的触碰里。

那天晚上，陆霆很晚才回来。

沈清宁已经躺在床上了，但她没有睡着。她睁着眼睛，看着天花板上的红色囍字，听着窗外哨兵换岗的脚步声。

门开了。

陆霆走进来，身上带着淡淡的酒气。他没有开灯，借着窗外的月光，走到沙发边坐下。

"还没睡？"他问，声音有些沙哑。

"睡不着。"沈清宁说。

沉默。

两人都没有说话。空气里弥漫着一种奇怪的张力，像是两根绷紧的弦，随时可能断裂。

然后，陆霆动了。

他抬起手，在黑暗中轻轻敲击着沙发扶手。

咚。咚咚。咚。

三短一长，自己人。

沈清宁的心跳漏了一拍。

她知道这是什么意思。这是他们之间的暗号，是只有他们才懂的语言。三短一长，自己人。两短两长，有危险。一长三短，撤退。

她应该装作不懂。她应该用困惑的眼神看着他，应该问他在做什么。

但她没有。

她的手指在被子里动了起来，轻轻敲击着床单。

咚咚。咚。咚咚。

两短两长，有危险。

陆霆的动作停了一下。

然后，他继续敲击。

咚咚咚。咚。

三长一短，我在。

沈清宁的眼眶忽然有些发酸。

三长一短，我在。这是他们十年前的暗号。那时候，每当她害怕的时候，陆沉就会用这个暗号告诉她，他在，他一直都在。

她的手指颤抖着，敲击出回应。

咚。咚咚咚。

一短三长，我也在。

黑暗中，两个人用手指敲击着各自的支撑物，传递着只有彼此能懂的信息。那些信息很简单，简单到只有几个字。

我在。

我也在。

我想你。

我也是。

沈清宁不知道自己是什么时候开始流泪的。她只知道，当她意识到的时候，枕头已经湿了一片。

十年了。

十年来，她一直以为陆沉死了。十年来，她一直在压抑自己，一直在假装自己什么都不记得。但那些暗号，那些只有他们才懂的暗号，就像是刻在她骨头里的烙印，怎么都抹不掉。

她想他。

她一直都在想他。

即使她以为他死了，即使她告诉自己要忘记，她还是在想他。每一个深夜，每一个独处的时刻，她都在想他。

想他的笑，想他的声音，想他的拥抱，想他在月光下对她说"等我回来"。

而现在，他就在这里。

就在几米之外的沙发上。

用他们的暗号，告诉她，他也在想她。

沈清宁从床上坐起来。

"陆霆。"她说，声音有些颤抖。

"嗯。"他应了一声。

"你……"她想问他是不是陆沉，想问他为什么要骗她，想问他这十年去了哪里。但话到嘴边，她又说不出口。

因为她害怕。

害怕听到否定的答案，害怕发现这一切都只是她的幻觉，害怕再次失去他。

"过来。"陆霆说。

沈清宁愣了一下。

"过来。"他重复了一遍，声音低沉，"我想抱你。"

沈清宁的心跳如雷。

她知道自己应该拒绝。她知道这是不对的。他们是政治联姻的夫妻，是组织安排的搭档，他们不应该有任何私人的感情。

但她控制不住。

她从床上下来，光着脚，一步一步走向他。

陆霆伸出手，把她拉进怀里。

他的怀抱很紧，紧得像是要把她揉进骨头里。他的下巴抵在她的头顶，他的呼吸喷在她的发间，他的心跳透过胸膛传来，和她的心跳渐渐同步。

"清宁。"他叫她的名字，声音沙哑得像是砂纸，"我找了你十年。"

沈清宁的眼泪终于决堤。

"我以为你死了。"她哭着说，"我以为你死了，我哭瞎了眼睛，我……"

"我知道。"陆霆打断她，"我都知道。对不起，让你等了这么久。"

"你为什么不来找我？"沈清宁抬起头，泪眼朦胧地看着他，"你为什么要骗我？你为什么要让我以为你死了？"

陆霆沉默了。

他的眼神很复杂，复杂到沈清宁看不懂。有痛苦，有愧疚，有无奈，还有一丝她不敢确定的东西。

"因为我以为你瞎了。"他终于开口，声音低沉，"十年前，你中了弹片，伤到了眼睛。我以为你再也看不见了。我以为你需要一个新的开始，一个没有我的新的开始。"

"所以你就假死？"沈清宁的声音有些尖锐，"所以你就让我以为你死了？你知道我这十年是怎么过的吗？你知道我每天晚上都在做噩梦吗？你知道我……"

"我知道。"陆霆再次打断她，"我都知道。对不起，清宁，对不起。"

他低下头，吻住了她的嘴唇。

那个吻很轻，轻得像是羽毛，却又重得像是山。沈清宁能尝到他嘴唇上的酒气，能感受到他舌尖的颤抖，能听到他喉咙里压抑的呜咽。

她回应了他。

她用尽全身的力气，回应了他。

十年的思念，十年的痛苦，十年的压抑，在这一刻全部爆发。她抱着他，吻着他，像是要把这十年错过的时光全部补回来。

窗外，哨兵的脚步声由远及近。

沈清宁的身体僵了一下。

陆霆也停了下来。

两人对视，都从对方的眼里看到了紧张和兴奋。

哨兵的脚步声越来越近，越来越清晰。沈清宁能听到皮靴踩在地上的声音，能听到枪带碰撞的声音，能听到哨兵低沉的交谈声。

他们就在窗外。

只有一墙之隔。

陆霆的手开始解她的扣子。

沈清宁想阻止他，但她的身体不听使唤。她的手也开始解他的扣子，动作急切而笨拙。

哨兵的脚步声停了。

就在窗外。

沈清宁的心跳几乎停止。

然后，脚步声继续远去。

哨兵走了。

两人同时松了一口气，然后同时笑了起来。那笑声很轻，轻得像是叹息，却又重得像是解脱。

"继续。"陆霆说，声音沙哑。

沈清宁点点头。

他们在黑暗中纠缠在一起，用战场暗语交流，用沉默做爱。那些曾用来杀人的手势，现在用来调情。那些曾用来传递情报的暗号，现在用来表达爱意。

三短一长，自己人。

两短两长，有危险。

一长三短，撤退。

三长一短，我在。

一短三长，我也在。

咚。咚咚。咚。

咚咚。咚。咚咚。

咚咚咚。咚。

咚。咚咚咚。

他们用手指敲击着彼此的身体，传递着只有他们才懂的信息。那些信息很简单，简单到只有几个字。

我爱你。

我也爱你。

我想你。

我也想你。

我在。

我也在。

窗外，哨兵的脚步声再次响起。

这一次，他们没有停下。

因为他们已经是共犯了。

共犯。

这个词在沈清宁的脑海里回荡，像是一首古老的歌谣，像是一个永恒的誓言。

他们是共犯。

他们背叛了组织，背叛了任务，背叛了所有人的期望。

但他们不在乎。

因为他们找到了彼此。

在这个红色的囚笼里，在这个压抑的世界里，他们找到了彼此。

这就够了。

这就够了。
