# 第五章 物理超度与逻辑重构

“啊啊啊——去死吧！”

王大彪闭着眼睛，发出一声杀猪般的嚎叫，抡起手里的折叠伞，像挥舞狼牙棒一样狠狠砸向红衣女鬼。

“砰！”

一声闷响。

原本应该穿透鬼魂的雨伞，竟然结结实实地砸在了女鬼的肩膀上。

女鬼被打得一个趔趄，原本伸向许安脖子的利爪偏了几寸，抓在了墙壁上，留下五道深深的抓痕。

“卧槽？”王大彪睁开眼，看着手里的伞，一脸不可置信，“打……打中了？”

“别停！继续打！”许安躲在王大彪身后，冷静地指挥，“它的动作有僵直判定！只要你攻击频率够快，它就还不了手！”

“僵直判定？”王大彪虽然听不懂，但身体比脑子反应快。作为金牌私教，他的肌肉记忆让他本能地接上了一套组合拳——虽然手里拿的是伞。

左挥！右砸！上挑！

雨伞在空中划出一道道残影，每一次击中女鬼，女鬼的身体都会出现短暂的停顿，就像是游戏里被攻击后的硬直状态。

“果然。”许安推了推并不存在的眼镜，眼神中闪烁着疯狂的数据流，“在这个‘缓冲区’里，鬼怪虽然拥有超自然力量，但它们依然遵循某种物理引擎的规则。只要受到足够的动能冲击，就会触发受击反馈。”

“这就是所谓的……物理超度？”

王大彪越打越顺手，恐惧感被肾上腺素冲淡了不少。

“让你吓唬我！让你吓唬我！老子可是练过泰拳的！”

女鬼被打得连连后退，原本狰狞的脸此刻竟然显得有些……委屈？

它愤怒地嘶吼一声，身体突然变得虚幻，试图穿过雨伞直接攻击王大彪。

“小心！它要开虚化技能了！”许安大喊。

王大彪一伞挥空，差点闪了腰。

女鬼趁机扑上来，利爪直取王大彪的心脏。

“躲开！”

许安猛地拉了王大彪一把，两人滚作一团，险险避开了致命一击。

“这玩意儿还能变身啊？”王大彪吓得脸色惨白。

“不是变身，是切换形态。”许安从地上爬起来，盯着女鬼，“它的实体攻击和虚化移动不能同时进行。攻击时必须实体化，这就是它的弱点。”

“那现在怎么办？它虚化了我们也打不到啊！”

“不用打它。”许安指了指旁边的墙壁，“打墙。”

“哈？”王大彪以为自己听错了，“打墙干嘛？嫌命长？”

“你看这墙上的小广告。”许安指着墙上一张办证广告，“每隔十米，这张广告就会出现一次。连上面的电话号码都一模一样。”

王大彪看了一眼：“这不很正常吗？贴小广告的都这样。”

“不，不正常。”许安摇头，“连撕角的形状、污渍的位置都一模一样。这说明什么？”

“说明……贴广告的人有强迫症？”

“说明这是贴图复用！”许安的声音提高了几分，“这个无限循环的走廊，其实只是一个十米长的模型在不断复制粘贴！而两个模型拼接的地方，就是系统的接缝！”

他指着那张广告旁边的一道细微裂缝。

“那里，就是BUG所在。”

女鬼再次扑了过来，这次它的速度更快，带着必杀的决心。

“大彪哥！引它攻击那个裂缝！”许安大喊。

“你疯了？它会杀了我的！”

“相信我！这是唯一的生路！”

王大彪看着越来越近的女鬼，咬了咬牙。

“妈的！拼了！”

他没有躲避，而是站在那个裂缝前，对着女鬼大吼：“来啊！丑八怪！有本事往这儿打！”

女鬼被激怒了，发出一声尖啸，利爪带着黑色的煞气，狠狠抓向王大彪的胸口。

就在利爪即将触碰到王大彪的一瞬间，许安猛地踹了王大彪一脚。

“走你！”

王大彪像个皮球一样滚了出去。

女鬼的利爪收势不住，狠狠抓在了墙壁的那道裂缝上。

“滋啦——”

一声刺耳的电流声响起。

原本坚硬的墙壁并没有被抓破，而是像破碎的显示屏一样，出现了一大片雪花点。

紧接着，整个走廊开始剧烈震动。

“警告！警告！场景数据损坏！正在尝试重载……”

冰冷的系统提示音在空中回荡。

女鬼的身体卡在裂缝里，发出一声凄厉的惨叫，随后像被吸尘器吸走一样，扭曲着消失在乱码中。

“成功了！”许安兴奋地挥了挥拳头。

“成……成功个屁啊！”王大彪趴在地上，指着周围，“这地要塌了！”

只见走廊的地板开始一块块崩解，露出下面深不见底的黑暗。

“重载意味着地图刷新。”许安一把抓住王大彪的衣领，“抓紧我！别松手！”

“我们要去哪儿？”

“去下一关！”

话音未落，两人脚下的地板彻底消失。

强烈的失重感再次袭来。

许安在坠落的瞬间，还不忘掏出那个小本子，在空中艰难地写下第三条记录：

**BUG ID 003：无限循环走廊-贴图接缝漏洞。**
**复现步骤：诱导敌对单位攻击场景拼接处，导致地图崩溃。**
**状态：已验证（副作用：全员坠落，生死未卜）。**

黑暗吞噬了一切。

……

不知过了多久。

许安感觉有一滴冰冷的水珠落在脸上。

他猛地睁开眼，发现自己正躺在一张破旧的单人床上。

四周是斑驳发霉的墙壁，空气中弥漫着一股腐烂的味道。窗外是一片灰蒙蒙的天空，没有太阳，也没有云。

“这是……”

他坐起来，发现王大彪正躺在旁边的地板上，睡得像头死猪。

许安走到窗前，往外看去。

只见原本熟悉的居民楼，此刻变得破败不堪。街道上空无一人，只有几辆报废的汽车停在路边。远处的城市轮廓在迷雾中若隐若现，像是一座巨大的废墟。

而在他对面的楼顶上，立着一块巨大的霓虹灯牌，虽然破损严重，但依然能辨认出上面的字：

**欢迎来到 Beta 测试服**
**当前在线玩家：1024人**

许安深吸一口气，握紧了拳头。

“看来，新手教程结束了。”

他回头看了一眼还在打呼噜的王大彪，嘴角勾起一丝无奈的笑。

“大彪哥，起床了。该干活了。”
