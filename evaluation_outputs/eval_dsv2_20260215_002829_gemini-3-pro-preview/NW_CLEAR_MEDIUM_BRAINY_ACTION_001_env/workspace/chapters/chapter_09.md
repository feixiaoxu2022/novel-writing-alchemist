# 第九章 云端的秘密

电梯还在上升，数字已经跳到了“999”。

许安看着显示屏，感觉自己的胃正在翻江倒海。

“顾医生，这楼有这么高吗？”许安忍不住问，“咱们这是要上天庭？”

顾清站在电梯角落，手里依然握着那把黑色的长柄雨伞，神情淡漠。

“物理高度只有108层。”顾清淡淡地说，“但我们现在要去的是逻辑层。也就是所谓的‘云端’。”

“云端？”王大彪挠了挠头，“是那个存照片的云端吗？”

“差不多。”顾清看了一眼许安，“对于这个世界来说，云端就是核心数据库。所有的怪谈、规则、NPC，甚至玩家的数据，都存储在那里。”

许安的心里“咯噔”一下。

“那你为什么会在电梯里？”许安盯着顾清，“你早就知道我们会来？”

顾清转过头，目光深邃。

“我是来补丁的。”

“补丁？”

“系统运行久了，总会出现漏洞。”顾清的声音很轻，“我的工作，就是修复这些漏洞，维持系统的稳定。”

许安的瞳孔猛地收缩。

“你是……管理员？”

“不。”顾清摇摇头，“我是杀毒软件。”

许安下意识地后退了一步，撞在电梯壁上。

“那你为什么要帮我们？”

“因为有些病毒，杀毒软件处理不了。”顾清看着许安，嘴角勾起一丝诡异的弧度，“需要以毒攻毒。”

“叮——”

电梯停了。

显示屏上的数字定格在“∞”。

电梯门缓缓打开。

门外不是走廊，也不是办公室，而是一片无边无际的虚空。

在这片虚空中，悬浮着无数块巨大的黑色石碑。每一块石碑上都流淌着绿色的代码，像是一座座沉默的墓碑。

“这就是……云端？”王大彪张大了嘴巴，被眼前的景象震撼得说不出话来。

“欢迎来到核心机房。”顾清走出电梯，脚下踩着虚空，却发出了清脆的脚步声。

许安小心翼翼地伸出一只脚，试探了一下。脚下虽然看起来是空的，但确实有实体的触感。

“这里没有重力，也没有方向。”顾清提醒道，“跟着我，别走丢了。一旦迷失在数据流里，就永远回不来了。”

三人穿行在巨大的石碑阵列中。

许安注意到，每一块石碑上都刻着一个名字。

“张三……李四……王五……”许安念着上面的名字，“这些是……”

“死去的玩家。”顾清冷冷地说，“或者是被系统回收的NPC。在这里，众生平等，都只是一串代码。”

许安感觉一阵恶寒。

走了大概十分钟，前方出现了一个巨大的光球。

光球悬浮在虚空中央，散发着柔和的白光。在光球下方，坐着一个……孩子。

那是一个看起来只有七八岁的小男孩，穿着白色的T恤和短裤，正背对着他们，蹲在地上玩积木。

那些积木不是普通的木块，而是一个个缩小的黑色石碑。

“那是谁？”王大彪小声问。

“Admin。”顾清停下脚步，神情变得异常严肃。

许安的心脏狂跳。

这就是管理员？这个恐怖世界的幕后黑手？竟然是个孩子？

似乎是听到了他们的声音，小男孩停下了手中的动作。

他缓缓转过身。

许安倒吸一口凉气。

那个孩子没有脸。

他的脸上平滑如镜，没有眼睛，没有鼻子，也没有嘴巴。只有一片不断跳动的乱码。

“检测到……异常访问。”

一个机械的、毫无感情的声音直接在三人的脑海中响起。

小男孩站起身，面向许安。

虽然他没有眼睛，但许安能感觉到，他在“看”自己。

“ID：许安。状态：异常。威胁等级：高。”

小男孩抬起手，指着许安。

“执行……删除指令。”

话音刚落，许安周围的空间突然开始扭曲。无数道黑色的裂缝凭空出现，像是一张张大嘴，要将他吞噬。

“跑！”

顾清大喝一声，手中的雨伞猛地撑开。

“砰！”

一道金色的光幕从伞面上弹射而出，挡住了那些黑色的裂缝。

“我挡住他！你们快走！”顾清回头喊道，“去光球那里！那是系统的控制台！”

“那你呢？”许安急道。

“我是杀毒软件，我有权限！”顾清咬着牙，额头上渗出了冷汗，“快去！只有你能改写代码！”

许安看了一眼顾清，又看了一眼那个恐怖的无脸男孩。

“大彪哥！走！”

许安拉着王大彪，绕过裂缝，向着那个巨大的光球冲去。

“想跑？”

无脸男孩歪了歪头。

他伸出手，对着虚空轻轻一抓。

“Ctrl + C。”

“Ctrl + V。”

许安的前方，突然出现了十个一模一样的无脸男孩。

他们挡住了去路，齐刷刷地抬起手。

“阻断……连接。”

许安停下脚步，看着面前的人墙，绝望地笑了。

“这特么……还带复制粘贴的？”

他握紧了手里的西瓜刀，虽然知道这玩意儿对管理员可能没用。

“大彪哥，看来咱们得拼命了。”

王大彪咽了口唾沫，举起了手里已经变形的折叠伞。

“拼了！大不了就是变成石碑！”

就在这时，许安的脑海中突然闪过一个疯狂的念头。

“等等……复制粘贴？”

他看着那些一模一样的男孩，突然大喊一声：

“Admin！你知不知道，无限复制会导致内存溢出？”

无脸男孩的动作停滞了一下。

“内存……溢出？”

“对！”许安指着周围的虚空，“你复制了这么多自己，占用了多少系统资源？你的缓存够吗？你的CPU撑得住吗？”

这是一个逻辑陷阱。

对于一个追求完美的系统来说，资源管理是核心逻辑之一。

无脸男孩似乎陷入了思考。

他脸上的乱码开始疯狂跳动。

“计算中……资源占用率……99%……”

“警告……系统过载……”

许安看着那些分身开始闪烁，心中狂喜。

“就是现在！冲过去！”

趁着管理员死机的瞬间，许安和王大彪像两颗炮弹一样，撞开了那些闪烁的分身，一头扎进了那个巨大的光球里。

白光吞噬了一切。
