# 第三章 只有疯子才匹配

苏清禾走向陆沉的那几步，走得很慢，却很稳。

每一步，都像是踩在林森那理性的神经上。

“苏清禾！”林森的声音第一次失去了那种冷漠的控制力，带上了一丝不可置信的焦急，“你在干什么？他是个疯子！他把你当宠物养了整整一年！你清醒一点！”

苏清禾停下脚步。她没有回头看林森，目光始终锁在陆沉身上。

陆沉被两个护工死死按在地上，脸颊贴着冰冷的地板，那道被她抓出的血痕显得格外刺眼。他仰着头，看着向他走来的苏清禾，眼神里充满了震惊、恐惧，还有一丝不敢触碰的希冀。

“我知道。”苏清禾轻声说。

她的声音不大，但在死寂的房间里，清晰得像是一声惊雷。

“我知道他是疯子。”苏清禾蹲下身，视线与陆沉平齐，“我也知道这里是笼子。”

她伸出手，指尖轻轻触碰陆沉颤抖的睫毛。

“可是林医生，”她转过头，看着那个代表着“正常”与“理智”的男人，嘴角勾起一抹凄凉的笑，“在那个正常的世界里，没有人需要我。连我自己都不需要我自己。”

“但在他的笼子里，我是他的全世界。”

林森愣住了。他推了推眼镜，试图用逻辑来分析这个荒谬的结论。

“这是斯德哥尔摩综合症。”他冷冷地判断，“典型的病理反应。你需要治疗。”

“去他的治疗。”苏清禾突然爆发了。她抓起地上的那个药瓶，狠狠地砸向林森。

药瓶砸在林森的胸口，滚落在地，发出清脆的声响。

“你们所谓的治疗，就是让我清醒地面对痛苦吗？”苏清禾吼道，“让我记起我是怎么被父母抛弃的？记起我是怎么在绝望中割开手腕的？那就是你们给我的‘正常’吗？”

林森后退了一步，显然被她眼中的疯狂震慑住了。

“放开他。”苏清禾转过头，盯着那两个护工，眼神冷得像冰，“否则我就死给你们看。”

她捡起地上那块碎裂的镜片，抵在自己的颈动脉上。锋利的边缘瞬间划破了皮肤，渗出一颗血珠。

“别！”陆沉嘶吼出声，拼命挣扎，“别伤害她！放开我！我听话！我什么都听你们的！”

护工们面面相觑，看向林森。

林森的脸色铁青。他看着苏清禾颈边的血，又看了看几近崩溃的陆沉。

作为医生，他知道实验已经彻底失败了。但他没想到，失败的方式竟然是这样的——两个病人，达成了某种病态的共识，联手对抗了整个理性的世界。

“放开他。”林森咬着牙说。

护工们松开了手。

陆沉猛地扑向苏清禾，一把夺下她手里的镜片，扔得远远的。然后他紧紧地抱住她，力气大得像是要把她揉进自己的骨血里。

“别做傻事……求你……”他浑身都在发抖，眼泪打湿了苏清禾的肩膀，“别丢下我……”

苏清禾回抱着他。她能感受到他剧烈的心跳，那是因她而跳动的频率。

在这个冰冷的世界上，只有这个怀抱是热的。

“我不走。”苏清禾在他耳边轻声说，“陆沉，我不走。”

陆沉猛地抬起头，看着她，眼神里满是难以置信。

“真的？”

“真的。”苏清禾捧着他的脸，拇指擦去他的泪水，“你是疯子，我也是。只有疯子才匹配，对不对？”

陆沉看着她，良久，突然笑了。

那个笑容不再是之前那种完美的、虚假的温柔，而是带着一种破碎的、狂乱的幸福。

“对。”他喃喃道，“只有疯子才匹配。”

林森看着这一幕，感到一种深深的无力感。他合上病历本，叹了口气。

“你们赢了。”他说，“但我必须提醒你们，这种共生关系是病态的，不可持续的。总有一天，你们会互相毁灭。”

“那也是我们的事。”陆沉冷冷地说，把苏清禾护在身后，“滚出去。”

林森深深地看了他们一眼，转身带着护工离开了。

门关上了。

房间里只剩下两个人。

满地的狼藉，撕裂的墙纸，破碎的镜片。这里不再是那个完美的白色天堂，而是一个充满了裂痕的废墟。

但苏清禾觉得，这才是真实的。

她捡起地上的药瓶，倒出两粒药。

“陆沉。”她叫他。

陆沉看着她手里的药，眼神有些慌乱。

“你……不用吃的。”他小心翼翼地说，“既然你都想起来了，我们可以……”

“不。”苏清禾打断了他。

她走到床边，坐下，拍了拍身边的位置。

陆沉乖顺地走过去，坐下，像是一只等待审判的大型犬。

“我不想记起那些痛苦的事。”苏清禾看着手里的药片，“你说得对，外面的世界太冷了。我宁愿活在你的谎言里。”

她抬起头，看着陆沉的眼睛。

“陆沉，我要你继续骗我。”

“我要你每天都重新追求我，每天都让我爱上你。我要你把那些痛苦的记忆都洗掉，只留下我笑的样子。”

“你能做到吗？”

陆沉看着她，眼眶再次红了。他颤抖着伸出手，握住她的手，把那两粒药片紧紧包裹在掌心。

“我能。”他哽咽着说，“我发誓，我会给你造一辈子的天堂。”

苏清禾笑了。这一次，她的笑容里没有了迷茫，只有一种尘埃落定的决绝。

她就着陆沉的手，吞下了那两粒药。

苦涩的味道在口腔里蔓延，但她觉得很甜。

药效很快上来了。困意像潮水一样袭来。

苏清禾躺在床上，陆沉帮她盖好被子。

“陆沉。”她在意识模糊前唤道。

“我在。”

“墙上的字……”她指了指那面斑驳的墙壁，“别忘了记。”

“好。”

“那你……明天记得再追我一次。”

“好。”陆沉俯下身，在她的额头上落下一个吻。这一次，那个吻是滚烫的。

“晚安，清禾。”

苏清禾闭上了眼睛，嘴角带着一丝满足的笑意，沉入了无梦的睡眠。

房间里安静下来。

陆沉坐在床边，看着她熟睡的脸庞，看了很久很久。

然后，他站起身，从口袋里掏出那把刻刀。

他走到墙边，在那个未完成的“正”字上，补上了最后一笔。

第三百二十五天。

他看着那个完整的“正”字，手指轻轻抚摸过墙面上那些密密麻麻的刻痕。

那是她的笑容。也是他的救赎。

他知道林森说得对，这是一种病态的共生。但他不在乎。

只要她还在，只要这个循环还在，这里就是天堂。

陆沉收起刻刀，关上了灯。

黑暗中，他躺在苏清禾身边，握住了她的手。

明天，又是新的一天。

也是旧的一天。

但这有什么关系呢？

只要是爱她的一天，就是好的一天。
