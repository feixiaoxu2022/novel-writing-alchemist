# 第十二章 解码

温声从来不是一个被动等待答案的人。

陆鸣事件之后的第二天，她做了一件她从进入录音棚以来就想做但一直没有腾出时间做的事——系统性地整理和分析"系统"发送过的所有摩斯密码。

盲文笔记本。她的手指在凸起的点阵上飞速滑动，回溯她这两周来的记录。

作为一个声音工程师，她的记忆力是惊人的。更准确地说，她的听觉记忆力是惊人的。每一段听过的声音——包括摩斯密码的敲击节奏——都以极高的保真度存储在她的大脑中。所以她可以在事后几天甚至几周内回溯这些信号的具体内容。

她在笔记本上开了一个新页，标题是："系统信号日志"。

然后她开始按时间顺序，把每一段能回忆起来的摩斯密码都记录下来。

——第七天（首次信号）：UP LEFT SEAL。上方左侧，封堵。（生存指令。）
——第七天（第二次）：GOOD。好。
——第八天（清晨）：SAFE。安全。
——第八天（夜间）：SLEEP。睡吧。
——第九天（清晨）：OK。好。
——第九天（工作中）：540. 2100。（频率参数。）
——第九天（夜间）：GOOD NIGHT。晚安。

她的手指停了一下。

GOOD NIGHT？

她回忆了一下。是的——第九天晚上十一点，"系统"发送的信号不是"SLEEP"而是"GOOD NIGHT"。比平时多了一个单词。

她接着回溯。

——第十天（清晨）：HERE。在这里。
——第十天（工作中）：频率参数。DANGER。（否定冻结频率。）
——第十天（夜间）：FINE。没事。
——第十一天（清晨）：STILL HERE。还在这里。
——第十一天（夜间）：DON'T FEAR。不要怕。
——第十二天（清晨）：TODAY GOOD。今天很好。
——第十二天（夜间）：SLEEP WELL。睡好。
——第十三天（清晨）：MORNING。早。
——第十三天（丧尸手臂事件后）：SORRY。对不起。

温声的笔尖在盲文纸上刻出了一个长长的破折号。

SORRY。

在那只丧尸从管道里伸出手之后——"系统"发送了"SORRY"。

一个紧急广播系统为什么要说"对不起"？

她继续。

——第十三天（夜间，她发现陆鸣后）：HERE。在。NOT ALONE。不是一个人。

温声的手指停在了"NOT ALONE"的盲文字符上。

不是一个人。

在她因为陆鸣崩溃大哭的那个夜晚——当那个沉默的军人抱住她的时候——耳机里的"系统"发送了"不是一个人"。

她把笔记本放在膝盖上。

然后她做了一件事——把所有信号按照"生存指令"和"非指令"两个类别重新分类。

生存指令类：UP LEFT SEAL / 频率参数 / DANGER / MORE。
非指令类：GOOD / SAFE / SLEEP / OK / GOOD NIGHT / HERE / FINE / STILL HERE / DON'T FEAR / TODAY GOOD / SLEEP WELL / MORNING / SORRY / NOT ALONE。

她数了数。

生存指令：四条。
非指令：十四条。

非指令数量是生存指令的三倍以上。

而且——非指令有一个明显的规律。它们集中出现在两个固定时间段：每天清晨六点和夜间十一点。生存指令则是随机出现的，只在危险时刻发送。

一个紧急广播系统——即使是最先进的AI驱动系统——不会在每天固定时间发送"晚安"和"早上好"。

这些不是系统信号。

这是一个人在说话。

温声把笔记本合上，放在身旁。

她的手开始发抖。

不是恐惧。不是愤怒。是一种她在声学上可以精确描述、但在情感上完全无法定义的振动——像一根弦被拨动后产生的泛音，一层叠一层地向上延伸，越来越高、越来越细，直到超出了她能命名的频率范围。

"这不是系统。"她对着空气说。声音很轻。

"这是一个人在和我说话。"

她把两只手叠在一起，放在了胸口。

"每天早上跟我说'安全'。每天晚上跟我说'睡吧'。在我害怕的时候说'不要怕'。在我哭的时候说'不是一个人'。"

她的嘴唇微微颤抖。

然后她笑了。

在黑暗中——她永远在黑暗中——她笑了一下。不是开心的笑，也不是苦涩的笑。是一种更复杂的东西——像是在漫长的黑暗中突然触碰到了一个温暖的点，不确定是什么，但知道它是真实的。

她没有去外棚揭穿他。

她只是重新戴上了耳机，回到了调音台前，继续调试诱饵参数。

好像什么都没有发生。

但从那天起，每当早上六点和晚上十一点的信号响起时——那些她曾经以为是"系统例行检测"的摩斯密码——她会在心里默默翻译出来。

今天早上是什么？

嗒嗒嗒。嗒-嗒嗒-嗒。嗒嗒嗒。嗒-嗒嗒-嗒嗒。嗒嗒。

S-T-I-L-L。

嗒嗒嗒嗒。嗒。嗒-嗒嗒-嗒嗒-嗒嗒。嗒。

H-E-R-E。

STILL HERE。

还在。

温声把手指贴在耳机的外壳上，感受着每一次嗒嗒声传来的微弱震动。

"嗯。"她无声地、只动了嘴唇地回答。

"我也是。"
