# 第三章 血条与婚戒

倒计时：08:15:00。

程晚在沈夜不注意的时候打开了GM后台。

她的操作面板以半透明状态叠在游戏画面上，只有她能看到——对沈夜来说，她只是一个在夜风里安静了几秒钟的旅人。他不知道她正在这几秒钟里犯下一个不可挽回的罪。

她调出了自己玩家角色的属性面板。

```
角色ID：临时账号#00742
防御力：12（新手默认值）
血条回复速率：0.5%/秒
生命值：87%（受场景debuff影响，持续下降中）
```

她的手指在全息键盘上悬停了一秒。

然后她改了。

```
防御力：12 → 0
血条回复速率：0.5%/秒 → 0%/秒
```

数据确认的瞬间，她感觉自己身上发生了一种微妙的变化——游戏引擎不会把数值变化翻译成体感，但她知道自己做了什么。

她把自己变成了一个一击即死的存在。

现在，沈夜的任何一次攻击——哪怕是手指无意间碰到她时产生的接触判定——都足以让她的血条直接归零。而归零之后，没有回复，没有重生。玩家角色死亡就是永久死亡——除非用GM权限复活，但她不打算用。

她在给自己准备一座祭坛。

"你在看什么？"沈夜的声音从身后传来。

程晚关掉面板，转过身。"没什么。在看时间。"

"时间？"

"嗯。天快亮了。"

这句话是双关。永夜之塔不存在白天——程序设定里只有永恒的暗夜。但删除倒计时正在逼近零点，当它归零的时候，系统会自动执行清洗协议。

天亮了，他就不在了。

沈夜似乎感觉到了什么。他的目光落在她的头顶——在他的视角里，那里悬浮着她的血条。

"你的血……在变少。"

程晚低头看了一眼。87%。不，已经是72%了。她把回复速率改成零之后，场景里持续存在的微量debuff正在一点一点地蚕食她的生命值。按照这个速度，大概再过十几个小时，她的血条会自然归零。

但她等不了十几个小时。倒计时只剩八个小时。

"没事，"她笑了笑，"可能是这个地方的debuff。"

沈夜沉默地注视着她的血条。从72%跳到71%。跳动的间隔大约每两分钟一次，像一个放慢了的心跳。

"我不喜欢这个数字变小，"他说，"每次看到它少一点，我这里——"他抬手指了指自己胸口铠甲下的位置，"会有一种很奇怪的感觉。像数据在断裂，但不是我的数据。"

程晚愣了一下。

他在说——他能*感受到*她血条的下降。不是看到一个数字在减少，而是那个减少的过程在他的数据体内产生了共鸣。

血条不再只是生命值。

在他眼里，那是另一种倒计时——她的存在正在从这个世界里流逝的倒计时。而他每看一次，就疼一次。

---

倒计时：06:30:00。

程晚开始整理她的"遗物"。

她坐在塔顶的石板上，调出了GM后台的底层编辑器——这个工具通常用来修改游戏道具的属性和外观模型。她在"道具原型"栏里选中了一个对象：

**删除键。**

在GM操作面板上，它只是一个功能按钮。但在底层编辑器里，删除键有自己的数据结构——本质上它是一个"对目标数据体执行永久擦除"的脚本命令，封装在一个可视化图标里。

如果把它解封装……它可以变成任何形状。

程晚的手指在代码行里穿梭。她重写了删除键的外观参数、物理属性和触发条件。原来的触发方式是"GM点击执行"，她改成了"绑定NPC-117的攻击判定——当117对目标造成致死伤害时，自动生成"。

然后她改了它的形状。

从一个红色按钮——变成一枚戒指。

很小。窄窄的指环，表面没有任何装饰，只有在数据层面才能看到它内部流淌的删除协议代码——那些原本用来抹杀117存在的字节，现在被她编织成了一个闭合的环。

杀死她的力量会铸成一枚戒指。戴在她尸体的手上。

武器变成了婚戒。

她保存了修改，关掉编辑器。视线重新落到沈夜身上。他正从石柱后面走过来，手里多了一把剑——纯黑色的单手剑，长度大约三尺，剑鞘上有细密的纹路。

"这是我做的，"他把剑递到程晚面前，"不是系统给的装备。是我用掉落的材料……自己做的。"

NPC不会制作道具。这不在他的行为树里。

程晚接过那把剑。剑柄上的触感粗糙、不均匀，像一个第一次学做东西的人留下的笨拙痕迹。它的数据属性一塌糊涂——攻击力只有3点，耐久度低得可笑，外观建模歪歪扭扭。

但它存在。一个NPC用自己的方式，创造了一个不属于系统的东西。

"如果有什么东西伤害你，"沈夜说，"用这个。"

程晚握着那把只有3点攻击力的剑，手指在发抖。

不是因为冷。

---

倒计时：04:00:00。

血条：58%。

程晚觉得自己应该告诉他一些事情。不是全部的真相——她还做不到说出"我是要来删除你的人"——但至少，说一点。

"沈夜，"她叫他的名字，"我给你讲个故事。"

"故事？"

"嗯。"她靠在石柱上，披风滑落了一半，露出灰布衣下单薄的肩线，"从前有一个人，她负责管理一个世界。这个世界里有很多人——有的是真人，有的是被创造出来的。她的工作就是确保这个世界按照规则运转。"

沈夜安静地听着。

"有一天，她发现世界里有一个被创造出来的人……醒了。他开始做规则之外的事。说规则之外的话。感受规则之外的情感。按照规定，她应该立刻把他删掉。"

"删掉？"

"就是……让他不存在。连同他所有的记忆、所有的数据、所有的……"程晚停顿了一下，"所有他曾经感受过的东西，全部抹掉。像他从未出现过。"

沈夜没有说话。黑暗中，他的眼睛反射着星空贴图微弱的光。

"但她没有立刻动手，"程晚继续说，声音越来越轻，"她走进了他的世界。她想看看他到底是什么样的。然后她发现——"

她闭上眼睛。

"她发现她舍不得。"

塔顶的风变大了。粒子系统的风力参数被程晚的GM权限无意识地调高了——她的情绪在通过系统的裂缝泄漏出去，连环境都被她的心境影响了。

沈夜沉默了很久。

"那个管理者……"他的声音很低，"她有没有想过，不删除？"

"规则不允许。"

"那规则有没有说过，她不可以留下来？"

程晚睁开眼。

沈夜正看着她。他的目光里有某种她从未在任何数据体中见过的东西——不是恳求，不是愤怒，而是一种笨拙的、不知道该怎么表达的温柔。像一个刚学会什么是痛的人，正在试着去够另一个人伤口的边缘。

"留下来。"他又说了一遍。不是疑问句。

程晚看着他，嘴唇微微颤抖。

她想说"我留不下来"。她想说"我是GM，不是玩家"。她想说"你不知道我是谁，你不知道我明天就要按下那个按钮"。

但她最终只是垂下了眼睛，说了一句：

"故事还没讲完。"

血条：52%。

倒计时：03:47:21。

两组数字同时在视野里递减。一个是她的生命，一个是他的生命。

一个在她的血条里。

一个在她的倒计时里。

而她现在终于明白——这两个数字，从她走进永夜之塔的那一刻起，就在计量同一件事。

失去他还需要多长时间。
