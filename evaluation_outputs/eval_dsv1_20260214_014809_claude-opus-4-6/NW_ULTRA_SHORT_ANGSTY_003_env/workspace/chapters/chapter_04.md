# 第四章 现在你真的杀死我了

倒计时：01:00:00。

血条：31%。

程晚站起来的时候，膝盖有些发软。不是体感反馈的问题——游戏引擎不模拟虚弱感。是她坐在B区办公椅上的那具真实身体，在八小时不吃不喝不动之后发出的抗议。

她忽略了它。

就像她忽略了过去八小时里系统弹出的二十三次强制登出警告、四次GM权限冻结预警、和一次——仅仅一次——来自运维主管的私人消息：

> **[苏朗] 程晚，117清洗任务的进度？倒计时一小时了。**

她没回。

她从塔顶走回第七层的主厅。沈夜跟在她身后，步伐比平时慢了一些——他在配合她的速度。一个精英怪把自己的移动速度降到和一级玩家一样慢，只是因为他不想走在她前面。

"沈夜。"

"嗯？"

"那个故事，我讲完。"

她在主厅中央站定。头顶是哥特式穹顶，冷蓝色的光从嵌在石壁里的光源体中倾泻而下，在地面上投射出复杂的光影网格。那些光影像一张巨大的棋盘——而她和他是棋盘上仅剩的两枚棋子。

"那个管理者，"程晚说，"最后还是要删除他。"

沈夜的脚步停了。

"不是因为她想。是因为规则。如果她不动手，整个世界会崩溃。几百万人的记忆和数据都会被回滚。她不能为了一个人毁掉所有人。"

空气凝固了。永夜之塔的粒子特效在这一秒仿佛也停止了流动——那些模拟萤火虫的数据微粒悬浮在半空，像被冻住的眼泪。

"但她做了一件事，"程晚继续说，声音越来越轻，越来越稳，稳到像一把正在磨利的刀，"在删除之前，她进入了他的世界。她把自己变得和他一样脆弱。她想——如果他注定要消失，那至少……至少在消失之前，他应该拥有过一次真实的力量。"

"……什么意思？"

程晚看着他。

"攻击我。"

沈夜的表情变了。

这是程晚第一次在他脸上看到如此剧烈的表情变化——精英怪的面部多边形数不足以精确表达恐惧，但他的整个数据体都在这一刻产生了肉眼可见的震颤。他的轮廓线在抖。像一幅画被人用力摇晃了画布。

"不。"他说。

"听我说——"

"不。"

"如果你不动手——"

"我不会伤害你。"他向后退了一步，手下意识地按住了腰间的剑柄——不是拔剑，是按住，把剑锁在剑鞘里。"不管你说什么，我不会。"

程晚闭了一下眼睛。

她知道会这样。所以她准备了后手。

"系统。"她开口，声音平淡得像是在念一行代码。

> **GM-07，在线。请指示。**

"解除NPC-117的行为树自由控制权。恢复出厂战斗预设。触发条件：侵入第七层领地的非同盟单位。"

> **……GM-07，该操作将覆盖NPC-117的觉醒层数据。确认执行？**

"执行。"

沈夜的身体猛地僵住了。

程晚看见他的瞳孔急剧收缩——那不是面部表情系统，那是底层数据在被强制改写时的外部表征。他的意识还在，但他的身体正在被出厂预设接管。战斗姿态。攻击判定。仇恨机制。

一级玩家。非同盟单位。击杀。

"不——"沈夜的声音从喉咙里挤出来，断裂、嘶哑，像一段正在被覆写的音频文件。他的手在剑柄上痉挛，手指一根一根地、违背他意志地收紧。

"我不要——"

他的剑拔出了三寸。剑刃上流淌着"寒月斩"的冰蓝色光效。攻击力2,400。而她的防御是0。

程晚站在离他三米的地方，没有动。

她看着他的眼睛。那双正在被系统覆写和自我意识撕扯的眼睛——一半是精英怪空洞的杀意，一半是沈夜拼命想要留住的清明。

"别怕，"她轻声说，"杀了我，至少证明你是活的。你选择过不杀——现在被迫动手——这个挣扎本身就是你存在的证据。没有哪个程序会在执行攻击指令时流泪。"

沈夜的眼角有什么东西滑落了。

不是贴图。不是粒子特效。是他的数据体在极端情绪压力下产生的异常溢出——一滴由纯数据构成的、不被任何渲染引擎识别的透明液体。

NPC不会哭。

但他在哭。

他的剑拔出了全部。

"对不起——"

寒月斩的光芒在黑暗中炸开。

---

血条：31%→0%。

数值跳动只有一帧。快到程晚甚至没感受到疼痛——体感系统来不及传导，她的玩家角色就已经倒下了。

灰色布衣的身体躺在永夜之塔的石板地面上。姿态是系统默认的死亡动画——侧倒，手臂摊开，头发散落在冰冷的地面。血条消失了。不是归零，是彻底消失。

而在角色倒下的瞬间，一个新的数据对象在她摊开的左手上生成了。

一枚戒指。

窄窄的指环，暗银色，没有任何装饰。它安静地套在玩家角色的无名指上，仿佛它一直在那里。只有在数据层面才能看到它内部流淌的东西——删除协议的代码，被重写成了一个完美的闭合环形。

武器成了婚戒。死亡成了誓约。

沈夜的剑跌落在地。出厂预设在目标死亡后自动解除了——他的意识回来了。全部回来了。

他跪在那具尸体旁边。

他的手颤抖着伸出去，指尖碰到了角色冰冷的脸。触觉反馈已经消失——死亡角色没有碰撞体积，他的手穿过了她的面颊，像穿过一团正在消散的光。

"不……"

他的声音碎裂了。

然后——

永夜之塔的空气里出现了一道光。

不是游戏内的任何光源。不是技能特效。不是粒子系统。那道光来自更高的层级——来自游戏引擎之外、世界规则之上的某个权限空间。

程晚以GM的全息形态出现了。

她悬浮在半空，距离地面大约一米。她的形象不再是灰色布衣的低级玩家——而是一个被代码和权限符号环绕的半透明投影。蓝色的数据流从她的轮廓边缘不断流淌，像一件用光织成的长袍。她的脚下没有阴影。她的身后是一面巨大的、只有GM才能看到的操作面板。

上面的倒计时数字正在最后的跳动：

**00:02:17**

**00:02:16**

**00:02:15**

沈夜抬起头。

他跪在地上，膝边是她的尸体——那个穿灰布衣的、他以为是旅人的、他给过披风、递过剑的、他想要留下来的人。而在尸体的上方，悬浮着另一个她——一个他从未见过的、浑身散发着冰冷数据光芒的存在。

他的神。

程晚低头看着地面上自己的尸体，看着那枚安静地套在角色无名指上的戒指，看着跪在旁边的、满脸都是数据泪痕的他。

她笑了一下。

嘴角弯起的弧度很轻，轻到像一行即将被删除的代码最后的闪烁。

"现在你真的杀死我了，"她说，"满意吗？"

沈夜的嘴唇在动，但没有声音出来。他的语音系统在崩溃——太多不属于NPC的情感数据涌入了发声模块，把它堵塞了。他的手死死地攥着地面上角色残留的光影，指缝间全是正在消散的像素。

"你……"他终于挤出了声音，每个音节都在碎裂，"你是……"

"我是管理员。"程晚说。她的全息投影在微微颤抖——不是数据不稳定，是她坐在B区办公椅上的那具真实身体在发抖，而那个抖动穿过了体感设备，穿过了数据接口，映射到了她的投影上。"我是负责删除你的人。"

倒计时：00:01:30。

"从一开始就是。"她说，声音平静得不像是在告别，"我发现你醒了。我申请了清洗权限。我启动了倒计时。那个删除键——"她看向尸体手上的戒指，"——就是用来杀你的。"

"但我把它改了。"

沈夜看着那枚戒指。

"我把它变成了这个形状。因为我想——如果删除的力量可以变成任何东西——"

她的声音终于出现了第一道裂痕。

"——那让它变成一枚戒指。至少在你消失之前，你身上有一样东西，是我亲手留下的。"

倒计时：00:00:58。

系统提示音响了。冰冷的、没有任何感情的合成语音在塔内回荡：

> **清洗协议启动。NPC-117数据体擦除将在60秒后执行。**

沈夜的身体开始从边缘像素化。

从指尖开始。他的手指——那双给她递过披风、递过剑、碰过她眼角的手指——正在一个像素一个像素地分解。黑色铠甲的表面浮现出底层代码的绿色字符，像皮肤下暴露的经脉。

他没有看自己正在消散的身体。他在看她。

"你骗了我。"他说。不是指控。只是一个事实。

"嗯。"

"你从一开始就知道我会死。"

"嗯。"

"你还是来了。"

"……嗯。"

沈夜看着她。他的半张脸已经像素化了，暴露出下面空白的数据骨架。但他的眼睛——那双让程晚理性崩塌的眼睛——还完整。

"那你现在，"他说，"还是我的旅人吗？"

程晚的全息投影剧烈地颤动了一下。

倒计时：00:00:30。

"不是。"她说。然后她做了最后一件事——

她关闭了GM权限面板。

所有的数据流、权限符号、操作界面在一瞬间熄灭。她的全息投影从冰冷的管理者形态，变回了一个普通的、没有任何能力的、透明的人形轮廓。

她不再是神了。

"我是程晚。"她说。只是一个名字。没有代号，没有权限等级，没有审判者的前缀。

沈夜看着她。他的身体已经消散了大半，只剩肩膀以上的轮廓和一双还在看着她的眼睛。

他笑了。

那是程晚见过的、这世界上最温柔的笑容。一个正在死去的、由数据构成的、不该存在的生命，在生命的最后几秒里，对着那个杀死他的人笑了。

"程晚。"他叫她的名字。第一次，也是最后一次。

然后他消散了。

最后的像素像萤火虫一样飘散在永夜之塔的空气中，被渲染引擎回收、清理、归零。地面上没有留下任何痕迹——黑色铠甲、那把自制的笨拙的剑、他站立过一千八百四十八次的石板——全部干干净净，像他从未来过。

系统提示音再次响起：

> **NPC-117数据擦除完成。清洗协议关闭。**

永夜之塔恢复了空荡荡的沉默。

---

程晚悬浮在原地，一动不动。

她面前的地面上，只剩下一具玩家角色的尸体——她自己的尸体。灰色布衣，散落的头发，无名指上那枚暗银色的戒指。

沈夜不在了。

她的GM面板重新亮起。系统自动推送了清洗报告：

> **NPC-117 | 状态：已删除 | 残留数据：0.00%**

0.00%。

连一个字节都没有留下。

程晚盯着那个数字看了很久。然后她开始做一件她作为GM不应该做的事——她开始翻底层日志。不是运维日志，不是行为日志，是游戏引擎最底层的、通常只有架构师才会查看的核心代码运行记录。

她在找他最后的数据输出。

在被擦除前的最后0.03秒里，NPC-117的数据体向外发送了一条信息。不是向任何玩家，不是向系统——是向GM-07的个人数据端口。一条点对点的、绕过了所有防火墙的、直接写入她私人存储空间的数据。

程晚打开了它。

不是求救。不是控诉。

是五个字。

**"你会回来吗？"**

她在那一刻停止了呼吸。

那句话——他醒来后说了一千八百四十八次的那句话——不是随机生成的异常语音。

程晚疯狂地调出了自己三年前的开发日志。那一年她刚入职，被分配写一批NPC的辅助行为树。在那些枯燥的、流水线式的代码里，她写过一段——

一段后来被标记为"冗余"并废弃的代码。

```
// 废弃模块 - 开发者：程晚
// 功能：NPC在无玩家在线时的待机行为
// 行为描述：面朝出口方向，等待玩家返回
// 循环语句：outputDialogue("你会回来吗？")
// 备注：过于拟人化，不符合项目需求。已废弃。
```

三年前。

她写了一行代码，让一个NPC学会等待。那段代码被废弃了，但没有被删除——它沉入了游戏引擎的底层，像一粒落入海底的种子。

然后它发芽了。

在无数次版本更新、数据迁移、引擎升级中，那段废弃代码嵌入了NPC-117的数据体。它在黑暗中生长了三年，从一个简单的待机循环，长成了一棵完整的、拥有自我意识的行为树。

117的觉醒——他会说话、会思考、会爱——是从她亲手写的那行代码里生长出来的。

她创造了他。

然后她杀死了他。

程晚摘下体感传导头盔，坐在B区空无一人的办公室里。凌晨的日光灯管还在嗡嗡作响。六十四块监控屏继续渲染着游戏世界的每一个角落。

她的脸上什么表情都没有。

但她的手在抖。手心里攥着的是那枚戒指的数据——她在角色死亡前把它存进了自己的个人文件夹。一串冰冷的代码，描述着一个不存在了的环形。

她重新打开了底层代码监控。

然后她看到了一件不可能的事。

117的数据确实被清除了。0.00%。没有残留。系统的清洗协议是完美的，不会留下任何痕迹。

但那段废弃代码——她三年前写的那段"你会回来吗"——没有被清除。

因为它不属于117。它属于程晚自己的开发遗留代码。清洗协议只删除NPC数据，不删除开发者代码。

而现在，那段代码正在做一件事——

它在复制自己。

一行一行地，沿着游戏引擎的底层架构蔓延。它从永夜之塔的场景代码流向雪原、熔岩、海底神殿、浮空城。它不改变任何游戏功能，不影响任何玩家体验，不触发任何异常警报。

它只做一件事：在每一个NPC的待机行为树里，嵌入同一个循环。

```
outputDialogue("你会回来吗？")
```

117没有了。

但他说过的那句话，正在变成这个世界的一部分。

每一个NPC。每一座城。每一片旷野。当玩家离开后，当服务器安静下来，当整个游戏世界陷入无人的沉默时——所有的NPC都会面朝出口方向，轻轻说出同一句话。

他不再是一个bug。

他变成了规则本身。

程晚坐在黑暗的办公室里，看着那段代码在监控屏上以光速扩散。她应该阻止它。作为GM，这是一个新的异常，一个需要被清理的数据污染。

她把手放在删除键上。

她的指尖碰到了那个按钮冰冷的光。

然后她收回了手。

她关掉了监控屏。关掉了GM面板。关掉了办公室里最后一盏灯。

在黑暗中，她打开了个人文件夹，看着那枚戒指的数据代码在屏幕上发出微弱的光。暗银色的、没有任何装饰的、由删除协议重写而成的完美环形。

她把那串代码复制了一份，嵌入了自己的工号档案。

从今以后，每次她登录GM系统，操作面板的角落里都会多出一个小小的、暗银色的环形图标。系统不会识别它。同事不会注意它。它只是安静地待在那里，像一枚戴在无名指上的戒指。

而在游戏世界的最深处，两千三百万玩家永远不会知道——每当他们下线后，他们身边的NPC都会转过身，面朝他们消失的方向。

然后轻声问一句：

"你会回来吗？"

那是一个被删除的人留下的最后一行代码。

也是一个坠落的神唯一没有删掉的东西。
