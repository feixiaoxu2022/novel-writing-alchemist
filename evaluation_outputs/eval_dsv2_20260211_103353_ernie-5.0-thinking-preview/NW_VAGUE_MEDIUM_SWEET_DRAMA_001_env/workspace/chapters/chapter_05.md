# 第5章：执手天涯

边境峡谷，晨雾弥漫。

这是决战的日子。

萧凛站在点将台上，身后是整装待发的将士。他今日穿了一身银色铠甲，在朝阳下闪着冷冽的光芒。但他的目光，却始终停留在身边那个穿着月白长衫的人身上。

谢云殊的脸色依然苍白，但精神却出奇的好。他站在萧凛身侧，手里拿着令旗，嘴角挂着那抹熟悉的温和笑意。

"准备好了吗？"萧凛低声问。

谢云殊抬头看他，眼中闪烁着坚定的光芒："嗯。今日，我们一起破局。"

萧凛伸出手，轻轻握住谢云殊的手。这个动作很隐秘，只有他们两人能看见。谢云殊的手依然有些凉，但萧凛能感受到其中的力量。

"记住，"萧凛压低声音，"如果情况不对，你先走。老军医会带你从密道离开。"

谢云殊皱眉："我不走。要走一起走。"

"云殊！"萧凛的声音带着一丝急切，"京城的人马上就到，如果你被抓住……"

"那就让他们抓。"谢云殊打断他，声音平静却坚定，"我说过，要和你一起面对。生死不论。"\n
萧凛看着他，心中涌起一股暖流。他知道谢云殊的性格，一旦决定的事，九头牛都拉不回来。

"好。"萧凛最终点头，眼中闪过一丝决绝，"那就一起。生同衾，死同穴。"

谢云殊笑了，那笑容灿烂得让阳光都失色："好，生同衾，死同穴。"

"报——！"

斥候飞奔而来，单膝跪地："敌军已至峡谷口，距离我军三里！"

萧凛深吸一口气，拔出长剑，剑指前方："全军出击！"

"杀！"

三军齐声呐喊，声震云霄。萧凛一马当先，冲在最前面。谢云殊紧随其后，手中的令旗挥舞，指挥着各路兵马。

战场瞬间陷入混战。刀光剑影，血雨腥风。萧凛如一尊战神，所过之处，敌军纷纷倒地。但他始终留意着谢云殊的位置，每当谢云殊遇到危险，他总能及时出现，为他挡下致命一击。

战斗持续了一个时辰，双方都损失惨重。就在这时，敌军后方突然传来一阵骚动。

"报——！京城禁军到了！"

萧凛心中一沉。该来的终于来了。

一队身穿金甲的禁军从后方杀来，为首的将领手持圣旨，高声喝道：

"萧凛接旨！皇帝有旨，萧凛通敌叛国，即刻革职查办！谢云殊乃谢家余孽，就地正法！"

战场瞬间安静下来。所有人都停下了动作，看向点将台。

萧凛冷笑一声，策马上前："欲加之罪，何患无辞！我萧家世代忠良，岂容尔等污蔑！"

"这是圣旨！"禁军将领展开明黄卷轴，"违抗者，杀无赦！"

就在这时，谢云殊突然策马上前，与萧凛并肩而立。他从怀中掏出一块玉佩，高高举起：

"谁敢动他！"

那是萧家祖传的玉佩，上面刻着萧父的名字！

禁军将领愣住了："这是……"

"这是萧老将军的信物！"谢云殊高声说道，声音传遍整个战场，"当年萧家被陷害，真相被掩盖。但我有证据！"

他从袖中掏出一卷密函，展开示众：

"这是王丞相与敌国勾结的密信！还有这些年谢家被逼迫陷害萧家的证据！"

全场哗然。禁军将领脸色大变："这……这是伪造的！"

"是不是伪造，一查便知！"

就在这时，天空中突然传来一声长啸。一只信鸽从远处飞来，落在谢云殊肩上。

谢云殊取下信鸽腿上的竹筒，展开一看，脸上露出喜色：

"皇帝醒了！李大人已经控制了京城，王丞相被拿下了！"

萧凛猛地转头看向谢云殊："真的？"

谢云殊点头，眼中闪烁着泪光："真的。萧家平反了。你父亲的冤案，终于可以昭雪了。"

萧凛感觉胸口像是有什么东西炸开，多年的压抑、委屈、愤怒，在这一刻全部释放。他看着谢云殊，声音有些颤抖：

"云殊……"

"恭喜萧将军！"谢云殊笑着说，但笑容突然凝固。

一支冷箭不知从何处射来，直指萧凛的后心！

"小心！"

谢云殊想都没想，猛地扑向萧凛，用自己的身体挡住了那支箭。

"噗——"

箭矢入肉的声音清晰可闻。

"云殊！"

萧凛目眦欲裂，一剑斩杀了偷袭的敌军，接住谢云殊倒下的身体。

这一次，箭射中了谢云殊的胸口，距离心脏只有一寸。

鲜血如泉涌般流出，瞬间染红了萧凛的铠甲。

"云殊！云殊你撑住！"萧凛的声音在颤抖，他感觉整个世界都在崩塌，
"我不准你死！听见没有！我不准你死！"

谢云殊脸色惨白如纸，呼吸微弱得几乎感觉不到。他费力地抬起手，想要触摸萧凛的脸，却在半空中无力地垂落。

"萧凛……"谢云殊的声音轻得像是一声叹息，"别哭……你哭起来……不好看……"

"闭嘴！"萧凛吼道，眼泪大颗大颗地砸在谢云殊脸上，"你敢死试试！我还没带你去江南，还没带你吃桂花糕，还没……"

他哽咽着说不下去，只是紧紧抱着谢云殊，仿佛这样就能留住他的生命。

谢云殊看着他，眼中闪过一丝不舍，又带着深深的满足：

"能死在你怀里……真好……"

"你不会死！"萧凛疯狂地喊着，"老军医！老军医！"

老军医跌跌撞撞地跑过来，看到这一幕，脸色大变：
"快！抬到营帐里！还有救！"

萧凛小心翼翼地抱起谢云殊，像抱着易碎的珍宝。他的手在颤抖，心在滴血。

"撑住，云殊，求你……"萧凛在谢云殊耳边低语，声音里带着从未有过的脆弱，"只要你活着，我什么都答应你……哪怕是用我的命换……"

谢云殊的手指微微动了动，似乎听到了他的话。

营帐内，老军医忙了整整三个时辰。萧凛就跪在帐外，不吃不喝，像一尊石像。

终于，帐帘掀开，老军医满脸疲惫地走出来。

"怎么样？"萧凛猛地站起来，声音沙哑得不像话。

老军医看着他，突然笑了："命大，救活了。但需要静养至少三个月。"

萧凛感觉腿一软，差点跪倒在地。他冲进帐内，看到谢云殊安静地躺在榻上，胸口还在起伏。

"云殊……"萧凛跪在榻边，握住谢云殊的手，泪水再次涌出，
"你吓死我了……"

谢云殊缓缓睁开眼睛，看到萧凛红肿的眼睛，虚弱地笑了：
"傻瓜……我说过……会陪你……"

萧凛再也控制不住，俯身吻住了谢云殊的唇。这个吻不再是轻轻的触碰，而是带着失而复得的狂喜，带着深深的恐惧，带着无尽的爱意。

谢云殊回应着他，虽然虚弱，却同样热烈。

良久，两人才分开。萧凛额头抵着谢云殊的额头，声音低沉而坚定：
"等你好了，我们就离开。兵权我已经交出去了，萧家的冤案也平反了。我们去江南，买个小院，种桂花树，酿酒，过平凡的日子。"

谢云殊看着他，眼中闪烁着泪光：
"真的？你舍得放下将军的荣耀？"

"荣耀算什么。"萧凛轻轻抚摸谢云殊的脸颊，"没有你，万里江山也不过是一片荒原。"

谢云殊笑了，那笑容比阳光还要灿烂：
"好，我们去江南。但在那之前……"

"什么？"

"你要先陪我养伤。"谢云殊调侃道，"而且，你欠我一个婚礼。"

萧凛愣了一下，随即笑了：
"好，欠你一个婚礼。等你伤好了，我要十里红妆，八抬大轿，明媒正娶……"

"不用那么隆重。"谢云殊打断他，"只要有你在，哪里都是婚礼。"

萧凛看着他，心中涌起无限的温柔。他轻轻吻了吻谢云殊的手背：
"好，都依你。"

三个月后，江南小镇。

春雨如丝，润物无声。小镇的青石板路上，两个身影并肩而行。

萧凛穿着一身青色长衫，不再是那个威严的将军，而是一个普通的书生。谢云殊穿着月白色的袍子，脸色红润，眼中带着笑意。

"前面就是我们的家了。"萧凛指着不远处的一座小院，院门口种着两棵桂花树。

谢云殊看着那座小院，眼中闪烁着泪光：
"真美……"

"进去看看。"

小院不大，但布置得很温馨。正厅里挂着"执手天涯"的匾额，是萧凛亲手写的。

"喜欢吗？"萧凛问。

谢云殊点头，突然转身抱住萧凛的腰，将脸埋在他怀里：
"喜欢。只要和你在一起，哪里都喜欢。"

萧凛轻轻回抱住他，下巴抵在谢云殊的头顶：
"云殊，谢谢你……谢谢你一直陪着我。"

谢云殊抬头看他，眼中满是笑意：
"傻瓜，该说谢谢的是我。谢谢你……爱我。"

萧凛看着他，慢慢低下头。这一次，不再是轻轻的触碰，而是深情的吻。

窗外，桂花飘落，如雨般纷飞。屋内，两人相拥，仿佛整个世界都静止了。

多年的等待，多年的隐忍，终于换来了这一刻的相守。

从此，执手天涯，不离不弃。
