# 第七章：风景：最后的旅程

自从林小暖获得真实资格后，陆沉变得更加宠溺她了。

或者说，他终于不再需要隐藏自己的感情了。

"陆沉，你看这朵花！"林小暖蹲在一片紫色的花海中，兴奋地向他招手，"它会随着音乐跳舞呢！"

陆沉坐在草地上，看着她快乐的样子，嘴角不自觉地上扬。这是第八个副本"梦境花园"，一个以美丽和宁静著称的副本。

"小心点，别踩到其他花。"他提醒道，但语气里满是纵容。

"知道啦！"林小暖站起来，跑到他身边坐下，把一朵发光的小花别在他耳边，"看，多帅！"

陆沉没有拒绝，任由她在自己头上别满各种奇花异草。如果是以前的他，绝对不会允许自己这副模样。但现在……

只要她开心就好。

"陆沉，我们还要通关多少个副本呀？"林小暖靠在他肩上，玩弄着他的手指，

"还有最后一个。"陆沉轻声说，眼神暗了暗，

其实他知道，这可能是最后一个副本了。系统虽然暂时接受了林小暖的真实存在，但那个"已注销玩家"的标记依然悬在她头顶，像一把达摩克利斯之剑。

但他没有告诉她。至少现在，让她享受这份宁静。

"最后一个啊……"林小暖有些失落，"通关之后呢？我们要去哪里？"

"去哪里都行。"陆沉握住她的手，"现实世界，或者继续在副本里冒险，或者……找个没人的地方隐居。你想去哪里，我们就去哪里。"

"真的吗？"林小暖眼睛发亮，"那我想去海边！我还没见过真正的大海呢！"

"好，去海边。买个房子，每天看日出日落。"

"还要养只猫！或者狗？"

"都养。再养只鹦鹉，让它学说话。"

"哈哈，那家里岂不是很热闹？"

两人有一搭没一搭地聊着未来，仿佛真的能实现一样。陆沉知道这可能只是奢望，但他愿意陪她做这个梦。

"陆沉……"

"嗯？"

"谢谢你。"

"又谢什么？"

"谢谢你给我第二次生命，谢谢你爱我，谢谢你……让我觉得自己是真实的。"

陆沉的心猛地一颤。他转头看着林小暖，发现她正认真地看着自己，眼里闪烁着泪光。

"小暖……"

"我知道的。"她轻声说，"我知道自己曾经只是个幻觉。我也知道……你为了我付出了多少。"

陆沉愣住了："你……什么时候知道的？"

"很早就有感觉了。"林小暖靠在他肩上，声音很轻，"比如，我没有之前的记忆；比如，系统有时候会对我视而不见；再比如……"

她顿了顿："你看我的眼神，有时候像在看另一个人。"

陆沉的手指微微颤抖："我……"

"但我不在乎。"林小暖抬起头，露出一个灿烂的笑容，"不管我是怎么来的，现在的我是真实的！我有你的爱，有我们的回忆，这就足够了！"

陆沉看着她，突然觉得眼眶发热。他伸手将她紧紧抱住：

"对，你是真实的。比任何人都真实。"

"那……如果有一天我真的要消失了……"

"不会的！"陆沉打断她，声音有些激动，"我不会让你消失的！我已经找到办法了！"

他从系统空间里取出那个珍贵的道具——【永恒之锚】。这是他用所有积分加上三件S级装备换来的传说级道具，可以将一个人的存在永久固定在现实维度。

"这是什么？"林小暖好奇地看着那个散发着金光的锚形道具，

"这是我们的未来。"陆沉轻声说，"只要使用它，你就永远不会消失，永远不会被系统清除。"

林小暖愣住了："可是……这一定很珍贵吧？你用了什么换的？"

"不重要。"陆沉把道具放在她手里，"只要你能留下来，什么都不重要。"

林小暖看着手里的道具，又看看陆沉，突然哭了出来：

"你这个笨蛋……大笨蛋……为什么要对我这么好……"

"因为我爱你啊。"陆沉轻轻擦去她的泪水，"这还需要理由吗？"

"可是……如果用了这个，你怎么办？你会不会有危险？"

"我没事。我有办法。"陆沉其实在撒谎。使用【永恒之锚】需要献祭使用者的一部分灵魂，但他不在乎。只要林小暖能活下来，哪怕变成行尸走肉他也愿意。

"不行！"林小暖突然把道具塞回他手里，"我不用！如果要用你的命来换，那我宁愿消失！"

"小暖！"

"不要再说了！"林小暖坚定地看着他，"我们一起面对，好吗？不管是生是死，一起面对！"

陆沉看着她坚定的眼神，知道说服不了她。他叹了口气，收起道具：

"好，一起面对。但你要答应我，如果真的到了那一步……"

"没有那一步！"林小暖捂住他的嘴，"我们会有办法的！相信我！"

陆沉看着她，突然笑了。也许她说得对。他们已经创造了一个奇迹，为什么不能创造第二个？

"好，相信你。"他在她额头上轻轻一吻，

两人在花海中坐了很久，直到夕阳将天空染成血红色。

"该走了。"陆沉站起身，伸出手，

"嗯！"林小暖握住他的手，借力站起来，"下一个副本是什么？"

"镜像世界。"陆沉的声音有些低沉，"那里……会有最终的答案。"

"不管是什么答案，只要和你在一起，我就不怕！"

"嗯，不怕。"

他们并肩走向出口。夕阳将两人的影子拉得很长，最终融为一体，再也分不清彼此。

而在花海的深处，一朵不起眼的小花突然绽放出金色的光芒，仿佛在为他们祝福。

系统日志悄然刷新：

**【检测到真挚情感！奇迹度+1】**

**【当前奇迹度：99.9%】**

**【预测：可能突破系统限制】**

但陆沉和林小暖都没有看到。

他们只看到彼此，和前方的路。
