# 第二十章：真相揭露

## 场景一：医院急诊室 - 伤势处理

**场景编号**：20-01
**场景位置**：市第一医院急诊室
**出场人物**：林清语、顾行舟、医生、护士、老陈
**场景目的**：处理顾行舟的伤势，情感交流
**核心动作**：顾行舟包扎伤口，两人对话
**冲突点**：伤势的严重性，对未来的担忧
**情感转变**：从后怕到坚定
**场景结果**：伤势无大碍，决定继续调查

急诊室的灯光有些刺眼。顾行舟坐在处置床上，医生正在给他清理手臂上的枪伤。子弹只是擦过，没有伤到骨头，但伤口很深，需要缝针。

"会留疤吗？"林清语站在一旁，手紧紧攥着衣角，指节发白。

"可能会。"医生一边缝合一边说，"但男人有点疤不算什么。倒是你，小姑娘，别看了，去外面等吧。"

"我不走。"林清语声音颤抖但坚定，"我要陪着他。"

顾行舟看着她苍白的脸，伸出没受伤的手轻轻握住她："别担心，皮外伤。比起你之前受的伤，这不算什么。"

"你是为了救我才受伤的。"林清语眼眶发红，"如果你......"

"我不会有事。"顾行舟打断她，眼神温柔，"而且，就算有事......我也心甘情愿。"

林清语的眼泪终于掉下来。她 quickly 擦掉，不想让他看到自己的软弱："你要是敢有事，我就......我就把你的拍卖行卖了！"

顾行舟笑了，虽然因为疼痛而有些扭曲："好，都给你。本来就是为你开的。"

"谁要你的拍卖行......"林清语破涕为笑，轻轻捶了他一下，"小心伤口！"

老陈在门口看着，欣慰地摇摇头，悄悄退了出去，把空间留给两人。

"说正经的。"顾行舟收敛笑容，"那个青铜鼎......"

"我知道。"林清语深吸一口气，"鉴定还没完成。但现在最重要的是你的伤。"

"不。"顾行舟摇头，"那些人不会给我们时间。如果不尽快查明真相，他们还会再来。而且......"他看着林清语，"你也不会安心养伤，对吧？"

林清语沉默片刻，然后点头："你总是这么了解我。好吧，等你包扎完，我们回实验室。老陈已经把陈先生安置在安全的地方了。"

"还有一件事。"顾行舟说，"报警吧。这次不能再私下处理了。"

"但你说警察里有他们的人......"

"所以要找可信的人。"顾行舟拿出手机，"我有个老同学在省厅刑侦总队，专门负责文物犯罪。他值得信任。"

## 场景二：鉴定实验室 - 最终鉴定

**场景编号**：20-02
**场景位置**：清语文物鉴定事务所实验室
**出场人物**：林清语、顾行舟、张教授、陈先生、刑侦总队刘队长
**场景目的**：揭示青铜鼎的真相
**核心动作**：热释光测年结果，真相大白
**冲突点**：真伪的悬念，各方势力的博弈
**情感转变**：从疑惑到震惊
**场景结果**：确认是真品，但有重大发现

深夜的实验室灯火通明。张教授、陈先生和一位穿警服的中年男子（刘队长）已经在等待。林清语和顾行舟匆匆赶来，顾行舟手臂上还缠着纱布。

"人都到齐了。"林清语没有废话，直接打开保险箱，取出青铜鼎，"开始吧。"

她连接好热释光测年仪，小心翼翼地从鼎底取了一小块陶片样本。这是破坏性检测，但现在别无选择。

"需要两小时。"技术员说。

"我们等。"刘队长沉声说，"如果这真是子龙鼎，那就是特级文物走私案。我已经调了特警队待命。"

等待的时间格外漫长。陈先生坐立不安，不停地看表。顾行舟靠在墙上，脸色因为失血而有些苍白，但眼神依然锐利。

"如果......如果是假的怎么办？"陈先生突然问，声音颤抖，"我冒着生命危险......如果只是个赝品......"

"那也是重要证据。"刘队长说，"能证明有人在制造高仿品，同样是犯罪。"

"但如果是真的......"陈先生看着青铜鼎，眼里闪着复杂的光，"它应该属于国家，属于所有人。不应该被锁在某个富豪的保险柜里。"

林清语看着他，突然问："陈先生，你到底是谁？为什么会有这个鼎？"

陈先生犹豫了一下，终于开口："我......我是个盗墓贼。或者说，曾经是。十年前，我和几个同伙挖了一座商代大墓，找到了这个鼎。但我良心不安，想把它上交。其他人不同意，他们杀了我的家人......我逃了出来，隐姓埋名。"

实验室里一片寂静。顾行舟冷冷地看着他："所以你是想赎罪？"

"是。"陈先生低下头，"我知道我有罪。但我真的想弥补。这个鼎......它太珍贵了，不能再流落在外。"

"结果出来了！"技术员喊道。

所有人围过去。屏幕上显示着测年数据：3200±50年。

"商代晚期！"张教授激动地说，"和传说中子龙鼎的年代完全吻合！"

"还有成分分析。"林清语指着另一组数据，"铜锡铅比例完全符合商代特征，而且......看这里，铸造痕迹显示这是一次性铸造，没有任何修复痕迹！"

"是真品！"刘队长猛地站起来，"这就是失传的子龙鼎！"

陈先生瘫坐在椅子上，泪流满面："真的......是真的......"

"但还有个问题。"林清语皱眉，指着鼎内的一个隐蔽角落，"这里有个现代标记——一个极小的二维码，用特殊材料刻的。"

"二维码？"顾行舟凑近看，"这是......"

"追踪标记。"林清语脸色大变，"有人在所有重要文物上都做了标记，方便追踪流向。这说明......"

"这不是简单的走私。"刘队长接过话，脸色阴沉，"这是有组织的文物盗窃和洗钱网络。他们不仅偷文物，还在文物上做标记，控制整个链条。"

## 场景三：安全屋 - 突袭行动

**场景编号**：20-03
**场景位置**：老陈提供的安全屋
**出场人物**：特警队、林清语、顾行舟、刘队长、陈先生、神秘组织成员
**场景目的**：抓捕犯罪分子，解决危机
**核心动作**：特警突袭，逮捕嫌疑人
**冲突点**：枪战风险，证据保全
**情感转变**：从紧张到胜利
**场景结果**：成功抓捕，危机解除

凌晨三点，特警队悄悄包围了安全屋。根据陈先生的供述和刘队长的调查，那个神秘组织的一个重要据点就在这里。

林清语和顾行舟坐在指挥车里，通过监控屏幕观察行动。顾行舟的伤口还在隐隐作痛，但他坚持要来。

"行动！"刘队长一声令下。

特警队员破门而入，喊声、枪声、爆炸声瞬间响起。林清语的心提到了嗓子眼。

"别担心。"顾行舟握住她的手，"特警是专业的。"

五分钟后，对讲机里传来声音："控制现场！抓获嫌疑人三名！发现大量文物！"

林清语长舒一口气。但就在这时，监控屏幕上出现了一个熟悉的身影——赵美娟的前助手，那个曾经帮林志远做假证的人！

"是他！"林清语指着屏幕，"他是赵美娟的人！"

"看来赵美娟虽然在监狱里，但她的网络还在运作。"顾行舟冷笑，"这个组织比我们想象的更庞大。"

行动结束了。嫌疑人被押上警车，其中就包括那个助手。他看到林清语时，眼里闪过一丝恐惧和怨恨。

"林小姐，又见面了。"他被押过时，突然开口，"你以为赢了？这只是开始。赵总在里面还有人脉，你们斗不过的！"

"闭嘴！"警察推了他一把。

林清语看着他被带走，心里却没有恐惧，只有坚定："那就让他们来吧。我会一直战斗下去，直到这个行业干净为止。"

"我们一起。"顾行舟说，握紧了她的手。

刘队长走过来："这次多亏了你们。特别是林小姐的鉴定，还有顾总提供的情报。子龙鼎会被送到省博物馆，陈先生......虽然有前科，但戴罪立功，会从轻发落。"

"谢谢刘队。"林清语说，"但这还没完，对吧？"

"没错。"刘队长神色凝重，"这个组织背后还有更大的势力。我们需要继续调查。你们......"他看着两人，"要小心。他们可能会报复。"

"我们知道。"顾行舟平静地说，"但我们不怕。"

走出指挥车，夜风微凉。林清语看着远处的警灯闪烁，心里却异常平静。

"在想什么？"顾行舟问。

"在想，我们终于做了一件真正有意义的事。"林清语轻声说，"不仅为了自己，也为了所有热爱文物的人。"

"是啊。"顾行舟看着她，月光下她的侧脸格外美丽，"而且，我们做到了。"

"但还有更多工作要做。"林清语转向他，眼里闪着光，"那个组织还在，赵美娟的余党还在。我们要继续战斗。"

"当然。"顾行舟笑了，"但首先......你需要休息。你已经两天没睡了。"

"你也是。"林清语指了指他的伤臂，"伤员没资格说别人。"

两人相视而笑。在这个充满危险的夜晚，他们的心却比任何时候都近。

子龙鼎的真相大白了，但更大的挑战还在后面。不过现在，他们已经准备好面对一切。

因为他们不再是孤军奋战，而是有彼此，有正义，还有无数支持他们的人。
