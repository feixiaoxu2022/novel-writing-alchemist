# 第三章：实验室的秘密

现实世界的旧实验室位于教学楼地下一层，入口被生锈的铁门封锁，门上挂着"危险勿入"的警示牌。

林浅站在铁门前，雨水顺着她的发梢滴落。透明化的后遗症还在——她的左手小指完全透明，像玻璃做的一样。她把手藏进口袋里，心跳加速。

距离第一次进入透明层已经过去了6小时。现实中只过了几分钟，但对她来说像过了一个世纪。

"密码是......"

她回忆顾沉最后的话。密码是什么？

铁门上的电子锁早已失效，屏幕漆黑一片。但在透明层的视觉残留中，她能看见微弱的能量流动——像血管一样的蓝色光线在门框内脉动。

林浅深吸一口气，闭上眼睛，主动触发透明化。

不需要等待三分钟，她已经学会了如何"切换"——就像调节眼睛的焦距一样，只要集中注意力，就能看见另一层世界。

青灰色的膜再次覆盖视野。世界溶解成半透明的轮廓。

铁门在透明层中呈现为巨大的能量屏障，上面流动着复杂的符文。而在屏障中央，有一个凹陷的手印形状。

林浅伸出透明的手，按在那个凹陷处。

*嗡——*

低频震动穿过她的身体，像大提琴的最低音弦。符文开始旋转，发出幽蓝的光芒。铁门无声地滑开。

一股陈旧的霉味扑面而来，夹杂着某种化学试剂的刺鼻气味——甲醛？还是更危险的东西？

走廊很长，墙壁上的瓷砖在透明层中呈现出血肉般的质感。地面上散落着各种实验器材的残骸：破碎的烧杯、扭曲的金属架、还有......

林浅停下脚步，胃里一阵翻涌。

那是衣服的碎片。校服的布料，上面还沾着暗红色的污渍。

*"这是......谁的？"*

她不敢细想，继续向前走。

走廊尽头是一扇厚重的铅门。门上有一个观察窗，玻璃已经破碎。

林浅凑近观察窗，向内张望。

实验室内部比她想象的要大得多。各种精密仪器排列成圆形，中央是一个巨大的......

她倒吸一口冷气。

那不是仪器。那是一个人。

或者说，曾经是人。

那个"东西"被固定在金属支架上，身体与各种管线相连。它的皮肤呈现出半透明的凝胶状，能看见下面搏动的器官和流动的液体。最可怕的是头部——那里没有脸，只有一个巨大的、不断旋转的眼睛，占据了整个面部。

*"克苏鲁......"* 林浅的思维颤抖着。

那个东西突然动了。巨大的眼睛转向观察窗，与林浅对视。

一瞬间，无数画面涌入她的脑海：

*穿着白大褂的人在记录数据*
*学生被绑在椅子上，尖叫着*
*蓝色的液体被注射进静脉*
*空间开始扭曲，墙壁融化*
*"实验体001号：意识上传成功"*
*"实验体002号：记忆提取失败，精神崩溃"*
*"实验体003号：顾沉......"*

林浅猛地后退，撞到了墙上。

*"顾沉是实验体？"*

那个巨大的眼睛还在注视着她，发出某种思维波动：

*"欢迎......回来......实验体......004......"*

林浅转身就跑。

透明的双腿在走廊里狂奔，周围的墙壁开始扭曲，像有生命一样蠕动。倒计时在视野中跳动：**18:23:45**

她冲出铁门，回到现实世界。

雨还在下，但实验室的霉味似乎粘在了她身上，挥之不去。

"你在这里做什么？"

一个冰冷的声音从身后传来。

林浅浑身僵硬，慢慢转身。

苏瑶站在走廊尽头，身后跟着两个跟班。她穿着干净的校服，头发一丝不苟，眼神阴冷如刀。

"我......"林浅的声音在颤抖，
"我躲雨......"

苏瑶走近，高跟鞋在地上发出清脆的响声。她停在林浅面前，上下打量着她。

"躲雨躲到地下室？"苏瑶冷笑，"你知道这里是禁区吗？"

林浅低头，不敢与她对视。在透明层的视觉中，她看见苏瑶的影子——不是普通的影子，而是一团黑色的、不断变化的烟雾，里面似乎有无数张扭曲的面孔在尖叫。

*"她也......被污染了？"*

"说话！"苏瑶突然提高声音，一把抓住林浅的衣领，
"你看见了什么？"

林浅被提起来，脚尖离地。肋骨的疼痛让她倒吸冷气。

"没......没看见什么......"

苏瑶盯着她看了几秒，突然松开手，林浅跌坐在地上。

"最好是这样，"苏瑶整理了一下自己的衣服，眼神中闪过一丝不易察觉的恐惧，"有些东西，看见了就会消失。就像......"

她停顿了一下，黑色阴影在她周围翻涌。

"......就像顾沉一样。"\n
林浅猛地抬头。

苏瑶嘴角勾起一个残忍的弧度："你以为他转学了？哈，天真。他是被'处理'了。就像所有知道真相的人一样。"

她转身离开，跟班们发出刺耳的笑声。

"对了，"走到走廊尽头时，苏瑶回头说，眼神冰冷，
"今晚午夜，旧实验室见。别让我等。"

她们走后，林浅瘫坐在地上，浑身发抖。

顾沉不是失踪。他是被绑架做实验。

而苏瑶......她知道一切。

甚至可能参与其中。

林浅看向自己的手。透明化正在蔓延，现在整个左手都呈现半透明状态。

倒计时：**18:22:10**

她必须回去找顾沉。

但这次，不只是为了听见他的声音。

而是为了救他。

哪怕代价是永远被困在透明层。

哪怕代价是被世界遗忘。

走廊深处，某种古老的存在正在苏醒。墙壁上的裂缝开始渗出黑色的液体，在地上汇聚成文字：

*记住*
*忘记*
*选择*

林浅站起身，擦干脸上的雨水——或者是泪水。

她已经没有退路了。

透明层在召唤她。

而这一次，她要带着武器回去。

她从口袋里掏出一支圆珠笔——这是她唯一的"武器"。

但在透明层中，也许思想才是最强大的武器。

林浅深吸一口气，再次闭上眼睛。

青灰色的膜覆盖视野。

这一次，她不再逃跑。

她走向实验室。

走向真相。

走向顾沉。
