# 第四天

白色。

林宁睁开眼睛，看到的是白色。白色的墙壁，白色的床单，白色的窗帘。

她坐起来，假装迷茫地看着四周。

"你醒了。"

声音从床边传来。林宁转过头，看到周影坐在椅子上，手里拿着橙色的药瓶。

"你是谁？"她问，声音沙哑。

"我是周影。"周影笑了，站起来，走到床边，"我们是病友。互相治疗的病友。"

林宁接过药瓶，倒出一粒药片，放进嘴里，藏在舌头下。

"很好。"周影说，"你比昨天配合多了。"

他开始讲故事，讲他记得的所有事情。林宁听着，假装入神，实际上在观察他的一举一动。

她注意到，周影讲故事的时候，眼神会不自觉地飘向墙上的刻痕，像是在确认什么。

她注意到，他的笑容虽然温柔，但眼睛里有一种奇怪的光芒，像是猎人看着猎物。

她注意到，他的手会不自觉地摸口袋，像是在确认什么东西还在。

"周影，"她打断他，"我可以看看墙上的刻痕吗？"

周影愣了一下，然后说："当然。"

林宁站起来，走到墙边，仔细看墙上的刻痕。

她之前只注意到"今天她笑了几次"这一行，但现在，她发现墙上不只是这一行，还有很多其他的记录。

```
第47天：她哭了2次，笑了5次，说了3次我爱你
第48天：她哭了1次，笑了3次，说了2次我爱你
第49天：她哭了0次，笑了3次，说了1次我爱你
第50天：她哭了0次，笑了0次，说了0次我爱你
```

林宁的心跳加速。她意识到，周影记录的不只是她笑了几次，还有她哭了几次，说了几次我爱你。

每一个细节，都被他记录下来。

"周影，"她转过身，"你为什么要记录这些？"

周影的笑容僵了一下，但很快恢复正常。

"这是治疗记录。"他说，"医生说，记录你的情绪变化，有助于了解你的病情。"

"但...为什么要记录我说了几次我爱你？"

周影沉默了一会儿，然后说："因为...我想知道，你是不是真的爱我。"

林宁愣住。

"爱我？"

"对。"周影走到她面前，眼神很认真，"林宁，我爱你。我知道你每天都会忘记，但我还是爱你。我想知道，你是不是也爱我。"

林宁看着他，看着他的眼睛。她想相信他，想相信他的爱是真的。

但她想起了纸条上的字："不要相信他。"

她想起了陈医生的话："被囚禁的事实。"

她想起了周影的话："实验很成功。"

"周影，"她说，"我想看看病历本。"

周影的表情僵住了。

"病历本是医生的，不是我们的。"他说。

"但我想看。"林宁坚持，"我想知道，里面到底写了什么。"

周影沉默了很久，最后叹了口气。

"好吧。"他说，"等陈医生来的时候，你可以问他。"

林宁点点头，但心里已经有了决定。

她要找机会，偷偷看病历本。

就在这时，门被推开了。陈医生走进来，手里拿着病历本。

"周影，林宁，今天感觉怎么样？"陈医生问。

"很好。"周影说。

陈医生翻看病历本，在某一页上写下什么。

"林宁，"陈医生说，"你今天看起来有些不一样。"

林宁的心跳加速，但她强迫自己保持冷静。

"我...我只是有些累。"她说。

"那就多休息。"陈医生说，"继续配合治疗，很快就可以出院了。"

他把病历本放在桌上，转身去和周影交谈。

林宁看到机会来了。她假装站起来走动，实际上悄悄靠近桌子，翻看病历本。

她看到病历本的第一页，写着她的基本信息：姓名、年龄、病史、诊断结果。

她翻到第二页，看到详细的记录：

```
第1天：患者入院，抑郁症+失忆症，情绪低落，拒绝交流
第2天：患者开始与周影交流，情绪有所好转
第3天：患者第一次对周影笑，记录为"治疗进展"
...
第47天：患者对周影说"我爱你"，记录为"情感依赖形成"
第48天：患者再次对周影说"我爱你"，记录为"依赖加深"
第49天：患者开始怀疑，记录为"需要观察"
第50天：患者没有吃药，记录为"实验继续"
```

林宁的手在颤抖。她翻到最后一页，看到周影的字迹：

```
实验目的：观察失忆症患者与超忆症患者的爱情反应
实验假设：疯狂的爱情比正常的爱情更纯粹，更持久
实验对象：林宁（失忆症），周影（超忆症）
实验阶段：第二阶段（观察依赖形成）
预测结果：患者会选择留下，自愿参与实验
```

林宁的心跳几乎停止。她意识到，自己不是病人，而是实验对象。

她想起了一切——药瓶数量的变化，墙上的刻痕，病历本的厚度，陈医生的话，周影的话。

她意识到，自己被囚禁在这个白色的房间里，被当作实验品，被周影追求，被记录每一个细节。

她想要尖叫，想要逃跑，想要离开这个可怕的地方。

但她强迫自己保持冷静。她不能让周影和陈医生发现她已经知道了真相。

她合上病历本，悄悄退回床边，坐下。

"陈医生，"她说，"我有些累了，想休息一会儿。"

"好的。"陈医生说，"那就多休息。"

他拿起病历本，转身离开。周影也站起来，跟着他走出去。

房间里只剩下林宁一个人。

她看着白色的天花板，看着白色的墙壁，看着白色的窗帘。

她想起周影的话："因为我爱她。"

她想起陈医生的话："疯狂的爱情比正常的爱情更纯粹。"

她想起病历本上的字："实验对象：林宁。"

她不知道该怎么办，但她知道，她必须逃跑。

她不能继续留在这个白色的牢笼里，不能继续被当作实验品，不能继续被周影追求。

她要离开。

但怎么离开？

她走到门边，试图打开门，但门锁着。她走到窗边，试图打开窗户，但窗户是加固的。

她被困住了。

她想起纸条上的字："不要相信他。"

她想起自己曾经清醒过，曾经怀疑过，曾经写下这张纸条。

但她的失忆症让她每天都会忘记，每天都会重新爱上周影，每天都会重新被囚禁。

她不知道该怎么办，但她知道，她必须保持清醒。

她不能吃药。

她要记住一切。

---

**第51天，她笑了0次。**

**她知道了真相。**

**她没有逃跑。**

**——周影的病历本**
