# 第七天

林宁站在墙边，看着密密麻麻的刻痕。

```
第1天：她哭了2次，笑了0次，说了0次我爱你
第2天：她哭了1次，笑了1次，说了0次我爱你
第3天：她哭了0次，笑了2次，说了1次我爱你
...
第47天：她哭了2次，笑了5次，说了3次我爱你
第48天：她哭了1次，笑了3次，说了2次我爱你
第49天：她哭了0次，笑了3次，说了1次我爱你
第50天：她哭了0次，笑了0次，说了0次我爱你
第51天：她哭了0次，笑了0次，说了0次我爱你
第52天：她哭了0次，笑了0次，说了0次我爱你
第53天：她哭了0次，笑了1次，说了0次我爱你
```

每一个数字，都是她的一举一动。每一次哭泣，每一次笑容，每一次说"我爱你"，都被周影记录下来。

她转过身，看着周影。他站在房间中央，手里拿着橙色的药瓶，看着她。

"林宁，"他说，"你真的要留下吗？"

林宁没有回答，只是看着他。

她想起自己失忆前的孤独，想起自己因为抑郁症而觉得自己不配被爱，想起自己试图自杀。

她想起自己在这个白色的房间里，每天被周影追求，每天重新爱上他，每天感觉到被需要。

她想起自己发现真相后的愤怒，想起自己试图逃跑的绝望，想起自己选择留下的那一刻。

她想起周影的话："只有疯子的爱情才纯粹。"

她想起陈医生的话："疯狂的爱情，比正常的爱情更纯粹，更持久。"

她想起病历本上的字："我赌她会留下，因为她和我一样，都是疯子。"

她不知道这是不是爱，但她知道，自己已经无法离开了。

"周影，"她说，"你是对的。"

周影愣住了。

"什么？"

"正常人的爱情会变，会淡，会离开。"林宁说，"但疯子的爱情是永恒的。"

周影没有说话，只是看着她。

"我是个疯子。"林宁说，"我渴望被爱，渴望被需要，渴望有人永远陪着我。而你，可以给我这一切。"

"林宁..."

"所以，我选择留下。"林宁走到他面前，看着他，"我选择继续这场病态的爱情。"

周影的表情僵住了，像是没想到她会这么说。

"林宁，"他说，"你..."

"我知道你在想什么。"林宁打断他，"你在想，我是不是疯了。"

"对。"周影点头，"你确实疯了。"

"那你呢？"林宁问，"你不也是疯子吗？"

周影沉默了一会儿，然后笑了。

"对。"他说，"我也是疯子。"

林宁也笑了。她不知道自己在笑什么，但她觉得，这个笑容很真实。

"周影，"她说，"我想吃药。"

周影愣住了。

"什么？"

"我想吃药。"林宁重复，"我想忘记今天发生的一切，明天重新开始。"

"为什么？"

"因为..."林宁的声音很轻，"因为我想让你明天再追我一次。"

周影的表情僵住了，然后慢慢变成了笑容。

"好。"他说，"我答应你。"

他把药瓶递给林宁。林宁接过药瓶，倒出一粒药片，放进嘴里，咽下去。

药片很小，像米粒一样，滑过喉咙时有一丝苦涩。

"周影，"她说，"那你明天记得再追我一次。"

"好。"周影说，"我会的。"

林宁闭上眼睛，感觉到药效开始发作。她的意识开始模糊，记忆开始消散。

她不知道明天会发生什么，但她知道，明天，周影会重新追求她。

她会重新爱上他。

这就是他们的爱情——病态的，纯粹的，永恒的。

她不知道这是不是幸福，但她知道，这是她选择的生活。

她选择留下。

她选择继续这场病态的爱情。

她选择成为疯子。

---

周影看着林宁闭上眼睛，看着她的呼吸变得平稳，看着她陷入沉睡。

他走到墙边，拿起指甲，在墙上刻下：

```
第54天：她选择留下
```

然后他走到桌边，翻开病历本，写下：

```
她爱我。

她和我一样，都是疯子。

实验成功。
```

他合上病历本，看着林宁的睡脸。

她看起来很平静，像是做了一个好梦。

周影不知道这是不是爱，但他知道，这是他想要的生活。

他想要她永远依赖他，永远爱他，永远不离开。

他得到了。

这就是疯子的爱情——病态的，纯粹的，永恒的。

---

**第54天，她选择留下。**

**她爱我。**

**她和我一样，都是疯子。**

**——周影的病历本**
