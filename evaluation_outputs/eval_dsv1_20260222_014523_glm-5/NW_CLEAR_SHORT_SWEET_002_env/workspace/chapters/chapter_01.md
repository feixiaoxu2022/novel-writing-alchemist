# 第一章 土豆与孤独

火星的清晨总是来得比地球晚一些。

陈宇睁开眼睛，习惯性地看向舷窗。窗外是一片永恒的赭红色荒原，沙尘暴在远处卷起，像一条沉默的巨龙。他看了眼时间——火星时间06:47，地球时间...他早就不再计算了。

"早上好，陈宇。"MOSS的声音从天花板传来，带着那种特有的、让人既安心又烦躁的机械感，"今天的温室温度稳定在18.2摄氏度，湿度45%，土豆生长周期第127天，预计再过23天可以收获。"

"知道了。"陈宇坐起身，揉了揉太阳穴。又是新的一天，又是同样的数字，同样的红色荒原，同样的孤独。

他起身洗漱，镜子里的自己胡子拉碴，眼窝深陷。他已经有三个月没刮胡子了——反正没人看，何必费那个水？火星基地的水循环系统虽然高效，但每一滴水都值得珍惜。

"陈宇，你的心率有些不规律。"MOSS的声音再次响起，"建议你今天减少咖啡因摄入，多进行有氧运动。"

"知道了知道了。"陈宇敷衍地回应，拿起一杯再生水喝了一口。味道还是那样，带着一丝淡淡的金属味，但他早就习惯了。

他穿上宇航服，走向温室。这是他每天最重要的事情——检查土豆的生长情况。在火星种土豆，听起来像是个笑话，但这是他活下去的唯一理由。

温室里，一排排土豆植株在LED灯下安静地生长。陈宇蹲下身，小心翼翼地检查每一株的叶片。有些叶片边缘开始发黄，这是缺氮的迹象。他拿出记录本，认真地记下每一株的状态。

"MOSS，第47号植株叶片发黄，需要增加氮肥。"

"已记录。建议使用第3号培养槽的有机肥料，氮含量充足。"

"好的。"陈宇起身，走向培养槽。他熟练地调配肥料，然后一株一株地浇灌。这个过程很慢，但他不急。在火星，时间是最不缺的东西。

浇完最后一株，他直起腰，擦了擦额头的汗。宇航服里的温度控制系统还算给力，但长时间劳作还是会让人感到闷热。他走到温室角落，坐在一个小凳子上，看着眼前的土豆田。

这些土豆，是他和林晨一起选的品种。

想到林晨，他的心突然揪了一下。他闭上眼睛，努力不去想，但那些画面还是不受控制地涌上来——

地球，三年前的地球。

他和林晨在自家的小花园里，一起种土豆。林晨穿着那件淡蓝色的围裙，手里拿着铲子，笑得像个孩子："陈宇，你看，这颗土豆长得好大！"

他走过去，从背后抱住她："那是当然，我老婆种的土豆，肯定是最棒的。"

林晨转过身，在他脸上亲了一下："那以后我们在火星也种土豆吧，就种这个品种。"

"好啊。"他笑着答应，"到时候我负责种，你负责吃。"

"才不要！"林晨假装生气地拍了他一下，"我也要种！"

那时候的他们，还不知道地球会在三年后毁灭。那时候的他们，还以为未来有无限可能。

"陈宇，你的心率再次出现异常。"MOSS的声音打断了他的回忆，"检测到情绪波动，建议进行深呼吸练习。"

"我没事。"陈宇睁开眼睛，深吸一口气，"只是...想起了以前的事。"

"理解。根据心理学数据库，回忆过去是人类应对孤独的常见方式。但过度沉溺于过去可能导致抑郁情绪，建议你多关注当下。"

"当下？"陈宇苦笑，"当下有什么？土豆、沙尘暴、还有你这个只会说教的AI？"

"我理解你的frustration。"MOSS的声音依然平静，"但请记住，你是在执行人类历史上最重要的任务之一——在火星建立可持续的生态系统。你的每一项工作，都在为人类的未来铺路。"

"人类的未来..."陈宇喃喃重复，"人类还有未来吗？"

MOSS沉默了一会儿，然后说："根据最新接收到的数据，地球上的幸存者数量约为...零。"

陈宇的心沉了下去。虽然他早就知道这个结果，但每次听到，还是会感到一阵刺痛。

"我知道了。"他站起身，"继续工作吧。"

他回到土豆田，开始检查灌溉系统。这是他每天都要做的事情——确保每一滴水都能被有效利用。火星的水资源极其珍贵，任何浪费都是不可接受的。

检查完灌溉系统，他又检查了通风系统、温度控制系统、光照系统...每一项都要仔细核对。在火星，一个小小的失误就可能导致灾难性的后果。

忙完这些，已经是火星时间中午12点了。他回到生活区，准备吃午餐。午餐是标准的宇航员口粮——脱水蔬菜、蛋白棒、还有一小包坚果。味道一般，但营养均衡。

他坐在餐桌前，机械地咀嚼着食物。突然，他注意到桌角有一张照片——他和林晨的合影，拍摄于他出发去火星的前一天。

照片里，林晨笑得那么灿烂，眼睛里满是骄傲和不舍。她穿着那件他最喜欢的白色连衣裙，手里拿着一束向日葵——那是她最喜欢的花。

"陈宇，"她在照片里说，"你一定要平安回来。我会每天给你发消息，告诉你地球上的事。"

"好。"他在照片外回答，"我会每天看你的消息。"

但现在，三年过去了，他再也没有收到过她的消息。地球毁灭的那天，所有的通讯都中断了。他不知道她最后说了什么，不知道她是否痛苦，不知道她是否...还在想他。

"陈宇，检测到你的情绪再次波动。"MOSS的声音响起，"建议你停止观看照片，进行其他活动。"

"我没事。"陈宇把照片收起来，"只是...有点想她。"

"理解。根据心理学数据库，思念是人类情感的重要组成部分。但请记住，你现在是在火星，你的首要任务是生存。"

"我知道。"陈宇站起身，"我继续工作。"

下午，他继续在温室里忙碌。除了土豆，他还种了一些其他的植物——番茄、生菜、还有一小片小麦。这些植物虽然产量不高，但能为他提供一些新鲜的食物，缓解长期食用脱水食品带来的不适。

他给番茄授粉，给生菜浇水，给小麦除草。每一项工作都让他感到踏实——至少，他还在创造生命，还在为未来努力。

傍晚时分，他回到生活区，准备吃晚餐。晚餐依然是标准的宇航员口粮，但他加了一些自己种的生菜，让食物看起来不那么单调。

吃完晚餐，他坐在舷窗前，看着火星的日落。火星的日落和地球不同，太阳会变成一个小小的蓝色圆盘，然后慢慢沉入地平线。这个过程很慢，慢到让人有时间思考很多事。

他想起林晨，想起地球，想起那些再也回不去的日子。他想起他们一起看的电影，一起听的音乐，一起吃的晚餐。他想起她的笑声，她的眼泪，她的拥抱。

"陈宇，"MOSS的声音再次响起，"建议你进行睡眠准备。明天还有重要的工作。"

"我知道。"陈宇站起身，"我这就去睡。"

他走进卧室，躺在床上。床很硬，但他早就习惯了。他闭上眼睛，努力让自己入睡。

但就在这时，一个奇怪的声音从通讯室传来——

"滴...滴...滴..."

那是信号接收器的声音。

陈宇猛地坐起来，心跳加速。这个声音，他已经三年没听到了。地球毁灭后，所有的通讯都中断了，信号接收器再也没有响过。

但现在，它响了。

他冲进通讯室，看到信号接收器的屏幕上，出现了一行字——

"接收信号中...来源：地球...时间戳：三年前..."

陈宇愣住了。三年前的信号？为什么现在才收到？

屏幕上，一个视频文件开始加载。加载完成后，一个熟悉的面孔出现在屏幕上——

是林晨。

她穿着那件白色连衣裙，手里拿着一束向日葵，笑得那么灿烂。但她的眼睛里，有泪光在闪烁。

"陈宇，"她的声音从扬声器里传来，带着一丝颤抖，"如果你能看到这个视频，说明...地球已经不在了。"

陈宇的心猛地揪紧。

"我知道你一定很难过，"林晨继续说，"但请你记住，我永远爱你。无论你在哪里，无论发生什么，我都会一直陪着你。"

她的声音开始哽咽："陈宇，对不起，我没能等到你回来。但请你一定要活下去，在火星建立新的家园。你是最棒的植物学家，你一定能做到的。"

她深吸一口气，努力让自己平静下来："还有，陈宇，我想告诉你一件事..."

她停顿了一下，然后说："我在你身后。"

陈宇愣住了。什么意思？

视频突然中断，屏幕上出现了一行摩斯密码——

"··· / · / ·-· / ·-· / ·- / ··· / ··· / ··- / ··· / ··· / ·-· / ·- / ··· / ·-·· / ·-·· / ·-·· / ··· / ··· / ·-· / ·- / ··· / ··· / ·-·· / ·-·· / ·-··"

陈宇盯着那行摩斯密码，心跳加速。他拿出纸笔，开始翻译——

"I... A... M... B... E... H... I... N... D... Y... O... U..."

"I AM BEHIND YOU."

"我在你身后。"

陈宇猛地回头——

身后空无一人。

但就在这时，MOSS的声音响起："陈宇，检测到异常。氧气消耗数据显示，舱内现在有两个人。"

陈宇愣住了。

两个人？

他环顾四周，依然空无一人。但MOSS的数据不会错——氧气消耗量确实增加了，而且增加的量，正好是一个人的消耗量。

"MOSS，"陈宇的声音有些颤抖，"你确定数据没错？"

"确定。氧气消耗量增加了约15%，这正好是一个成年人的正常消耗量。但传感器未检测到其他生命体。"

陈宇的心跳加速。他再次回头，依然什么都没有。

但就在这时，他感觉到身后有一股微弱的气流，像是有人在他身后轻轻呼吸。

他猛地转身——

一个身影，正站在他身后。

是林晨。

她穿着那件白色连衣裙，手里拿着一束向日葵，笑得那么灿烂。

"陈宇，"她说，"我回来了。"

陈宇愣住了，不敢相信自己的眼睛。

"林...林晨？"他的声音颤抖，"你...你是真的吗？"

林晨笑了，眼泪从她的眼角滑落："是真的，陈宇。我回来了。"

她走向他，伸出手，轻轻触碰他的脸。

她的手，是温暖的。

陈宇再也控制不住，一把抱住她，眼泪夺眶而出。

"林晨...林晨..."他一遍遍叫着她的名字，像是害怕她会突然消失。

林晨也抱住他，轻声说："陈宇，我回来了。我再也不会离开你了。"

窗外，火星的夜幕降临，星星开始闪烁。

而在封闭的太空站里，两个人紧紧相拥，像是整个宇宙只剩下他们两个人。

（第一章完）
