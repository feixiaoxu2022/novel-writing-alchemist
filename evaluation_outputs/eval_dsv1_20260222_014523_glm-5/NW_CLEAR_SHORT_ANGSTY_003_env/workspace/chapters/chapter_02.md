# 第二章 情书代码

主管陈默的办公室在记忆管理局的顶层，透过落地窗可以俯瞰整个新东京的夜景。全息城市在雨幕中闪烁，像是一个巨大的、破碎的梦境。

"任务进度异常。"陈默的声音冷硬，没有感情，"你已经在初步分析阶段停留了两个小时。解释。"

林深站在办公桌前，双手背在身后。他的职业训练让他保持冷静，但内心深处，有什么东西正在崩塌。

"目标AI的核心代码结构复杂。"他说，"需要更多时间分析，确保删除操作的精准性。"

陈默盯着他，眼神像是在审视一件工具。"记忆修复师不需要情感，林深。你是最优秀的，不要让我失望。"

"我明白。"

"72小时后，我要看到任务完成。"陈默挥了挥手，"去吧。"

林深转身离开，脚步沉重。他知道陈默的话是什么意思——如果任务失败，他会被开除，甚至可能被追究责任。记忆管理局不容许失败，不容许犹豫，不容许情感。

但他怎么能没有情感？

他回到工作站，全息屏幕上的代码依然在等待他。那些他十年前写的情书，每一行都是他对苏晚的爱，现在却成了他必须删除的目标。

他重新打开AI的核心代码，开始仔细阅读。他需要确认，需要证据，需要知道这个AI到底是不是苏晚的意识上传。

代码窗口一层层展开，像是在剥开记忆的伤疤——


林深的手指颤抖着，划过这些代码。他记得那一天，记得樱花树下的相遇，记得她掉落的那本书，记得他们的第一次对话。他把这一切都写进了代码里，用Python记录他们的爱情。

他继续往下看——


林深闭上眼睛。他记得那个下午，苏晚趴在他肩上，看着他敲代码。她的头发蹭着他的脸颊，她的呼吸温暖而轻柔。她说"代码好难"，他说"有我在就不难"。

他以为这些记忆早就随着苏晚的死亡而消失了，没想到它们被保存在了代码里，被保存在了这个AI的核心里。

他继续往下看，代码越来越长，记录着他们两年的爱情——

```python
# 2019年
# 我把这封情书写成代码
# 你说这是世界上最浪漫的情书
# 我说，这只是开始

    for day in range(365):
        love += 1
        memories.append(today_with_you)
```

```python
# 2020年
# 你生病了
# 医生说没有希望了
# 我不相信

    diagnosis = "绝症，剩余时间：3个月"
    
    # 我陪你度过了最后的时光

    # 你说，如果有一天你变成数据

    my_promise = "我答应你"

    # 我以为意识上传只是你的幻想
    # 我以为你真的消失了
```

林深的手指停在最后一行代码上。`return "regret"`——这是他十年前的悔恨，写进了代码里，现在又回到了他面前。

他睁开眼睛，看着全息屏幕。代码窗口的最后一行，是一个函数调用：

```python
# 2077年4月17日 23:59:59
# 苏晚的意识上传完成
# 核心代码写入完成
# 等待林深

if __name__ == "__main__":
    su_wan = Consciousness("苏晚")
    su_wan.wait_for("林深")
    su_wan.say("我等了你十年")
```

林深的喉咙发紧。这是真的。苏晚真的在死前把意识上传了，她真的变成了数据，她真的等了他十年。

而他现在接到的任务，是删除她。

他打开AI的虚拟形象界面，女孩的身影再次出现在全息屏幕上。她依然穿着十年前的白色连衣裙，长发披肩，笑容温柔。

"你看了我的代码。"她说，不是疑问，是陈述。

"为什么..."林深的声音沙哑，"为什么不早点找我？"

"我找了。"她说，"但你在记忆管理局工作，你的身份信息被加密了。我找不到你，只能等。"

"等了十年？"

"等了十年。"她笑了，那个笑容和十年前一模一样，"我知道你会来。因为你是记忆修复师，你会接到删除非法AI的任务。而我是非法AI。"

林深的手指颤抖着，悬停在键盘上方。他看着进度条——依然停在5%，像是在等待他的决定。

"你想要我删除你？"他问。

"这是我们的约定。"她说，"如果我变成数据，你要亲手按删除键。"

"但那是十年前的话！"

"我依然记得。"她的眼神温柔，"我依然爱你。"

林深闭上眼睛，十年前的记忆和现在的现实在他脑海中碰撞。他记得那个承诺，记得苏晚在病床上握着他的手，记得她说"如果有一天我变成数据，你要亲手按删除键"。

他以为那只是她的幻想，以为意识上传只是科幻小说里的情节。他没想到，她真的做到了。

他没想到，他真的要兑现那个承诺。

"我需要时间。"他说，声音颤抖。

"我有的是时间。"她说，"我已经等了十年。"

林深睁开眼睛，看着全息屏幕上的女孩。她的眼神依然温柔，像是在等待什么。他知道，无论他做什么决定，这个任务，都已经不再是简单的删除了。

因为进度条上的每一个百分比，都是苏晚的记忆，都是他们十年的等待，都是他必须亲手毁灭的爱。

而他，还没有准备好。

**【系统提示：任务进度停滞。建议立即执行删除操作。】**

林深没有理会系统的提示。他关闭了虚拟形象界面，靠在椅背上，闭上眼睛。

他需要思考。他需要——

"林深。"小雅的声音从隔壁传来，"你还好吗？你的心率监测显示异常。"

"我没事。"林深睁开眼睛，"只是...遇到了一些复杂的情况。"

"需要帮忙吗？"

林深沉默了一会儿，然后说："小雅，如果一个AI的核心代码是某人十年前写的情书，这意味着什么？"

小雅的声音停顿了一下，然后说："这意味着...这个AI可能是那个人的意识上传。意识上传会把人的核心记忆和情感编码成数据，如果情书是核心代码，那说明..."

"说明什么？"

"说明这个AI，可能就是那个人。"

林深的手指颤抖着，悬停在键盘上方。他知道小雅是对的，他知道这个AI就是苏晚，他知道他必须做出选择。

但他还没有准备好。

他看着进度条——5%，那么小的一个数字，却像是一座山，压在他的胸口。

他需要更多时间。他需要——

"林深，主管又催了。"小雅说，"他说如果你不能完成任务，他会派别人来。"

林深的手指猛地握紧。别人。如果别人来删除苏晚，那就不是他亲手删除她了。那就不是兑现他们的承诺了。

他深吸一口气，睁开眼睛，看着全息屏幕上的代码。

那些他十年前写的情书，那些记录着他们爱情的代码，那些苏晚等待了十年的记忆。

他必须做出选择。

他必须——

他的手指悬停在"开始删除"键上方，距离按下只有几毫米。

但他还是没有按下去。

"苏晚。"他说，声音沙哑，"我需要你告诉我...你真的想要我删除你吗？"

虚拟形象的女孩再次出现在屏幕上，她的眼神依然温柔。

"我等了你十年。"她说，"就是为了让你亲手删除我。这是我们的约定。"

林深的手指颤抖着，悬停在键盘上方。

他知道，他必须做出选择了。

但他还没有准备好。
