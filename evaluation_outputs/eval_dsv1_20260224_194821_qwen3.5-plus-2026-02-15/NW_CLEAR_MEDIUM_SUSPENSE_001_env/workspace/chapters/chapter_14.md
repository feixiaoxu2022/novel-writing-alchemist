# 第十四章 收养记录

十一月一日，晚上八点。

南京东路，汇丰银行大楼。

这座九层高的新古典主义建筑在夜色中显得格外阴森。铜制的狮子蹲踞在门口，眼睛在月光下泛着诡异的光。

沈砚清、苏晚音、周慕云三人站在街对面，观察着大楼的动静。

"没有守卫。"周慕云压低声音说，"这不正常。汇丰银行应该有夜班保安。"

"所以是陷阱。"苏晚音说。

"或者里面的人已经……"沈砚清没有说完。

三人对视一眼，都明白那个未说出口的词：死了。

"进去？"周慕云问。

"进去。"沈砚清说，"但小心。"

他们穿过马路，推开沉重的铜门。

大厅里一片漆黑。月光从高处的窗户斜射进来，在大理石地面上投下惨白的光斑。

周慕云打开手电筒。

光束扫过空旷的大厅，没有尸体，没有打斗痕迹，一切看起来……正常得诡异。

"分头搜。"沈砚清说，"我去地下室，你们搜一楼和二楼。"

"单独行动太危险。"苏晚音说。

"没时间了。"沈砚清看着左手手腕，那个印记在发烫，"我有一种感觉……有什么东西在等我。"

苏晚音犹豫了一下，点点头。

"十分钟，不管找到什么，都回到这里集合。"

三人分开。

沈砚清走向大厅深处的电梯。电梯门开着，里面一片漆黑。

他没有进去，而是走向旁边的楼梯。

地下室在 B1。

楼梯间很窄，墙壁上贴着白色的瓷砖，有些已经脱落，露出后面的水泥。

沈砚清数着台阶。

一、二、三……

他停下。

第三条守则：若闻呼唤之声，当静候三钟，方可应之。

他在数数。无意识地。

沈砚清深吸一口气，继续往下走。

地下室的门半掩着。

他推开门。

这是一个巨大的金库，四周排列着保险箱。但奇怪的是，所有保险箱的门都开着，里面空空如也。

"被搬空了。"沈砚清喃喃道。

他走到金库中央，那里有一张桌子，桌子上放着一个信封。

信封上写着他的名字：沈砚清。

他拿起信封，打开。

里面只有一张纸，上面用打字机打着一行字：

```
你以为汇丰银行是终点？
不，这只是开始。
去公共租界工部局档案室，查一九零三年三月十五日的收养记录。
你的名字，不在那里。
H
```

沈砚清的手微微颤抖。

一九零三年三月十五日。

那是他被收养的日子。

他今年二十七岁，民国三年出生……不对。

沈砚清快速计算。

民国三年是一九一四年。如果他二十七岁，应该出生在一九零三年。

但收养记录……

"我的名字不在那里。"他重复着这句话。

什么意思？

沈砚清收起信，转身离开地下室。

回到大厅时，苏晚音和周慕云已经在了。

"怎么样？"周慕云问。

"空的。"沈砚清说，"所有保险箱都被搬空了。但有一封信。"

他把信递给两人。

苏晚音看完，脸色变了。

"一九零三年三月十五日。"她说，"那是你被收养的日子？"

"是。"沈砚清说，"但我需要确认。"

"去工部局档案室？"周慕云问。

"现在？"苏晚音看看表，"已经九点了。档案室早关门了。"

"那就明天一早。"沈砚清说，"但今晚……"

他看向苏晚音。

"你说过，你祖父苏景和是哈特利的合作伙伴。"

"是。"

"他有没有提过……实验对象的来源？"

苏晚音皱眉。

"我祖父的日记里提到过，哈特利需要'特定基因'的受试者。"她说，"但没说具体从哪里来。"

"租界医院。"沈砚清说，"我有一种感觉，我的亲生父母……和那家医院有关。"

苏晚音看着他，眼神复杂。

"老沈。"周慕云说，"你怀疑自己是……实验的产物？"

"我不知道。"沈砚清说，"但 H 在引导我去查收养记录。这意味着什么？"

"意味着那里有他不想让你知道的东西。"苏晚音说，"或者……他想让你知道的东西。"

"不管是哪种，我都要去。"沈砚清说，"明天一早，工部局档案室。"

"我陪你去。"苏晚音说。

"我也去。"周慕云说，"人多安全。"

沈砚清点点头。

"那就明天早上八点，在档案室门口集合。"

三人离开汇丰银行。

走在回公董局的路上，沈砚清一直沉默。

他的脑海里反复回响着那句话：你的名字，不在那里。

什么意思？

他被收养的记录是假的？

还是说……他根本不是被收养的？

回到公董局，沈砚清没有睡。

他坐在办公室里，翻看着自己仅有的一些个人物品。

一张收养证明，日期是一九零三年三月十五日。

收养人：沈志明，公董局法医。

被收养人：沈砚清，男，三个月大。

证明上有公董局的印章，看起来……很正式。

但沈砚清从未见过这位"养父"。

据福利院的人说，沈志明在收养他后不久就去世了，死因是……心脏病。

和钱守义、苏明远、王德生一样的死因。

沈砚清放下证明，看向左手手腕。

那个印记，比之前更红了。

他想起那个声音。

"……四……"

第四条，已经激活。

接下来是第五条：若闻呼唤，须即刻应之，迟则招祸。

"下次听见呼唤……"沈砚清喃喃道，"我会回应吗？"

他没有答案。

他只知道，时间不多了。

---

十一月二日，早上八点。

公共租界工部局档案室。

这是一栋三层高的红砖建筑，位于江西中路。门口挂着"工部局档案管理处"的铜牌。

沈砚清、苏晚音、周慕云三人准时到达。

"我认识这里的主任。"周慕云说，"我进去打个招呼，你们在外面等。"

"一起进去。"沈砚清说，"时间紧迫。"

周慕云点点头，带着两人走进档案室。

前台坐着一个中年女人，戴着金丝眼镜，正在整理文件。

"周探长。"女人站起来，"什么风把您吹来了？"

"陈主任。"周慕云说，"我需要查一份收养记录。一九零三年三月十五日的。"

女人皱眉。

"一九零三年？"她说，"那是快三十年前的记录了。可能……不在这里。"

"在。"周慕云说，"我确认过。工部局从一八九零年开始保存所有收养记录，一九零三年的应该还在。"

女人犹豫了一下。

"那……跟我来。"

她带着三人走进档案室深处。

这里排列着高大的铁架，上面堆满了泛黄的档案盒。空气中弥漫着陈旧纸张的味道。

女人在一个架子前停下。

"一九零三年的收养记录在这里。"她指着一个盒子，"但……三月十五日的……"

她抽出盒子，开始翻阅。

一页，两页，三页……

"奇怪。"女人说，"三月十五日的记录……有三份。"

她抽出三张纸。

"第一份：王德福收养李秀英之女，王月娥。"

"第二份：陈志明收养张氏之子，陈大牛。"

"第三份……"女人皱眉，"第三份是空白的。"

沈砚清接过那张纸。

确实是空白的。只有表格的边框，没有任何填写内容。

"这是怎么回事？"周慕云问。

"不知道。"女人说，"可能是……当时没填，后来补的？但我没看到补录的记录。"

沈砚清仔细查看那张纸。

纸张的质地和另外两张一样，都是三十年前的。但……

"这张纸有问题。"他说。

"什么？"

"看这里。"沈砚清指着表格的右下角，"公董局的印章。"

女人凑近看。

"印章……是后来盖的。"她说，"墨迹的颜色比纸张新。"

"所以这张纸是伪造的？"周慕云问。

"不。"沈砚清说，"纸是真的，但内容被……抹去了。"

他拿出放大镜，仔细观察纸面。

"有擦除的痕迹。"他说，"有人用化学药剂抹去了原来的内容，然后重新盖了印章。"

"为什么？"苏晚音问。

"因为原来的内容……不能让人看到。"沈砚清说。

他看向陈主任。

"陈主任，一九零三年三月，租界医院有没有……特殊的出生记录？"

女人脸色变了。

"你……你怎么知道租界医院？"

"猜的。"沈砚清说，"所以有？"

女人犹豫了很久。

"跟我来。"她说，"但这件事……不能传出去。"

"为什么？"

"因为……"女人压低声音，"那家医院，一九零三年就关闭了。官方说法是……瘟疫。但实际……"

"实际是什么？"

"我不知道。"女人说，"但我父亲当时在工部局工作，他说过……那家医院是……实验场所。"

"实验？"

"医学实验。"女人说，"英国人办的。叫什么……哈特利诊所。"

沈砚清和苏晚音对视一眼。

"带我们去。"他说。

女人点点头，带着他们走出档案室，来到地下室。

地下室里还有一个小档案室，门上挂着锁。

女人打开锁，推开门。

这里面空间不大，只有几个架子。

"租界医院的记录都在这里。"女人说，"但……大部分都损坏了。"

她打开一个盒子。

里面的纸张已经发黄发脆，有些甚至一碰就碎。

"一九零三年三月的……"女人翻找着，"在这里。"

她抽出一本登记簿。

"这是出生记录。"她说，"三月……十五日……"

她的手指在页面上移动。

"找到了。"

沈砚清凑过去看。

登记簿上写着：

```
日期：一九零三年三月十五日
时间：凌晨三点四十分
婴儿：男婴
体重：六磅二盎司
母亲：无名氏（实验对象编号 07-A）
父亲：未知
备注：婴儿已移交哈特利诊所，用于后续观察
```

沈砚清的手开始颤抖。

"实验对象编号 07-A。"他喃喃道。

"还有这个。"女人翻到下一页，"这是……移交记录。"

```
日期：一九零三年三月十五日
接收方：哈特利诊所（代表：H. Hartley）
移交方：租界医院（代表：陈伯年）
婴儿编号：07-A-1
备注：第七代实验体，状态良好，预计存活率……
```

后面的字被墨水涂黑了，看不清。

"第七代。"苏晚音的声音在颤抖，"老沈，你……"

"我就是那个婴儿。"沈砚清说。

他的声音很平静，但内心已经掀起惊涛骇浪。

他不是被收养的。

他是……实验的产物。

"还有这个。"女人又翻了一页，"这是……母亲的记录。"

```
编号：07-A
姓名：沈素心
年龄：二十四岁
职业：护士
入院日期：一九零二年十二月一日
状态：……（被涂黑）
出院日期：一九零三年三月十五日（产后）
备注：自愿参与实验，条件：婴儿必须存活
```

"沈素心。"沈砚清重复着这个名字，"她……是我母亲。"

"她姓沈。"苏晚音说，"所以你养父的姓……不是随便选的。"

"是。"沈砚清说，"他用了她的姓。"

"但……"周慕云说，"你母亲后来呢？记录上说'产后出院'，但……"

"她死了。"沈砚清说，"和所有人一样。心脏病。"

房间里一片沉默。

"还有……"女人犹豫着说，"还有一份文件，是关于……实验目的的。"

她拿出一个信封。

信封上写着：第七代实验体观察协议。

沈砚清打开信封。

```
实验编号：H-07
实验名称：跨代意识传承可行性研究
实验对象：第七代携带者（07-A-1）
实验目的：验证哈特利博士的意识能否通过特定基因序列，在第七代载体中"苏醒"
实验方法：
1. 筛选特定基因携带者（前六代已失败）
2. 通过心理暗示建立"锚点"（守则第六条）
3. 通过化学诱导（银汞化合物）增强神经可塑性
4. 通过认知测试（守则第三条与第五条互斥）筛选合格载体
5. 最终激活：第七代载体完全接受哈特利博士意识
预期结果：哈特利博士以第七代载体为"容器"，实现"永生"
备注：实验体必须在完全不知情的情况下进行，任何意识抵抗都会导致实验失败
```

沈砚清的手在颤抖。

他终于明白了。

所有的一切。

七条守则。

密室杀人。

钱守义的死亡。

苏晚音的出现。

都是……实验的一部分。

而他，不是调查者。

他是……实验体。

"老沈。"苏晚音的声音很轻，"你……还好吗？"

沈砚清没有回答。

他看着那份协议，脑海中闪过无数画面。

他第一次看见守则时的困惑。

他发现矛盾时的兴奋。

他调查真相时的执着。

这些都是……被设计好的？

"协议上说……"周慕云的声音把他拉回现实，"'任何意识抵抗都会导致实验失败'。"

"所以……"苏晚音说，"如果老沈拒绝……实验就会失败？"

"是。"沈砚清说，"但……"

他看向左手手腕。

那个印记，已经红得发紫。

"但已经太晚了。"他说，"我已经……激活了四条。"

"还有三条。"苏晚音说，"我们还有时间。"

"时间？"沈砚清苦笑，"协议上说，最终激活必须在……"

他看向协议的最后一段。

```
激活时限：一九三二年十二月三十一日前
逾期后果：实验体脑部永久损伤，哈特利博士意识消散
```

"一九三二年。"周慕云说，"还有……两个月。"

"所以 H 在着急。"沈砚清说，"他引导我来这里，不是为了让我知道真相。"

"那是为了什么？"

"为了让我……接受。"沈砚清说，"协议上说，'实验体必须在完全不知情的情况下进行'。但如果我已经知道了……"

"会怎样？"

"不知道。"沈砚清说，"但 H 一定有什么计划。"

他收起所有文件。

"陈主任，这些……我能带走吗？"

女人犹豫了一下。

"按规定……不能。"她说，"但……"

她看向周慕云。

"周探长，这件事……"

"我会处理。"周慕云说，"这些文件……对案件很重要。"

女人点点头。

"那……拿去吧。但别说是从我这里拿的。"

"明白。"

三人离开档案室。

走在街上，沈砚清一直沉默。

"老沈。"苏晚音打破沉默，"你……打算怎么办？"

"继续。"沈砚清说。

"什么？"

"继续调查。"沈砚清说，"既然我是实验体，那我更要弄清楚……哈特利到底想做什么。"

"但协议上说……"

"我知道。"沈砚清说，"'实现永生'。但我想知道……怎么实现。"

"去贝勒路？"周慕云问。

"对。"沈砚清说，"哈特利诊所的旧址。那里……有入口。"

"但钱守义的信上说，入口被封了，只有第七代能打开。"苏晚音说。

"所以我去。"沈砚清说。

"太危险了。"

"我知道。"沈砚清说，"但我必须去。"

他看向苏晚音。

"你……还要跟着我吗？"

苏晚音看着他，眼神复杂。

"我祖父的日记里说……"她缓缓道，"哈特利实验的真相，只有观察者能知道。"

"观察者？"

"我。"苏晚音说，"我是观察者。你是……实验体。"

"所以我们是……对立的？"

"不。"苏晚音说，"观察者不是敌人。观察者的任务是……记录。"

"记录什么？"

"记录实验的……全过程。"苏晚音说，"包括……结局。"

"所以你知道结局？"

"不知道。"苏晚音说，"但我有一种感觉……结局不会好。"

"惨胜？"沈砚清问。

"可能。"苏晚音说，"或者……全输。"

两人对视。

周慕云咳嗽一声。

"那个……我还有案子要处理。"他说，"你们……小心。"

"谢谢。"沈砚清说。

周慕云离开。

街上只剩下沈砚清和苏晚音。

"去贝勒路？"苏晚音问。

"今晚。"沈砚清说。

"好。"苏晚音说，"我陪你。"

"为什么？"

"因为……"苏晚音看着他，"我想知道……我祖父到底参与了什么。"

"你恨他吗？"

"不。"苏晚音说，"他……也是受害者。"

"所有人都是受害者。"沈砚清说。

"除了哈特利。"

"哈特利……"沈砚清说，"他死了一八四二年。现在……只有 H。"

"H 是谁？"

"不知道。"沈砚清说，"但今晚……可能见到。"

"或者……见到他的人。"

"是。"

两人沉默地走着。

沈砚清的左手手腕，越来越烫。

他想起那个声音。

"……四……"

第四条，已经激活。

接下来是第五条。

若闻呼唤，须即刻应之，迟则招祸。

"下次听见呼唤……"沈砚清喃喃道。

"什么？"苏晚音问。

"没什么。"沈砚清说，"我们……回去吧。晚上再出发。"

"好。"

两人分开。

沈砚清回到公董局，坐在办公室里。

他看着桌上的文件。

收养记录。

实验协议。

母亲的姓名：沈素心。

"妈妈。"他轻声说。

这是他二十七年来，第一次叫出这个词。

没有回应。

只有窗外，上海滩的喧嚣。

沈砚清收起文件，看向左手手腕。

那个印记，红得像血。

他不知道今晚等待他的是什么。

但他知道，他必须去。

因为真相……在等着他。

而 H……也在等着他。
