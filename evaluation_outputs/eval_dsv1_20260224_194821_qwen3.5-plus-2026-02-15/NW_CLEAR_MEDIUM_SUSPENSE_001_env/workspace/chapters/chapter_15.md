# 第十五章 哈特利的日记

十一月二日，晚上十点。

贝勒路，哈特利诊所旧址。

这是一栋三层高的西式建筑，外墙爬满了爬山虎，窗户大多破碎，在月光下像一双双空洞的眼睛。

诊所已经废弃快九十年了。

沈砚清和苏晚音站在门口，看着那扇摇摇欲坠的木门。

"就是这里。"苏晚音说，"我祖父的日记里提到过，哈特利的实验室在地下室。"

"入口在哪？"

"不知道。"苏晚音说，"但……应该有个隐蔽的门。"

沈砚清绕着建筑走了一圈。

外墙的砖块已经风化，有些地方露出了里面的水泥。他仔细查看每一处缝隙，寻找……

"在这里。"他说。

建筑北侧，有一个被爬山虎完全覆盖的角落。拨开藤蔓，露出了一扇铁门。

铁门上有一个奇怪的装置：一个圆形的凹槽，周围刻着复杂的纹路。

"这是……"苏晚音凑近看，"指纹锁？"

"不。"沈砚清说，"比那更古老。"

他看着那个凹槽。

凹槽的大小……刚好能放下一个手掌。

"第七代才能打开。"他想起钱守义信上的话。

沈砚清深吸一口气，将左手按在凹槽上。

印记发烫。

铁门内部传来机械转动的声音，咔哒，咔哒，咔哒……

三声。

铁门缓缓打开。

"进去了。"沈砚清说。

"小心。"苏晚音提醒道。

两人走进门内。

里面是一条向下的楼梯，墙壁上挂着煤油灯，但……

沈砚清点燃一盏灯。

灯光亮起，照亮了楼梯。

"这些灯……"苏晚音说，"还能用？"

"有人维护。"沈砚清说，"H 的人。"

他们沿着楼梯往下走。

大约走了两层楼深，来到一个大厅。

这里……不像废弃了九十年的地方。

墙壁干净，地面整洁，甚至……有电灯。

沈砚清按下墙上的开关。

灯亮了。

"有电。"苏晚音说，"这里……一直有人用。"

大厅四周排列着书架，上面摆满了书籍和文件。中央有一张巨大的书桌，桌上放着一盏台灯，一本摊开的日记本。

"有人刚来过。"沈砚清说。

他走到书桌前。

日记本上，墨迹还未干。

他拿起日记本。

第一页写着：

```
一八四二年八月二十九日

今日，《南京条约》签订。

大英帝国获得了在上海设立租界的权利。

这是……千载难逢的机会。

我将在这里，建立我的实验室。

实验名称：意识传承。

目标：找到完美的载体，让我的意识……永生。
```

"哈特利的日记。"苏晚音说。

"但……"沈砚清翻看着，"这字迹……不像是九十年前的。"

"是抄录的。"苏晚音说，"有人把哈特利的日记……抄了下来。"

"为什么？"

"为了……传承。"苏晚音说，"每一代 H，都在抄录这本日记。"

沈砚清继续翻。

```
一八四三年三月一日

第一批实验对象到位。

十二名中国劳工，从码头"招募"。

实验方法：注射水银化合物，观察神经反应。

结果：十一人死亡，一人……出现异常。

那人说，他"看见"了我的思想。

有趣。
```

"水银化合物。"沈砚清说，"就是银汞化合物。"

"影响神经系统的。"苏晚音说。

```
一八四五年六月十五日

实验进入第二代。

第一代失败者中，有一人留下了后代。

那孩子……有特殊的基因。

我称之为："载体基因"。

必须筛选出携带这种基因的人。
```

"载体基因。"沈砚清重复着，"所以我……携带这种基因？"

"可能。"苏晚音说，"继续看。"

```
一八五零年一月十日

苏景和加入实验。

他是……聪明的中国人。

他理解我的理想。

他说，意识传承是"人类的未来"。

我任命他为……第一任守护者。

但守护者中，必须有观察者。

观察者记录，守护者执行。

苏景和……选择成为观察者。

那守护者……需要另找他人。
```

"苏景和是观察者。"苏晚音说，"所以他……没有直接参与实验的执行。"

"他是……记录者。"沈砚清说。

```
一八五二年八月三日

实验进入第三代。

载体基因的遗传规律……逐渐清晰。

这是一种……显性基因。

但表达率很低。

一百个后代中，只有一个……能携带完整基因。

所以需要……七代。

七代之后，基因才会……完全激活。
```

"七代。"沈砚清说，"所以我是……第七代。"

"完全激活的载体。"苏晚音的声音在颤抖。

```
一八五五年十二月一日

身体……越来越差了。

水银中毒。

我知道……我活不了多久。

但实验……不能停止。

我培养了……一个学生。

英国人，姓……（被涂黑）

他将继承我的意志。

代号：H。

每一代负责人……都用这个代号。

这样……实验就能……永远继续。
```

"H 是代号。"沈砚清说，"不是一个人。"

"是……一个职位。"苏晚音说。

```
一八五七年四月二十九日

今日，我立下遗嘱。

实验继续，直到第七代出现。

守护者名单：

第一代：陈伯年（中国，医生）
第二代：（被涂黑）
第三代：（被涂黑）
……
第六代：钱守义（中国，通灵会会长）
第七代：待定

观察者名单：

第一代：苏景和（中国，学者）
第二代：苏明远（中国，商人）
第三代：（待定）

注意：守护者中……有叛徒。

苏明远……想销毁实验记录。

必须……监视他。
```

"苏明远。"苏晚音说，"我父亲。"

"他想销毁实验。"沈砚清说，"所以……被杀了。"

"被谁？"

"钱守义。"沈砚清说，"或者……当时的 H。"

继续翻。

```
一八五七年五月十日

我……快不行了。

最后的……实验记录。

意识传承的方法……已经完善。

步骤：

一、筛选第七代载体（基因完全激活）
二、建立心理锚点（守则第六条，每日默念）
三、化学诱导（银汞化合物，增强神经可塑性）
四、认知测试（守则第三条与第五条互斥，筛选能发现矛盾者）
五、最终激活（载体完全接受……我的意识）

但……有一个问题。

载体……必须有足够的……意志力。

太弱……无法承受意识转移。

太强……会抵抗。

所以需要……测试。

七条守则……就是测试。

能发现矛盾的人……才有资格……知道真相。
```

"第三条和第五条。"沈砚清说，"互斥的设计……是故意的。"

"认知测试。"苏晚音说，"能发现矛盾的人……才是合格的载体。"

"所以我……通过了测试。"

"是。"苏晚音说，"你……是完美的载体。"

沈砚清继续翻。

日记的最后几页，字迹变得潦草。

```
一八五七年五月十五日

最后……的……记录。

我……把……意识……封存在……

（后面的字无法辨认）

只有……第七代……能……打开……

源……在……

（被涂黑）

记住……

实验……必须……完成……

为了……人类……的……未来……
```

日记到此结束。

"源在哪？"苏晚音问。

"被涂黑了。"沈砚清说。

"但前面提到过……"苏晚音说，"钱守义的信上说，源在哈特利诊所的地下室。"

"就是这里。"沈砚清环顾四周，"但……在哪？"

两人开始搜索大厅。

书架后面，墙壁上，地面下……

"这里。"沈砚清说。

大厅中央，书桌下面，有一块地砖……颜色略有不同。

他移开书桌。

地砖上有一个凹槽，和门口的装置一样。

"又要用手？"苏晚音问。

"是。"

沈砚清再次将左手按在凹槽上。

印记发烫，比之前更烫。

地砖缓缓下沉，露出一个……保险箱。

保险箱上没有锁，只有一个把手。

沈砚清打开保险箱。

里面有一个……玻璃罐。

罐子里……装着……

"大脑。"苏晚音的声音在颤抖。

玻璃罐里，装着一个……浸泡在液体中的……人类大脑。

"哈特利的……"沈砚清说。

"他……把自己的大脑……保存了下来？"

"为了……意识转移。"沈砚清说。

但……不对。

一八五七年到现在，快八十年了。

大脑……怎么可能……

"这是……假的。"沈砚清说。

"什么？"

"哈特利的大脑……不可能保存这么久。"沈砚清说，"这是……后来放的。"

"谁放的？"

"H。"沈砚清说，"每一代 H，都在……维护这个……'圣物'。"

"为了……让实验看起来……更真实。"

"是。"沈砚清说，"心理暗示的一部分。"

他拿起玻璃罐。

罐子底部……有一张纸条。

他取出纸条。

```
致第七代：

如果你看到这个，说明……你已经走到了这里。

我是……当前的 H。

我想……和你……谈一谈。

明晚，八点。

地点：外滩，和平饭店，顶层套房。

一个人来。

不要告诉……任何人。

否则……她会死。

她……指的是……苏小姐。

H
```

沈砚清的手在颤抖。

"他……在威胁我。"

"谁？"

"H。"沈砚清把纸条递给苏晚音，"明晚，和平饭店。"

"你不能去。"苏晚音说，"这是陷阱。"

"但……"沈砚清说，"他说……'否则你会死'。"

"那是……威胁。"

"但如果……是真的呢？"沈砚清看着苏晚音，"如果……我不去，H 会……杀了你？"

苏晚音沉默。

"老沈。"她说，"你不能……为了我……"

"为什么不能？"

"因为……"苏晚音看着他，"我是……观察者。"

"观察者……是实验的一部分。"

"所以……我的命……不重要？"

"不。"苏晚音说，"我的命……重要。但……你的命……更重要。"

"为什么？"

"因为……"苏晚音深吸一口气，"如果……你死了，实验……就失败了。"

"但如果……我去了，可能……也回不来。"

"所以……我们……需要……计划。"

"什么计划？"

"你……去。"苏晚音说，"但……不是一个人。"

"周慕云？"

"不。"苏晚音说，"他……是警察。目标太大。"

"那……谁？"

苏晚音看着他。

"我。"

"什么？"

"我……跟你……一起去。"苏晚音说，"但……不进去。"

"什么意思？"

"你在……里面……和 H 谈。"苏晚音说，"我……在外面……等着。"

"如果……有危险……"

"我会……报警。"苏晚音说，"周慕云……会在……附近。"

"你们……早就……计划好了？"

"不。"苏晚音说，"是……现在……计划的。"

沈砚清看着她。

"为什么……帮我？"

"因为……"苏晚音说，"我……不想……成为……实验的……帮凶。"

"你……祖父……"

"我祖父……是……受害者。"苏晚音说，"他……被……哈特利……欺骗了。"

"所以……你……想……结束……实验？"

"是。"苏晚音说，"彻底……结束。"

沈砚清点点头。

"好。"他说，"明晚……八点……和平饭店。"

"但……今晚……"苏晚音说，"我们……先……回去。"

"是。"

两人离开地下室。

走出诊所时，沈砚清回头看了一眼。

那栋建筑……在月光下……像……一座……坟墓。

"老沈。"苏晚音说，"你……怕吗？"

"怕。"沈砚清说，"但……更……好奇。"

"好奇……什么？"

"哈特利……到底……想……做什么。"沈砚清说，"意识……传承……真的……可能吗？"

"你……相信……吗？"

"不。"沈砚清说，"但……我想……知道……他……为什么……相信。"

"为了……永生？"

"可能。"沈砚清说，"或者……为了……别的。"

"什么？"

"不知道。"沈砚清说，"明晚……会……知道。"

两人……沉默地……走着。

沈砚清的……左手手腕……越来越……烫。

他……想起……那个……声音。

"……四……"

第四条……已经……激活。

接下来……是……第五条。

若闻呼唤……须即刻……应之……迟则……招祸。

"下次……听见……呼唤……"沈砚清……喃喃道。

"什么？"苏晚音……问。

"没什么。"沈砚清……说，"回去……吧。"

"好。"

两人……分开。

沈砚清……回到……公董局。

坐在……办公室里……他……看着……桌上的……文件。

哈特利的……日记。

实验……协议。

母亲的……姓名：沈素心。

还有……那个……玻璃罐……里的……大脑。

"意识……传承。"他……喃喃道，"真的……可能……吗？"

他……不……知道。

他……只……知道……明晚……八点……和平饭店。

他……会……见到……H。

而……那……可能……是……他……最后……的……机会。

结束……实验。

或者……成为……实验的……一部分。

沈砚清……看向……左手手腕。

那个……印记……红得……像……血。

他……想起……日记里的……话。

"七代之后……基因……才会……完全……激活。"

"所以……我……是……完美的……载体。"

"完美……到……无法……拒绝。"

沈砚清……苦笑。

他……不……知道……明晚……等待……他的……是……什么。

但……他……必须……去。

因为……真相……在……等着……他。

而 H……也……在……等着……他。

窗外……上海滩……的……灯火……闪烁。

像……无数……双……眼睛。

在……注视……着……他。

在……等待……着……他。

在……审判……着……他。

沈砚清……关上……灯。

黑暗……中……他……听见……一个……声音。

"……五……"

第五条……激活了。

他……没有……回应。

因为……没有……人……在……呼唤。

至少……现在……没有。

但……明晚……

明晚……会……有。
