# 第二十章 没有超自然

十一月四日，上午九点。

工部局档案室。

沈砚清站在陈主任的办公桌前。

"陈主任，我需要一个完整的档案。"他说，"一八五七年，哈特利的学生，英国人。"

女人看着他。

"沈先生，你……知道了？"

"知道什么？"

"陈伯年……死……了。"女人说，"昨晚。"

沈砚清沉默。

"是。"他说，"但实验还没有结束。"

"所以你需要……"

"哈特利学生的记录。"沈砚清说，"他叫什么名字？"

女人犹豫了一下。

"跟我来。"

她带着沈砚清走进档案室深处。

这次不是地下室，而是二楼的一个密室。

女人打开门。

里面只有一个架子，上面放着一个铁盒。

"这是……"沈砚清问。

"哈特利实验的完整档案。"女人说，"陈伯年……生前交给我保管的。"

"他说过如果……"

"如果他死了，就交给你。"女人说，"还有苏小姐。"

"她来过？"

"昨天。"女人说，"她拿走了另一份档案。"

"什么档案？"

"苏家的家族记录。"女人说，"从苏景和开始，到苏明远，到……她。"

"所以她知道……"

"知道自己是第七代。"女人说，"但她没有告诉你。"

"为什么？"

"不知道。"女人说，"但她说……这是为了保护你。"

沈砚清沉默。

"档案给我。"

女人把铁盒递给他。

"沈先生，小心。"她说，"有些真相……知道了就无法回头。"

"我已经回不了头了。"沈砚清说。

他带着铁盒回到公董局。

打开。

里面是一叠文件。

最上面是一张泛黄的照片。

哈特利和一个年轻人的合影。

年轻人下面写着一行字：

亨利·威廉·哈特利（Henry William Hartley），哈特利博士之侄，一八三五年生。

"侄子？"沈砚清皱眉，"不是学生？"

他继续看。

一八五七年五月十五日，哈特利死亡。

遗嘱执行人：亨利·威廉·哈特利。

实验继承人：亨利·威廉·哈特利。

"所以 H 是……哈特利的侄子？"

他继续翻。

一八六零年。

亨利·威廉·哈特利开始第一代载体实验。

实验对象：自己。

"他拿自己做实验？"

沈砚清继续看。

一八六五年。

实验失败。亨利·威廉·哈特利出现精神异常。

一八七零年。

亨利·威廉·哈特利死亡。

死因：水银中毒。

"但……"沈砚清皱眉，"H 还活着。"

"除非……"

他继续翻。

一八七一年。

新的 H 出现。

姓名：（被涂黑）

身份：亨利·威廉·哈特利的学生。

"所以 H 真的是代号。"沈砚清说，"每一代负责人都用这个代号。"

他继续翻。

一八八零年。

第二代 H 死亡。

一八八一年。

第三代 H 出现。

……

一九零零年。

第五代 H 出现。

姓名：约翰·史密斯（John Smith）

身份：英国领事馆官员。

"约翰·史密斯。"沈砚清重复着这个名字，"这是……假名。"

他继续看。

一九三零年。

第五代 H 仍在活动。

状态：意识部分转移完成。

"所以现在的 H 就是约翰·史密斯。"沈砚清说，"他活了一百三十年。"

"因为意识转移。"

但……不对。

陈伯年的信上说，意识转移从未成功过。

那 H 为什么能活这么久？

沈砚清继续翻。

最后一份文件。

是一份实验报告。

标题：银汞化合物长期摄入对寿命的影响。

"银汞化合物。"沈砚清说，"就是那个影响神经系统的东西。"

他看报告内容。

```
实验对象：第五代 H（约翰·史密斯）
实验时间：一九零零年 - 一九三零年
实验方法：每日摄入微量银汞化合物
实验结果：
1. 神经系统出现异常（幻觉、幻听）
2. 细胞老化速度减缓
3. 预期寿命延长约 50-80 年
副作用：
1. 精神不稳定
2. 需要持续摄入
3. 停止摄入后迅速衰老死亡
结论：
银汞化合物可以延长寿命，但代价是精神异常和药物依赖
```

"所以 H 能活这么久……"沈砚清喃喃道，"不是因为意识转移。"

"是因为……银汞化合物。"

他继续看。

报告最后有一段附注：

```
注：哈特利博士的意识转移理论从未被证实。
所有"成功"案例都是安慰剂效应。
但 H 坚信理论正确，继续实验。
真正的目的可能是……
（后面的字被涂黑）
```

"真正的目的……"沈砚清皱眉。

他拿起电话。

"喂？"苏晚音的声音。

"你在哪？"

"通灵会。"苏晚音说，"赵德明……不见了。"

"什么？"

"通灵会……空了。"苏晚音说，"所有人都走了。"

"但……"

"我找到了一些东西。"苏晚音说，"赵德明的办公室。"

"什么？"

"一封信。"苏晚音说，"是给 H 的。"

"内容？"

"实验……已经……无法……继续。"苏晚音读着，"第七代……拒绝……合作。"

"源……已……被……摧毁。"

"建议……终止……实验。"

"但 H……回复……了。"

"说什么？"

"不。"苏晚音说，"实验……必须……完成。"

"即使……需要……强制……激活。"

"强制激活？"沈砚清说。

"是。"苏晚音说，"还有……一个……方法。"

"什么方法？"

"杀了……第七代。"苏晚音说，"取……他……的……大脑。"

"然后……"

"用……特殊……方法……提取……基因。"苏晚音说，"注入……H……的……身体。"

"这样……H……就……能……成为……完美……载体。"

沈砚清的手在颤抖。

"所以……他……会……来……杀……我。"

"是。"苏晚音说，"但……还有……一个……问题。"

"什么？"

"信里……提到……'原始……实验室'。"苏晚音说。

"哪里？"

"贝勒路……诊所……的……地下。"苏晚音说，"还有……一个……更……深……的……地方。"

"多深？"

"不……知道。"苏晚音说，"但……入口……在……陈伯年……死……的……那个……房间。"

"石台下面？"

"是。"苏晚音说，"我……回去……查……了。"

"有……发现？"

"石台……可以……移动。"苏晚音说，"下面……有……楼梯。"

"通……向……哪里？"

"不……知道。"苏晚音说，"我……没……敢……下去。"

"等我。"沈砚清说，"我……马上……来。"

"好。"

沈砚清挂断电话。

拿起铁盒。

走出公董局。

贝勒路，哈特利诊所。

苏晚音在门口等他。

"进去。"她说。

两人走进地下室。

陈伯年的尸体已经被移走了。

但地上还有血迹。

沈砚清走到石台前。

石台……确实可以移动。

他用力推。

石台缓缓移开。

露出一个向下的楼梯。

比之前的楼梯……更窄，更陡。

"下去？"苏晚音问。

"下去。"沈砚清说。

他点燃煤油灯。

两人走下楼梯。

大约走了三层楼深。

来到一个大厅。

这里……不像废弃的地方。

墙壁干净，地面整洁。

甚至……有电灯。

沈砚清按下开关。

灯亮了。

大厅中央有一个……装置。

像……一个……巨大的……玻璃舱。

舱里……装着……液体。

液体里……泡着……

"大脑。"苏晚音说。

和之前看到的那个一样。

但……这个……更大。

"哈特利的……真正……大脑？"沈砚清问。

"可能。"苏晚音说。

大厅四周排列着……仪器。

沈砚清走近看。

"这是……"

"脑电波……记录仪。"苏晚音说，"但……很……古老。"

"一八四零年代……的……技术。"沈砚清说。

"但……还在……工作。"苏晚音说。

仪器上的指针在跳动。

"所以……"沈砚清说，"这个……大脑……还……活着？"

"不……可能。"苏晚音说，"快……九十年……了。"

"但……仪器……在……工作。"

沈砚清继续看。

仪器旁边有一本日志。

他翻开。

```
一九三零年十月一日

脑电波活动稳定。

哈特利博士的意识……仍在。

```

"最近的记录。"沈砚清说，"十月一日。"

"维护……这个……装置。"

```
一九三零年十月十五日

沈砚清。

```

"取……我……的……大脑。"

"不。"苏晚音说，"日志……里……说……'提取……基因'。"

"不是……整个……大脑。"

"那……怎么……提取？"

```
一九三零年十一月一日

时间：十一月……五日。

```

"所以……他……要……在……明天……行动。"苏晚音说。

"是。"沈砚清说。

"我们……需要……计划。"

"怎么……计划？"

"这是……温度……控制。"

"这是……液体……循环。"

"这是……"

他停下。

"这是……什么？"苏晚音问。

"意识……提取……装置。"沈砚清说。

按钮上刻着一行字：

Consciousness Extraction Protocol.

"然后……注入……第七代……载体。"
