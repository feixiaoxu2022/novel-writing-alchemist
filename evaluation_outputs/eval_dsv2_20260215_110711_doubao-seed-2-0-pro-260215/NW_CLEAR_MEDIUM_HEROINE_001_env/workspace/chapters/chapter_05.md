# 第五章 律师函

苏清宁一晚上没睡好。

脑子里反复转着两件事：一是陆时衍的身份，二是拍卖行的那个电话。知道她有青花罐的人只有她和外公，消息不可能是外公漏出去的，唯一的可能就是陆时衍，他在鉴定中心看到她抱着防震箱，猜到里面是好东西，所以把消息放了出去，想等着压价收。

越想越觉得是这样，苏清宁心里堵得慌，本来以为遇到了个好人，没想到还是冲着东西来的。

第二天早上九点，门被敲响了，是快递员，送来一个EMS的文件袋。

苏清宁拆开一看，脸色瞬间就沉了。

是律师函。

周氏集团起诉她不当得利，要求她七日内返还离婚当日周子豪交给她的那一箱旧物，否则就要向法院提起诉讼，还要追究她的法律责任。律师函下面盖着周氏集团的公章，措辞强硬，半点情面都没留。

苏清宁捏着律师函的手指都在抖。冯美兰这是赶尽杀绝啊，当初是他们亲口说那箱东西是破烂，送给她当补偿，现在知道里面有好东西了，就反过来告她不当得利。

她立刻给林薇薇打了电话。

林薇薇二十分钟就赶来了，手里还拎着早餐，看到律师函的时候，“啪”的一声把豆浆放在桌子上，气得跳脚：“我靠！周家还要不要脸了？当初离婚协议写得明明白白，那箱东西是给你的补偿，现在还好意思要回去？真当法律是他们家开的啊？”

“我也没想到他们能这么不要脸。”苏清宁坐在椅子上，脸色发白，“昨天还有拍卖行给我打电话，问我是不是有永乐青花罐要出手，我没和任何人说过这件事，不知道他们是怎么知道的。”

“还有这事？”林薇薇皱起眉，“你是不是被人跟踪了？还是你和谁说过？”

“我只和我外公说过。”苏清宁顿了顿，还是把陆时衍的事说了，“我前几天认识了一个古董店老板，叫陆时衍，他帮过我两次，昨天我在鉴定中心遇到他，他还提醒我周家在打听我。但我昨晚发现他爷爷和我外公当年是同事，一起修复过永乐官窑的残件，我怀疑……是他把消息放出去的。”

林薇薇想了想：“也不一定吧？万一不是他呢？周家的人不是一直在跟踪你吗？说不定是他们看到你去鉴定中心，猜到你手里有好东西，故意放消息试探你呢？”

“我不知道。”苏清宁揉了揉太阳穴，“现在说这些也没用，当务之急是怎么应付这个官司。”

“你放心，这个官司我们肯定赢。”林薇薇把律师函扔在一边，“离婚协议是白纸黑字写的，他们说那箱东西是他们的，就得拿出证据证明那箱东西里确实有贵重物品，而且是他们不小心放进去的，谁主张谁举证，他们拿不出证据，法院根本不会受理。再说了，你那青花罐是他们扔的，你是善意取得，就算真闹到法院，也不可能判还给他们。”

“但他们说那箱旧物里有传家宝，是冯美兰的母亲留下的，价值连城，是整理的时候不小心放进去的。”苏清宁说。

“让他们吹牛逼。”林薇薇嗤笑一声，“价值连城的传家宝能不小心放到要扔的破烂里？鬼才信。到时候上了法庭，你就把你卖那几件小物件的记录拿出来，就说你以为那箱东西都是破烂，值钱的都已经卖了，剩下的都扔了，他们能拿你怎么样？”

苏清宁愣了一下：“这样……没问题吗？”

“有什么问题？”林薇薇挑眉，“他们有证据证明你手里有青花罐吗？没有吧？只要你一口咬定不知道什么青花罐，他们拿你一点办法都没有。不过我还是建议你把青花罐转移到安全的地方，别放在家里，万一他们狗急跳墙，派人来偷来抢，就得不偿失了。”

苏清宁点点头，林薇薇说得对，现在这房子已经不安全了，周家的人能派助理上门，就能派人进来偷东西，青花罐放在这里太危险。

“我知道了，我一会儿就把它搬到我外公那里去，他那里有保险柜，安全。”

“对，放你外公那里最安全。”林薇薇拍了拍她的肩膀，“你别担心，这个官司我帮你打，保证他们赢不了。对了，你要不要找那个陆时衍问问？看看到底是不是他走漏的消息，别冤枉了好人。”

苏清宁犹豫了一下，摇了摇头：“不用了，不管是不是他，我和他都没什么好说的，以后不往来就是了。”她现在一想到陆时衍可能是冲着青花罐来的，心里就不舒服，干脆就不要联系了。

林薇薇也没勉强，帮她整理了一下证据材料，中午吃完饭就走了，说回去帮她写答辩函，发给周家的律师。

苏清宁送走林薇薇，回到修复室，打开柜子，把青花罐抱出来，用防震棉重新包好。她打算下午给外公送过去，放在他那里确实安全。

就在这时，手机响了，是陆时衍打来的。

苏清宁看着屏幕上的名字，皱了皱眉，接了起来，语气很冷：“陆老板，有事吗？”

陆时衍似乎听出了她语气不对，顿了顿才说：“我听说周氏给你发律师函了？你要是需要帮忙的话，我可以给你介绍几个厉害的律师，或者你手里的东西要是急着出手，我可以给你出市场价，比拍卖行高两个点。”

“不用了，谢谢。”苏清宁的语气更冷了，“我的事我自己能处理，就不麻烦陆老板了。还有，我手里没有什么值钱的东西，陆老板不用惦记了。”

陆时衍沉默了几秒，声音也沉了下来：“你是不是误会什么了？”

“我没误会什么。”苏清宁说，“以后我们还是别联系了，我不想和古董行的人有太多牵扯。”说完就挂了电话，把陆时衍的号码拉进了黑名单。

做完这一切，她心里并没有轻松多少，反而更堵得慌。不知道为什么，明明是她先疏远的对方，心里却有点难受。

她摇了摇头，把乱七八糟的情绪甩开，抱着青花罐出了门，打车去了外公家。

陈敬之听她说了律师函的事，气得拍了桌子：“简直是欺人太甚！当年那只青花罐明明是冯美兰的男人当年从盗墓贼手里收的，不敢拿出来见人，才扔在老宅仓库里，现在还好意思往回要？宁宁你放心，外公手里有当年的记录，真闹到法庭上，我去给你作证，看他们还要不要脸！”

“外公，你别生气，我能处理好。”苏清宁安抚了老人半天，才把青花罐放进他的保险柜里。

从外公家出来的时候，已经是下午了，深秋的风有点凉，吹在脸上有点疼。苏清宁站在公交站台上，看着来来往往的车流，突然觉得有点累。

离婚，被试探，被起诉，被怀疑，所有的事都堆在一起，压得她有点喘不过气。

但她不能退。

这是她证明自己的机会，也是她拿回属于自己的一切的机会。她不能输给周家，更不能输给那些看她笑话的人。

苏清宁深吸了一口气，拿出手机，给林薇薇打了个电话：“薇薇，答辩函你尽量写得硬气一点，我不光要赢官司，还要让他们公开给我道歉。”

电话那头的林薇薇笑了：“没问题！就等你这句话呢！我告诉你，咱们不光要让他们道歉，还要让他们赔偿你精神损失费！”

挂了电话，苏清宁看着远处的夕阳，嘴角慢慢翘了起来。

来吧，不管是什么牛鬼蛇神，她都接着。
