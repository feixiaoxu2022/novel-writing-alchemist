# 第六章 走眼

鉴定中心的检测报告第二天就出来了，结果和苏清宁判断的一样，青花罐的胎质成分、釉色参数和1994年的残件完全匹配，确实是永乐官窑的真品。

苏清宁把报告和外公的修复记录放在一起，锁进了抽屉里。现在有了这些证据，就算真闹到法庭上，她也不怕。

只是钱的问题有点棘手。林薇薇说律师费加上诉讼费大概要十万，她手里只有之前卖小物件赚的一万三，远远不够。青花罐不能动，只能想办法再卖点别的东西，或者看看有没有捡漏的机会，赚点快钱。

她翻了翻旧物箱里剩下的东西，还有一件汝窑的笔洗，是宋代的，不过有冲线，价值不高，最多卖几万块，还是不够。

苏清宁想了想，还是决定再去潘家园逛逛，看看有没有合适的东西，她做了四年鉴定助理，眼光还是有的，运气好捡个漏，律师费就有了。

十月二十号上午，苏清宁又去了潘家园。她没去西边的店，反而去了东边，上次陆时衍说东边的店老板都和王老板认识，她想看看有没有捡漏的机会。

逛到最大的那家“百川堂”的时候，她被门口摆的一件青花观音瓶吸引了，走进去看了看。店里装修得古色古香，博古架上摆满了瓷器玉器，老板是个留着山羊胡的老头，穿一身唐装，左手戴个羊脂玉的扳指，看起来很有分量。

“小姑娘，看点什么？”老头笑着打招呼，语气很和蔼。

“我随便看看。”苏清宁的目光落在那件青花观音瓶上，刚要伸手拿，就听到旁边有人说：“张老，您这观音瓶不错啊，雍正朝的？”

苏清宁回头，看到几个穿着中式褂子的男人走进来，为首的那个笑着和老头打招呼。她才知道这个老头就是张百川，业内有名的泰斗级人物，做了一辈子古董生意，很少看走眼。

“是雍正的，昨天刚收的。”张百川笑着回应，目光落在苏清宁身上，“小姑娘也懂瓷器？”

“略懂一点。”苏清宁礼貌地笑了笑。

“哦？那你看看这件观音瓶，是真的还是假的？”张百川指了指那件观音瓶，语气里带着点试探。

苏清宁拿起来仔细看了看，胎质细腻，釉色温润，款识也对，是雍正官窑的真品：“是真品，雍正朝的青花观音瓶，市价大概三十万左右。”

张百川眼睛亮了：“小姑娘眼光不错啊，学这个的？”

“嗯，以前在拍卖行做过鉴定助理。”苏清宁说。

“难怪，年纪轻轻有这眼光，不容易。”张百川笑着点头，“我刚收了一件汝窑笔洗，北宋的，你要不要看看？”

苏清宁心里一动。汝窑的东西存世量极少，就算是残件也很值钱，如果是真的，就算有瑕疵也能卖几十万。

张百川从柜台后面拿出一个锦盒，打开来，里面放着一件天青色的汝窑笔洗，开片自然，釉色温润，看起来品相很好，只是底部有一点小磕碰。

“你看看，东西是老的，就是底上磕了一点，我本来想自己留着的，最近急需用钱，打算出手。”张百川说，“你要是要，五十万给你，拿到拍卖行，最少能卖八十万。”

苏清宁的心跳快了起来。她拿起笔洗，仔细看了半天，胎质是香灰胎，釉色是典型的天青色，开片是蝉翼纹，支钉烧的痕迹也对，所有特征都符合北宋汝窑的特点，而且五十万的价格确实很低，转手就能赚三十万，刚好够律师费。

她有点心动，又有点犹豫，天上掉馅饼的事，哪有这么容易。

“张老，您怎么不卖给别人啊？”苏清宁问。

“我这不是看你小姑娘实诚，眼光也好，便宜你了。”张百川笑着说，“要是卖给那些老狐狸，最少要宰我一笔，我看着你顺眼，就便宜你了。”

苏清宁又仔细检查了一遍，确实没发现什么问题，她做了四年鉴定助理，汝窑的标本也见过不少，这件应该是真品。她咬了咬牙：“行，我要了。”

她卡里有之前工作攒的四十万，加上这次卖小物件赚的一万三，还差八万多，她给林薇薇打了个电话，借了十万，凑齐五十万转给了张百川。

拿着锦盒走出百川堂的时候，苏清宁心里美滋滋的，这下律师费不仅够了，还能剩点钱当工作室的启动资金。

她没回家，直接去了之前工作的拍卖行，找以前的同事帮忙估个价，看看能不能尽快出手。

同事王哥看到她拿来的汝窑笔洗，一开始也以为是真的，仔细看了半天，脸色慢慢变了：“清宁，你这东西……不对啊。”

苏清宁心里一紧：“怎么不对？”

“你看这开片，虽然做得很像，但太均匀了，北宋汝窑的开片是自然形成的，不可能这么均匀。还有这胎质，看起来是香灰胎，但比真品重一点，应该是高仿，最多值五千块。”王哥把笔洗递给她，“你这是在哪买的？被人坑了吧？”

苏清宁的脑子“嗡”的一声，一片空白。她接过笔洗，按照王哥说的地方又看了一遍，果然，开片确实太均匀了，胎质也比真品稍重一点，她之前太想赚钱了，居然忽略了这些细节。

五十万，她全部的积蓄，加上借的十万，就这么打了水漂。

她不知道自己是怎么走出拍卖行的，手里的锦盒重得像千斤巨石，压得她喘不过气。她做了这么多年鉴定，从来没有走眼过，这次居然栽得这么惨。

她蹲在路边，看着手里的笔洗，眼泪忍不住掉了下来。这三年在周家，她明明没有丢了专业，为什么会看走眼？是她太想赚钱了，所以才放松了警惕，还是她的本事真的不行？

就在这时，一辆车停在她面前，车窗降下，露出陆时衍的脸。他看到她蹲在路边哭，皱了皱眉，下车走过来：“你怎么了？”

苏清宁抬起头，看到是他，擦了擦眼泪，站起身就要走。

“等等。”陆时衍拉住她的胳膊，看到她手里的锦盒，又看到她通红的眼睛，“你是不是买了张百川的东西？”

苏清宁愣了一下：“你怎么知道？”

“张百川专门做高仿坑新人，业内谁不知道。”陆时衍叹了口气，“他是不是卖给你一件汝窑笔洗？五十万？”

苏清宁点点头，眼泪又掉了下来：“是我太蠢了，居然没看出来是高仿。”

“不怪你，他做的高仿，有时候我都要仔细看半天才能看出来。”陆时衍递给她一张纸巾，“钱的事你别担心，我帮你要回来。”

“不用你假好心。”苏清宁别过脸，“你是不是早就知道他会坑我，等着看我笑话呢？”

陆时衍皱起眉：“我为什么要看你笑话？我知道你和我闹脾气是觉得我走漏了青花罐的消息，我可以告诉你，不是我。那天在鉴定中心，你走之后，周子豪的人进去问了你的检测样本是什么，是他们走漏的消息，和我没关系。”

苏清宁愣住了：“你说什么？”

“我接近你，不是为了青花罐，是因为我爷爷是陆明远，他临终前说过，当年没找到的那只完整青花罐，一定要找到，捐给故宫。”陆时衍看着她的眼睛，“我知道你是陈敬之的外孙女，也知道那只罐在你手里，我从来没想过要抢，我只是想帮你。”

苏清宁呆呆地看着他，一时间不知道该说什么。原来她冤枉他了？

“你……你说的是真的？”

“我没必要骗你。”陆时衍说，“你要是不信，我可以带你去我家看我爷爷的日记，里面写得清清楚楚。”

就在这时，苏清宁的手机响了，是林薇薇打来的，语气很着急：“清宁！不好了！周家不知道从哪拿到了证据，证明那箱旧物里有永乐青花罐，现在向法院申请了财产保全，要冻结你的所有资产！”

苏清宁的脸色瞬间变得惨白。

屋漏偏逢连夜雨，她刚赔了五十万，现在周家又来这一出。

她该怎么办？
