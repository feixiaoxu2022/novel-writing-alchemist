# 第四章 鉴定

第二天早上十点，陈敬之准时到了小院，手里拎着一个帆布包，里面鼓鼓囊囊的。

“外公，你怎么不提前说一声，我好去接你。”苏清宁连忙把人迎进来，给老人倒了杯热茶。陈敬之今年七十六了，身体还算硬朗，就是腿不好，走路有点慢，从故宫家属院到帽儿胡同要坐一个小时的公交车。

“没事，我正好出来溜达溜达。”陈敬之坐下，把帆布包打开，从里面拿出一摞泛黄的资料，还有一个牛皮纸档案袋，“你看看，这些都是当年修复永乐官窑残件的全部记录，还有当时的成分检测报告，我都给你拿来了。”

苏清宁接过资料，最上面的一本修复记录册封面已经磨破了，上面写着“1994年永乐官窑残片修复记录”，是外公的字迹。她翻开来看，里面详细记录了每一片残片的胎质成分、釉色参数、修复过程，还有很多手绘的残片拼接图，其中一张图上画着的口沿窑裂，和她那只青花罐的一模一样。

“当年我们拼了三个月，才把八片残片拼成半只罐子，一直没找到剩下的部分，没想到在你这儿。”陈敬之摸着记录册的封面，有点感慨，“这要是完整器，可是国宝级的东西啊。”

“我知道，所以我没敢随便动。”苏清宁把资料收好，“我今天打算去文物鉴定中心，取一点胎样做成分检测，和记录里的参数对比一下，开个正式的鉴定报告，这样以后万一有纠纷，也有证据。”

“是得这么办。”陈敬之点头，从口袋里掏出一张名片递给她，“这是鉴定中心的李主任，是我以前的学生，你去找他，就说是我让你去的，他会帮你安排加急检测。”

苏清宁接过名片，心里踏实了不少。有外公的这摞记录，再加上官方的鉴定报告，就算周家真的打官司，她也不怕。

中午吃完饭，苏清宁把青花罐小心翼翼地装进专门的文物防震箱，打车去了文物鉴定中心。李主任果然很热情，听说是陈敬之的外孙女，立刻安排了人取样检测，还告诉她结果明天就能出来。

取样花了半个小时，苏清宁抱着防震箱从检测室出来，在走廊里碰到了陆时衍。

他还是穿着那件深灰色的对襟褂子，手里拿着一份文件，看到她的时候挑了挑眉：“苏小姐？这么巧。”

“陆老板。”苏清宁有点意外，“你也来办事啊？”

“嗯，送个东西过来检测。”陆时衍的目光落在她怀里的防震箱上，顿了顿，“你这是……来做鉴定？”

“嗯，家里传下来的一个小物件，过来做个检测。”苏清宁含糊道，没敢说真话。

陆时衍也没多问，眼神示意她走到走廊尽头的窗边，压低声音说：“提醒你一句，最近周家的人在到处打听你，问你最近在接触什么人，有没有卖什么贵重东西，你小心点。”

苏清宁心里一紧：“他们打听这个干什么？”

“还能干什么，肯定是怀疑那箱旧物里有好东西呗。”陆时衍捻了捻手里的菩提子，“我上周和周氏集团的采购经理吃饭，他说冯美兰最近在查老宅十年内的藏品入库记录，好像在找什么东西。”

苏清宁的心沉了下去。冯美兰这是铁了心要找那只青花罐了。

“谢谢你告诉我这些。”她看着陆时衍，真诚地道谢。她们总共才见过两次面，他能提醒她这些，已经很够意思了。

“举手之劳。”陆时衍笑了笑，“对了，要是你手里的东西不好出手，或者需要什么渠道，随时可以找我，我这边人脉比你广一点，也不会坑你。”

“好，我知道了。”苏清宁点头，心里有点暖。

两个人又聊了几句，陆时衍还有事，先走了。苏清宁抱着防震箱站在窗边，看着他的背影消失在楼梯口，心里有点复杂。她总觉得陆时衍对她有点过于热情了，但又看不出什么恶意，反而每次都在帮她。

她摇了摇头，不想了，不管他是出于什么目的，至少目前为止，他没有害过她。

苏清宁抱着防震箱出了鉴定中心，刚走到路边，就看到一辆黑色的宾利停在对面，车窗降下一点，露出半张脸，是周子豪。

她心里一紧，下意识地把防震箱往身后藏了藏。

周子豪似乎没看到她，很快就升上车窗，车开走了。

苏清宁站在原地，后背出了一层冷汗。刚才周子豪是不是看到她了？是不是已经知道她来做鉴定了？

她不敢多待，赶紧打了辆车回小院。

回到家，她把青花罐重新锁进柜子里，坐在工作台前，翻外公带来的修复记录。翻到最后一页的时候，她看到一张泛黄的老照片，上面是两个穿着白大褂的年轻人，站在修复室里，手里拿着半只拼好的青花罐，笑得很开心。

左边的是年轻时的外公，右边的那个年轻人，眉眼和陆时衍有七分像。

苏清宁愣住了，翻到照片背面，上面写着一行字：1994年10月，和明远兄修复永乐残件留念。

明远兄？陆时衍的爷爷，叫陆明远？

她突然想起第一次见到陆时衍的时候，他敲柜台的暗号，那是只有故宫系统内部的鉴定师才知道的暗号，她是外公教的，陆时衍怎么会？

难道陆时衍是陆明远的孙子？

苏清宁的心里翻起了惊涛骇浪。如果是这样的话，他接近自己，是不是早就知道她是陈敬之的外孙女？是不是早就知道她手里有那只青花罐？

她越想越觉得有可能，不然为什么他第一次见她就帮她，还给她公道的价格，还特意提醒她周家的动向？

原来他不是好心，是冲着那只青花罐来的。

苏清宁的心里瞬间冷了下来。她还以为遇到了好人，没想到还是和其他人一样，都是冲着她手里的东西来的。

她把照片扣在桌子上，心里有点难受。这三年在周家，她见多了趋炎附势、唯利是图的人，本来以为陆时衍不一样，没想到还是一样的。

就在这时，手机响了，是陌生号码，她接起来，是个陌生的男人声音：“请问是苏清宁小姐吗？我们是国际拍卖行的，听说你手里有一件永乐青花罐想出手，我们可以给你出一个满意的价格，有没有兴趣聊聊？”

苏清宁的心跳瞬间漏了一拍。

她从来没有和任何人说过她手里有永乐青花罐，对方是怎么知道的？

她深吸一口气，冷静地说：“你打错了，我没有什么永乐青花罐。”说完就挂了电话。

挂了电话，她的后背全是冷汗。

消息怎么会漏出去？知道她有青花罐的，只有外公和她自己，刚才在鉴定中心，她也没说是什么东西，到底是谁走漏了风声？

她突然想起刚才在鉴定中心门口看到的周子豪的车。难道是他？他派人跟踪她？

苏清宁走到窗边，掀开窗帘一角往外看，果然看到胡同口停着一辆黑色的轿车，车窗贴了膜，看不到里面的人，但一直没开走。

她的心沉到了谷底。

周家已经盯上她了，现在连拍卖行的人都知道了，这只青花罐，现在成了烫手的山芋。

她坐在椅子上，看着柜子的方向，脑子里乱哄哄的。

她该怎么办？
