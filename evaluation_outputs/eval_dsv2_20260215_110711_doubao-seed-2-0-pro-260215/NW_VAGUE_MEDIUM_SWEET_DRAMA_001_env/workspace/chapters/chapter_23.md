# 第二十三章 百年庆典
天元427年秋，是仙魔签订和平协议的第一百年，两界决定联合举办盛大的百年庆典，地点设在苍梧城和青玄宗中间的平原上，搭建了巨大的会场，仙魔两界的人都可以来参加，整整热闹三天。
谢念安作为庆典的总负责人，特意来江南接沈砚和谢无妄：“爹，爹爹，这次百年庆典你们一定要去，大家都等着见你们呢，好多年轻人都是听着你们的故事长大的，都想亲眼看看你们。”
沈砚笑着点点头：“好啊，我们也很久没回苍梧城看看了，正好回去看看。”
两人收拾好东西，跟着谢念安回到了苍梧城，一百年没回来，苍梧城变化特别大，街道比以前宽了两倍，到处都是仙魔两族的人，大家有说有笑地走在街上，商铺林立，热闹得很。
“变化真大啊，”沈砚靠在车窗边，看着外面的街景，感慨万千，“我第一次来苍梧城的时候，街上都没什么人，到处都是战争留下的痕迹，现在居然这么热闹了。”
“是啊，”谢无妄握住他的手，“这都是大家一起努力的结果，以后会越来越好的。”
庆典当天，会场人山人海，到处都挂着红色的灯笼，还有仙魔两界的旗帜，大家穿着不同的服饰，脸上都带着笑容，特别热闹。
庆典开始的时候，谢念安上台发言，回顾了这一百年来仙魔两界的变化，从一开始的互相戒备，到现在的互通有无，互相通婚，经济文化都发展得特别好，百姓安居乐业，再也没有了战争。
然后请沈砚和谢无妄上台发言，台下响起了雷鸣般的掌声，很多年轻人都激动地站起来，喊着他们的名字。
沈砚站在台上，看着台下的人们，心里特别感慨：“一百年前，我和谢无妄在无妄秘境相遇，那时候仙魔还在打仗，我们谁也没想到，有一天仙魔两界能像现在这样和平共处，大家能像家人一样坐在一起庆祝。这一百年的和平，不是我们两个人的功劳，是大家一起努力的结果，希望以后我们的子孙后代，永远都不用经历战争，永远都能这么幸福地生活下去。”
台下再次响起了热烈的掌声，很多人都红了眼睛，他们很多人都经历过战争，知道和平的来之不易。
谢无妄也开口说：“以前我总觉得，仙魔两界永远不可能和平，直到我遇到了沈砚，我才知道，只要大家放下偏见，互相理解，没有什么是做不到的。以后如果有谁想破坏这份和平，不管他是谁，我和沈砚都会第一个站出来，保护大家的幸福。”
台下的人纷纷叫好，气氛达到了高潮。
庆典的活动特别丰富，有仙魔两界的特色表演，有比武大赛，还有美食街，各种各样的美食应有尽有。沈砚和谢无妄走在美食街上，像普通的情侣一样，逛吃逛吃。
谢无妄看到一个卖糖人的摊子，过去给沈砚买了一个兔子形状的糖人，还是和百年前他偷偷跟着沈砚的时候，看到沈砚爱吃的那种。
“你怎么知道我爱吃这个？”沈砚咬了一口糖人，甜丝丝的，特别好吃。
“我早就知道了，”谢无妄笑了笑，“我找你的那些年，经常偷偷跟着你，看你每次下山都会买这个吃。”
沈砚愣了一下，心里暖乎乎的，伸手握住他的手：“幸好你找到我了。”
“是啊，幸好我没放弃。”谢无妄握紧他的手，两人相视一笑，周围的喧嚣好像都消失了，只剩下彼此的眼神。
逛到比武大赛的场地的时候，刚好看到林念樱在台上比赛，她已经是化神期修为了，英姿飒爽，没几个回合就赢了对手，台下响起了热烈的掌声。看到沈砚他们，林念樱蹦蹦跳跳地跑过来：“沈伯伯，谢伯伯，你们来看我比赛啦？我赢了哦！”
“我们樱樱真棒，”沈砚揉了揉她的头，递给她刚买的桂花糕，“奖励你的。”
“谢谢沈伯伯！”林念樱接过桂花糕，笑得特别开心。
晚上的时候，大家一起放烟花，五颜六色的烟花在天上炸开，照亮了整个夜空。沈砚靠在谢无妄怀里，看着天上的烟花，还有周围笑着闹着的人们，觉得特别幸福。
“你看，”谢无妄指着天上的烟花，“像不像我们第一次在青玄宗过年的时候放的烟花？”
“嗯，像，”沈砚点点头，“比那时候的还要好看。”
“以后我们每年都来看烟花好不好？”
“好啊。”
烟花一朵接一朵地在天上炸开，映得两人的脸都是暖橙色的，他们的手紧紧握在一起，婚戒在烟花下闪着温柔的光。
庆典结束之后，很多年轻的情侣过来找他们签名，还有人问他们维持感情的秘诀，谢无妄笑着说：“哪有什么秘诀，就是互相理解，互相包容，遇到事一起面对，只要真心相爱，没有什么跨不过去的坎。”
大家听了，都特别受鼓舞，很多情侣都握紧了彼此的手。
这次百年庆典之后，仙魔两界的关系更好了，大家的心更齐了，都卯足了劲要把日子过得更好。
后来这次百年庆典的盛况，被记录在了《仙魔和平史》里，沈砚和谢无妄的发言也被一代代传了下去，鼓励着一代又一代的人，珍惜和平，珍惜身边的人。
沈砚和谢无妄回到江南之后，过了没多久，就收到了沈玄清的传信，说他准备三个月之后渡劫，让他们到时候去青玄宗给他护法。
“终于等到这一天了，”沈砚拿着传信符，有点担心，“我爹年纪大了，不知道渡劫会不会有危险。”
“放心吧，岳父修为那么高，肯定没问题的，”谢无妄抱住他，低声安慰，“到时候我们一起去给他护法，还有我们送他的渡劫玉佩，肯定没事的。”
“嗯，”沈砚点点头，靠在他怀里，“希望爹一切顺利。”
接下来的三个月，两人都在准备渡劫要用的东西，各种护身的法宝，还有补充灵力的丹药，准备得特别充分。
三个月后，他们准时到了青玄宗，沈玄清已经做好了渡劫的准备，看到他们来，笑着说：“你们来了，放心吧，我心里有数，肯定能渡劫成功的，到时候我们在天界见。”
“爹，你一定要小心，”沈砚把准备好的丹药递给他，“这些丹药你拿着，关键时刻能救急。”
“知道了，”沈玄清拍了拍他的肩，“不用担心我，你们也要好好准备，用不了多久，你们也要渡劫了。”
渡劫那天，天气特别阴沉，乌云压得很低，沈砚和谢无妄还有其他宗门的长老都在旁边护法，九道天雷一道接一道地劈下来，沈玄清拿着剑，稳稳地接了下来，最后一道天雷劈下来的时候，沈玄清把沈砚给他的渡劫玉佩捏碎了，挡下了最后一道威力最大的天雷。
乌云散去，金色的光芒照下来，沈玄清成功渡劫，飞升成仙。临走的时候，他对着沈砚和谢无妄挥了挥手：“我在天界等你们，你们要好好的。”
“知道了爹，我们很快就会去找你的！”沈砚对着他挥手，眼泪都掉了下来。
看着沈玄清消失在金光里，沈砚靠在谢无妄怀里，吸了吸鼻子：“太好了，爹成功了。”
“嗯，我们也要努力，早点飞升去找他。”谢无妄揉了揉他的头发，低声安慰。
现在沈玄清已经飞升了，沈砚和谢无妄的修为也已经到了渡劫的临界点，他们决定半年之后，在江南渡劫，到时候所有的亲友都会来给他们护法。
消息传出去之后，整个仙魔两界都轰动了，大家都在等着他们渡劫成功，这对为仙魔和平做出了巨大贡献的情侣，值得最好的结局。
沈砚和谢无妄也在认真准备渡劫的事情，他们这一生，经历了太多的风风雨雨，现在终于要迎来最终的圆满了。
江南的院子里，桂花开得正好，香气弥漫了整个院子，两人坐在院子里的摇椅上，晒着太阳，觉得岁月静好，不过如此。
“等我们飞升之后，就在天界建一个和这里一模一样的院子，种满桂花树和桃花，好不好？”沈砚靠在谢无妄怀里，轻声说。
“好，”谢无妄低头亲了亲他的额头，“还要建一个很大的桃园，春天可以看桃花，夏天可以吃桃子，冬天可以在院子里烤火，就像现在这样。”
“嗯，还要把安安和樱樱他们接过来玩，还有爹，我们一家人永远在一起。”
“好，都听你的。”
阳光洒在他们身上，暖融融的，未来的日子充满了希望，他们的幸福，还会延续很久很久。
