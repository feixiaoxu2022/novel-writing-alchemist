# 第6章 祭司身份曝光，王胖子的卧底秘密
林安站在原地，盯着棺材里的人看了半天，伸手摸了摸自己的脸，又看了看棺材里的人，长得确实一模一样，连左眉旁边的那颗小痣都一样。
“这……这是怎么回事？”林安懵了，“我祖宗？不对啊，我家三代都是普通农民，没出过什么祭司啊。”
苏清走到棺材旁边，伸手摸了摸棺材上的云纹，和他们胳膊上的印记一模一样：“《颛顼本纪》应该就在棺材旁边，你去看看，上面应该有记载。”
林安点头，小心翼翼地走过去，棺材旁边果然放着一个老旧的木盒子，上面挂着一把铜锁，没有钥匙。
“锁怎么办？”林安看向苏清，“总不能砸开吧？万一触发规则怎么办？”
王胖子凑过来，看了看锁：“这是古代的机关锁，我之前学过怎么开，给我一分钟。”他从口袋里掏出一根回形针，捅进锁孔里拧了两下，“咔哒”一声，锁开了。
林安愣了一下：“你还会开这个？”
王胖子摸了摸头，有点不好意思：“以前上学的时候撬过学校储物柜，练出来的。”
苏清没说话，只是深深看了他一眼。
林安打开木盒子，里面果然放着一本线装书，封面上写着《颛顼本纪》四个古字，纸张已经泛黄，看起来年代很久远了。
他小心翼翼地翻开，里面都是文言文，还好他上学的时候语文学得不错，能看懂大概意思。
书上记载，千年前颛顼帝绝地天通，切断了人间和天界的连接，防止天界的神扰乱人间秩序。但这个屏障每一百年就会松动一次，需要颛顼麾下的大祭司献祭自己的神魂来加固屏障，不然天界的怪物就会跑到人间来，造成生灵涂炭。
而每一代大祭司的转世，身上都会有云纹印记，会被自动拉入副本历练，直到成年后自愿献祭。
林安看到这里，浑身发凉。
合着他就是这一代的大祭司转世？这些副本都是为了让他历练，然后献祭的？
“原来我生来就是祭品？”林安笑了一声，有点自嘲，“我还以为我只是个普通社畜呢。”
苏清拍了拍他的肩膀，没说话，她不知道该怎么安慰。
王胖子站在旁边，脸色复杂，想说什么又没说出口。
林安继续往下翻，后面的内容写着，大祭司如果不愿意献祭，也可以用千年来所有死在副本里的玩家的执念代替献祭，但是代价是所有玩家的记忆都会被清除，再也不会记得副本的存在。
林安眼睛一亮：“还有这个办法？那我们不用死了啊！”
就在这时，门外的刮门声突然停了，紧接着传来管理员的声音：“王磊先生，时间到了，请你出来一下，我有话和你说。”
王胖子的脸色瞬间白了。
林安和苏清都看向他，眼神里带着疑惑。
“你……”林安刚要说话，王胖子突然从口袋里掏出一把刀，架在了林安的脖子上，脸色难看：“对不起了林安，我也是没办法。”
苏清脸色一变，立刻摆出攻击的姿势：“王磊，你干什么？”
“我是零号大人派来的卧底，专门盯着林安的，等他拿到《颛顼本纪》就带他去见零号大人，准备献祭。”王胖子的声音发颤，“零号大人答应我，只要我完成任务，就清除我的印记，让我回归正常生活，我妈还在医院等着我拿钱做手术呢，我不能死。”
林安愣了一下，心里有点复杂。他和王胖子同事三年，平时关系很好，经常一起吃饭摸鱼，他从来没想过王胖子会背叛他。
“所以之前我被拉进副本，也是你设计的？”林安问。
“是。”王胖子点头，“我故意把优惠券给你，让你去路口买夜宵，踩中那块地砖。地铁副本也是我触发的，就是为了让你早点解锁称号，快点成长到可以献祭的程度。”
林安叹了口气：“胖子，你傻啊，零号的话你也信？他要是真能清除印记，张叔也不会瘸了一条腿退休了。”
王胖子愣了一下：“你说什么？”
“张叔二十年前就是玩家，他通关了十几次副本，零号答应他只要完成最后一个任务就清除他的印记，结果最后一个任务里，零号故意修改规则，害得他断了一条腿，差点死在里面。”林安说，“零号就是颛顼的残魂，他根本不会放过任何一个玩家，你完成了任务，他只会杀了你灭口。”
王胖子的手抖了起来，显然是动摇了。
就在这时，门突然“砰”的一声被撞开了，蓝衣服小女孩和管理员站在门口，管理员脸色阴沉：“王磊，你敢背叛零号大人？你会后悔的！”
王胖子咬了咬牙，突然把刀扔了，站到林安旁边：“去你妈的零号，老子不干了！林安，我对不起你，等出去了我请你吃一年的卤味赔罪！”
林安笑了：“行，这可是你说的。”
管理员脸色一变，挥了挥手，小女孩朝着三人扑了过来。
苏清立刻迎上去，和小女孩打了起来，她战斗力果然很强，一时之间小女孩居然近不了身。
管理员也冲了过来，王胖子虽然怂，但打架还是有点本事的，拦住了管理员。
林安站在原地，脑子疯狂运转，找规则漏洞。
规则1说开放时间内不得离开图书馆，现在还没到早上8点，肯定不能走。规则8说《颛顼本纪》只有12点到1点能取，现在已经12点过5分了，符合要求。规则3说所有书籍不得带出图书馆，那没说不能撕啊？
还有规则9说不要相信管理员的任何话，除了找书的问题，那反过来，管理员说的话反着来是不是就是对的？
管理员刚才说让王磊带林安出去，那反着来就是不能带林安出去，要留在里面。
还有，规则10说不要回答小女孩的任何问题，那反过来，问她问题是不是就没事？
林安眼睛一亮，从盒子里拿出《颛顼本纪》，对着小女孩大声喊：“我问你，你是不是死在这个图书馆里的？”
小女孩愣了一下，动作瞬间停了下来，抱着洋娃娃站在原地，眼泪流了下来：“我……我是来找我妈妈的，我找不到她了……”
“管理员是不是把你关在这里的？”林安又问。
小女孩点头，哭得更厉害了：“他不让我走，让我帮他抓坏人。”
管理员脸色大变：“闭嘴！谁让你说话的！”
林安趁着管理员分神，拿起《颛顼本纪》，对着管理员晃了晃：“你看这是什么？你是不是想要？过来拿啊。”
管理员果然被吸引了，朝着林安走过来，刚走到棺材旁边，林安突然按下棺材旁边的机关——刚才翻书的时候他看到书上写着，棺材旁边有个陷阱机关，只要按下去就会把靠近的人吸进棺材里封印住。
“咔哒”一声，机关启动，棺材盖打开了，一股巨大的吸力传来，管理员尖叫着被吸了进去，棺材盖“砰”的一声关上了。
小女孩看到管理员被封印了，露出了笑容，对着林安鞠了一躬，身体慢慢消失了。
【恭喜玩家林安、苏清、王磊完成隐藏任务：解救被困小女孩，封印邪恶管理员，通关D级副本「老旧图书馆」，获得奖励：副本难度永久降低一级，云纹印记抗性+30%。】
半透明的面板浮现在三人眼前，绿色的字格外显眼。
林安松了口气，腿一软差点坐在地上。
王胖子也松了口气，拍了拍林安的肩膀：“兄弟，刚才对不住啊，我也是被逼的。”
“没事，等出去记得请我吃一年卤味就行。”林安笑了笑，没放在心上。
苏清走过来，看了看林安手里的《颛顼本纪》：“接下来你打算怎么办？真的要收集执念代替献祭吗？”
“当然。”林安点头，“我还没活够呢，凭什么要我献祭？我命由我不由天，更不由什么颛顼残魂。”
他刚说完，眼前白光一闪，三人回到了张叔的便利店门口。
张叔站在门口，看到他们出来，松了口气：“还好你们都没事，我就知道你小子可以。”
王胖子挠了挠头，有点不好意思：“张叔，对不起，之前是我鬼迷心窍帮零号做事。”
“没事，年轻人，知错能改就好。”张叔摆了摆手，“接下来你们打算怎么办？”
“收集所有玩家的执念，打破屏障，结束这一切。”林安说，眼神前所未有的坚定。
他之前只想苟活，现在他有了要保护的人，有了要做的事。
苟了二十多年，也该雄起一次了。
