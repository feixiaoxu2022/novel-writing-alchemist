# 第5章 图书馆规则陷阱，假名的优势
王胖子欲哭无泪，想去找管理员改名字，被林安一把拉住了：“你疯了？现在去改不是告诉管理员我们写的是假名吗？反正登记又不会少块肉，怕什么。”
“可是万一登记错了会被惩罚啊！”王胖子脸都白了，他上次进副本的时候，就是因为填错了资料，差点死在里面。
“怕什么，规则9说不要相信管理员说的任何话，那他让我们登记，肯定是陷阱，填真名才会倒霉。”林安拍了拍他的肩膀，“放心，死不了，大不了真有危险我把你推出去挡刀。”
王胖子：“……”
我真是谢谢你啊！
苏清没理两人的斗嘴，她走到前台旁边，看了看墙上的时钟，现在刚好是晚上8点，图书馆正式开放。
“我们先去一楼的阅览室待着，观察一下情况，等9点管理员值班的时候，问他能不能上三楼。”苏清说，“规则8说12点到1点才能取书，现在还有四个小时，不用急。”
林安和王胖子都没有意见，苟着什么的，最符合他们的人设了。
三人走到一楼的阅览室，里面摆着十几张旧桌子，椅子都掉漆了，书架上摆满了旧书，灰尘很厚，看起来很久没人来了。
阅览室里还有其他三个玩家，两男一女，看起来都是刚进来的，脸色发白，坐在角落不敢动。
林安找了个最角落的位置坐下，刚好能看到门口和楼梯口的位置，方便有情况随时跑路。王胖子坐在他旁边，紧张得浑身冒汗，不停地往门口看。
苏清从书架上拿了一本旧杂志，翻了起来，看起来镇定得很。
大概过了一个小时，晚上9点，楼梯口传来脚步声，那个穿蓝衣服的小女孩走了下来，大概七八岁的样子，扎着羊角辫，脸色苍白，手里抱着一个洋娃娃，一边走一边哭。
阅览室里的三个玩家立刻站了起来，想起规则6说看到穿蓝衣服的小女孩要带到管理员那里，其中一个穿运动服的男生立刻走上去，想拉小女孩的手：“小朋友，你是不是走丢了？我带你去找管理员好不好？”
小女孩抬起头，露出一张没有眼睛的脸，黑洞洞的眼窝对着他，咧嘴笑了：“哥哥，你能陪我玩捉迷藏吗？”
那个男生愣了一下，下意识地回答：“好啊。”
他刚说完，身体瞬间僵住了，皮肤以肉眼可见的速度变得灰白，变成了一座石像，立在原地。
剩下的两个玩家吓得尖叫起来，转身就跑。
小女孩咯咯地笑了起来，朝着他们追了过去，走廊里传来两个人的惨叫，很快就没了声音。
阅览室里瞬间安静下来，只剩下林安、苏清和王胖子三个人。
王胖子吓得浑身发抖，紧紧抓住林安的胳膊，指甲都快掐进他的肉里了：“我操我操我操！太他妈吓人了！”
林安也吓得够呛，但还是强装镇定，脑子里疯狂回想规则。
规则10说不要回答穿蓝衣服小女孩的任何问题，刚才那个男生回答了她的问题，所以被惩罚了。规则6说要把她带到管理员那里，但是没说不能骗她啊？
小女孩解决了那三个玩家，蹦蹦跳跳地朝着阅览室走过来，看到林安他们，停了下来，歪了歪头：“哥哥姐姐，你们能陪我玩捉迷藏吗？”
王胖子赶紧捂住嘴，使劲摇头，生怕发出一点声音。
林安也不敢说话，只是指了指前台的方向，又指了指小女孩，做了个“走”的手势。
小女孩愣了一下，好像听懂了，蹦蹦跳跳地朝着前台走去，找管理员去了。
林安松了口气，后背全是汗。
刚才太险了，还好他反应快，规则说不能回答问题，但没说不能用手势啊。
苏清看向他的目光里又多了点赞许：“反应挺快。”
“那是，苟命要紧。”林安摸了摸鼻子，刚要说话，就看到管理员朝着他们走过来了。
管理员走到他们桌子旁边，敲了敲桌子，对着王胖子笑了笑：“王磊先生对吗？刚才登记的年龄是26岁，没错吧？”
王胖子的脸瞬间白了，吓得说不出话来。
林安心里咯噔一下，果然，登记真名会被盯上。
他赶紧抢在王胖子前面开口：“对，他是王磊，我们想借一本《颛顼本纪》，在三楼对吗？能不能给我们开一下三楼的门？”
按照规则9，找书的问题是可以相信管理员的，他现在问找书的问题，管理员不会骗他。
管理员点了点头：“《颛顼本纪》确实在三楼藏书库，你们要借的话，我可以给你们开门，但是只能在12点到1点之间进去，超过时间就不能留在里面了。”
说完，他递给林安一把铜钥匙，上面刻着云纹：“这是三楼的钥匙，12点准时开门，1点之前必须出来，不然门会锁上，你们就永远留在里面了。”
林安接过钥匙，说了声谢谢。
管理员没再多说，转身走了。
王胖子松了口气，瘫在椅子上：“吓死我了，我还以为他要杀了我呢。”
“你还好意思说，谁让你写真名的。”林安翻了个白眼，把钥匙递给苏清，“清姐，钥匙你拿着，我们11点50再上去，省得早了遇到危险。”
苏清接过钥匙，点了点头：“嗯，现在还有两个多小时，我们就在这里待着，别乱走。”
林安点头，正想说话，突然听到二楼传来奇怪的脚步声，还有人说话的声音，但是现在二楼应该没有人啊？
他抬头往楼梯口看，一个穿白衣服的女人站在楼梯口，直勾勾地看着他们，看到林安看她，转身就消失了。
林安的后背一凉，拉了拉苏清的袖子：“清姐，你刚才看到楼梯口的女人了吗？”
苏清抬头看了一眼，楼梯口空空的，什么都没有：“没有，你看错了吧？”
“不可能啊，我刚才明明看到了。”林安皱了皱眉，难道是幻觉？
王胖子也吓得往周围看：“林安你别吓我啊，我胆子小。”
林安没说话，心里隐隐觉得不对劲。
规则4说二楼阅览室的灯12点会熄灭，熄灯后不能留在二楼，那现在还没到12点，二楼为什么会有人？
还有刚才那个白衣服女人，会不会是副本里的NPC？
他拿出张叔给他的铜铃，铜铃安安静静的，没有响。张叔说过，这个铜铃遇到危险会响，现在没响，说明暂时没有危险。
林安把铜铃收起来，决定还是先苟着，等12点上去拿了书就赶紧下来，多一事不如少一事。
时间一分一秒过去，很快就到了11点50分。
苏清站了起来：“时间差不多了，我们上去吧，小心点，别乱碰东西。”
林安和王胖子赶紧跟上，三人走到楼梯口，楼梯是木制的，踩上去吱呀吱呀响，在安静的图书馆里格外刺耳。
二楼的灯还亮着，阅览室里空荡荡的，一个人都没有，刚才的白衣服女人果然不见了。
三人走到三楼门口，林安拿出钥匙，刚要插进去，旁边的王胖子突然“啊”了一声，指着走廊尽头：“你们看！那个小女孩又回来了！”
林安抬头一看，那个穿蓝衣服的小女孩站在走廊尽头，抱着洋娃娃，直勾勾地看着他们，嘴里哼着奇怪的儿歌。
“操，她怎么在这里？”林安心里咯噔一下，现在离12点还有10分钟，管理员不在，他们要怎么把小女孩带过去？
苏清皱了皱眉：“别管她，我们开门进去，规则说12点到1点才能进去，现在时间快到了，她应该不会跟进来。”
林安点头，赶紧把钥匙插进锁孔，拧了一下，门开了。
就在这时，小女孩突然朝着他们跑了过来，一边跑一边喊：“哥哥姐姐，陪我玩啊！”
王胖子吓得转身就跑，刚好撞到了旁边的消防栓，上面的玻璃碎了，警报响了起来。
二楼阅览室的灯闪了两下，熄灭了。
现在才11点55分，离12点还有五分钟。
林安的脸色瞬间变了。
规则4说二楼的灯12点才会熄灭，现在提前灭了，说明规则被打破了。
苏清也变了脸色：“不好，王胖子碰坏了消防栓，触发了隐藏规则，我们赶紧进三楼！”
三人赶紧冲进三楼藏书库，林安刚关上门，就听到门外传来小女孩的敲门声，还有指甲刮门的声音，听得人牙酸。
林安靠在门上，松了口气，还好进来了。
他抬起头，看向藏书库里面，瞬间愣住了。
藏书库的最里面，立着一个透明的棺材，里面躺着一个穿古装的男人，面容和林安长得一模一样。
棺材上面的牌子写着：颛顼祭司，林安。
苏清也愣住了，转头看向林安，眼神复杂：“你……和他长得一样。”
林安站在原地，脑子里一片空白。
这是什么情况？
