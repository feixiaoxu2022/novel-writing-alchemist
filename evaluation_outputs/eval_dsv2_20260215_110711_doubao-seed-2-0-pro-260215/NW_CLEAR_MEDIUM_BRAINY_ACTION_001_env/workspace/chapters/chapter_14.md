# 第十四章 小区副本
距离S级前置副本通关过去了三天，主角团一边联络各地的幸存玩家汇合，一边等零号开启下一个副本——毕竟还差五千多份执念才够一万份，多通关几个小副本凑得更快。
这天下午，大家正在张叔的便利店整理各地玩家寄过来的执念徽章，突然所有人的云纹同时发烫，机械音响起：「C级副本「幸福小区」开启，玩家传送中。」
白光散去，林安站在一个老旧小区的门口，墙皮掉得斑驳，门口的梧桐树下坐着一堆乘凉的老头老太太，广场上的大喇叭放着《最炫民族风》，一群穿红舞服的大妈正在跳广场舞，热闹得和现实里的老小区一模一样。
「C级副本？零号这是给我们送执念来了？」王胖子摩拳擦掌，这段时间连续通关高难度副本，他现在对C级副本一点都不慌，「这次我来先找漏洞！」
林安走到门口的公告栏旁边，上面贴着红纸写的居民公约，字歪歪扭扭的：
【幸福小区居民公约】
1. 小区每晚8点准时锁大门，禁止任何人员进出，违者追究责任
2. 遇到穿红色舞服的广场舞爱好者邀请跳舞，不得拒绝，需跳满十分钟方可离开
3. 小区公共垃圾桶不得随意翻动，否则会引来流浪犬攻击
4. 请在48小时内找到3张业主门禁卡，即可通关
5. 违反以上任意规则，后果自负
王胖子看完，挠了挠头：「我找到漏洞了！8点锁门不许进出，没说不能翻围栏对吧？还有不许翻垃圾桶，没说戴手套翻就不算随意翻动？不过这个跳十分钟舞我是真的不行，我四肢不协调啊！」
「算你聪明，进步挺快。」林安拍了拍他的肩膀，「第一枚卡肯定在跳广场舞的大妈手里，规则特意提了她们，肯定有线索。你去跳舞，跳满十分钟拿卡，我们在旁边给你加油。」
「啊？我去？」王胖子脸都垮了，但是没办法，谁让他刚才吹牛皮说自己找漏洞，只能不情不愿地走过去。
果然，他刚走到广场旁边，一个穿红舞服的大妈就走了过来，笑着说：「小伙子，来跟我们一起跳啊！」
王胖子硬着头皮加入了队伍，他胖，动作又不协调，跳得歪歪扭扭的，旁边的大妈们都笑，还夸他跳得认真。林安和苏清站在旁边看着，苏清看着跳广场舞的大妈们，眼神柔和了一点——如果苏晓没死，现在应该也工作了，有空了说不定会陪着妈妈来跳广场舞。她下意识摸了摸口袋里的草莓糖，没说话。
十分钟到了，音乐停了，大妈递给王胖子一张门禁卡，笑着说：「小伙子跳得真好，以后常来玩啊！」
王胖子满头大汗地接过卡，跑回林安旁边，喘着气说：「累死我了，下次再也不吹牛皮了。」
大家都笑了起来，气氛很轻松。
「第二张卡在垃圾桶里。」林安拿出随身携带的橡胶手套分给大家，「戴好手套翻，不算随意翻动，符合规则。」
几人走到小区的分类垃圾桶旁边，王胖子捏着鼻子翻开厨余垃圾桶，里面乱七八糟的什么都有，翻了半天，终于在一个纸盒子下面找到了第二张门禁卡，上面沾了点菜汤，王胖子嫌弃地擦了擦，揣进兜里。
「第三张卡应该在物业办公室。」陈峰以前来过这个副本，轻车熟路地带着大家走到小区最里面的物业办公室，门是锁着的，窗户没关，林安翻窗户进去，在办公桌的抽屉里找到了第三张门禁卡，上面还挂着一串钥匙。
三张卡都齐了，现在才下午6点，离8点锁门还有两个小时，几人懒得等，走到小区围栏旁边，林安率先翻了出去，其他人也跟着翻了出去，脚刚落地，机械音就响了：
「恭喜玩家通关C级副本「幸福小区」，奖励：3张业主门禁卡，获得2103份玩家执念。」
白光闪过，所有人都回到了便利店门口，王胖子第一件事就是去卫生间洗手，一边洗一边吐槽：「下次再也不想翻垃圾桶了，太臭了！」
苏清点了点执念数量，现在累计已经有4931+2103=7034份了，还差不到三千份就够一万了。
「还差不到三千份，再通关一个B级副本就够了。」陈峰笑了笑，「没想到零号这么贴心，还给我们送执念。」
话音刚落，所有人的胳膊又开始发烫，机械音再次响起：「B级副本「废弃地铁站」开启，玩家传送中。」
林安笑了，说曹操曹操到，刚好还差三千份，这个B级副本的执念量刚好够。
白光闪过，他们站在了一个废弃的地铁站门口，墙上的广告牌都掉了，轨道里传来呼呼的风声，地上散落着很多废弃的地铁票，看起来荒废了很多年。
林安抬头看向入口处的规则公告，心里已经开始找漏洞了，反正不管什么规则，都肯定有可以钻的空子。
王胖子站在他旁边，撇了撇嘴：「等通关这个副本，凑够一万份执念，我们就去揍零号那个王八蛋，让他知道知道我们社畜的厉害。」
林安拍了拍他的肩膀，笑着说：「放心，揍他的时候我让你第一个上。」
王胖子立刻怂了，挠了挠头嘿嘿笑：「还是你先来，你是大祭司，你说了算。」
苏清站在旁边，看着他们打闹，嘴角难得露出了笑容。
这段时间的并肩作战，她早就把这些人当成了家人。等终结了副本，她要去妹妹的墓前，告诉她，姐姐给她报仇了。
