# 第十八章 秋意浓
入秋之后，天慢慢凉了下来，路边的梧桐树叶子开始变黄，风一吹就落满地，踩上去沙沙响。
林安今天下班早，拎着刚从王胖子卤味店拿的辣卤鸭头和草莓糖，去失踪人口救助协会接苏清下班。协会在老城区的一个二层小楼里，门口种了两棵桂花树，花开得正好，香得不行。
他推开门进去，苏清正坐在办公桌前整理资料，穿着米白色的风衣，头发扎成低马尾，侧脸被夕阳照得很柔和。她对面坐着个满头白发的老太太，拉着她的手不停道谢：“小苏啊，真是太谢谢你了，要不是你，我到死都找不到我儿子的下落，我下辈子给你当牛做马报答你。”
“阿姨您太客气了，这都是我应该做的。”苏清给老太太倒了杯热水，“后面的手续我会帮您跑，您在家等消息就行，天气凉，您慢点走。”
把老太太送出门，苏清转过身，看到林安站在门口，嘴角翘了起来：“你怎么来了？今天下班这么早？”
“我们领导儿子结婚，提前放我们下班了。”林安举了举手里的袋子，“王胖子刚卤出来的鸭头，还有你爱吃的草莓糖，我买了点，等下我们去公墓看看苏晓吧，今天是她的生日。”
苏清愣了一下，眼睛有点红，点了点头：“好。”
两人开车去了城郊的公墓，苏晓的墓在半山腰，采光很好，能看到下面的湖。林安把草莓糖放在墓碑前，照片上的小女孩笑得很灿烂，扎着高马尾，露出两个虎牙。苏清蹲下来，用纸巾擦了擦照片上的灰尘，轻声说：“晓晓，我来看你了，凶手已经死了，所有的副本都消失了，以后再也不会有人像你一样无缘无故失踪了，你安息吧。”
风一吹，旁边的松树沙沙响，像是在回应她。
林安站在她旁边，没有说话，只是轻轻拍了拍她的肩膀。苏清靠在他的胳膊上，沉默了一会儿，很快就擦干了眼泪，站起来说：“走吧，我们去逛超市，晚上我做饭给你吃。”
“你还会做饭呢？”林安有点惊讶，认识这么久，他还没见过苏清做饭。
“小看我？”苏清挑了挑眉，“我做饭可好吃了，我妹妹小时候最喜欢吃我做的番茄炒蛋。”
两人开车去了附近的超市，周末的超市人很多，推着手推车逛的情侣和一家人随处可见。苏清推着手推车，林安走在她旁边，路过蔬菜区的时候，苏清拿起一把香菜，问林安：“你吃不吃香菜？”
“不吃，不吃，我最讨厌香菜了。”林安赶紧摇头，他不吃香菜的习惯还是之前在副本里养成的，有次在医院副本里饿急了吃了个带香菜的包子，吐了半天，从此留下了阴影。
苏清笑了笑，把香菜放了回去，拿起旁边的番茄和鸡蛋：“那我们做番茄炒蛋、可乐鸡翅、卤鸭头，再煮个青菜汤，行不行？”
“行，都听你的。”林安点头，顺手拿了瓶冰可乐，刚要放进推车里，苏清就拿了出来，放了瓶常温的：“天气凉了，少喝冰的，对胃不好。”
林安挠了挠头，有点不好意思，还是乖乖放回去了。他自己都没注意到，他天不怕地不怕，连零号都敢怼，唯独在苏清面前，乖得像个小学生。
路过零食区的时候，林安看到货架上的红色包装红烧肉零食，想起之前医院副本里的红色红烧肉，忍不住笑了，苏清也看到了，两人相视一笑，都想起了当时在副本里紧绷着神经找漏洞的日子，现在想想，居然有点怀念。
路过童装区的时候，看到挂着的蓝白相间的初中校服，苏清的脚步顿了一下，林安悄悄握住了她的手，她的手有点凉，但是很软，苏清转过头看了他一眼，没有挣开，反而回握了他的手。
两人就这么手牵着手逛完了超市，付完款出门的时候，天已经黑了，风有点凉，林安把自己的外套脱下来，披在苏清身上，苏清抬头看了他一眼，耳朵尖有点红，说了声“谢谢”。
回到林安的出租屋，苏清围上围裙去厨房做饭，林安想进去帮忙，被她赶了出来：“你别进来添乱，在外面等着吃就行。”
林安靠在厨房门口，看着苏清在里面忙碌的身影，油烟飘出来，带着番茄炒蛋的香味，暖黄的灯光照在她身上，特别温馨。林安从来没想过，自己一个天天加班的社畜，居然也能有这样的日子，有喜欢的人在厨房给自己做饭，桌子上放着爱吃的卤味，不用担心突然被拉进副本，不用时时刻刻抠规则保命，太幸福了。
大概四十分钟，菜就做好了，番茄炒蛋、可乐鸡翅、清炒青菜，还有王胖子的卤鸭头，摆了满满一桌子，看起来就很有食欲。林安尝了一口可乐鸡翅，甜咸适中，特别好吃，忍不住竖大拇指：“太好吃了！你这手艺可以去开饭店了，比王胖子的卤味还好吃。”
苏清笑了笑，给他夹了一块鸡翅：“好吃就多吃点。”
两人边吃边聊天，从工作上的趣事聊到之前副本里的事，聊到王胖子在图书馆副本里被管理员追得跑丢了鞋，两人都笑出了声。吃完饭，林安主动去洗碗，苏清坐在沙发上，抱着林安养的橘猫撸猫，猫是从张叔家抱来的，叫“漏洞”，胖乎乎的，特别粘人。
洗完碗，林安拿了个毯子盖在苏清腿上，打开电视放电影，是个很老的文艺片，节奏很慢，看着看着，苏清就靠在林安的肩膀上睡着了，呼吸很轻，头发蹭得林安的脖子有点痒。
林安不敢动，怕吵醒她，就这么坐着，看了她半宿。月光从窗户照进来，洒在她的脸上，长长的睫毛投下淡淡的影子，特别好看。林安心里软得一塌糊涂，他之前最大的梦想就是躺平，现在觉得，要是能一直这样，和苏清一起过着安稳的小日子，比什么都强。
他没有趁机动手动脚，也没有趁着苏清睡着告白，就这么安安静静地陪着她，直到天快亮的时候，苏清才醒过来，揉了揉眼睛，有点不好意思：“我居然睡着了，不好意思啊。”
“没事，电影挺好看的。”林安笑了笑，站起来给她倒了杯热水，“天还早，要不要再睡会儿？我去给你做早餐。”
“不用了，我得回去换衣服，今天还要去郊区走访。”苏清站起来，拿起包准备走，走到门口的时候，她停下脚步，转过头，看着林安，“明天周末，要不要一起去爬南山？听说山上的枫叶红了，很好看。”
林安愣了一下，立刻点头：“好啊！我明天早上去接你，带上王胖子的卤味和可乐，哦不对，带常温的。”
苏清笑了起来，眼睛弯成了月牙：“好，我等你。”
送苏清下楼，风有点凉，林安把她的围巾系紧了点，看着她开车走了，才转身上楼。
回到出租屋，“漏洞”趴在沙发上睡觉，桌子上还留着苏清没喝完的半杯水，林安坐在沙发上，摸了摸自己的嘴角，发现自己一直在笑。
他和苏清从来没说过“我喜欢你”，也没有正式告白过，但是他们都懂对方的心意。那些在副本里互相挡过的刀，互相救过的命，一起抠过的规则漏洞，一起吃过的苦，都是最动人的告白。
秋意越来越浓了，但是林安觉得，这个秋天，是他长这么大以来，过得最暖的一个秋天。
