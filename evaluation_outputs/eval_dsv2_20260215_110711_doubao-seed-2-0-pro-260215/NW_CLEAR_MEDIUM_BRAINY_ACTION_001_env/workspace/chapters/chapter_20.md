# 第20章 万家灯火
时间一晃就是两年。
入夏的傍晚，蝉鸣声扯得悠长，黏腻的热风裹着街边梧桐树的叶子沙沙响，林安拎着刚从单位领的端午福利，慢悠悠地从国企大门走出来，手里还攥着行政部刚发的五百块降温补贴购物卡，指尖被卡面印的卡通老虎硌得有点痒。
他现在的日子过得简直是学生时代就梦想中的完美状态：朝九晚五，从不加班，除非遇上极特殊的情况，否则到点办公室的人走得比谁都快；每年有十五天年假，逢年过节的福利塞满后备箱，去年过年发的米面油他吃到现在还没吃完；领导是个快退休的老好人，一辈子勤勤恳恳，从来不会给员工穿小鞋，唯一的缺点就是偶尔要开个半小时没用的务虚会，不过忍忍就过去了，反正开会的时候他可以躲在后排摸鱼刷短视频，或者在笔记本上画小王八。
他沿着街边慢悠悠地走，路过当年踩中云纹的那个十字路口，下意识地低头看了一眼——当年刻着深色云纹、踩上去就会被吸进副本的地砖早就换成了普通的浅灰色大理石地砖，平整光滑，被太阳晒得暖融融的，路过的学生踩着滑板飞快地掠过去，普通人经过这里，根本不会知道两年前这里曾经是个能要人命的副本入口，也不会知道有一群普通人曾经在这里赌上性命，换来了现在的安稳日子。
路口旁边就是王胖子开的第37家「漏洞卤味」分店，玻璃门擦得透亮，门口排队的人拐了个小弯，大都是附近下班的上班族和接孩子放学的家长，玻璃门上还贴着可爱的卡通鸭子贴纸，旁边写着“儿童免费送迷你卤藕”。
王胖子穿着熨得笔挺的浅蓝色衬衫，肚子比两年前又圆了一圈，正站在柜台后面给客人装卤味，旁边站着他的老婆小楠，怀里抱着刚满一岁的儿子王小胖，小家伙胖嘟嘟的，脸上沾着点卤汁，正啃着一个迷你卤藕节，口水淌得满下巴都是。
“安哥！”王胖子眼尖，一眼就看见玻璃门外的林安，连忙隔着玻璃招手，“快进来！今天刚卤的麻辣鸭头，给你留了两斤，还有你爱吃的卤藕和卤毛豆，都给你装好了！”
林安推开门走进去，冷气瞬间裹住了他，舒服得他叹了口气。他伸手捏了捏王小胖软乎乎的脸，小家伙咯咯笑，把手里啃了一半的卤藕节递给他，含糊不清地喊：“叔叔吃。”
“乖，叔叔不吃，你吃。”林安笑着接过王胖子递过来的打包袋，沉甸甸的，估摸着有三四斤重，“多少钱啊？我扫给你。”
“要什么钱！”王胖子眼睛一瞪，嗓门大得整个店都能听见，“你是我们店的终身钻石VIP，吃卤味永远免费！再说了，当年要不是你带我找漏洞躲NPC，我早就变成医院副本里的针下亡魂了，这点卤味算个屁！”
排队的客人都好奇地看过来，林安脸一红，连忙踹了他一脚：“你小点声，别胡说八道。”
小楠笑着从柜台后面拿了两盒刚烤好的草莓曲奇塞给他，发梢上还沾着点面粉：“苏清姐爱吃这个，我今天下午刚烤的，你带回去给她。对了，我妈昨天从老家带了土鸡蛋，给你们装了一筐，在后厨，你待会一起拿回去。”
林安也不客气，接过来连声道谢，转身走的时候听见王胖子又跟新来的客人吹牛：“看见没，刚才那是我安哥，当年可是凭一己之力找规则漏洞干翻大BOSS的人，我这卤味店的名字都是他给取的！我们这卤味的配方，都是当年在副本里躲难的时候研究出来的，独家秘方，别家吃不到！”
林安忍不住笑，摇了摇头，拎着东西往路口走，刚到路口就看见苏清的白色SUV停在路边，她正坐在驾驶座上刷救助站的消息，看见他过来，按了按喇叭。
“今天怎么来接我了？”林安拉开车门坐进去，把卤味、曲奇和鸡蛋都放在后座，后座还堆着两袋刚买的猫砂和猫条，“你今天不是要去郊县的救助站送物资吗？我还以为你要晚上才能回来。”
“忙完了，事情办得顺利，就提前回来了。”苏清发动车子，递给他一瓶冰可乐，瓶身上还挂着水珠，“今天允许你喝冰的，刚从超市冰箱拿出来的。”
林安眼睛一亮，连忙拧开瓶盖喝了一大口，冰得他打了个哆嗦，二氧化碳在嘴里炸开，爽得他差点眯起眼睛。要知道苏清平时管着他，不让他喝太多冰的，说他胃不好，只有表现好的时候才会奖励他一瓶冰可乐。
苏清现在是本地失踪人口救助协会的负责人，这两年跑遍了周边的十几个县城，帮着三百多个失踪人口找到了家，上个月还拿了市里的“年度公益人物”奖，金色的奖状现在还挂在他们家客厅的墙上，旁边贴着林安去年在单位年会抽到的“最佳摸鱼奖”的搞笑奖状，一正一谐，反差感拉满。
上个月赵磊结婚，林安和苏清当伴郎伴娘，王胖子也当伴郎，喝多了抱着酒店门口的柱子喊“我再也不躲NPC了！我有老婆儿子了！”，大家笑到直不起腰，还是刘强把他扛上车送回家的，第二天王胖子醒过来被小楠罚了三天不许吃卤鸭头，可怜兮兮地蹲在店门口啃白米饭，被路过的林安拍了照做成了表情包，现在大家聊天都爱用。
过年的时候大家还聚在张叔的社区超市门口吃火锅，下着鹅毛大雪，炭火烧得旺旺的，锅里的卤味咕嘟咕嘟冒泡，王小胖穿着厚厚的棉袄，在旁边堆雪人，堆了个歪歪扭扭的胖鸭子，说是王胖子，被王胖子追着跑了半条街。漏洞和卤蛋两只橘猫蹲在旁边的台阶上，披着小毯子，一边烤火一边吃猫条，张叔还给大家写了春联，每个人家的春联都是张叔亲手写的，林安家的春联是“朝九晚五摸鱼爽，卤味可乐幸福多”，横批“平安喜乐”，现在还贴在他家的大门上。
赵小宇今年高考考了全市第二，顺利考上了清华的计算机系，升学宴的时候他给林安敬酒，举着杯子说：“林哥，当年要不是你教我找规则漏洞，我也不会喜欢上计算机，以后我就要去给系统找漏洞了，跟你当年一样！”林安喝了一口可乐，拍着他的肩膀说“好好干，以后别让资本家薅你羊毛”，被陈峰笑了好久，说他教坏小孩子。
车子慢悠悠地开在老街上，路过张叔的社区超市，看见张叔正坐在门口的竹摇椅上摇扇子，怀里抱着他家的胖橘卤蛋，旁边蹲着林安家的橘猫“漏洞”，两只猫正凑在一起吃金枪鱼猫条，吃得满脸都是。张叔看见他们的车，抬了抬手打招呼，手里的蒲扇晃了晃。
“对了，张叔说卤蛋上个月又生了一窝小猫，都是橘色的，问我们要不要抱一只回去养，给漏洞做个伴。”苏清打了个转向灯，车子拐进小区的路。
“行啊，刚好漏洞天天在家拆家，有个弟弟妹妹陪它玩说不定能消停点。”林安啃着鸭头，含糊地说，“不过先说好，你负责铲屎，我负责喂粮，我可不想天天铲猫屎。”
苏清瞥了他一眼，没说话，嘴角却微微翘了起来，露出个很浅的笑。
上周苏清带林安去给苏晓扫墓，苏清把一束白菊放在墓碑前，又放了两颗草莓糖，蹲在那里坐了好久，没说话，林安就站在她旁边，陪着她，给她挡太阳，也没说什么安慰的话，只是在她起身的时候，递给她一瓶温的矿泉水。苏清接过水，轻轻碰了碰他的手，说“走吧，回家”，声音很轻，但是很稳，没有哭，她已经放下了，现在的日子很好，妹妹肯定也会很高兴。
他们现在住的是一套一楼的两居室老房子，带个小小的院子，林安闲着没事在院子里种了几盆草莓和小番茄，还有几株薄荷，长势正好，红通通的草莓挂在绿叶中间，风一吹就晃，薄荷的清香味飘得满院子都是。
开门进去，刚从张叔家跑回来的漏洞就蹭了过来，围着苏清的腿转，尾巴翘得高高的，林安把卤味和曲奇放在餐桌上，去厨房拿碗筷，苏清已经盛好了刚煮好的番茄炒蛋，还有他爱吃的腊肠焖饭，电饭煲还插着电，焖饭冒着淡淡的热气。
电视里放着无聊的社会新闻，女主播的声音柔和，说最近本市的治安越来越好，失踪人口率降到了十年最低，还特别提到了苏清的救助协会，说他们帮助了很多家庭团圆。林安咬了一口番茄炒蛋，酸甜可口，是苏清的手艺，咸淡刚好。
“今天赵磊给我发消息，说周瑶怀孕了，明年春天就要生了，让我们当干爹干妈。”苏清给他夹了一筷子腊肠，“还有陈峰，他的网约车公司现在已经有两百多辆车了，上个月还捐了十万块给救助站，用来给走失的老人买定位手环。”
“嗯，我知道，陈哥早上已经给我发过消息了，还给我发了他儿子的奖状，明明这次奥数比赛又拿了一等奖，说要我请他吃卤鸭头。”林安点头，“陈桂兰阿姨的生鲜店现在开了十七家了，昨天还给我送了两箱阳光玫瑰，甜得很，放在冰箱里，你待会记得吃。李萌下个月要升市场总监了，说等她升职了请大家去海南玩，全部她请客，她那个程序员男朋友也去，人挺好的，脾气好，还会做饭。刘强的货运公司现在都做跨省业务了，上周还给我送了两箱新疆的哈密瓜，甜得很。”
所有人的日子都过得越来越好，大家每隔两个月就会在王胖子的总店聚一次，吃卤味，喝冰可乐，聊最近的生活，没有人会主动提起当年的副本，那些心惊胆战、不知道下一秒能不能活下来的日子，就像做了一场很长的噩梦一样，醒过来，就是满目的安稳幸福。只有偶尔喝多了，王胖子才会拍着桌子吹牛，说当年他怎么在副本里当卧底，怎么反水帮林安他们，每次都被陈峰拆台，说他当年吓得躲在桌子底下哭，大家笑成一团。
吃完饭，林安瘫在沙发上刷手机，苏清坐在旁边的地毯上喂猫，夕阳从客厅的窗户外面照进来，落在她的头发上，镀上了一层暖融融的金边。
林安刷到王胖子刚发的朋友圈，是他抱着王小胖举着卤鸭头的照片，配文：“老婆孩子热炕头，还有吃不完的卤味，人生圆满！”下面一堆人点赞，陈峰评论：“别忘了你当年躲在棺材里啃苹果的时候。”王胖子回复了个愤怒的表情：“滚啊！能不能别揭我老底！”
林安忍不住笑出了声，苏清转头看他，眼睛亮晶晶的：“笑什么呢？”
“没什么，笑胖子又被陈哥怼了。”林安坐起来，从口袋里掏出两颗草莓糖，是今天单位发的，包装是粉色的，他递了一颗给她，“给你，草莓味的，你爱吃的。”
苏清接过来，拆开糖纸塞进嘴里，甜丝丝的草莓味在嘴里散开，和她当年在副本里第一次吃的草莓糖味道一模一样。那时候他们刚通关校园副本，林安从口袋里掏出两颗皱巴巴的草莓糖，递给她一颗，说“甜的，吃了就不怕了”，那是她在副本里第一次吃甜的东西，甜得她眼睛都有点酸。
林安靠在沙发上，看着窗外的天一点点暗下来，路边的路灯一盏接一盏地亮起来，远处的居民楼里，家家户户的灯也亮了，暖黄色的光从窗户里透出来，每一盏灯下面，都是一个普通的家庭，过着普通的、安稳的日子。
他想起两年前的那个晚上，他加班到十点，也是从这个路口路过，踩中了那片泛着冷光的云纹，一下子掉进了那个乌漆嘛黑的医院副本里，那时候他以为自己肯定会死在里面，最大的愿望就是能活着出来，吃一顿热乎的卤味，找个朝九晚五的工作，不用担惊受怕，安稳过一辈子。
现在这些居然都实现了。
他没有变成什么拯救世界的大英雄，也没有什么超能力，还是那个怂兮兮的、爱抠规则漏洞、爱吐槽的社畜，武力值还是0，遇到麻烦第一反应还是躲，唯一的变化就是，现在他身边有了苏清，有了一群过命的朋友，有了安稳的小日子，不用再天天盯着规则找漏洞，不用再躲NPC，不用再担心下一秒会不会没命。
什么大祭司转世，什么宿命，什么拯救世界，都不如现在这样，下班回家有热饭吃，有冰可乐喝，猫在旁边打呼，身边有喜欢的人，这样的日子，给个神仙都不换。
苏清见他发呆，轻轻碰了碰他的胳膊，递给他一块刚切好的冰西瓜，沙瓤的，甜得很：“想什么呢？西瓜要化了。”
“没什么。”林安接过西瓜咬了一大口，甜汁顺着嘴角往下流，他伸手擦了擦，笑了起来，眼睛亮得很，“就是觉得，现在的日子真好。”
苏清也笑了，点了点头，风吹过院子里的薄荷，清香味飘进屋里，凉丝丝的。
窗外的蝉鸣声还在响，远处的广场舞音乐隐约飘过来，电视里的新闻还在播，漏洞吃饱了，趴在沙发上打呼，爪子搭在林安的腿上，餐桌上的卤味还冒着淡淡的香气，远处的万家灯火，一盏比一盏亮，暖融融的，像撒了一地的星星。
都是普通人的安稳日子，都是触手可及的幸福。

## 后记
很多年后，还有熟悉的朋友开玩笑问林安，当年是怎么靠一个普通人的身份，干翻了活了几千年的零号的，是不是偷偷藏了什么金手指没告诉大家。
林安每次都耸耸肩，啃着鸭头含糊地说：“哪有什么金手指，就是找规则漏洞呗，零号自己定的规则，他自己也不能违反，我只是钻了个空子而已。”
其实他心里知道，哪里是他一个人的功劳。是所有拼命想要活下去的普通人，凑在一起的执念；是苏清哪怕拼了命也要给妹妹报仇、也要保护队友的坚持；是王胖子贪生怕死但关键时候敢站出来反水的勇气；是张叔潜伏了几十年默默引导玩家的隐忍；是陈峰藏在暗处二十年收集执念的布局；是所有队友互相帮衬、不肯放弃彼此的心意，才最终换来了现在的安稳日子。
这个世界上从来就没有什么天生的英雄，也没有什么无所不能的神明。普通人就算没有超能力，没有金手指，只要肯动脑子，肯互相帮衬，哪怕只是抠点规则漏洞，也能过上自己想要的日子。
毕竟，最厉害的从来都不是什么翻云覆雨的大人物，而是拼尽全力想要好好活下去的普通人啊。
