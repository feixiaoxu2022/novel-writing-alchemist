# 第十六章 终极漏洞
暗红色的天空下，上古祭坛的广场上刮着阴冷的风，那些穿着盔甲的古代士兵像雕塑一样站在两旁，手里的长矛闪着寒光，零号站在祭坛最高处，黑色的衣袍被风吹得猎猎作响，眼神冷漠地看着下方的主角团。
林安抬头看着他，一点都不慌，反而还有闲心打量周围的环境。祭坛是用整块的黑石砌成的，上面刻满了云纹和甲骨文，中间的献祭台冒着淡金色的光，周围的石碑上刻着最终的献祭规则，他之前在《颛顼本纪》里见过这些字，很容易就能读懂。
「先看规则。」林安指了指旁边的石碑，所有人都凑了过去，逐字逐句地读：
【上古祭坛献祭规则】
1. 献祭必须由当代大祭司本人自愿发起，神魂纯粹无杂念，献祭方可生效
2. 献祭的唯一有效祭品为当代大祭司的完整神魂，其余任何物品均无法作为替代
3. 献祭仪式一旦开启，任何人不得打断，否则献祭直接失败，天通屏障即刻崩溃
4. 自副本开启时起72小时内未完成献祭，天通屏障自动崩溃，天界怪物涌入人间
5. 本规则为颛顼大帝亲定，所有神族、人族均需遵守，违者神魂俱灭
零号的声音从祭坛上传下来，带着嘲讽：「看完了？规则写得明明白白，只有你的神魂能献祭，你收集的那些玩家执念一点用都没有，别白费功夫了，要么乖乖献祭，要么等着所有人一起死。」
王胖子气得要骂回去，被林安拦住了。林安看着规则，嘴角慢慢翘了起来，漏洞比他想象的还要明显。
「你笑什么？」零号皱起眉，心里有种不好的预感。
「我笑你定了这么久的规则，自己都没看懂漏洞在哪。」林安举起手里装着执念的木盒子，里面的执念发出淡蓝色的光，「规则第二条说，唯一有效祭品是当代大祭司的完整神魂，对吧？那我问你，什么是神魂？」
零号愣了一下，脱口而出：「神魂就是你的灵魂，是你作为大祭司的本源力量！」
「哦？规则里写了吗？」林安挑了挑眉，指了指石碑，「规则里只说了要大祭司的神魂，没定义神魂是什么，对吧？我是大祭司转世，我的前世就是千年前的那个大祭司，这些玩家的执念里，包含了千年来所有受副本影响的人的怨念，也包含了我前世临死前留下的、想要终结副本的执念，那这些执念算不算我神魂的一部分？」
零号的脸色瞬间沉了下来：「你胡说！这不算！」
「算不算不是你说了算，是规则说了算。」林安笑得更开心了，「规则是颛顼定的，你只是个残魂，没资格修改规则，也没资格解释规则。还有第一条，说要大祭司自愿发起献祭，没说我不能自愿献祭我的「神魂」——也就是这些执念集合体，对吧？」
零号气得浑身发抖，但是他没办法反驳，规则确实是这么写的，他作为颛顼的残魂，必须遵守规则，不能违背。他想直接动手杀了林安，但是规则规定不能杀死遵守规则的玩家，他只能眼睁睁看着林安走到献祭台旁边，伸手摸了摸献祭台的表面，献祭台感应到大祭司的气息，发出了更亮的金光。
「你敢！」零号怒吼，「你要是敢用这些破烂献祭，我就算违反规则也要杀了你！」
「你试试。」林安抬头看着他，一点都不怕，「规则第五条说，违反规则的神魂俱灭，你要是敢动手，先死的是你。」
零号僵在原地，不敢动了。他好不容易熬了一千年，就等着这次献祭巩固自己的力量，他不能死。
林安没理他，转头跟陈峰和张叔说：「刚才我看规则第三条说，献祭仪式一旦开启就不能打断，没说我们不能在开启之前补充祭品对吧？张叔你之前说，规则里的执念还包括所有人类的求生欲，对吧？」
张叔点了点头：「对，颛顼当年定规则的时候，留了后手，就是怕后世的大祭司不愿意献祭，所以只要是人类的求生执念，都可以算进祭品里，越多越好。」
「那好。」林安闭上眼睛，集中精神，他胳膊上的云纹发出金色的光，扩散开去，联系所有幸存的玩家——全球各地的玩家胳膊上的云纹都亮了起来，他们都收到了林安的消息：「我是当代大祭司林安，现在需要所有人的帮助，把你们的求生执念传递给我，我们一起终结副本，回归正常生活。」
全球各地的幸存玩家都响应了，无数的淡蓝色执念从世界各地汇聚过来，像流星雨一样飞到上古祭坛的上空，原本只有一万多份的执念，很快涨到了十万、一百万、一千万……
零号看着满天的执念，脸色越来越白，他知道自己输了。这些执念的力量已经远远超过了林安一个人的神魂力量，只要献祭成功，不仅屏障会被加固，他的残魂也会被执念的力量冲散，彻底消失。
「不！你们不能这么做！」零号慌了，他想冲下来阻止，但是刚动一步，规则的力量就惩罚了他，他的胳膊开始变得透明，像烟一样消散了一部分，他不敢再动了，只能站在原地，眼睁睁看着执念越来越多。
「苏清，帮我护法！」林安喊了一声，苏清立刻站到献祭台旁边，握着刀警惕地盯着零号，王胖子和陈峰他们也站了过来，把献祭台围在中间。
时间一分一秒地过去，离72小时时限还有最后12个小时，执念的数量已经涨到了三千多万份，几乎覆盖了整个天空，淡蓝色的光把暗红色的天空都照亮了。
林安看着差不多了，转头跟大家说：「准备开启献祭仪式，等下我启动仪式，大家保护好献祭台，别让零号搞破坏，虽然他不敢违反规则，但是说不定会搞小动作。」
所有人都点了点头，拿出武器，警惕地看着零号。
林安深吸了一口气，把装着玩家执念的木盒子放在献祭台的中央，然后按照《颛顼本纪》里记载的仪式，念起了献祭的咒语。他是大祭司转世，咒语念出来的瞬间，献祭台发出了刺眼的金光，漫天的执念都被吸引了过来，像潮水一样涌入献祭台里。
零号看着这一幕，知道自己已经没有退路了，他咬牙，就算违反规则，也要打断献祭！他冲了下来，手里凝聚出黑色的能量球，朝着献祭台砸过去。
「小心！」苏清喊了一声，冲上去挡在献祭台前面，拿刀挡住了能量球，巨大的冲击力把她震得后退了好几步，嘴角流出了血。
「苏清！」林安喊了一声，想停下来，但是仪式已经开启了，不能中断。
「我没事！」苏清擦了擦嘴角的血，「你继续！我们挡着！」
王胖子、陈峰、张叔、赵磊他们都冲了上去，和零号打了起来。零号的力量很强，但是他刚才违反规则，已经被削弱了很多，而且他不能杀死遵守规则的玩家，所以打的时候处处受限，一时之间居然被几人缠住了。
时间一分一秒地过去，离72小时时限还有最后10分钟，献祭已经完成了90%，献祭台的光越来越亮，零号的身体越来越透明，他知道自己要输了。
「林安！我不会放过你的！就算我死了，屏障也撑不过一百年！到时候你们还是要献祭！」零号怒吼着，身体开始消散。
林安没理他，继续念咒语，最后一分钟的时候，所有的执念都涌入了献祭台，献祭仪式完成了！
刺眼的金光从献祭台爆发出来，照亮了整个天空，零号的残魂在金光里发出一声惨叫，彻底消散了。天空的暗红色慢慢褪去，变成了正常的蓝色，远处传来了鸟叫声，一切都恢复了正常。
机械音最后一次响起，这次的声音很温和，像是颛顼的声音：「献祭成功，天通屏障已加固，所有副本将永久消失，玩家云纹印记将全部清除，除献祭参与者外，其余人将失去副本相关记忆。」
白光闪过，所有人都回到了张叔的便利店门口，外面阳光明媚，车水马龙，和平时没有任何区别。林安摸了摸自己的胳膊，云纹印记已经消失了，苏清、王胖子他们的印记也都没了。
「结束了？」王胖子捏了捏自己的脸，还有点不敢相信，「我们真的赢了？零号死了？副本都没了？」
「嗯，结束了。」林安笑了笑，看着外面的阳光，心里终于松了口气。
他不用献祭了，所有人都不用死了，终于可以回到正常的生活了。
张叔拄着拐杖，看着天空，眼里含着泪，等了二十年，终于结束了。
苏清站在旁边，摸着口袋里妹妹的照片，眼泪终于流了下来，这么多年的仇恨，终于报了。
陈峰拍了拍林安的肩膀，笑着说：「你小子可以啊，连神的规则都能钻空子，我果然没看错人。」
林安挠了挠头，嘿嘿笑了。他就是个普通社畜，没什么大本事，就是擅长抠规则字眼而已，没想到居然拯救了世界。
王胖子突然想起了什么，拍了拍脑袋：「对了！我还欠你一年份卤味呢！走！我现在就去盘个店，明天就开业，给你管够！」
大家都笑了起来，阳光洒在他们身上，暖洋洋的。
这么久的出生入死，终于换来了想要的生活。
