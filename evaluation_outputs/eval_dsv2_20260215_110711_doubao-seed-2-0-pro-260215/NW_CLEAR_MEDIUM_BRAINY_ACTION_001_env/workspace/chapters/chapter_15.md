# 第十五章 末班车
废弃地铁站里阴冷潮湿，空气中弥漫着一股霉味和铁锈混合的味道，轨道里的风呼呼地吹过来，吹得人后背发凉，地上散落着很多旧地铁票，还有一只落单的红色小鞋子，和居民楼副本里看到的一模一样。
林安举着手电筒晃了晃，光柱扫过墙壁上的规则公告，上面的字已经有些模糊了，但是还能看清：
【废弃地铁站乘车规则】
1. 末班车23:00准时发车，错过末班车的乘客将被永久留在地铁站内
2. 车厢内有空位可随意乘坐，禁止乘坐编号为4、7、13的座位，违者后果自负
3. 地铁广播内容均为错误引导，请按照站台指示牌方向行走
4. 请在48小时内找到3张2014年的旧地铁票根，即可通关
5. 违反任意规则，永久滞留
林安把规则看了一遍，很快找到了漏洞：「第一，错过末班车要永久滞留，没说一天只有一班末班车，也没说不能在站台等下一班；第二，禁止坐4、7、13号座位，没说不能拿这三个座位底下的东西；第三，广播是错误引导，我们反着听就行。三张票根肯定就在那三个禁止乘坐的座位底下，直接上去拿。」
几人沿着站台走到停着的旧地铁旁边，车门是开着的，车厢里的灯一闪一闪的，很多座位上都落满了灰。林安他们找到4号座位，底下果然压着一张旧地铁票根，2014年的，边缘已经磨毛了。王胖子蹲下来，伸手去够，刚碰到票根，地铁的广播突然响了：「各位乘客请注意，末班车即将发车，请没有上车的乘客尽快上车，本次列车终点站为黄泉路。」
「我靠！」王胖子吓得手一抖，差点把票根掉了，「什么终点站黄泉路，太吓人了！」
「怕什么，规则说广播都是错误引导。」林安拍了拍他的肩膀，「他说终点站是黄泉路，肯定就是出口的方向。继续找剩下的两张。」
几人又找到7号和13号座位，顺利拿到了另外两张票根，三张都齐了。现在才晚上22点，离23点还有一个小时，几人坐在站台的椅子上等末班车，王胖子从背包里摸出半包卤鸭头，分给大家吃，说：「先垫垫肚子，等通关了我请大家吃火锅，这次真不记账！」
苏清拿着2014年的票根，指尖轻轻摩挲着票面，2014年是苏晓死的那一年，她当年就是放学坐地铁的时候失踪的。她把票根小心地放进贴身的口袋里，没说话，只是抬头看向轨道尽头的黑暗，眼神冷得像冰。
到了22点55分，广播又响了：「各位乘客请注意，末班车已提前发车，请未上车的乘客等待下一班。」
刘强急了：「我靠！末班车提前走了？我们要被留在这了？」
「别急。」林安笑了笑，「广播是错误引导，他说提前走了，就是还没走，等23点整肯定来。」
果然，23点整，远处传来了地铁的轰鸣声，一束光从轨道尽头照过来，末班车准时开了过来，停在他们面前，车门打开，里面空荡荡的，一个人都没有。
几人上了车，车门关上，地铁缓缓开动，广播又响了：「本次列车即将驶入隧道，请乘客抓好扶手，前方到站——上古祭坛。」
林安挑了挑眉，零号还挺贴心，直接把他们送到最终副本门口？
地铁开了大概十分钟，停了下来，车门打开，外面就是白光，是通关出口。几人走出去，机械音响起：「恭喜玩家通关B级副本「废弃地铁站」，奖励：3张2014年旧地铁票根，获得2967份玩家执念。」
白光闪过，他们回到了张叔的便利店门口，苏清点了点执念数量，7034+2967=10001份，刚好超过一万份！
「凑够了！」王胖子高兴得跳了起来，「我们凑够一万份执念了！终于可以去揍零号那个王八蛋了！」
所有人都很激动，熬了这么久，终于要结束了。张叔拿出早就准备好的火锅食材，说要给大家庆祝一下，吃完火锅就去最终副本。
就在王胖子刚把火锅底料放进锅里的时候，所有人的胳膊突然剧烈发烫，比之前任何一次都要疼，天花板上的灯瞬间全部熄灭，零号的声音在整个便利店里响起，带着抑制不住的怒气：
「你们居然真的凑够了执念？很好，我在S级副本「上古祭坛」等你们，给你们72小时，要么献祭，要么所有人一起死。」
白光瞬间笼罩了整个便利店，连张叔都被拉进了副本里，所有人眼前一黑，再次睁开眼的时候，已经站在了上古祭坛的广场上。
天空是暗红色的，云层翻涌，远处的祭坛高耸入云，刻满了云纹，广场上站满了穿古装的士兵，都是颛顼时期的守卫，手里拿着长矛，面无表情地盯着他们。
零号站在祭坛的最高处，还是穿着黑色玄衣，摘了面具，脸和林安有七分像，他看着林安，冷冷地说：「给你们72小时，要么你自愿献祭，要么我就打碎屏障，让天界的怪物把你们全部吃掉，你们自己选。」
林安抬头看着他，一点都不害怕，反而笑了笑。
他们连一万份执念都凑够了，还怕他这点威胁？规则漏洞都已经找好了，这次谁输谁赢还不一定呢。
