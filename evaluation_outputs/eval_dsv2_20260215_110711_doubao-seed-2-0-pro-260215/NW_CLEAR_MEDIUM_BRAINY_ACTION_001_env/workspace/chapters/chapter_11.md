# 第十一章 校园惊魂
距离医院副本通关才过了半天，所有人的云纹同时发烫，冰冷的机械音带着明显的怒意：「B级副本「育英私立高中」开启，玩家传送中。」
白光散去，林安站在高中校门口，铁门上的油漆掉得斑斑驳驳，门口的保安室里，穿制服的保安面无表情地盯着他们，周围的学生穿着蓝白校服，脸色惨白，背着书包往教学楼走，一点声音都没有。
「B级副本，死亡率超过60%，规则有诱导性陷阱，跟紧我，别乱碰东西。」苏清的脸色沉得厉害，她的目光扫过学生身上的校服，和苏晓当年穿的那件一模一样，指尖下意识捏紧了袖口，没多说话。
校门口的公告栏上贴着打印的校规，红章盖得很清晰：
【育英中学校规】
1. 所有在校生必须身着统一校服，不得染发、佩戴首饰，男生头发不得长过耳朵，女生不得留刘海
2. 上课铃响后必须进入教室，迟到者禁止进入教学楼
3. 食堂三餐免费供应，可随意食用，但不得打窗口的红色红烧肉
4. 晚自习时间为18:00-22:00，22:00后教学楼全部锁门，禁止在教学楼内逗留
5. 宿舍23:00准时锁门，禁止夜不归宿，禁止串寝
6. 请在72小时内找到三张2014届高三毕业生的毕业照，即可通关
7. 违反任意校规，直接开除（即死亡）
林安把规则扫了三遍，很快找到了漏洞：「第一，迟到禁止进教学楼，没说不能翻墙进；第二，不能打红色红烧肉，没说不能打了送给别人；第三，22点后禁止在教学楼逗留，没说不能去天台。三张毕业照大概率在校长办公室，需要门禁卡，门禁卡在教导主任那里。」
几人领了校服换上，王胖子太胖，最大号的校服裤都拉不上，只能用皮带勒着，走两步就往下滑，林安忍不住笑：「你这像偷穿你爸衣服的小学生，等下跑的时候别被裤子绊倒了。」
王胖子翻了个白眼，刚要反驳，上课铃突然尖锐地响了起来，所有学生都加快脚步往教学楼跑。「快进教室，别迟到！」苏清拉着李萌往前跑，几人随便钻进了一间高三教室，刚坐好，戴眼镜的女老师就走了进来，开始讲天书一样的题，听得人昏昏欲睡。
林安坐在靠窗的位置，偷偷观察周围的人，赵磊坐在他斜前方，脸色发白，手心全是汗，时不时抬头看门口，像是在等什么人。林安皱了皱眉，想起之前匿名短信说的卧底，心里留了个心眼。
下课铃一响，老师刚走，林安就站起来：「走，去食堂，搞门禁卡。」
几人到了食堂，窗口果然摆着红亮的红烧肉，香气飘得老远。王胖子眼睛都直了，刚要伸手打，被林安按住：「你不要命了？规则说不能吃，没说不能送。」
林安拿了个餐盘，打了满满一勺红烧肉，端着往教导主任的桌子走。教导主任正坐在那里吃饭，看到红烧肉眼睛一下子亮了，林安把餐盘递过去：「主任，我不爱吃肥肉，这份给你吃。」
教导主任也没说话，狼吞虎咽吃完，把胸前的门禁卡摘下来塞给林安，含糊不清地说：「小子懂事，下次有事找我。」
王胖子看得目瞪口呆：「我靠，还能这么操作？送个菜就给门禁卡？」
「不然你以为B级副本的漏洞这么好找？」林安把门禁卡揣进兜里，刚要往校长办公室走，突然楼道里传来了保安的脚步声，还有对讲机的声音：「收到收到，有外来人员在校长办公室楼层，马上过去抓捕。」
几人立刻躲进拐角，林安的目光落在赵磊身上，赵磊的脸瞬间白了，攥着手机的手都在抖。
「是你给他们报的信？」林安的声音很平静，没有愤怒，只有冷。
「我不是故意的！」赵磊一下子就哭了，「零号抓了我弟弟，他才十岁！说我要是不把你们的位置报给NPC，就把我弟弟扔到S级副本里喂怪物！我没办法啊！」
王胖子气得举起拳头要打他，被林安拦住了。林安看着赵磊，沉默了两秒：「我可以帮你救你弟弟，但是你现在要帮我们把保安引开，通关之后我们再算账，行不行？」
赵磊愣了一下，疯狂点头：「行！我帮你们引开！」
他转身冲了出去，一边跑一边喊：「我在这！来抓我啊！」保安们立刻追了上去，脚步声越来越远。林安趁机带着其他人往顶层走，用门禁卡刷开校长办公室的门，书柜上摆着一排毕业照，很快找到了三张2014届的，林安刚拿到手里，门就开始被砸，是保安追回来了。
「走，去天台！」林安拉着苏清往天台跑，推开门的瞬间，外面就是白光的通关出口，几人刚跑出去，赵磊也冲了过来，林安伸手把他拉进白光里。
「恭喜玩家通关B级副本「育英私立高中」，奖励：三张2014届毕业照，获得217份玩家执念。额外奖励：成功解救NPC赵小宇（赵磊弟弟），获得100份执念加成。」
白光散去，所有人都回到了便利店门口，一个十岁左右的小男孩抱着赵磊的腰哭：「哥！我还以为再也见不到你了！」赵磊抱着弟弟，哭得话都说不出来，对着林安“噗通”一声跪了下来：“谢谢你！我这条命以后就是你的了！你让我干什么都行！”
林安赶紧把他扶起来：“别来这套，以后别再被零号要挟就行，多个人多份力，我们也更容易活下去。”
苏清点了点执念，现在累计已经有196+217+100=513份了，离目标近了一步。她拍了拍林安的肩膀，没说话，但是眼神里带着点赞许。
王胖子凑过来，撞了撞林安的胳膊：“可以啊你，还会策反卧底，以前没看出来你还有这本事。”
“什么策反，我只是不想少个队友而已。”林安翻了个白眼，他才不是什么圣母，多一个有副本经验的队友，下次通关的概率就大一点，他只是为了自己能活下去而已。
张叔给赵小宇拿了瓶可乐，摸着他的头叹了口气：“零号现在越来越过分了，连小孩子都不放过。”
就在这个时候，林安的手机又响了，还是那个空号，这次的短信很长：「下一个是A级副本「鼎盛写字楼」，零号会亲自改规则，别信任何系统提示，找规则里的矛盾点，你是运营，你最擅长这个。」
林安看着短信，皱起了眉。这个人到底是谁？怎么连他以前做运营的事都知道？
还没等他想明白，所有人的云纹同时剧烈发烫，机械音和零号的声音重合在一起，带着冰冷的怒意：「A级副本「鼎盛写字楼」开启，我看你这次还能找出什么漏洞。」
林安深吸了一口气，把手机揣进兜里。
A级副本就A级副本，就算是S级，他也能抠出漏洞来。
他还没活够呢，绝对不会栽在这里。
