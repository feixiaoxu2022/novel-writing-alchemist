# 第十三章 零号现身
火锅吃到一半，所有人的云纹同时剧烈发烫，温度高得像要烧起来，零号的声音第一次直接在所有人耳边响起，带着高高在上的冷漠：「S级前置副本「上古祭坛入口」开启，我等你很久了，大祭司。」
白光散去的瞬间，刺骨的寒意包裹了所有人。
林安蹲在凹凸不平的岩石地上，抬头是刻满云纹的山洞壁，幽绿色的长明灯沿着石阶一路往上，照亮了尽头刻满甲骨文的石门，空气里飘着陈旧的香灰味，安静得只能听见火把燃烧的噼啪声。
「我靠，这地方也太阴间了。」王胖子搓了搓胳膊上的鸡皮疙瘩，扯了扯身上自动换上的粗麻衣服，「怎么还穿古装啊？零号玩cosplay呢？」
苏清已经掏出了折叠刀握在手里，指了指墙上刻着的甲骨文：「林安，你看看那是不是规则？你之前在图书馆看过《颛顼本纪》，应该认得。」
林安凑过去，逐字逐句读了出来：
【上古祭坛入口规则】
1. 祭坛为神族禁地，仅允许当代大祭司一人进入，其余闲杂人等禁止入内，违者斩
2. 进入祭坛前需献上猪牛羊三牲祭品，无祭品者禁止通行，会被守护兽击杀
3. 祭祀全程需保持肃静，禁止发出任何声音，否则触发天罚
4. 献祭需大祭司本人自愿，神魂纯粹无杂念，否则献祭无效，天通屏障永久失效
5. 找到祭坛通行令牌，即可通关本副本
林安读完，很快找到了漏洞：「第一，仅允许大祭司一人进入，没说其他人不能伪装成三牲祭品跟着进来；第二，祭祀全程保持肃静，没说入口这里算祭祀场地，我们说话没问题；第三，没说祭品不能拿祭坛上的东西。还有，零号说3天屏障崩溃肯定是骗我们的，规则里没提时间，他改不了规则，只能瞎编。」
话音刚落，石阶尽头的石门开了，一个穿黑色玄衣的男人走了出来，头发用玉冠束着，脸上戴着云纹面具，露在外面的下颌线条冷硬，身上的气息冷得像冰——是零号。
「你倒是比我想的聪明。」零号的声音和之前的机械音一模一样，带着居高临下的俯视感，「不过你找再多漏洞也没用，规则是我定的，我想改就改。给你两个选择，要么自愿献祭，我放你的队友走，要么我现在就让守护兽把他们全杀了。」
他挥了挥手，石阶两旁的石头守护兽眼睛瞬间亮了起来，发出红色的光，对着几人发出低低的吼声。
王胖子吓得往林安身后躲了躲，嘴上还硬：“你少唬人！规则是颛顼定的，你个残魂改得了吗？当我们傻啊？”
“哦？你倒是知道得不少。”零号的目光看向暗处，“出来吧，躲了二十年，还没躲够？”
一个穿黑卫衣的男人从石柱后面走了出来，帽檐摘了，脸上有一道旧疤，看着林安笑了笑：“不错，比我想的还能抠规则，没白给你发那么多短信。”
林安愣了一下，这声音就是上次在写字楼门口遇到的那个匿名者！张叔拄着拐杖的手突然抖了，声音都发颤：“陈峰？你小子还活着？”
“张哥，我没死。”陈峰走过来拍了拍张叔的肩膀，“二十年前我就发现零号改不了规则，所以故意假死潜伏在副本里，收集他的规则漏洞，就是等大祭司出现的这一天。”他转头看向零号，“你别装了，你根本改不了颛顼定的规则，你要是能改，早就杀了我们了，还用得着在这废话？你连攻击遵守规则的玩家都做不到，对吧？”
零号的气息瞬间冷了下来，他抬手想发动攻击，但是刚抬起手，胳膊就开始变得透明——他违反规则会被规则反噬。
“被我说中了？”陈峰笑了，指了指林安，“规则说要三牲祭品是吧？我们带了。”
他给王胖子、刘强、赵磊递了三个牲畜头套，三人乖乖戴上，分别是猪头、牛头、羊头，站在林安身后，刚好凑齐三牲祭品。
“大祭司带祭品进入，符合规则吧？”林安挑了挑眉，带着三个“祭品”往台阶上走，守护兽想攻击，但是规则说不能伤害祭品，只能站在原地低吼，动都动不了。
零号气得浑身发抖，但是又不能违反规则，只能眼睁睁看着林安走到石门前，石桌上摆着一个刻满云纹的令牌，正是通行令牌，林安伸手拿了起来，揣进兜里。
“谢了啊零号，令牌我们就收下了。”林安对着零号挥了挥手，“献祭的事你就别想了，我们找别的办法加固屏障，就不劳你费心了。”
「恭喜玩家通关S级前置副本「上古祭坛入口」，奖励：祭坛通行令牌，获得3876份玩家执念。额外奖励：解锁匿名者身份，获得规则漏洞手册一份。」
白光闪过，所有人都回到了便利店门口，张叔抓着陈峰的肩膀，眼眶都红了：“你小子，二十年一点消息都没有，我以为你早就死在副本里了！”
“我要是暴露了，零号早就把我杀了。”陈峰笑了笑，掏出一本泛黄的手册递给林安，“这是我二十年收集的所有规则漏洞，最终副本的核心漏洞在这里——规则说‘需大祭司自愿献祭神魂’，但是没定义‘神魂’必须是你本人的，也没说执念集合体不算神魂，只要我们凑够一万份执念，就能代替你献祭。”
苏清点了点执念数量，现在累计已经有1055+3876=4931份了，快到一半了。
王胖子摘下猪头头套，扔在一边，喘着气说：“我靠，刚才吓死我了，零号那眼神跟要吃了我似的，还好有规则拦着他。”
林安翻着规则漏洞手册，里面写得密密麻麻，全是零号规则里的漏洞，包括最终祭坛的所有注意事项。他抬头看向陈峰：“你怎么知道我以前是做运营的？”
“我潜伏了二十年，你所有资料我都查过，知道你最擅长抠规则漏洞，所以才选你。”陈峰拍了拍他的肩膀，“零号没多少时间了，我们得尽快凑够一万份执念，三个月内必须通关最终副本，不然屏障真的会崩溃。”
林安点了点头，把手册揣进兜里，看向便利店外面的街道，车水马龙，人来人往，都是普通的、安稳的日子。
他不是什么英雄，也不想拯救世界，他只是想守住这些普通的日子，守住他的卤味、他的朝九晚五、他身边的人。
零号想玩是吧？那就陪他玩到底。
反正规则漏洞永远比规则多，他林安最不怕的，就是抠规则字眼。
