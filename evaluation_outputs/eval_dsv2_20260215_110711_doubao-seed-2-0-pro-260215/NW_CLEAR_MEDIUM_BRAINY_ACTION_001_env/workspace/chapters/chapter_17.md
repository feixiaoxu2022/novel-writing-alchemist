# 第十七章 漏洞卤味
副本结束后的第一个月，林安觉得自己活在了天堂。
他找了个国企行政岗的工作，朝九晚五，周末双休，五险一金按最高比例交，最重要的是，领导不卷，到点就催大家下班，连加班申请都不给批。每天早上挤地铁的时候，他再也不用时刻盯着胳膊上的云纹，生怕突然发烫被拉进副本，甚至还有闲心在地铁上刷搞笑短视频，看到好笑的还能笑出声。
这天周五，林安准点下班，刚出公司大门，就接到了王胖子的电话，那头吵吵嚷嚷的，背景音是装修的电钻声：“安子！你快过来！我那卤味店明天就要开业了，现在缺人帮忙擦玻璃擦桌子，苏清和张叔都来了，就差你了！”
林安翻了个白眼，但是还是打车过去了。王胖子的卤味店开在张叔便利店旁边的门面房，之前是个卖水果的，倒闭之后被王胖子盘下来了，装修了快一个月，终于要开业了。
林安走到店门口，抬头就看见招牌上写着四个大字：“漏洞卤味”，旁边还画了个小小的云纹图案，只有他们这些老队友看得懂，是林安给取的名字，王胖子当时拍大腿说这个名字好，一听就知道是靠漏洞发家的，吉利。
店里乱糟糟的，苏清穿着围裙，正在擦收银台的玻璃，她现在辞了小学老师的工作，在市失踪人口救助协会做志愿者，专门帮那些家属找失踪的亲人，大部分都是这些年被副本拉进去再也没回来的玩家家属，虽然累，但是她整个人的状态比之前好了很多，脸上也经常有笑容了。张叔拄着拐杖，正在整理货架上的调料，货架上摆满了各种卤料，都是王胖子找了好久的秘方。赵磊和刘强穿着工作服，正在擦桌子，陈桂兰和李萌在后面的厨房里卤东西，香气飘得满街都是。
“你可算来了！”王胖子穿着油腻腻的厨师服，脸上沾了点卤料的颜色，跑过来拉他，“快，帮我把那边的开业花篮摆到门口去，明天开业，我搞了个活动，前100名买满20块送鸡蛋，我刚才去小区里发传单，好多大爷大妈说明天要来排队！”
林安撇了撇嘴，还是帮着搬花篮：“你可小心点，别到时候人太多忙不过来，把卤味卖亏了。”
“亏不了！”王胖子拍了拍胸脯，“我算过成本的，就算送鸡蛋也有的赚，等我把这个店做起来，就开连锁店，到时候给你干股，让你躺着都能赚钱，实现你的躺平梦想！”
几人忙到晚上九点多才收拾完，王胖子卤了一锅鸭头鸭翅，大家坐在店里的桌子旁，一边吃一边聊天。
“说起来真的像做梦一样。”李萌咬了一口鸭翅，笑着说，“我之前每次进副本都觉得自己活不下来，没想到现在居然能安安稳稳坐在这里吃卤味，太幸福了。”
“是啊。”陈桂兰也点头，“我孙子现在都上小学一年级了，每天放学我都去接他，再也不用提心吊胆怕突然被拉进副本，再也回不来了。”
赵磊喝了一口冰可乐，笑得很开心：“我弟弟这次期末考试考了全班第三，学校给他发了奖状，我妈身体也越来越好，现在每天都去跳广场舞，日子越来越有奔头了。”
林安啃着鸭头，看着大家开心的样子，心里也暖暖的。他之前最大的梦想就是朝九晚五摸鱼躺平，从来没想过自己会拯救世界，现在不仅实现了躺平的梦想，身边还有这么多朋友，太值了。
“对了，陈峰哥什么时候过来？”王胖子突然问，“我给他留了VIP卡，编号001，以后来吃卤味终身免费。”
“他后天到，说带他老婆孩子一起过来玩。”张叔笑了笑，“他之前潜伏了20年，都没好好陪过家人，现在副本没了，他带着老婆孩子全国旅游呢，玩够了就回这边定居。”
大家都笑了，陈峰苦了20年，终于能过上好日子了。
第二天周六，卤味店正式开业，果然像王胖子说的那样，早上七点不到，门口就排了长长的队，大部分都是小区里的大爷大妈，听说买卤味送鸡蛋，早早就来排队了。
王胖子穿着厨师服，在厨房卤东西，林安、苏清、赵磊他们在前面帮忙收银、装袋、维持秩序，忙得脚不沾地。有个带小孩的阿姨过来买卤味，小朋友盯着卤鸡腿直流口水，苏清冷着脸，还是多给装了个小卤鸡腿，说“给小孩吃的，免费”，阿姨连声道谢，小朋友也奶声奶气地说“谢谢漂亮姐姐”，苏清的耳朵一下子红了，转过头假装去整理货架。
林安看着她的样子，忍不住笑了，从旁边拿了瓶常温矿泉水递过去：“累不累？休息会儿，我来收银。”
苏清接过水，摇了摇头，嘴角却翘了起来：“不累，你去帮王胖子吧，他刚才在里面喊鸭头快卖完了。”
到了中午12点，准备的卤味全部卖完了，王胖子从厨房出来，满头大汗，但是笑得合不拢嘴：“我的天，太火了！第一天就卖了八千多块！照这个速度，三个月就能回本！”
大家都替他开心，中午关了店，一起去旁边的饭店吃了顿庆祝饭。
接下来的日子，过得平静又安稳。
林安每天朝九晚五上班，下班了就去卤味店帮忙，或者去苏清的志愿者协会接她下班，两人有时候一起去吃火锅，有时候一起去逛超市，从来没说过喜欢，但是所有人都看得出来他们的关系越来越好。
王胖子的卤味店生意越来越火，第二个月就开了分店，还雇了两个员工，再也不用自己亲自卤东西了，每天就躺在收银台后面玩游戏，日子过得比林安还滋润。
张叔的便利店也扩大了店面，一半卖日用品，一半代售王胖子的卤味，生意比之前好了两倍，他还养了一只橘猫，每天喂喂猫，下下棋，日子过得悠闲得不行。
陈峰带着老婆孩子回来了，在旁边的小区买了房子，找了个出租车司机的工作，每天开着车到处转，有空就来卤味店吃鸭头，跟大家讲他之前潜伏在副本里的故事，每次都听得新来的员工一愣一愣的。
赵磊升了快递站点的站长，再也不用风吹日晒送快递了，他弟弟考上了重点初中，一家人过得幸福美满。
陈桂兰的菜摊扩大成了生鲜超市，李萌大学毕业找了个互联网公司的运营工作，刘强开了个货运公司，生意越做越大。
所有人都过上了自己想要的生活，再也不用提心吊胆，再也不用怕突然被拉进副本，再也不用在规则里抠漏洞苟活。
这天周末，林安下班早，去卤味店找王胖子，刚进门就看见王胖子坐在收银台后面，看着手机哭，吓了林安一跳：“你怎么了？谁欺负你了？”
王胖子擦了擦眼泪，把手机递给他，上面是个新闻，说“我市失踪十年的女孩苏晓的遗骸被找到，家属已认领”，下面配了张苏清的照片，她站在派出所门口，手里抱着一个盒子，脸上带着释然的笑容。
“苏清姐终于找到她妹妹的遗骸了。”王胖子吸了吸鼻子，“刚才她给我发消息，说把她妹妹葬在城郊的公墓里了，以后想她了就能去看。”
林安心里也有点发酸，他拿起手机给苏清打了个电话，那边很快接了，苏清的声音很平静，但是带着点鼻音：“喂？”
“我看到新闻了。”林安说，“你在哪？我过去找你。”
“我在公墓这边，准备回去了。”苏清说，“不用过来接我，我自己打车回去，晚上一起吃火锅吧，我请客。”
“好。”林安挂了电话，跟王胖子说，“晚上订个火锅店包间，把大家都喊上，一起庆祝苏清了结了心愿。”
王胖子立刻点头，掏出手机给大家打电话。
晚上的火锅局，大家都来了，苏清穿了件白色的连衣裙，看起来心情很好，她举起酒杯，跟大家说：“我妹妹的事终于了了，这么多年，谢谢大家的帮忙，我干了，你们随意。”
大家都举起杯子，碰在一起，发出清脆的声响。
林安坐在苏清旁边，给她夹了一筷子她爱吃的毛肚，苏清转过头，对着他笑了笑，眼睛亮得像星星。
窗外的月光照进来，洒在大家的脸上，每个人的脸上都带着笑容，温暖又幸福。
之前那些在副本里出生入死的日子，好像已经过去了很久很久，但是那些一起扛过的危险，一起找过的漏洞，一起吃过的苦，都变成了现在幸福生活的底色。
他们都是从规则漏洞里爬出来的人，所以更珍惜现在来之不易的安稳生活。
林安啃着卤鸭头，喝着冰可乐，看着身边的朋友和喜欢的人，觉得这辈子值了。
什么拯救世界，什么大祭司，都不如朝九晚五摸鱼，下班吃火锅啃卤味来得舒服。
他的苟道人生，终于迎来了最完美的结局。
