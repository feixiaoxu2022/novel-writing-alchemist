# 第七章 匿名短信
白光消退的瞬间，林安条件反射抱头蹲在地上，后背的冷汗还没干，鼻尖先钻进了烤肠混着关东煮的烟火气。
他眯着眼抬头，张叔便利店的卷帘门半拉着，夕阳把梧桐叶的影子斜斜印在人行道上，挎着菜篮子的大妈擦着他的胳膊走过，嘟囔了一句“现在的年轻人怎么总蹲路边”，脚步声慢悠悠远了。
那种副本里浸到骨头里的阴冷还没散，林安摸了摸胳膊上的三个云纹，触感微凉，没像前两次那样发烫升级——图书馆副本利用漏洞抵消难度的设定是真的，他暂时不用面对C级副本的鬼东西。
“我靠……活了？”王胖子整个人瘫在地上，T恤湿得能拧出水，胖脸上还沾着藏书库的灰尘，伸手就拽林安的衣角，“安子，之前说的一年份卤味，能不能先结三个月的？我刚才被管理员追得跑掉了一只鞋，现在胃里空空的。”
“结个屁。”林安拍开他的手，刚要站起来，胳膊突然被苏清拽了一把，力道大得他差点摔个趔趄。
“躲树后面。”苏清的声音压得很低，拽着他俩躲进梧桐树的阴影里，直到那个挎菜篮的大妈拐进单元楼才松手，“突然出现在路边容易被当成疯子，下次落地先看周围有没有人。”
不愧是通关九次的资深玩家，谨慎程度和他这个苟道社畜不相上下。林安拍了拍裤子上的灰，刚要说话，便利店的卷帘门“哗啦”一声被拉开，张叔拄着拐杖站在门口，左手端着三杯冒热气的姜茶，脸上没什么表情：“进来吧，姜茶煮好了。”
便利店里暖黄的灯开着，烤肠机滋滋转着，油星子蹦得欢快，和副本里的阴冷压抑像两个世界。林安捧着姜茶喝了一大口，暖意从胃里漫到四肢，终于有了点活过来的实感。
他把图书馆副本的事从头到尾说了一遍，包括那具和他长得一模一样的祭司棺材、《颛顼本纪》里的献祭规则、王胖子卧底反水的前因后果，还有他们商量的“收集玩家执念代替献祭”的计划。张叔全程没插话，手指轻轻敲着收银台的桌面，等他说完，才从抽屉里拿出个泛黄的笔记本。
“这是二十年来我记的幸存玩家名单。”张叔把笔记本推到他面前，纸页边缘都磨毛了，上面密密麻麻记着名字、联系方式、最后出现的地址，“大部分都隐姓埋名躲起来了，少部分被零号要挟当过卧底，愿意帮忙的估计不多。”
林安翻了两页，头摇得像拨浪鼓：“我不干啊张叔，我就是个普通社畜，只想苟着活，找玩家这种事太危险了，我找个出租屋锁起来苟着不行吗？反正我会找漏洞，下次副本再混过去就是了。”
他本来就是想躺平才选的运营岗，996都受不了，更别说冒着被零号盯上的风险到处跑。拯救世界这种事轮不到他，他只想攒够首付，朝九晚五，每天下班能啃个卤鸭头。
苏清坐在他对面，手指划过笔记本某一行的名字，突然顿住了。
林安抬头看过去，她手里捏着张皱巴巴的旧照片，上面的小姑娘扎着高马尾，穿蓝白校服，笑起来露出两个虎牙，和苏清有七分像。苏清的指尖捏着照片边缘，指节泛白，指甲几乎嵌进掌心里，声音平得像在说别人的事：“这是我妹苏晓，10年前初中放学失踪，所有人都以为她被拐了。我第三次进副本的时候，在走廊见过她的尸体，手里攥着半块没吃完的草莓糖。”
她没哭，甚至表情都没什么变化，只是捏着照片的手微微抖了一下，翻到笔记本的下一页，“她是上一任大祭司备选，不愿意献祭，被零号设计死的。我跟你组队一开始是想利用你找零号报仇，现在我们目标一致。”
林安看着她泛红的眼尾，到了嘴边的拒绝突然说不出口了。他挠了挠头，从货架上拿了包草莓糖递过去：“那个……下次通关的卤鸭头我分你两个，别难过。”
苏清接过糖，指尖碰到他的手，很凉。她几不可察地点了点头，把糖塞进了口袋。
几人又商量了几句，张叔给了他们三瓶艾草精油，说喷在身上能暂时掩盖云纹的气息，降低被副本怪物盯上的概率。等到天完全黑透，林安才揣着笔记本和《颛顼本纪》，和苏清、王胖子一起离开了便利店。
回到出租屋，林安第一件事就是把门锁了三道，推了推确认锁死，才把《颛顼本纪》塞到床垫最底下。他洗了个热水澡，把身上的灰尘和副本的阴气都冲掉，刚裹着浴巾出来，放在桌上的手机突然“叮”地响了一声。
是个陌生空号发来的短信，只有四个字：
「别信规则。」
林安的血液瞬间凉了半截。
他指尖发抖地点开详情，号码归属地显示为空，拨过去只有机械的“您所拨打的号码不存在”的提示音。下一秒，他胳膊上的云纹突然剧烈发烫，温度高得像要烧起来，他疼得嘶了一声，撸起袖子看，三个云纹亮得刺眼，中间慢慢浮出一行极小的淡蓝色字：
「下次副本开启时间：72小时后。」
他猛地转头看向窗户，窗帘没拉严，缝隙里能看到楼下路灯下站着个穿黑色卫衣的人，帽檐压得极低，似乎抬头往他的方向看了一眼，转身就钻进了巷子，消失得无影无踪。
林安的后背瞬间被冷汗浸湿了。
他以为从副本出来就安全了，以为躲在家里就能苟住，可是那条短信、那个站在楼下的人、云纹上的倒计时……无一不在告诉他，零号已经盯上他了，他躲不掉的。
如果他不找其他幸存玩家抱团，不提前做准备，下次副本就是死路一条。
他不是想拯救世界，他只是想活下去，想攒够首付，想朝九晚五摸鱼，想吃王胖子欠的一年份卤味。
林安深吸了一口气，拿出手机给苏清和王胖子发微信：「明天上午九点，张叔便利店集合，联系幸存玩家。」
苏清秒回了个「好」，王胖子回了个哭唧唧的表情包，后面跟着一句「能不能先吃顿卤味再去拼命啊哥」。
林安看着手机屏幕，擦了擦额头上的冷汗，走到窗边把窗帘拉得严严实实。
窗外的万家灯火很暖，远处传来广场舞的音乐声，一切都和往常没有任何区别。只有林安知道，那张看不见的规则大网，从来都没有消失过，它一直藏在普通人看不见的地方，冷冰冰地窥视着每一个云纹持有者。
他没得选，只能往前走。
毕竟他还不想死。
