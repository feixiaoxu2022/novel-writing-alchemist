# 第五章 真凶疑云
第二天一早，沈砚就去了工部局档案室。
他的胳膊还缠着绷带，是苏晚昨天晚上给他包扎的，动作很轻，不像她平时风风火火的样子。沈砚摇了摇头，把脑子里的杂念赶出去，现在最重要的是找顾守义问清楚。
档案室的门虚掩着，里面没有开灯，昏暗得很，沈砚推开门走进去，敲了三下门框——这已经是他的习惯了。
“顾叔？”他喊了一声。
没有人回答。
沈砚皱了皱眉，走进去，里面很安静，只有档案架上的纸张被风吹得哗啦响，顾守义平时坐的桌子上空荡荡的，茶杯里的水还冒着热气，说明他刚走没多久。
桌子上放着一份打开的档案，是1842年镇江保卫战的记录，上面有那个清朝官员的照片，和之前死者手里的照片一模一样，名字写着“顾衍”，是当年镇江的守城官员，城破之后被英国鸦片商害死，全家都被杀了，只有一个小儿子被仆人救走，下落不明。
顾衍，顾守义。
沈砚的心脏猛地一缩。
原来顾守义就是当年那个官员的后代。
他的目光落在桌子上的全家福照片上，顾守义和一个年轻的女人还有一个小男孩站在一起，笑得很开心，那个小男孩眉宇间和林阿生有七分像。
林阿生是顾守义的儿子。
沈砚只觉得浑身发冷，原来他一直信任的两个人，一个是凶手，一个是凶手安插在他身边的眼线。
“你都看到了。”
身后传来顾守义的声音，沈砚转过身，看到顾守义站在门口，穿着灰色的长衫，头发白了一半，脸上没什么表情，手里拿着一把枪，对准了他。
“顾叔，真的是你？”沈砚的声音有点发抖，“那些人都是你杀的？我爸也是你杀的？”
“是我。”顾守义点了点头，语气很平静，“那些鸦片商的后代，都该死，他们的祖先当年害死了我全家，血债血偿，天经地义。你父亲当年查到了我的身份，我没办法，只能杀了他。”
“为什么？”沈砚红了眼，“我爸一直把你当最好的朋友，你怎么下得去手？”
“我也不想杀他。”顾守义叹了口气，“他太固执了，非要查下去，我劝过他很多次，他不听，我只能动手。阿生是我儿子，我让他跟着你，就是想看看你会不会像你父亲一样，也要查到底。”
“张佩兰和史密斯也是你的同伙？”沈砚问。
“他们只是拿钱办事的走狗而已。”顾守义冷笑一声，“我答应给他们一大笔钱，让他们帮我做事，现在他们没用了，我已经处理掉了。”
沈砚的心里咯噔一下：“你杀了他们？”
“算是吧，伪装成违反规则被天谴的样子，没人会怀疑。”顾守义说，“小砚，我一直很喜欢你，把你当自己的侄子看，你不要查了，这件事就这么过去，好不好？我保证以后不再杀人了。”
“不可能。”沈砚摇了摇头，“你杀了那么多人，还杀了我爸，我必须把你绳之以法。”
“你以为你走得出去吗？”顾守义举着枪，慢慢逼近，“这里是地下室，没人会来，我杀了你，伪装成你违反规则被天谴的样子，没人会怀疑。”
沈砚的手慢慢摸向口袋里的枪，刚要拿出来，就听到门口传来林阿生的声音：“爸！不好了！苏探长带着人来了！”
顾守义的脸色变了变，转身就要跑，沈砚立刻扑过去，一把抓住他的胳膊，两个人扭打在一起，顾守义手里的枪掉在地上，走火了，子弹打在档案架上，灰尘落了一脸。
“不许动！”
苏晚带着巡捕冲了进来，举枪对准顾守义，林阿生想要反抗，被旁边的巡捕按住了，铐了起来。
顾守义看着沈砚，苦笑着摇了摇头：“我早该知道，你和你父亲一样，都是死心眼。”
巡捕把顾守义和林阿生带了出去，苏晚走到沈砚身边，看着他胳膊上的绷带渗出血来，皱了皱眉：“你没事吧？怎么不叫我和你一起来？多危险啊。”
“我没想到真的是他。”沈砚叹了口气，看着地上顾守义的全家福，心里很不是滋味，“我爸把他当最好的朋友，他却杀了我爸。”
“坏人总是藏得很深的。”苏晚拍了拍他的肩膀，“现在好了，真凶抓到了，案子也结了，你也可以给你爸报仇了。”
沈砚点了点头，心里却总觉得哪里不对。
顾守义刚才说他已经处理了张佩兰和史密斯，他们去张佩兰的家查看，果然发现张佩兰死在了自己的公寓里，和之前的死者一样，浑身湿透，密室，墙纸上印着守则，史密斯也死在了自己的办公室里，死状一模一样。
案子好像真的结了。
所有的证据都指向顾守义，他也对自己的罪行供认不讳，说所有的人都是他杀的，张佩兰和史密斯是他杀的，沈砚的父亲也是他杀的，手法就是干冰水雾密室，和沈砚推测的一模一样。
史密斯收受贿赂的证据也被搜了出来，上面的命令下来，案子正式结案，顾守义和林阿生被关进了监狱，等待审判。
巡捕房的人都很高兴，说这么离奇的案子这么快就破了，沈砚是个天才法医，苏晚也很高兴，说要请沈砚吃饭庆祝。
只有沈砚高兴不起来。
他回到家，把那份1842年的档案摊在桌子上，看着上面的规则，第三条和第五条互斥，第七条是不得违反任何一条。
他忽然发现，顾守义的供词里有个漏洞。
他说他杀张佩兰和史密斯，是因为他们没用了，但是按照规则，张佩兰和史密斯都是通灵会的核心成员，肯定知道第三条和第五条是互斥的，不会同时遵守，不会触发陷阱，那他们是怎么死的？
除非，凶手不是顾守义。
沈砚的心里猛地一跳。
他拿出顾守义的口供，仔细看了一遍，顾守义说他每次作案都是提前把干冰气瓶放在死者家里，等死者回家后触发，但是第三起命案发生的时候，顾守义正在档案室和他说话，有完美的不在场证明。
他当时怎么没注意到这个？
沈砚立刻站起身，朝着监狱走去，他要再见顾守义一面，问清楚。
监狱的接待室里，顾守义穿着囚服，脸色很憔悴，看到沈砚进来，笑了笑：“怎么了？还有什么要问的？”
“第三起命案发生的时候，你正在档案室和我说话，你怎么去作案？”沈砚盯着他的眼睛问。
顾守义的眼神闪烁了一下，很快恢复了正常：“我提前布置好的，定时装置，到时间自动释放干冰。”
“什么定时装置？我们在现场没有找到任何定时装置的痕迹。”沈砚追问。
顾守义沉默了几秒，然后说：“我销毁了，你们当然找不到。”
他在撒谎。
沈砚看得出来，他在撒谎。
“真凶不是你，对不对？”沈砚的声音很沉，“你在替谁顶罪？”
顾守义抬起头，看着他，眼里闪过一丝复杂的情绪，很快又掩饰过去了：“没有，人都是我杀的，你不用再查了。”
他说完，站起身，朝着监狱里面走去，不管沈砚怎么喊，都没有回头。
沈砚站在原地，只觉得后背一阵发凉。
他之前以为抓到了真凶，现在才发现，一切才刚刚开始。
真正的凶手，还在外面。
