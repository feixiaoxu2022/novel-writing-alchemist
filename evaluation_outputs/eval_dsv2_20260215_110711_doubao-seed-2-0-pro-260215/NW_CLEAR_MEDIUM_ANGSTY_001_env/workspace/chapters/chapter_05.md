# 第5章：内鬼踪迹
2024年9月15日晚22:15，陆沉的越野车碾过湿漉漉的柏油路，轮胎碾过积水的声音在寂静的市局大院里格外清晰。副驾的苏清禾指尖还捏着那枚烫得发暖的加密U盘，指节因为长时间用力泛着青白，刚才在家摊牌时的慌乱还没完全从胸腔里褪去，她抬眼扫了眼陆沉紧绷的下颌线，悄悄把揣在兜里捂了半小时的热奶茶递过去。
是他常喝的乌龙少糖，三分冰，她下午出门去仓库和林峰对接前特意绕到巷口那家老店买的，放在随身的保温杯里捂到现在，杯壁还带着恰到好处的温度。陆沉愣了半秒，左手接过来的时候，掌心那道两厘米长的旧疤不经意蹭过她的手背，两人的动作同时顿了半秒，都没说话，默契得像是已经做过千百遍。
“我去技术队核对拆弹坐标，你先去见张局？”苏清禾拉开车门下车，风衣下摆扫过台阶上的积水，右耳那颗小痣在廊灯下晃了晃，声音压得很低，“就按我们之前说好的说，别露馅。”
陆沉“嗯”了一声，指尖捏着温热的奶茶杯，看着她快步走向技术楼的背影，直到转角看不见了才转身走向办公楼大厅。赵勇正叼着薄荷糖靠在大厅的自动售货机旁，左手攥着一张皱巴巴的打印纸，看见他进来连忙把糖嚼碎了咽下去，快步迎上来：“陆队，你可算回来了，张局找你找了快半小时，脸色黑得像要吃人，估计是知道陈默推迟转移的事了。”
陆沉把奶茶塞进赵勇怀里：“给你的，上次你说想喝这家的。陈默的病历我已经让保密医院那边开好了，没问题。”
赵勇愣了下，抱着热奶茶挠了挠头：“我就是上次随口提了一句……哎不是，张局刚才放话了，说你要是来了直接去他办公室，连门都不用敲。”
陆沉点头，把警官证往上衣口袋里塞了塞，转身走向三楼的局长办公室。走廊里的感应灯随着他的脚步一盏盏亮起来，空气中还残留着消毒水和烟味混合的味道，他走到办公室门口，还没抬手敲门，里面就传来张正国的声音：“进来。”
推开门的瞬间，浓重的烟味扑面而来，张正国坐在办公桌后面，左眉那道旧疤拧成了一团，面前的烟灰缸里已经堆了小半缸烟蒂，看见他进来，“啪”的一声把一份病历拍在桌上：“陆沉，你跟我说实话，陈默到底怎么回事？上周我去保密点看他，他还能跑三公里，你告诉我他突发急性胃穿孔？谁给你的胆子擅自推迟转移时间？”
陆沉面不改色地走过去，拿起那份病历翻了两页，是他之前让保密医院的老熟人开的，连胃镜报告都做得天衣无缝：“张局，陈默有三年的胃病史，之前一直在吃药控制，今天下午突然疼得满地打滚，医生说至少要观察48小时，要是这时候转移，路上出了问题谁负责？恐怖分子要的是他活着，我们拖着不转移，他们反而不敢轻举妄动。”
张正国盯着他的眼睛看了足足半分钟，指尖的烟烧到了过滤嘴才反应过来，随手按灭在烟灰缸里：“我警告你陆沉，省厅那边已经催了三次了，最多给你48小时，48小时之后必须转移陈默，要是出了任何问题，你脱了这身警服都担待不起。”
“是。”陆沉敬了个礼，转身要走，身后张正国又补了一句：“还有，刚才档案室那边说，有人下午用A级权限调过陈默的卷宗，登记的名字是赵勇，你回去问问他，调卷宗干什么。”
陆沉的脚步顿了顿，应了声“知道了”，带上门走了出去。
他下楼的时候刚好碰到苏清禾从技术楼过来，手里拿着一张打印纸，脸色比刚才更白了，看见他就快步走过来，声音压得几乎听不见：“出事了，近24小时的档案室访问记录显示，今天下午16:30确实有人用A级权限调过陈默的卷宗，登记的名字是赵勇，但赵勇下午14:00到17:00一直跟着你在西郊凶案现场，根本不可能去档案室。还有，赵勇的权限卡上周丢过，三天前才补办回来，肯定是有人捡了他的卡冒用身份。”
陆沉皱了皱眉，刚好赵勇叼着半颗薄荷糖跑过来，听见这话眼睛都瞪大了：“啥？有人用我的权限卡调卷宗？我上周去现场勘察的时候丢的，找了半天没找到，补办的时候还被行政科骂了一顿，我还以为是掉现场了呢！”
“你补办新卡之后，旧卡没注销？”苏清禾问。
赵勇的脸“唰”的一下白了：“我……我当时急着出警，就忘了说这事，行政科的人也没提醒我……”
“现在不是追责的时候。”陆沉摆了摆手，看向苏清禾手里的打印纸，“还有别的发现吗？”
“有。”苏清禾的指尖捏着打印纸的边缘，指节泛白，“我刚才查了今天晚上21:00到22:00的市局网络通讯记录，发现我和省厅拆弹组对接加密消息的时候，有个内部IP一直在监听我们的通讯，我们发的所有坐标和拆弹时间安排，对方都截获了。”
赵勇倒抽了一口冷气：“你的意思是……内鬼就在这栋楼里？”
话音刚落，陆沉兜里的手机突然震了起来，是个没有备注的陌生号码，他接起来贴在耳边，对面传来林峰刻意压低的声音，背景里还有风刮过的呼啸声：“陆队，我是林峰，出事了，第三枚炸弹的坐标不对，我刚才冒着暴露的风险潜入进去确认了，原来的旧仓库位置是空的，他们把炸弹转移到了旁边的江城小学器材室，还加了个压力触发装置，只要重量有超过一克的变化就会炸，拆弹组现在不敢动。还有，我刚才截获了恐怖分子头目的消息，有人给他发了‘陈默转移推迟，计划有变’的短信，发消息的IP地址是市局内网的。”
陆沉的心脏猛地一沉，江城小学虽然现在已经放学了，但旁边就是居民楼，要是炸弹炸了，至少要波及半个小区的人：“你现在在哪？有没有暴露？”
“我没事，还在恐怖分子那边卧底，他们暂时没怀疑我。”林峰的声音顿了顿，“你们尽快查内鬼，不然我们的所有安排都会泄露，炸弹拆不了，12枚一起炸的话，整个江城南部都完了。”
挂了电话，陆沉把手机揣回兜里，抬眼看向赵勇：“你现在去技术队，查刚才截获通讯和发那条短信的IP具体地址，越快越好。”
赵勇连忙点头，转身就往技术楼跑，连嘴里的薄荷糖都忘了嚼。
走廊里只剩下陆沉和苏清禾两个人，感应灯因为长时间没动静暗了下来，苏清禾往前走了半步，借着窗外透进来的路灯灯光，能看见陆沉紧绷的下颌线，她犹豫了一下，抬手轻轻拍了拍他的胳膊：“别担心，我们能查到的。”
她的指尖带着外面的凉意，隔着薄薄的警服布料传过来，陆沉看着她右耳那颗小痣，心里紧绷的弦莫名松了一点，他刚要说话，赵勇就从技术楼方向跑了过来，额头上全是汗，手里拿着一张IP查询记录，声音都在抖：“陆队，查……查出来了，那个IP地址是张局的秘书刘昊的工位，而且我刚才调了监控，今天下午16:20，刘昊确实去过档案室，穿的还是一件黑色的外套，和现场监控里拍到的人一模一样。”
陆沉接过那张查询记录，目光落在“刘昊”两个字上，刚要说话，就看见走廊尽头的楼梯口，刘昊端着一杯泡好的热茶从楼上走下来，看见他们站在这儿，还笑着挥了挥手，快步走了过来：“陆队，苏法医，你们还没下班呢？张局让我把明天的会议资料整理出来，我刚去茶水间泡了杯茶。”
他说话的时候脸上带着恰到好处的笑，看起来和平时没有任何区别，陆沉盯着他的额头看了两秒，犯罪预警系统一片平静，没有任何红色的预警文字——他没有要杀人的迹象，这意味着，他只是个跑腿的，背后还有更大的鱼。
“没什么，刚处理完点事。”陆沉不动声色地把那张IP查询记录塞进兜里，“刘秘书这么晚还加班，辛苦了。”
“应该的应该的。”刘昊笑了笑，端着茶往自己办公室走，走过苏清禾身边的时候，视线不经意扫过她风衣口袋里露出来的加密U盘边缘，脚步顿了半秒，随即又恢复了正常，快步走回了办公室。
等他的身影消失在走廊转角，苏清禾才皱着眉开口：“他刚才看见我的U盘了。”
陆沉点头，指尖敲了敲兜里的查询记录，抬眼看向墙上的挂钟，时针刚好指向23:15，距离原定的炸弹引爆时间还有不到7个小时，距离陈默原定的转移时间还有8个小时45分钟。
“让拆弹组先别动第三枚炸弹，我们先按兵不动。”陆沉沉声道，“刘昊只是个棋子，我们要抓的是他背后的人，还有，别让张局知道我们查到刘昊了，现在还不确定张局有没有参与。”
苏清禾“嗯”了一声，掏出手机给省厅拆弹组发消息，指尖划过屏幕的时候，陆沉看见她手腕上的红绳——是三年前她生日的时候他送的，很便宜的红绳，上面串着一颗小小的银珠子，她戴了三年，从来没摘下来过。
风从走廊尽头的窗户吹进来，带着夜晚的凉意，陆沉看着她低头发消息的侧脸，右耳的小痣在灯光下泛着浅淡的光泽，他忽然想起刚才在家的时候，她红着眼眶说“我不能让你去送死”的样子，心脏像是被什么东西轻轻撞了一下，软得一塌糊涂。
他刚要说话，兜里的手机突然又震了起来，是保密医院那边打来的，电话里的护士声音慌得发抖：“陆警官，不好了，陈默不见了！”
