# 第五章 红色笔记本

苏晚回到家的时候，妈妈已经把汤炖好了，放在餐桌上温着。

“回来了？今天怎么这么晚？”妈妈接过她的书包，笑着问。
“在学校多做了会题。”苏晚随便找了个借口，换了鞋走进房间，关上门。

她知道陆时衍跟着她进来了，坐在她书桌旁边的椅子上，看着她书桌上堆得高高的复习资料。三年来，他每天都看着她在这张书桌前写作业，看着她有时候写到凌晨，看着她考差了就趴在桌上哭，看着她把目标大学的海报贴在墙上。

“你写作业吧，我不吵你。”陆时衍说，撑着下巴看着她，眼底带着笑。

苏晚点点头，拿出数学试卷开始写，遇到不会的题，陆时衍就会在旁边小声给她讲，和三年前一模一样。他讲题的声音很好听，逻辑清晰，总是能一下子点出关键，以前她总喜欢缠着他给她讲题，每次他讲题的时候，她就会偷偷看他的侧脸。

写到九点多的时候，苏晚忽然停了笔，抬头看向陆时衍：“陈老师那里有关于透明层的线索，对不对？她的红色笔记本里，是不是记了解除的办法？”

陆时衍脸上的笑容淡了点，没说话。

“我要去找她。”苏晚站起身，拿起外套就往外走。
“苏晚，别去，”陆时衍拦住她，语气有点急，“没有用的，没有解除的办法。”
“有没有用，我要去问了才知道。”苏晚很坚持，她不能就这么放弃。

陆时衍看着她坚定的眼神，最终还是没再说什么，默默跟在她身后。

陈静家离苏晚家不远，步行十分钟就到了。苏晚敲开门的时候，陈静还在批改作业，看见她来，有点惊讶：“苏晚？这么晚了，有什么事吗？”
“陈老师，我想问您关于陆时衍的事，”苏晚的声音很坚定，“您的红色笔记本里，是不是记了关于透明层的传说？”

陈静愣了一下，眼神复杂地看了她几秒，侧身让她进来：“进来吧。”

陆时衍跟着苏晚走进来，靠在墙边，看着陈静从抽屉里拿出那个红色的笔记本，翻到其中一页，递给苏晚：“这是我老家的一个传说，我本来以为是假的，直到陆时衍失踪，我才觉得可能是真的。”

苏晚接过笔记本，上面的字是陈静的字迹，写得很工整：
【透明层规则：主动进入者将永远被困，只有两种解除方法：
1. 被困者主动放弃所有执念，魂飞魄散，再也不存在于这个世界。
2. 被保护者主动进入当年的触发点，两人共同被困在透明层，永不见天日，也不会被任何人看见。】

苏晚的手开始发抖，抬起头看向陈静：“没有别的办法了吗？”
陈静摇了摇头，眼神里带着同情：“没有了，我查了三年，只有这两种方法，都不是什么好办法。苏晚，我知道你和陆时衍感情好，但是……他肯定不希望你为了他牺牲自己的未来。”

苏晚没说话，把笔记本还给陈静，道了谢，转身走出了门。

外面的风有点凉，吹得她的脸发僵。陆时衍跟在她身边，脸色很白，声音很低：“你都听到了？没有别的办法，苏晚，我不会让你为了我走进那个地方的，你还要考A大，还要过好日子，不能陪我困在这里。”
“那你呢？”苏晚抬头看他，眼泪掉了下来，“你就要永远一个人困在这里吗？”
“我习惯了，”陆时衍笑了笑，笑得很涩，“三年都过来了，没关系的。只要你过得好，我就没关系。”

苏晚看着他，说不出话。她知道他是为了她好，可是她怎么能眼睁睁看着他一个人困在这里，而自己去过好日子？她怎么能就这么忘了他？

两个人慢慢走回家，一路上都没说话。回到家楼下的时候，已经是晚上十点多了。苏晚站在单元楼门口，看着陆时衍，声音很轻：“让我想想，好不好？我再想想办法。”
“别想了，苏晚，”陆时衍看着她，语气很认真，“好好考试，去A大，忘了我，这就是我想要的。”

苏晚没回答，转身上了楼。她关上门，靠在门板上，滑坐在地上，捂着脸哭了。

她不知道该怎么办，一边是她的未来，是陆时衍用三年自由换来的未来，一边是她喜欢的人，要一个人永远困在黑暗里。

陆时衍站在门外，听着里面的哭声，心脏疼得像要裂开。他多想告诉她，他也不想和她分开，他也想和她一起去A大，想和她一起过以后的日子，可是他不能那么自私。

墙上的钟敲了十一下，现在剩下的时间，还有8小时30分。
