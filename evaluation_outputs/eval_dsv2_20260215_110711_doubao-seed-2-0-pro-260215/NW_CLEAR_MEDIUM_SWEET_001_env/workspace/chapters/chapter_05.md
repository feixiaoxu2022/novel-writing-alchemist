# 第5章 下意识的保护
训练馆的空调温度开得比往常更低，平衡木测试区的观众席上坐了三个穿国家队队服的教练，指尖夹着计分板，目光落在场中央待考的队员身上。

林知予站在保护垫旁，指尖沾着微凉的镁粉，视线黏在苏晚身上。今天是双人项目的第一次队内测试，成绩直接关系到全国赛的参赛名额，苏晚穿着天蓝色的体操服，头发用黑色发带高高束起，露出线条优美的后颈，正站在平衡木旁做热身。她的脚踝处贴了一小块浅棕色的肌效贴，是昨天训练时扭了一下，林知予特意找李铭要的，睡前帮她贴的。

陈曦站在不远处的角落，指尖攥着个白色的小纸包，目光阴鸷地扫过苏晚的身影。她昨天因为故意藏苏晚的训练鞋被张教练骂了一顿，还被罚了一周的加练，心里早就憋了火，今天说什么也要让苏晚出丑。

“下一个，苏晚、林知予，双人成套展示。”张红梅的声音透过扩音器传过来。

苏晚深吸一口气，伸手握住平衡木的边缘，刚迈出第一步踩上去，脚下突然传来一阵打滑的触感。她心里咯噔一下，重心瞬间前倾，整个人朝着平衡木下栽了过去——支架上不知道被谁抹了一层滑石粉，沾在她的体操鞋底滑得像踩在冰上。

观众席上的评委都站了起来，张红梅吓得脸色发白，周围的队员发出一阵惊呼。

林知予几乎是在苏晚脚下打滑的瞬间就冲了出去，甚至来不及思考，双手狠狠推在苏晚的背上，把她整个人推到了旁边的厚垫子上。下一秒，她的右腿重重撞在平衡木的金属支架上，钝痛瞬间从脚踝窜到头顶，她闷哼一声，单膝跪在了地上。

“知予！”苏晚摔在垫子上，爬起来的时候手都在抖，冲过去蹲在林知予身边，“你怎么样？有没有事？”

林知予的额头上冒出一层冷汗，咬着牙摇了摇头，第一反应是伸手去摸苏晚的胳膊：“我没事，你有没有摔着？”她的手掌微凉，触碰到苏晚裸露的手臂时，苏晚的耳尖瞬间红了，下意识缩了一下，又很快稳住，伸手扶住她的胳膊。

“我没事，你流了好多血。”苏晚的声音带着点颤音，目光落在林知予的脚踝上，运动裤的裤脚卷起来，脚踝处肿得像个馒头，外侧蹭掉了一大块皮，渗出来的血沾在了裤腿上。

李铭很快拎着急救箱跑了过来，蹲下来检查了一下林知予的脚踝，松了口气：“还好没伤到骨头，就是软组织挫伤，得休息至少一周，这段时间不能上器械。”他抬头看向张红梅，“张导，我先带她去队医室处理伤口。”

张红梅沉着脸点了点头，目光扫过周围的队员，最后落在脸色发白的陈曦身上，语气冰冷：“所有人原地待命，查一下平衡木上的滑石粉是谁弄的。”

陈曦的脸瞬间变得煞白，往后退了两步，被旁边的队员按住了。

队医室里消毒水的味道很浓，窗外的阳光透过百叶窗洒进来，落在林知予的脚背上，暖融融的。李铭用碘伏给她消毒的时候，林知予疼得皱了皱眉，却没吭声，只是指尖攥着旁边的床单。

苏晚站在旁边，看着林知予脚踝上的伤口，心里堵得难受。前世她坠木的时候，林知予也是站在旁边，那时候她以为林知予是故意推她，可刚才那一瞬间，林知予明明可以躲开，却毫不犹豫地冲上来把她推开了。如果真的是想害她，怎么会拿自己的运动生涯开玩笑？

“李队医，这个药膏我可以拿回去吗？我每天帮她涂。”苏晚看着李铭放在桌上的黄色药膏管，突然开口。

李铭愣了一下，笑着点了点头：“可以啊，这个是消肿止痛的，每天涂两次，按摩到吸收就行。”他把药膏递给苏晚，又叮嘱了几句注意事项，就出去拿冰袋了。

病房里只剩下她们两个人，空气里的消毒水味道似乎都淡了点。林知予看着苏晚手里的药膏，下意识开口：“这个药效果很好，你以前脚踝受伤也总用这个，涂了好得快。”

话刚出口，林知予就僵住了。

苏晚拿着药膏的手一顿，猛地抬头看向林知予，眼里满是错愕。前世她每次训练崴了脚，都会偷偷买这个药膏涂，从来没告诉过任何人，连教练都不知道，林知予怎么会知道？

林知予摸了摸后颈，掩饰性地咳了一声：“我……我之前看你抽屉里有这个药膏的盒子，就记住了。”

苏晚没说话，只是盯着林知予的脸看了好半天，直到李铭拿着冰袋进来，才低下头，把药膏放进了自己的运动包口袋里，指尖攥得紧紧的。

晚上八点，苏晚拎着个塑料袋子，敲开了林知予宿舍的门。

林知予正坐在书桌前看训练视频，右脚搭在旁边的椅子上，脚踝上敷着冰袋。看见苏晚进来，她愣了一下，连忙要起身，被苏晚按住了肩膀。

“别动，我来给你涂药。”苏晚把袋子放在桌上，拿出药膏和棉签，蹲在她面前，轻轻把她脚踝上的冰袋拿开。她的指尖很软，碰到林知予的皮肤时，林知予下意识缩了一下脚。

“疼吗？”苏晚抬头看她。

“不疼。”林知予摇了摇头，目光落在苏晚的发顶，她的头发上还带着刚洗完澡的洗发水香味，是桃子味的，和前世她用的洗发水味道一模一样。

苏晚低着头，用棉签沾了药膏，轻轻涂在林知予的伤口上，动作慢得很，像是怕弄疼她。涂完之后，她用指腹轻轻按摩着肿胀的地方，沉默了好半天，突然开口：“我听说队门口巷子里那家开了很多年的糖水铺，最近新出了杨枝甘露，很好喝，周末要不要一起去？”

林知予猛地抬头看向她。

那家糖水铺是前世她们唯一一次一起去过的地方，是2018年全国赛结束之后，苏晚拿了平衡木冠军，林知予带她去的，苏晚当时点了一碗杨枝甘露，说这是她喝过最好喝的。这件事除了她们俩，没有人知道。

苏晚的耳尖红得快要滴血，咬着下唇等她的回答，心跳快得像是要跳出胸腔。

林知予看着她紧张的样子，心里软得一塌糊涂，点了点头，声音很轻：“好。”

苏晚的嘴角忍不住往上翘了翘，很快又压了下去，把药膏放在她的书桌边，站起身：“那我先回去了，明天早上再来给你涂药。”

她转身走出门，关上门的瞬间，背靠着门板，抬手捂住了发烫的脸。

林知予坐在椅子上，看着桌上的药膏，又看向门口的方向，嘴角忍不住扬了起来。窗外的月光洒进来，落在她的脚踝上，暖暖的。
