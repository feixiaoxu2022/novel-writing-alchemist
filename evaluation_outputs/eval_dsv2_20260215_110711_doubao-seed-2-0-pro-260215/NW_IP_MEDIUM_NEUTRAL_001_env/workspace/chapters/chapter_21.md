# 第21章 少年的成长
公路修到一半的时候，周边的土匪眼红鹅城的富裕，纠结了两百多个人，趁着晚上过来抢东西，还放火烧了老百姓的几间房子。
六子当时正在巡逻，看见火光立刻带着十几个民兵赶了过去，他没有冲动硬拼，而是让一部分人去救老百姓灭火，自己带着剩下的人绕到土匪的后面，断了他们的退路。
土匪们正忙着抢东西，根本没注意到后路被断了，六子举着左轮枪开了一枪，大喊：“我们是鹅城民兵，你们已经被包围了，放下武器投降，饶你们不死！”
土匪们吓了一跳，转身看见六子只有十几个人，哄然大笑：“小屁孩也敢来管爷爷的事，兄弟们，先把这小子抓了，然后去抢县衙！”
六子冷笑一声，举着左轮枪，“砰！砰！砰！”三枪，打掉了三个土匪手里的火把，周围瞬间暗了下来。埋伏在旁边的民兵一起开枪，土匪们瞬间倒下了一片，剩下的人吓得转身就跑，刚好撞在老二带来的增援队伍手里，全都被抓了起来。
等约翰和亚瑟赶到的时候，六子已经把土匪都绑了起来，正在安抚受惊的老百姓，还给他们发了粮食和布匹，安排他们暂时住到县衙的空房子里。
约翰看着有条不紊处理事情的六子，欣慰地笑了，以前那个冲动莽撞的少年，现在已经成长为能独当一面的男子汉了。亚瑟拍了拍六子的肩膀：“好小子，干得漂亮，比你爹我年轻的时候强。”
第二天，鹅城召开了公审大会，把那些作恶多端的土匪头子当众枪毙，剩下的土匪愿意悔改的就留下来修路挖矿，不愿意的就打发路费让他们回家，以后不许再作恶。
经过这件事，老百姓都对六子心服口服，一致推举他当鹅城的民兵队长，负责鹅城的安保工作。六子也不推辞，上任之后第一件事就是扩充民兵队伍，加强训练，还在鹅城周围建了三个岗哨，一旦有情况立刻预警，从此以后，再也没有土匪敢来骚扰鹅城了。
这天傍晚，六子带着巡逻队回来，刚好碰到约翰和亚瑟在院子里擦枪，他走过去，给他们倒了两杯茶：“约翰叔，爹，今天岗哨都安排好了，以后老百姓晚上睡觉都能踏实了。”
约翰接过茶，喝了一口，看着六子脸上的坚毅神情，点了点头：“你长大了，以后我们就放心了。”
夕阳透过院子里的梨树，洒下一片金色的光斑，少年穿着牛仔服，腰上别着雕花左轮，站在阳光里，眼里满是对未来的憧憬。他终于活成了父亲和约翰叔期望的样子，成了一个能守护一方百姓的男子汉。
