# 第23章 双喜临门
通车之后的第一个月，鹅城又迎来了一件大喜事：六子要和学堂的林老师结婚了。
林老师是省城过来支教的老师，温柔善良，长得也漂亮，六子经常去学堂给孩子们上课，一来二去两人就好上了，大家早就看在眼里，现在终于要结婚了，都替他们高兴。
约翰和亚瑟忙前忙后给六子准备婚礼，约翰把自己当年在西部结婚时用的银马鞍送给了六子，亚瑟把自己珍藏了多年的猎枪送给了他，汤师爷给他们准备了一套三进的院子当新房，武举人亲自打了一套新家具，兄弟们都凑钱给他们买了不少礼物。
婚礼那天，整个鹅城都热闹起来了，老百姓们都自发过来帮忙，摆了一百多桌酒席，比老二上次结婚还要热闹。六子穿着崭新的牛仔服，胸前戴着大红花，牵着穿着红色嫁衣的林老师的手，给约翰和亚瑟敬酒：“约翰叔，爹，谢谢你们把我养大，教我做人，以后我一定会好好照顾阿樱，好好守护鹅城。”
约翰接过酒，喝了一口，笑着说：“好小子，以后你就是有家室的人了，要好好对待人家，不能再像以前一样冲动了。”亚瑟也拍了拍他的肩膀，眼里满是笑意：“你小子比爹有福气，找了这么好的媳妇，以后好好过日子。”
席间，汤师爷拿着账本过来，笑呵呵地说：“张县长，还有个好消息，今年我们的铜矿和粮食都卖了好价钱，老百姓的收入比去年翻了三倍，还有不少商人过来投资建厂，以后我们鹅城只会越来越好。”
约翰点了点头，看着下面热热闹闹的酒席，看着一张张笑脸，心里满是欣慰。他从1899年的西部穿越过来，经历了帮派的分崩离析，经历了逃亡和迷茫，没想到在这个东方的小县城，找到了家的感觉，不仅找到了失散的兄弟，还看着养子长大成人，成家立业，还有什么比这更圆满的呢？
晚上闹完洞房，约翰和亚瑟坐在院子里喝酒，月亮挂在天上，照得院子里亮堂堂的。亚瑟喝了一口酒，笑着说：“我以前从来没想过，我能有儿子，还能看着他结婚生子，我这辈子值了。”
约翰点了点头，也笑了：“是啊，我们都值了。以前在西部，我们天天想着抢银行，劫火车，想找一个没有压迫的地方，现在我们找到了，还亲手建起来了，还有什么不满足的呢？”
风吹过院子里的梨树，花瓣落下来，飘在酒杯里，两人碰了碰杯，一饮而尽。这一辈子的颠沛流离，终于在鹅城，画上了圆满的句号。
