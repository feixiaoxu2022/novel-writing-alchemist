# 第22章 通车那天
半年后，从鹅城到省城的公路终于修好了，通车那天，鹅城的老百姓都跑到路边看热闹，敲锣打鼓，比过年还热闹。
第一辆开进鹅城的货车是省城来的商人，拉着满满的布匹、盐巴、还有各种各样的新鲜玩意儿，司机下车之后对着约翰竖起了大拇指：“张县长，你们鹅城真了不起，这么难修的路居然半年就修好了，以后我每周都过来拉铜矿和玉米，你们的东西在省城卖得特别好！”
老百姓们欢呼起来，以前他们卖粮食要走半个月的山路，现在开车只要一天就能到省城，卖的价格还比以前高了两倍，大家的收入翻了好几倍，日子越过越红火。
汤师爷还和省城的学校签了合作协议，每个学期都有省城的老师过来支教，鹅城的孩子们以后还能去省城读书，有机会上大学。医院也和省城的医院合作，省城的医生定期过来坐诊，老百姓有什么大病再也不用跑几百里路了。
老三跟着货车去了一趟省城，回来的时候带回来好多先进的挖矿设备，还有拖拉机、抽水机，以后种地挖矿都不用全靠人力了，效率能提高好几倍。武举人带着人建了一个贸易市场，周边的商人都过来做生意，鹅城成了附近最富裕的县城，很多人都想搬到鹅城来住。
通车典礼上，约翰站在台上，看着下面欢呼的老百姓，看着身边的兄弟们，眼睛有点湿润。他们从西部穿越过来，从一开始的迷茫，到后来推翻黄四郎，建设鹅城，一步步走到今天，终于实现了他们一直追求的理想：人人平等，安居乐业，不用再被压迫，不用再东躲西藏。
亚瑟站在他旁边，拍了拍他的肩膀：“我们做到了，约翰。”约翰点了点头，擦了擦眼睛，笑了。
六子带着民兵队在周围维持秩序，身边站着一个穿碎花裙子的姑娘，是学堂的老师，两人互相看了一眼，都红了脸。约翰和亚瑟看着，都笑了，这孩子也到了成家的年纪了。
晚上的时候，大家在新修的公路边摆长街宴，来了好多周边县城的客人，大家一起喝酒吃饭，唱歌跳舞，热闹了一整夜。
约翰喝了点酒，站在公路边，看着远处的群山，风拂过他的牛仔外套，好像又回到了西部的草原上。不一样的是，以前的风里是风沙和逃亡的味道，现在的风里，是麦子的香味，是老百姓的笑声，是安稳幸福的味道。
他知道，他们选对了路，鹅城就是他们最好的归宿。
