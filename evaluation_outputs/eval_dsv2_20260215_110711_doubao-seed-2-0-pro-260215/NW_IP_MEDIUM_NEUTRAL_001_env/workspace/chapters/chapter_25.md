# 第25章 城楼上的夕阳
五年后，约翰和亚瑟回到了鹅城，刚进城门，他们就差点认不出来了。
以前的土路都变成了柏油路，两边盖起了二三层的小洋楼，街上有汽车、自行车，还有穿着新衣服的老百姓，一个个脸上都带着笑。六子现在已经是远近闻名的好县长，把鹅城治理得路不拾遗，夜不闭户，老百姓都念他的好。
张念西已经五岁了，长得特别结实，看见约翰和亚瑟，噔噔噔跑过来，抱着他们的腿喊“爷爷”，把两个老人高兴得合不拢嘴。
汤师爷已经退休了，在家带孙子，武举人也退休了，每天在公园里打拳，老二老三把铜矿和工厂管理得井井有条，鹅城现在已经是省里最富裕的县城，好多人都慕名过来参观学习。
这天傍晚，约翰、亚瑟、六子三个人又爬上了城后面的山坡，站在他们当年站过的地方，看着下面的鹅城，高楼林立，车水马龙，学校里传来孩子们的读书声，工厂里传来机器的轰鸣声，到处都是生机勃勃的景象。
“没想到啊，我们离开这几年，鹅城变化这么大。”约翰感慨地说，他头发已经白了，但是精神还是很好，腰上还是别着那对双持左轮，擦得锃亮。
亚瑟点了点头，他的胡子也白了，手里还拿着那个旧酒壶：“是啊，六子这孩子干得比我们好，我们当年的理想，他实现得比我们想象的还要好。”
六子站在他们身边，笑着说：“这都是你们打下的基础，没有你们当年推翻黄四郎，建设鹅城，哪有现在的好日子。”
夕阳洒在三个人的身上，把他们的影子拉得很长很长，风拂过他们的衣角，带着麦子的香味，和当年的味道一模一样。
约翰想起了第一次穿越到民国的时候，他躺在鹅城外面的草地上，迷茫得不知道该去哪里，亚瑟想起了他被关在铜矿里的时候，以为自己这辈子都见不到儿子了，六子想起了当年在凉粉摊杀胡万的时候，他还是个冲动的少年。
那些颠沛流离的岁月，那些枪林弹雨的日子，都过去了，现在他们有的，是安稳的生活，是幸福的家人，是充满希望的未来。
他们从西部来，在这个东方的小县城，找到了最好的归宿，实现了他们追求了一辈子的理想：公平，自由，人人都能过上好日子。
夕阳慢慢落下，天边是一片火烧云，像极了西部的晚霞。三个人站在山坡上，看着下面的万家灯火，脸上都带着笑意。
鹅城的故事还在继续，他们的传奇，会被这里的老百姓，永远记在心里。
