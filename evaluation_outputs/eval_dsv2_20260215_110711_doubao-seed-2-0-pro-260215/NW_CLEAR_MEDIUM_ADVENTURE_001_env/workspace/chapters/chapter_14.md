# 第14章 村寨真相
太阳快落山的时候，五人终于走到了山脚下的白族村寨门口。阿黑走在最前面，刚到村口就被几个护林员拦住了，他们看到王叔的时候都愣了，以为见了鬼：“阿黑哥，这不是当年那个失踪的探险队员吗？”
“是我，”王叔笑了笑，“我没死，在山里待了二十年。”
村里人听到消息都围了过来，老村长拄着拐棍走过来，看到王叔的时候，手都抖了：“小王？真的是你？当年我们都以为你……”
“老村长，我没事，”王叔点了点头，把当年的事一五一十地告诉了村里人，包括父辈探险队是来做考古研究的，陈峰的父亲为了救队友牺牲，林砚的父亲为了保护资料没能出来，根本不是什么冒犯山神被诅咒了，当年的事故是因为突发山洪和溶洞坍塌，都是自然灾害。
阿黑也站出来，把这次进山的经历说了，还拿出了他们拍的石刻照片和测绘资料：“他们说的都是真的，我亲眼看到的，那些叔叔们都是英雄，不是来偷东西的。”
村里人听完都沉默了，当年他们一直以为探险队是惹怒了山神才失踪的，没想到真相是这样。老村长叹了口气，对着陈峰和林砚鞠了一躬：“是我们误会了，委屈你们父辈了，他们是好人。”
“没事，”陈峰摇了摇头，“现在真相大白了就好。”
当晚村里人给他们准备了丰盛的饭菜，还收拾了干净的屋子让他们住。林砚的脚崴得有点严重，肿得老高，陈峰端了一盆热水进来，放在他脚边：“把脚泡进去，活血的，我给你揉两下。”
“不用，我自己来就行。”林砚不好意思地说。
“废什么话，”陈峰蹲下来，不由分说地把他的脚放进热水里，动作很轻地给他揉脚踝，“你要是明天走不了路，难道还要我背你回城里？”
林砚看着他低着头认真揉脚的样子，心里暖暖的，伸手递给他一瓶碘伏：“你后背的伤口还没处理，等会我给你消消毒，别发炎了。”
“知道了。”陈峰应了一声，嘴角偷偷扬了起来。
王叔坐在旁边的椅子上，看着他俩，笑着说：“你俩真的跟你爸他们当年一模一样，当年陈哥也是这样，林哥脚崴了，他给揉了好几天，嘴上还不饶人，说林哥娇气。”
林砚听完笑了，原来父辈的情谊早就刻在了骨子里，传到了他们这一代。
第二天一早，村里人给他们准备了很多出山的干粮和特产，老村长把当年没收的装备还给了他们：“这些东西物归原主，以后要是考古队来，我们肯定配合，再也不拦着了。”
阿黑牵着两匹马走过来：“我送你们到县城，山路不好走，骑马快一点。”
五人告别了村里人，骑着马往县城走。王叔坐在马上，看着身后的大山，眼里满是释然，二十年的隐居生活终于结束了，他终于可以光明正大地回去，告诉所有人当年的真相。
林砚坐在陈峰前面的马上，风拂过他的脸，他回头看了一眼身后的大山，那座沉睡了千年的白崖城，还有长眠在那里的父辈们，终于可以安息了。
陈峰坐在他后面，伸手抓着缰绳，把他护在自己怀里，避免他摔下去。阳光洒在两人身上，温暖而耀眼。
路还很长，但他们再也不是当年那个带着执念、互相拌嘴的陌生人了，他们是生死之交，是接过了父辈接力棒的同行者，未来还有很多路要一起走。
