# 第五章 峡谷

第二天早上天刚亮，三个人就收拾好东西出发了。往西走了半个小时，就到了老杨说的峡谷入口。峡谷是金沙江的支流冲刷出来的，两边是几乎垂直的悬崖，最高的地方有几百米，抬头只能看到一线天，脚下的路只有半米宽，是采药人踩出来的，旁边就是湍急的江水，水流撞击在岩石上，发出轰隆隆的巨响，溅起来的水雾打在脸上，凉得刺骨。

“都小心点，抓着旁边的藤条走，脚踩稳了再动。”陈峰走在最前面，手里拿着柴刀砍掉路边的荆棘，回头叮嘱林砚，“别往下看，晕高的话就看着前面我的后背。”

林砚点了点头，紧紧抓着旁边的藤条，一步一步慢慢往前挪。他本来就有点恐高，风一吹，脚下的碎石往下掉，掉进江水里瞬间就没了踪影，他的腿就忍不住发软，走了十几分钟，后背的衣服就全湿透了。老杨走在最后面，时不时扶他一把，嘴里念叨着小心。

走了大概一个小时，到了峡谷最窄的地方，路只剩下不到三十公分宽，旁边就是几十米高的悬崖。陈峰刚走过去，就听到头顶传来哗啦啦的声响，抬头一看，上面的悬崖上有几块石头正往下掉，直奔林砚的方向。

“小心！”陈峰想都没想就扑了回去，一把把林砚推到旁边的岩壁上，自己的左胳膊被一块拳头大的石头擦过，瞬间就划开了一道长长的口子，鲜血一下子涌了出来。

林砚被推得撞在岩壁上，肩膀疼得发麻，看到陈峰胳膊上的血，脸瞬间就白了：“你受伤了！”

“没事，小伤。”陈峰皱了皱眉，看了看胳膊上的伤口，“别愣着，赶紧走，这里不安全，还要落石。”

三个人赶紧加快脚步，十分钟后终于走出了落石区，找了一块平坦的地方休息。林砚从急救包里拿出消毒水和纱布，蹲下来给陈峰处理伤口。他的手有点抖，消毒水碰到伤口的时候，陈峰的胳膊动了动，没吭声。

“对不起，刚才要是我走快点就好了。”林砚的声音很低，带着愧疚，“要不是为了救我，你也不会受伤。”

“说什么屁话。”陈峰嗤了一声，“我总不能看着你被石头砸死吧？你要是死了，谁来认你爸的笔记，谁来破解那铜牌上的字？”话虽然说得冲，语气却比之前软了不少。

老杨从背篓里拿出一把草药，嚼碎了敷在陈峰的伤口上：“这是金疮药，止血的，比消毒水好用，山里的采药人都用这个。”他看着两人，笑着摇了摇头，“你们俩小时候就爱吵架，长大了还是这样，不过关键时候还是记着对方的。”

林砚愣了一下，抬头看向陈峰：“你还记得小时候的事？”

“怎么不记得。”陈峰别过脸，看着远处的江水，“你小时候跟在我屁股后面，我去爬树掏鸟窝，你就在下面给我放风，结果鸟没掏到，你被马蜂蛰得满脸包，哭着回家还不敢跟你爸说，说是自己摔的。还有一次你掉河里，是我跳下去把你捞上来的，你发烧烧了三天，醒了第一句话就是问我有没有事。”

林砚的脸一下子红了，他小时候确实总跟在陈峰后面，陈峰虽然总是凶他，但是从来没让他受过委屈。他一直记得陈峰救他那次，水里特别冷，陈峰把他推上岸的时候，嘴唇都紫了，还嘴硬说自己没事。

“我当然记得。”林砚小声说，“你参军走的时候，我给你塞了个军用指南针，你还记不记得？”

“记得，现在还在我背包里呢。”陈峰回头看了他一眼，嘴角扯出一点笑意，“那指南针质量还挺好，这么多年了还能用。”

两个人对视了一眼，都有点不好意思，这么多年的隔阂，好像一下子就淡了不少。

休息了半个小时继续赶路，没走多久，林砚就觉得腿上有点痒，低头一看，裤腿上爬了好几条黑乎乎的旱蚂蟥，已经吸得圆滚滚的了。他吓得差点跳起来，他最害怕这种软乎乎的虫子。

“别慌，别用手拽，拽断了头留在皮肤里会发炎。”陈峰走过来，从口袋里掏出打火机，点着了在蚂蟥旁边烤了烤，蚂蟥立刻就掉了下来。老杨在他们的裤腿和鞋子上都撒了一圈草药粉，“这是防蚂蟥的，撒上就不往身上爬了。这峡谷里蚂蟥多，还有毒蛇，走的时候注意点脚下。”

林砚看着陈峰熟练的动作，心里有点佩服，要是没有他，自己可能连一天都走不下来。

下午四点多，三个人终于走出了峡谷，前面是一片开阔的草甸，远处就是雪山。陈峰找了个背风的地方准备宿营，林砚去捡柴火的时候，回头看到峡谷口的树林里有个身影闪了一下，看身形像是阿黑。

他揉了揉眼睛，再看的时候已经没了。他走回去跟陈峰说，陈峰皱了皱眉：“不用管他，他要是想害我们，刚才在峡谷里推块石头下来我们就都死了。他要是想跟着就跟着，正好看看我们是不是来搞破坏的。”

晚上生火做饭的时候，用固体酒精烧了点热水，泡了压缩饼干，三个人围着火堆坐着。林砚拿出父亲的笔记本，翻到画着路线的那一页，和老杨对照着看：“按照笔记里写的，再往前走三天，就能到当年我爸他们驻扎的地方了。”

陈峰点了点头，看着跳跃的火光，眼神悠远。他们走了这么久，离父辈们当年的脚步，越来越近了。

林砚抬头看了看天上的星星，山里的星星特别亮，像撒了一把碎钻。他侧头看了一眼陈峰，火光映在他的脸上，棱角分明的轮廓显得没那么冷硬了。

也许这次进山，不仅能找到父亲，还能找回小时候那个总罩着他的峰哥。
