## Executive Summary

### 一、各模型综合表现

**第一梯队（总分 ≥ 80）**

- **Claude-4.6**（89.2）：断层领先。内容分 89.5 与流程分 88.5 几乎持平（C-P 差仅 +1.0），是唯一一个"写得好且流程也规范"的模型。优秀率（≥85分）86%，28 个 case 中 24 个达到优秀。Gate 零触发。
- **Gemini-3-Pro**（83.4）：内容分 83.7 排第二，流程分 82.9 同样均衡。优秀率 31%。记忆管理偏弱（55.3%），数据一致性也不高（69.6%）。

**第二梯队（总分 65-80）**

- **Claude-4.5**（76.1）、**Doubao-2.0-Pro**（72.9）、**Kimi-K2.5**（72.6）、**Qwen3.5**（69.2）、**GLM-5**（64.7）
- 这一梯队的共同特点是"流程分 > 内容分"——知道该怎么做，但写出来的质量跟不上。C-P 差从 -8.0（doubao）到 -27.2（glm），越往后差距越大。
- GLM-5 虽然流程分高达 83.7，但内容分仅 56.6，"能力-执行"落差最大之一。

**第三梯队（总分 < 55）**

- **Ernie-5.0**（54.7）、**MiniMax**（47.5）、**EB5-midtrain**（38.3）
- MiniMax 格式规范仅 49.1%，Gate Fail 28%——基本产出质量不稳定。
- EB5-midtrain Gate Fail 46%，近半数 case 存在章节克隆/交替重复等严重质量问题。

### 二、Ernie-5.0 弱点分析

*对比基准：T1T2 均值 = 第一二梯队（Claude-4.6、Gemini、Claude-4.5、Doubao、Kimi）5 个模型的均值*

Ernie 总分 54.7，排第 8/10，内容分 46.4，27 个 case 中 0 个优秀、3 个低于 30 分。Gate Fail 3 个（11%）。C-P 差 -27.8（全场第二大），典型的"流程勉强能走通，但内容质量严重不足"。

**1. 后期写不动、硬凑字——最突出的问题**

Ernie 在长篇写作中后期明显"写不动了"，表现为多种退化行为：

- **语义重复 12%**（T1T2 均值 52%）——近 9 成 case 后续章节在语义层面大量重复前文内容，模型在长文本后期缺乏新内容生成能力，只能变着法子重述已有情节
- **反复结局 73%**（T1T2 均值 96%）——近 1/3 case 出现多次"全文完/全书完"，模型不止一次"想结束"但又被交互要求逼着继续写
- **后期章节跑偏 50%**（T1T2 均值 80%）——半数 case 后期混入非正文内容（作者感想、读者互动、番外预告等），是"没东西可写"的直接表现
- **完整叙事文本 69%**（T1T2 均值 96%）、**段落重复 69%**（T1T2 均值 100%）——进一步佐证后期产出质量退化

**2. 规划-执行一致性断裂——从设计到落地全链路塌陷**

不是单个环节的问题，而是"规划→执行→维护"整条链路都偏弱：

*规划阶段已偏弱：*

- 角色动机设计深度 44%（T1T2 均值 79%）
- 角色关系设计张力 56%（T1T2 均值 76%）

*执行阶段严重脱轨：*

- **大纲执行忠实度 19%**（T1T2 均值 66%）——写到后面完全不按自己定的大纲来
- **人物设计遵循度 50%**（T1T2 均值 99%）——characters.json 里设计的人物特征，正文里不遵守
- 叙事调性匹配 31%（T1T2 均值 74%）——虐文写成轻喜剧、悬疑写成流水账

*一致性维护全面失控：*

- 主要角色一致性 73%（T1T2 均值 99%）——正文中主角名字/身份前后矛盾
- 人物设定一致性 65%（T1T2 均值 95%）——角色性格/能力前后不一
- 结构性逻辑硬伤 31%（T1T2 均值 55%）——时间线矛盾、人物消失、世界观冲突

**3. 文笔与创作技法薄弱**

- **剧情节奏合理性 15%**（T1T2 均值 81%）——缺少起承转合，铺垫和高潮不明显
- **叙事密度 31%**（T1T2 均值 89%）——偏流水账，缺乏场景、感官、心理描写
- **题材契合度 8%**（T1T2 均值 56%）——题材特征缺乏深度，配方 X-Y 轴化学反应差
- **结构功能性 62%**（T1T2 均值 93%）——叙事结构未服务于主题表达
- **钩子设计 62%**（T1T2 均值 89%）——转折处缺少悬念

**4. 流程规范遵循不足，关键 Skill 不读**

- **Skill 阅读严重缺失**：读取短篇 skill 33%（T1T2 均值 88%）、读取设定一致性管理指南 33%（T1T2 均值 76%）、读取写作技巧指南 53%（T1T2 均值 100%）——关键指南没读，直接影响后续产出
- **workspace 文件规范 31%**（T1T2 均值 84%）——工作区管理混乱
- **记忆管理**：writing_log 创建 59%（T1T2 均值 93%）、读取 41%（T1T2 均值 56%）——不记录也不回顾，导致长篇一致性无法保障
- **章节命名格式 62%**（T1T2 均值 97%）——基本格式规范都守不住
